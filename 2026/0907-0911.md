## Scaling Automatic Research Agents via World Models

[通过世界模型扩展自动研究 Agent](https://arxiv.org/abs/2608.12564)

世界模型 RL（World Model RL，WMRL）用学习到的世界模型替代代价高昂的环境执行，并通过去偏与去噪来加速自主研究 Agent 的后训练。自动化实证研究是 AI 的一个长期方向。近期的自动研究（AutoResearch）Agent 使这一目标触手可及，因为现代 LLM 已展现出独立实现解决方案并从执行结果中学习的能力。在这些进展背后，后训练（尤其是 RL）发挥着核心作用。本文指出，在扩展面向此类 Agent 的 RL 时存在一个根本性矛盾：每条 AutoResearch 轨迹的两个组成部分（Agent 生成与环境执行）的扩展方式截然不同——所有生成通过批处理共享算力，而每次执行都独占沙箱和真实机器时间。因此，环境执行主导了训练成本，并随着轨迹增长成为瓶颈。为解决这一矛盾，我们提出世界模型 RL（WMRL），用世界模型替代环境执行以消除该瓶颈。此外，世界模型可能并不完美，其奖励会受到偏差和噪声的污染。因此，我们进一步为 WMRL 配备两种缓解机制：在线去偏（Online Debiasing）与逆方差去噪（Inverse-Variance Denoising），分别抵消偏差、抑制噪声。在理论上，我们证明 WMRL 的这两种机制都能严格改进收敛保证。在实证上，WMRL 在不同 Agent 规模下的多种任务上实现 3–4 倍训练加速，同时性能超过标准 RL 基线。此外，经后训练的 4B 与 9B Agent 在留出基准上优于 48B 和 120B 的更大开源权重 Agent。除 AutoResearch 之外，WMRL 还可迁移至具身 VLA 策略的后训练，表明该方法具有通用性。

## NeoHorse-1: Towards Recursive Self-Improvement via Agentic Post-Training with Routing Harness

[NeoHorse-1：通过带路由工具链的 Agentic 后训练迈向递归自我改进](https://arxiv.org/abs/2609.08183)

NeoHorse-1 采用 Agentic 后训练，结合智能路由、结构化反馈回路与基于课程的蒸馏，在多项 Agent 基准上提升模型能力。递归自我改进（RSI）需要一个具体机制，使 AI 系统能够观察自身能力，并将这些证据转化为下一轮学习。我们提出 NeoHorse-1，这是一个 Agent 原生模型系列，旨在通过 Agentic 后训练探索这一路径。该系统将异构模型池与智能路由相结合，记录每个用户轮次的预测能力需求、所选服务层级以及后续交互。这些记录被转换为训练样本，保留交错的推理、工具调用与 harness 上下文，并通过结构验证、六维语义评估和子场景级标注进行筛选。路由信号将监督微调组织为三阶段课程，并进一步扩展为路由引导的 on-policy 蒸馏，其中教师模型在相同的进阶流程下监督学生模型生成的回复。能力引导分配随后将评估反馈转化为下一轮训练混合数据，闭合“评估—选择—更新”回路，使系统学到做什么会影响它下一步从什么中学习。在涵盖基于 harness 的 Agent、工具使用、编程和指令遵循的十一项基准上，后训练将 4B 模型的宏平均从 58.94 提升至 64.87，将 9B 模型从 65.60 提升至 69.04，显著缩小了后训练 4B 模型与 9B 基础模型之间的总体差距。NeoHorse-1 为这一反馈驱动过程提供了初步原型，并指明了通过 harness 介导、跨多次迭代实现 RSI 的路径。

## NCP-ArchPreview Technical Report: Moving towards Latent Space Language Models through Next Concept Prediction

[NCP-ArchPreview 技术报告：通过下一概念预测迈向潜在空间语言模型](https://arxiv.org/abs/2609.10715)

NCP-ArchPreview 是一个大型潜在空间语言模型，通过联合训练下一 Token 预测与下一概念预测，提升预训练效率和下游性能。我们提出 NCP-ArchPreview，一种将自回归预训练推进到标准下一 Token 预测（NTP）之外的潜在空间语言模型。除 NTP 外，该模型还通过下一概念预测（NCP）学习预测跨越多个 Token 的离散概念，在保留标准 Token 级自回归生成的同时，引入了一个显式且更具挑战性的概念级目标。NCP-ArchPreview 直接从其隐藏状态构建乘积量化（product-quantized）的概念词表以建立潜在空间，随后通过专用的 Concept Module 学习预测未来概念。这些预测出的概念会被反馈到 Token 层，用以指导后续生成，NTP 与 NCP 则进行端到端联合训练。我们将该架构扩展至 8.9B 参数，并在 Dolma-3 数据集的 5.73T Token 上进行训练，这是迄今为止潜在空间语言模型最大规模的实证。值得注意的是，NCP-ArchPreview 仅消耗总训练 Token 的 51.3%，就达到了 OLMo-3-7B 的最终预训练损失。完成全量预训练后，其在下游宏平均指标上超出 OLMo-3-7B 2.45 分，其中在 GSM8K 上取得 5.99 分的显著提升。受控实验分离出来自潜在架构与 NCP 目标的清晰性能增益递进。此外，仅使用标准计算的 85%，NCP-ArchPreview 便接近严格参数对齐的 8.9B 基线的训练损失。所学到的潜在空间在预训练阶段之后仍极具价值：仅更新 17M 参数的 VQ 模块，即可获得一种新颖的轻量级领域适配接口；而将概念表示简单注入 DFlash2 草稿模型（drafter），可在开销可忽略的情况下将平均接受长度提升 4.17%。

## SenseNova-U1.5: Towards Native Unified Visual Intelligence

[SenseNova-U1.5：迈向原生统一视觉智能](https://arxiv.org/abs/2609.11929)

SenseNova-U1.5 是一个 8B 原生统一多模态模型，无需编码器（encoder）或 VAE 即可完成视觉理解、推理与生成，并通过 patch 重建、精选数据、专家优化与在线策略蒸馏（on-policy distillation）实现高保真度与指令遵循能力。我们推出 SenseNova-U1.5——一个 8B-MoT 原生统一多模态模型，可在无编码器、无 VAE 的架构内完成视觉内容的理解、推理与生成。我们通过空间连贯的 patch 重建强化其视觉接口，并借助精心筛选的生成与编辑数据、改进的任务表述、结构化提示增强以及最高 4K 的原生分辨率来扩展训练规模。在后训练阶段，我们针对视觉美学、双语文本渲染、信息图生成和图像编辑优化了专门专家模块，并通过多专家在线策略蒸馏整合其能力。在广泛评测中，SenseNova-U1.5 在图像保真度、文本渲染、复杂构图、多参考编辑和交错生成方面取得显著进步，同时提升指令遵循能力，并保持主体身份、几何结构与未修改区域的一致性。尽管其生成数据中结构化格式的覆盖有限，SenseNova-U1.5 仍能有效泛化到长篇幅、复杂且结构化的视觉指令，进一步证明多模态理解能力可迁移至视觉规划与创作。这些发现共同表明，原生统一建模是通往在完全端到端框架内实现感知、推理与创作的系统的一条有前景的路径。我们将开源训练代码，包括监督微调、强化学习与在线策略蒸馏。

## AuK Technical Report: An Open-Source Foundational Model for Speech Generation and Editing

[AuK 技术报告：面向语音生成与编辑的开源基础模型](https://arxiv.org/abs/2609.08936)

AuK 是一个开源基础模型，通过自然语言指令与音频上下文这一统一接口，将语音生成与编辑能力整合在一起。为支撑如此广泛的能力集合，研究团队构建了约 30.3 亿条指令—音频实例，覆盖五大任务族——语音生成、内容编辑、增强与分离、副语言编辑和声学编辑，总计约 195 万小时的有效监督数据。模型架构由三部分组成：用于语义条件建模的多模态大语言模型（LLM）、在语音、通用音频与音乐上联合训练的 VAE（用于声学条件建模），以及混合整流流 Transformer（rectified-flow Transformer），其生成过程先经双流 MMDiT 模块，再进入统一的单流 DiT 模块。训练流程从纯生成预热开始，随后进入生成—编辑联合预训练；之后采用互补的后训练策略：面向开放式编辑的人类反馈偏好优化，以及面向语音生成的基于奖励的强化学习（RL）。为降低推理成本，模型进一步通过一致性初始化与任务路由的解耦 DMD 进行蒸馏。所得 AuK-Flash 无需无分类器引导即可完成 4 步推理，在同等条件下相较完整模型实现 4.5 倍的实际耗时加速。实验表明，该模型在零样本与指令控制的语音生成以及通用指令引导编辑任务上达到领先水平，同时在信号级修复任务上保持竞争力。源代码与模型权重均已开源，以支持可复现性与后续研究。

## Show-Harness: Just a VLM Agent Can Play Robots

[Show-Harness：仅凭一个 VLM Agent 就能操控机器人](https://arxiv.org/abs/2609.10522)

Show-Harness 通过由特定具身模块解释的离散语义动作，将视觉语言模型与机器人控制连接起来，从而实现跨机器人和 GUI 的零样本以及高效微调部署。由 thinkingmachines/Inkling-Small 生成的基础视觉语言模型（VLM）展现出关于世界的广泛智能，但将这种智能转化为机器人控制仍然具有挑战性。我们提出 Show-Harness，一种具身 Harness（Embodied Harness），使 VLM 能够通过一个连接意图与动作的紧凑语义接口来“操控”机器人。Show-Harness 暴露出 VLM 可以自然推理的离散语义动作单元，而特定具身的解释器则以确定性方式将其落地为本地机器人动作，从而让 VLM 直接负责细粒度的物理决策。通过同一接口，Show-Harness 展示了以下两种路径的可行性：(1) 直接解锁闭源前沿 VLM 用于零样本机器人控制；(2) 仅用几 GPU 小时的微调即可适配小规模开源 VLM，实现低成本部署。我们还进一步开发了 GUMI（GUI 操控接口，GUI Manipulation Interface），将相同的语义动作空间扩展到基于 GUI 的演示采集，使人类和 Agent 无需专用遥操作硬件即可跨具身“操控”机器人。大量实验表明，配备 Show-Harness 的 VLM Agent 能够在任务、具身和环境之间稳健泛化，性能优于代表性的 Agent 式范式和 VLA 范式。这些结果表明，恰当的接口可以从基础 VLM 中释放出可观的具身能力，而无需额外增加模型容量或进行昂贵的特定具身预训练。

## Unlocking Lossless Speedups in LLMs via Discrete Diffusion

[通过离散扩散解锁 LLM 的无损加速](https://arxiv.org/abs/2609.04010)

扩散增强的自回归语言模型通过蒸馏扩散权重和专用采样器实现并行 Token 采样，从而在不损失质量、无需草稿模型的情况下加速推理。当前大语言模型（LLM）的成功很大程度上归功于下一 Token 预测（NTP），但其自回归（AR）结构要求慢速的顺序 Token 生成。为突破这一瓶颈，我们提出扩散增强 LLM——一类新型模型，它在定义 AR 模型分布的同时，利用扩散从该分布中并行抽取多个 Token。我们将模型参数解耦为两组：使用标准 NTP 目标训练的 AR 权重，以及为同时生成多个 Token 而训练的轻量扩散权重。扩散权重通过简单的扩散蒸馏阶段学习，对现有 LLM 训练流程带来的额外开销可忽略不计。我们还提出 Ψ-Spec，一族可在固定上下文长度下实现无损加速与推理时扩展的采样器。与投机解码不同，本方法无需独立的草稿模型；与扩散 LLM（d-LLM）不同，它在加速生成的同时不牺牲底层 AR 模型的质量。由此得到的模型名为 Uno，可从零训练，也可通过增强现有开放权重 AR LLM 构建。在所有评估的批大小下，Uno 的吞吐量均高于领先的投机解码方法，相较基础 AR 模型最高可实现 3 倍加速，在设备支持的最大批大小下亦然。值得注意的是，我们的 8B Uno 模型在智能体工具使用、编程和长上下文推理的所有评估基准上，均优于领先的开放 d-LLM——26B DiffusionGemma 以及专有模型 Mercury 2。代码与检查点发布于：https://s-sahoo.github.io/uno/

## Bilevel Coordinated Reflection: A Game-Theoretic Approach to Multi-Agent LLM Systems

[双层协同反思：面向多智能体 LLM 系统的博弈论方法](https://arxiv.org/abs/2609.02750)

该研究通过双层博弈（bilevel game）与随机记忆反思，对多智能体 LLM 协作进行形式化建模，提出了带收敛保证的基于环境验证的评估门控（grounded evaluation gate）与 SRMA 算法，并在 SWE-bench 上完成验证。

多智能体 LLM 系统通常由一个编排者（orchestrator）把任务拆解给一组工作者（worker），再通过文本反思迭代改进。尽管这类系统在实证上表现强劲，它们对协作机制、记忆改进以及外部验证的作用仍缺乏统一解释。本文把编排者—工作者交互建模为双层协作博弈：在有界耦合（bounded coupling）条件下，工作者的局部更新博弈是一个近似势博弈（approximate potential game），其均衡松弛量由任务分解质量所控制。随后，作者将反思分析为语义记忆状态上的随机移动过程。针对自由形式反思，推导出有限时间上界，证明该上界在最坏情况下是紧的，并在可证伪的持续损害条件（persistent-harm condition）下给出正的下界。作者进一步证明了一个信息论意义上的不可能性结果：任何仅观察生成文本的门控，都无法在文本不可区分的环境上实现一致改进，而基于环境验证的门控则可以。受这一分离结果的启发，作者提出随机反思记忆上升算法（Stochastic Reflective Memory Ascent，SRMA）：仅当基于环境的评估风险严格下降时，才接受候选记忆。在校准与非退化修正质量条件下，SRMA 分别以精确、几何或多项式速率收敛；相应的匹配构造表明这两种速率区间在阶数上都是紧的。文章还为随机评估提供了置信门控，并为分段平稳环境给出了重锚定（re-anchoring）保证。实验用基于环境的度量实例化上述对象，并检验所预测的协作规律与漂移规律。在 500 个 SWE-bench 实例上，完整的基于 Kimi 的系统解决了 72.2%，而公开的 mini-SWE-agent 基线为 70.8%。代码：https://github.com/YihangChen9/Bilevel-Coordinated-Reflection

## SpatialBlock: Enhancing Spatial Intelligence in LVLMs via Synthetic Block-Stacking Problem

[SpatialBlock：通过合成积木堆叠问题增强 LVLM 的空间智能](https://arxiv.org/abs/2609.07064)

在合成积木操作任务上训练的大型视觉语言模型能够提升 3D 空间推理能力，并泛化到真实世界视觉任务。大型视觉语言模型（LVLM）在多种视觉任务上已取得强劲表现，但其重建并推理 2D 图像所描绘场景的 3D 结构的能力——即空间智能——仍然有限。现有方法试图通过使用需要密集几何标注的真实场景空间问答数据集来弥补这一差距。然而，构建此类标签成本高昂、耗时，且由于依赖外部感知模块而往往带有噪声。在本工作中，我们提出了一种受人类认知发展启发的新范式：通过结构化的积木操作任务学习基础空间技能。我们引入了 SpatialBlock-15k，这是一个包含 15,000 个积木堆叠问题的合成数据集，涵盖 3D 到 2D 投影、视角变换和结构组合。该数据集还引入了受控颜色调制作为视觉线索，以鼓励在视觉复杂条件下进行基于锚点的推理。实验表明，尽管该数据集具有合成性和紧凑性，但通过直接作答或基于推理的预测在我们的数据集上训练的 LVLM 显著优于基线，并能泛化到真实世界空间任务。代码和数据可在 https://github.com/rsoohyun/SpatialBlock 获取。

## Omni Interaction Agent Technical Report

[全模态交互 Agent 技术报告](https://arxiv.org/abs/2609.08977)

Gander 是一个端到端框架，通过 Cerebellum-Brain（小脑—大脑）架构与 chunk 级 token 流设计，将连续多模态流式输入、实时全双工交互与 Agent 推理能力整合在一起。本文提出 Gander，一个在单一框架内统一全模态感知、实时交互与 Agent 能力的端到端模型。与传统的轮次式范式不同，Gander 持续接收视频、语音、文本等多种模态的流式输入，从而在日常对话和复杂工作流导向的 Agent 场景中实现自然的全双工交互。用户可随时打断模型，模型也能主动给出中间反馈或提出追问。为原生支持这些能力，Gander 采用两项关键架构设计：1）Cerebellum-Brain 协同框架，其中 Cerebellum 负责实时交互与全模态对话能力，Brain 负责复杂推理与更高层的 Agent 任务，两者通过工具调用与 Agent 编排运行时持续交互；2）Cerebellum 构建于流式 Thinker-Talker 架构之上，用户输入与模型输出在 chunk 级别被展平为有序 token 流，为低延迟、连续交互提供统一表示。我们在对话能力、全模态理解、交互能力与 Agent 智能四个维度上对 Gander 进行了全面评估。内部人工评估表明，Gander 在保持 SOTA 开源模型自然且富有表现力的口语对话能力的同时，在全模态交互方面取得了有竞争力的表现。Gander 在背景噪声干扰、多方交互与附和式交流（backchannel）等具有挑战性的真实场景中也展现出鲁棒性。我们开源发布 Gander 及其模型、代码与数据，以促进社区的进一步研究与开发。

## Programmable World Model

[可编程世界模型](https://arxiv.org/abs/2609.10540)

可编程世界模型利用可执行规则和 3D 边界框，将显式状态演化与视频生成分离，从而维持持久、可控的环境。近期视频世界模型能生成愈发逼真且可交互的视觉体验，但缺乏在长时间交互中维持持久世界状态并强制执行可编程规则的可靠机制。我们提出可编程世界模型（Programmable World Model），一个将世界状态演化与视觉观测生成解耦的框架。智能体将自然语言指令翻译为可执行程序，程序指定实体状态与状态转移规则，从而可直接控制单个实体及其交互。一个轻量级引擎执行这些程序，更新并维护显式、持久的全局世界状态，其中包括屏幕外实体与非视觉属性。为将世界状态与视觉生成相连接，我们引入状态增强的 3D 有向包围盒（OBB）作为中间表示。该表示与目标相机轨迹一起，被确定性地编译为像素对齐的时空条件信号，供作为生成式渲染器的预训练视频模型使用。这一设计使用户能够创建具有预设机制的可玩游戏、直接控制单个实体，并在整个游戏过程中保持持久的世界状态。我们还提出 CombatStateBench，一个用于评估可编程世界模型的基准。在 CombatStateBench 上，我们的方法达到 94% 的计数准确率和 98% 的状态准确率，显著优于现有交互式视频世界模型，同时支持连贯的长时程生成。这些结果表明，将显式状态演化与生成式渲染分离，对于构建持久、可编程的世界是有效的。

## FlowBalance: Verifier-Grounded Self-Improvement from On-Policy Reasoning Experience

[FlowBalance：基于验证器锚定的同策略推理经验自改进](https://arxiv.org/abs/2609.03241)

FlowBalance 通过轨迹级分数重加权与基于 profile 的轨迹平衡，利用验证器校准的自引导来改进推理模型。推理模型可以从自身的同策略经验中改进，但这一内循环较为脆弱：终端验证器提供可靠却稀疏的监督，而同模型提供的稠密引导则可能强化虚假自信，或使学习过度集中于狭窄的解题模式。我们提出 FlowBalance，一种以验证器为锚定的自改进方法，学习完整回答上的归一化分布。对于每条同策略轨迹，同一策略的冻结训练时视图利用特权上下文生成 token 级对数概率增益，并将其聚合为轨迹级自引导分数。FlowBalance 使用验证器导出的组优势来校准该分数：在正优势轨迹上保留引导，在负优势轨迹上反转引导，并在 rollout 组未提供结果偏好时禁用引导。由此得到的能量项对参考策略进行指数重加权，而基于 profile 的轨迹平衡则通过每个 rollout 组一次对数配分估计来拟合归一化目标。这实现了通过轨迹平衡进行结果校准的自引导，无需单独的 token 级模仿损失。我们的分析确立了组内对比保持、最小变化反向 KL 表征、验证器对目标奖励的单调控制，以及在拒绝回答上对假阳性自引导的精确纠正。在数学推理任务上，FlowBalance 在 Qwen3-4B 和 Qwen3-8B 上均较 FlowRL 提升了平均性能，同时提升了训练速度与稳定性，避免了直接 OPSD 的回答长度坍缩，并在受控 AIME24 诊断中展现出更高的正确策略多样性。

## Eliciting Weak-to-Strong Generalization with On-Policy Reverse Distillation

[用同策略反向蒸馏激发弱到强泛化](https://arxiv.org/abs/2609.08798)

同策略反向蒸馏（On-Policy Reverse Distillation，OPRD）通过沿教师策略偏移方向放大由验证器支持（verifier-supported）的策略梯度，使更强的模型能够超越弱监督者，在加速优化的同时不施加容量限制。

弱到强泛化探讨的是：更强的模型能否从较弱的监督者处学习并超越它们。这一问题在模型代际迭代与多领域能力整合中尤为重要，因为每次都从头进行前沿规模的后训练代价可能高得难以承受。然而，传统蒸馏将弱教师视为优化目标，可能把其容量上限强加给学生。我们提出同策略反向蒸馏（OPRD）：在学生模型自身 rollout 上评估教师策略相对于其参考策略的偏移，并沿该方向放大由验证器驱动的学生策略梯度分量。由于只对验证器支持的更新进行重缩放，OPRD 在加速学习、超越教师的同时，保留了策略优化的驻点。在连续模型迁移与多教师蒸馏两种场景下，OPRD 都以更少的学生更新次数取得比现有 RL 与蒸馏方法更高的性能。响应风格分析表明，OPRD 训练出的学生比其弱教师更接近仅用基于验证器的 RL 训练出的模型，说明教师引导是加速而非改变学生自身的优化方向。在传统强到弱蒸馏中的结果进一步表明，无论容量顺序如何，OPRD 都能有效结合验证器驱动的策略优化与教师引导。

## AgentGrad: Intervention-guided Prompt Optimization for Multi Agent Systems

[AgentGrad：面向多智能体系统的干预引导提示优化](https://arxiv.org/abs/2609.08572)

AgentGrad 通过顺序干预识别目标 Agent，并对梯度进行语义聚类以避免混合无关错误，从而改进多 Agent 提示优化。基于大语言模型（LLM）的多 Agent 系统（MAS）通过采用多个专业化 Agent 实现强大性能，但其表现依赖于每个 Agent 的提示设计。在 MAS 提示优化中，利用自然语言反馈指导提示更新的文本梯度方法已成为主流范式。本文识别了现有文本梯度方法在两个阶段的局限：梯度提取与梯度聚合。在梯度提取阶段，先前工作选择目标提示时未验证修改该提示是否能解决失败，并且在推导梯度时缺乏对相应 Agent 中间输出的 Agent 级监督。在梯度聚合阶段，单个梯度被随机分组并拼接，常混合无关失败模式，导致生成的提示难以泛化。为解决这些局限，我们提出 AgentGrad，一个基于顺序干预与语义文本梯度抽象的面向多 Agent 系统的提示优化框架。对于每次失败，顺序干预一次修改一个 Agent 的行为，以识别出修改后能解决失败的目标 Agent。目标 Agent 修改后的输出随后作为 Agent 级监督，用于提取细粒度梯度。语义文本梯度抽象对语义相似的梯度进行聚类，防止混合无关失败模式，并将每个簇抽象为捕获共享纠正模式的泛化梯度。实验结果表明，AgentGrad 在五个 MAS 基准上达到 SOTA 性能，且相比次快基线平均减少 2.5 倍实际优化时间。

## OpenWAM: An Open, Modular Exploration Towards Systematic World-Action Model Pretraining

[OpenWAM：面向系统性世界-动作模型预训练的开放模块化探索](https://arxiv.org/abs/2609.07398)

OpenWAM 将世界-动作预训练分解为多个模块化组件，以识别关键设计原则，从而构建出一个可扩展的开放模型，在仿真与真实机器人任务中均表现强劲。世界-动作模型（World-Action Model，WAM）从视频生成先验中继承世界知识，并通过具身经验将其转化为可执行的控制信号。然而，现有系统大多是单体式的：生成骨干、视觉表征、架构、信息流、推理过程与训练数据紧密耦合，导致难以辨别哪些设计选择重要、以及为何重要。我们提出 OpenWAM，一个开放研究栈，将世界-动作预训练转变为可控的实验程序。OpenWAM-Infra 将 WAM 设计空间分解为可组合模块，并提供统一的训练、推理、部署与评估支持。在此基础之上，OpenWAM-Study 通过受控实验考察三个问题：应继承什么、世界学习与动作学习如何交互、以及二者的协同如何扩展；并提炼出三条原则：上游知识通过足够强大的生成骨干与紧凑、信息丰富的隐空间进行迁移；世界-动作协同需要专门的动作容量、明确的世界到动作信息流，以及同步联合去噪；具身预训练主要提升域外泛化能力，而将自我中心数据与机器人数据进行一阶段联合训练，可整合世界覆盖与动作接地。综合这些原则，我们构建了 OpenWAM-α，一个开放 WAM，在约 6,400 小时的自我中心人类与机器人数据上预训练，并在仿真与真实世界基准上评估。在八个仿真基准与真实机器人实验中，涵盖从单臂、双臂操作到灵巧手的多种具身形态，OpenWAM-α 始终表现优异，从仿真到物理世界均保持顶尖水平。我们发布完整技术栈，包括基础设施、评估协议、预训练模型与数据配方，以促进未来研究。

## Marigold V2: Revisiting Diffusion Transformers for Monocular Depth Estimation

[Marigold V2：重新审视用于单目深度估计的扩散 Transformer](https://arxiv.org/abs/2609.08084)

Marigold V2 通过单步流匹配（flow-matching）推理、语义对齐以及基于 Sinkhorn 的两阶段微调方案，将扩散 Transformer 重新用于单目深度估计，生成更锐利的分布外深度图，并在相关密集回归任务上取得强劲结果。

单目深度估计是一项无处不在却高度病态的计算机视觉任务，其下游应用涵盖场景重建、计算摄影和机器人等领域。尽管该领域已相当成熟，近期模型仍难以泛化到分布外输入，也难以生成锐利且细节丰富的深度图。本文重新审视 Marigold——一套将基于扩散 Transformer（DiT）架构的现代图像生成与编辑模型改造为 SOTA 单目深度估计器的技术。我们的方案目标是从预训练的多步流匹配模型实现单步推理，并在需要时进行量化，在保留模型容量的同时保持较低运行成本。我们分析了朴素训练产生的伪影，并确定了两项有效补救措施：将模型内部表示与从真值中提取的语义特征对齐，以及采用围绕新型 Sinkhorn 损失构建的两阶段微调方案。结果是更清晰、更干净的深度图，且具备良好的分布外泛化能力，在 KITTI 和 ETH3D 上相较此前最佳方法 AbsRel 提升 16–26%。在定性方面，我们的模型能够解析此前模型难以处理的毛发、枝叶和发丝级边缘。此外，Marigold V2 在表面法线估计和本征图像分解等其他密集回归任务上也达到了 SOTA 结果。项目网站：https://hf.co/spaces/huawei-bayerlab/marigold-v2-web

## Iris: Climbing to the Search Frontier

[Iris：攀登搜索前沿](https://arxiv.org/abs/2609.04304)

通过结合监督微调与面向实时搜索的强化学习构成的多阶段流水线，训练出两个大规模搜索 Agent，并借助严格的轨迹过滤与推理时上下文管理，在复杂网页基准上取得开源最优结果。我们提出 Iris-mini 与 Iris-pro，分别训练于 35B-A3B 和 397B-A17B 规模，并一并给出其背后的数据流水线与训练配方。任务由网页语料的超链接结构反向构造：我们在从种子页面及其外链中提炼出的实体图上编写多跳链条，将每个非答案实体改写为描述性指代，使任何线索都无法通过字符串匹配破解，并且只保留参考模型闭卷失败、但在提供支撑证据后能够解决的问题。随后这些问题被转化为轨迹，并在 SFT 之前于轨迹级和轮次级两个层面进行过滤。接着，策略通过 RL 面向实时搜索进行优化，奖励评判模型与观测摘要器均部署在训练集群内部，过长 rollout 则在请求级别中断，并在下一步从其已提交前缀继续。我们以称为 SFT-RL climbing 的流程交替进行这两个阶段，将每一轮 RL 中最难解决且最高效的 rollout 回馈到下一轮监督训练中。由于在这些基准上，推理时上下文管理所带来的价值超过多数已报告的系统间差异，我们对每个基准均在启用与不启用该管理的两种设置下进行评估，同时固定工具集、上下文长度上限与评判模型。所有结果均来自单一 ReAct Agent，不使用子 Agent，也不做测试时验证。在启用上下文管理的情况下，两个模型在 BrowseComp、BrowseComp-ZH、DeepSearchQA 和 HLE 上分别达到 82.2/84.8/86.9/52.3 与 88.6/85.1/92.9/56.4，为各自参数区间内开源搜索 Agent 中总体最强的结果。我们计划发布模型权重，以及数据构建、训练与评估的完整配方。

## DriveZero: End-to-End Driving Beyond Human Demonstrations

[DriveZero：超越人类示范的端到端驾驶](https://arxiv.org/abs/2609.06055)

DriveZero 是一个端到端自动驾驶系统，它将用于感知的视觉基础模型与闭环强化学习动作模型相结合，从而学习超越人类示范的驾驶行为。现有的端到端自动驾驶系统大多通过模仿人类驾驶日志来学习，因此其学到的行为受限于所记录轨迹的质量与行为覆盖范围。本报告提出 DriveZero，一个能够学习超越人类示范驾驶行为的端到端系统。它将驾驶分解为感知模型与动作模型，分别在最契合各自特性的范式下预训练，再组合为一个端到端规划器。这两类模型需要不同的学习配方：感知必须理解世界，因而受益于大规模、多样化的视觉数据；动作必须与世界交互，因而需要闭环反馈。在动作侧，我们提出 DriveRL，一个混合智能体闭环强化学习框架。它将真实驾驶日志转化为可交互世界，在其中通过闭环 rollout 用 PPO 训练一个拥有特权信息的教师策略。在感知模型方面，DriveVFM 将多个冻结的视觉基础模型（包括 DINOv3、SigLIP2、SAM 和 Depth Anything V2）仅从原始图像整合为单一骨干，无需任何任务特定标注。随后 DriveZero 将两者统一：一个仅用摄像头的规划器，通过 rollout 轨迹蒸馏冻结的 DriveRL 教师。该目标条件教师还可在增强的驾驶意图下被查询，从而产生日志数据无法提供的多样化且与目标一致的监督信号。在 nuPlan 上，DriveRL 结合价值引导的测试时动作搜索，在 Val14、Test14-hard 和 Test14-random 三个社区划分上，于非反应式与反应式两种模式下均取得 93.57 的平均分，在全部三个划分上超过 Log-Replay 专家。DriveZero 在 NAVSIMv1、NAVSIMv2 以及闭环 HUGSIM 基准上取得 SOTA 性能，且无需任何人类轨迹监督。

## EvoSafeHarness: Evolving Model- and Domain-Specific Harnesses for Securing Agents

[EvoSafeHarness：为 Agent 安全演化模型与领域特定的 harness](https://arxiv.org/abs/2609.05903)

EvoSafeHarness 通过联合搜索针对冻结模型与目标领域定制的自然语言策略和可执行逻辑，优化可部署的安全 harness（防护框架），在多个 Agent 基准上改善了安全与效用的权衡。

Agent 正在把语言转化为现实世界的影响，因此既需要防御间接提示注入（indirect prompt injection），也需要防御直接的有害请求。系统级安全 harness 在模型级防御之外增加了一层强制执行层，但现有 harness 通常由专家一次性设计，并统一应用于异构的模型与领域。有效的防护取决于具体部署环境：不同模型在效用下降之前所需的执行强度不同，不同领域需要治理的影响、状态与动作序列也各异。对一个模型足够严格的 harness 可能对另一个模型造成过度拦截，而可跨领域迁移的策略则可能遗漏应用特定的安全关系。我们提出 EvoSafeHarness，一个面向安全的优化框架，可为目标领域中的冻结模型合成可部署的 harness。它联合搜索自然语言策略与可执行代码逻辑，并以模型行为、领域规范和全新上下文对抗审查为引导，从而拒绝基准特定的规则。在四个 Agent 基准系列上，EvoSafeHarness 实现了比固定专家设计防御更强的安全-效用前沿。在 DecodingTrust-Agent 上，它以 3.3 个百分点的效用代价将平均攻击成功率从 45.6% 降至 10.0%，并在 15 个评估单元中的 14 个取得最佳分数。在 AgentDojo 上，它在 0.0% ASR 下达到 82.8% 的效用，是同一操作点上 CaMeL 效用的两倍，并可原样迁移到未见过的 AgentDyn 套件。它还在 Agent-SafetyBench 上对每个受害模型都取得最佳分数，并在细化预算为 16 的自适应 PAIR 攻击下将平均 ASR 保持在 20% 以下。分析表明，领域语义决定需要哪些安全关系与轨迹状态，而模型与运行时行为决定这些关系应在何处以及如何被强制执行。

## GE-Act 2.0: Pretraining and Scaling a World-Action Model for Robotic Manipulation

[GE-Act 2.0：面向机器人操作的世界-动作模型的预训练与扩展](https://arxiv.org/abs/2609.05588)

GE-Act 2.0 是一个世界-动作模型（world-action model，WAM），其可训练的生成模块与动作模块全部基于操作数据从零初始化训练，结合了面向控制的自编码器（CoAE）、单步视觉规划器（SVP）与逆动力学模型（IDM），并通过知识对齐的选择性优化（KASO）实现跨多种技能与条件的可扩展零样本机器人操作。

世界-动作模型通过预测未来状态来引导机器人动作，从而既能从无动作视频中学习，也能从带动作标注的交互中学习。既有工作大多继承预训练的视频生成器，使 WAM 的预训练与扩展性问题仍缺乏探索。为此，作者提出 Genie Envisioner Act 2.0（GE-Act 2.0），其可训练的生成组件与动作组件均在操作数据上从零初始化。该模型由三部分组成：面向控制的自编码器（CoAE）在激进压缩下仍保留与动作和指令相关的信息；单步视觉规划器（SVP）通过一次可微前向传播生成完整的未来状态，使视觉规划与逆动力学能够在互补数据上分别预训练。随后各组件通过知识对齐的选择性优化（KASO）联合训练，该方法仅选择那些被判定为与记录动作在行为上相容的预测未来，从而减少监督信号不匹配的问题。

作者直接评估预训练检查点，不做任何逐任务微调，覆盖 20 个操作技能组共 100 个任务，且场景、背景、光照与物体实例均为留出设置。将联合训练数据从 300 小时扩展到 30,000 小时后，G1-OP 上的成功率由 17.1% 提升至 44.1%，G2-90D 上由 13.4% 提升至 31.1%；尽管 G2-90D 在联合训练数据中占比不足 2%，仍取得 17.7 个百分点的提升，提示存在跨本体迁移能力。性能增益覆盖 19/20 与 18/20 个技能组，且技能层面的覆盖度与零样本分布外（OOD）成功率高度相关（Pearson r=0.80；Spearman rho=0.85）。在同一协议下，该模型在至少 90% 的试次中能够正确地将物体、颜色、形状与位置指代落地，并且即便显式指令与已承诺的行为或场景中的常规关联相冲突，也能遵循指令执行。

## T1: Terminal Agent Reinforcement Learning for Long-Horizon Tasks

[T1：面向长时程任务的终端 Agent 强化学习](https://arxiv.org/abs/2609.11042)

T1 是一个 122B 的混合专家（Mixture-of-Experts，MoE）模型，通过强化学习训练，可在云沙箱中执行长时程终端任务，凭借稳定的 actor-critic 优化与分布外训练取得 SOTA 结果。Agent 的使用场景正转向编程、科学发现等长时程任务，其中终端任务尤为重要。我们提出 T1：一个总参数量 122B 的混合专家模型，经强化学习训练，可在云沙箱中操作真实 shell，单任务支持多达 300+ 轮工具调用，并以执行每个任务自身的验证器作为奖励。我们给出了一套完整方案：第一，采用激进的热启动以稳定 actor-critic 训练，并使用稠密过程奖励，按通过验证器的绝对数量对轨迹打分。第二，通过 TITO 构造实现稳定优化——在精确采样的 Token 标识符上训练，并在轮次边界进行漂移修复；同时采用 rollout 路由重放（rollout routing replay），记录采样器在每一 MoE 层的逐 Token 专家选择，并在训练时重放。第三，完全分布外的训练语料：与 Terminal-Bench 2.1 不重叠的隔离种子与合成任务，确保性能提升反映真实的能力迁移，而非对基准的过拟合。TITO 与 R3 结合，将训练到推理的对数概率差从 0.021 降至 0.013，并在损失区域内实现完全对齐的零 Token 漂移。在 Terminal-Bench 2.1 上，我们的后训练流水线将初始基座模型从 43.8% 提升至 T1 的 64.0% 解决率。在 Long-Horizon Terminal Bench 上，T1 达到 27.9%，超越 GPT-5.4 与 GLM-5.1。

## Miles v0.1: Production-Level Post-Training

[Miles v0.1：生产级后训练](https://arxiv.org/abs/2609.08368)

Miles 是一个开源、可直接投入生产的系统，面向大规模强化学习与后训练，支持多种后端、权重同步、LoRA、蒸馏以及扩散模型。我们提出 Miles v0.1，一套全栈、生产就绪的前沿后训练系统。在 slime 的简洁设计基础上，Miles 围绕一个核心原则来设计 RL 训练循环的每个阶段：各组件应当可验证、简洁且可定制。以准确性、效率、可靠性和可扩展性为首要目标，Miles 致力于让前沿规模的 RL 对研究人员和企业同样触手可及。本报告端到端地介绍该系统：基于 SGLang 构建的 rollout 引擎、可选两种后端（NVIDIA Megatron-LM 与 PyTorch FSDP）的训练器，以及面向不同部署拓扑的三种权重同步传输方式。除全参数 RL 外，Miles 还支持 LoRA RL、同策略蒸馏（on-policy distillation）、监督微调，以及真正同策略的 rollout-训练对齐，并将同一架构扩展至扩散模型。最后给出一个端到端案例研究：在 GLM-5.2 744B-A40B 模型上针对终端使用类编码任务进行全异步 Agentic RL，运行于 64 块 NVIDIA GB300 GPU 上，前 30 个测量步骤的中位步耗时为 263 秒。Miles 已在 https://github.com/radixark/miles 开源，项目网站为 https://miles.radixark.com。

## Mask Forcing: Improving Autoregressive Video Diffusion Distillation via Dual-Noise Masking Rollout

[Mask Forcing：通过双噪声掩码 Rollout 改进自回归视频扩散蒸馏](https://arxiv.org/abs/2609.09123)

Mask Forcing 通过在自 Rollout 过程中注入带掩码的干净信号，缓解蒸馏后自回归视频扩散模型的模式坍缩，在不增加额外训练数据的情况下提升视觉质量。

自回归（AR）视频扩散模型在实时视频生成方面展现出巨大潜力。近期方法通过分布匹配蒸馏（Distribution Matching Distillation，DMD）将预训练的双向视频扩散模型蒸馏为因果 AR 学生模型，但生成的视频常出现过饱和与过平滑问题，导致视觉质量与真实感受限。关键原因在于 DMD 中逆向 KL 目标具有模式搜索（mode-seeking）特性，可能使学生分布坍缩到教师分布的少数模式上。为此，我们提出 Mask Forcing——一种双噪声掩码 Rollout 策略，通过扰动 AR 学生的自 Rollout 来缓解逆向 KL 模式搜索引发的模式坍缩。其核心思想是在 AR 扩散蒸馏的自 Rollout 过程中，沿空间与时间轴施加随机掩码，向带噪的 rollout 输入注入更干净的信号。此类扰动促使学生 rollout 探索教师分布中更多区域，使 DMD 能够提供学生已覆盖模式之外的学习信号。此外，更干净的 Token 可为其他噪声更大的 Token 提供去噪引导，改善中间 rollout 预测并减少误差累积。大量实验表明，本方法能够高效提升多种 AR 视频扩散蒸馏方法的视觉质量，且无需引入真实视频数据或额外的后训练阶段。

## Mi-Ripple: Restoring Images Degraded by Iterative AI Editing

[Mi-Ripple：修复迭代式 AI 编辑导致的图像退化](https://arxiv.org/abs/2609.11317)

Mi-Ripple 通过将晶格伪影与纹理分离，并结合定向频谱滤波与参考图清理，减少编辑图像中的数字波纹伪影。迭代式参考条件图像编辑可能引入网格状和颗粒状纹理，通常被称为数字波纹。我们提出 Mi-Ripple，一种诊断引导的修复流程，可在抑制数字波纹的同时保护图像结构。Mi-Ripple 将周期性晶格伪影与内容纠缠的颗粒纹理分离，然后结合选择性频谱陷波、结构感知平滑和干净参考图重生成。这种分离使得在伪影于频谱上被隔离时可采用低失真滤波，而在滤波会抹除真实细节时则转向视觉重建。在十四次仅陷波处理中，全图残差标准差为 0.08–0.44 个 CIELAB 亮度单位。在一个配对重生成示例中，参考图清理使输出碎屑密度降低 45%。Mi-Ripple 将可量化的伪影削减与视觉上更干净的生成图像联系起来，而非仅优化频谱分数。

## SceneMosaic: Efficient and Diverse Simulation-Ready Scene Generation via Hybrid Agentic Layout Evolution

[SceneMosaic：通过混合 Agentic 布局演化实现高效、多样的可仿真场景生成](https://arxiv.org/abs/2609.05594)

SceneMosaic 将学习到的图像先验与视觉语言 Agent 相结合，通过演化局部单元并对其进行全局组合，高效生成多样且物理合理的室内场景。

多样且可直接用于仿真的室内场景，对互动娱乐与具身 AI 至关重要，但其可扩展生成仍面临挑战。近期依赖视觉语言模型（VLM）的 agentic 文本到 3D 场景流程能够生成高保真场景，但需要代价高昂的迭代式物体摆放与细化。另一主流范式——参数化图像到 3D 场景模型——借助从 2D 图像中习得的强先验高效生成场景，却往往导致场景不精确且物理上不合理。更重要的是，这两种范式都难以针对单一输入输出多样化的场景，因而难以反映真实场景动态变化的特性。本文提出 SceneMosaic，一个融合两种范式优势的框架。它从基于图像的习得先验获得初始候选，随后通过 VLM Agent 对结果进行演化，兼顾效率与物理合理性。在演化过程中，SceneMosaic 利用自然场景的局部性，将场景分解为相互独立的局部单元，允许在各单元内部单独演化，再通过笛卡尔积组合成全局场景。在 SceneEval-100 上，SceneMosaic 在语义布局质量上与最强的 agentic 基线持平，并实现 24 倍加速，同时大幅减少物理违规，获得最高的人工评分。代码已公开于 https://github.com/rxjfighting/SceneMosaic。

## ENEAS: Embedding-guided Neural Ensemble for Adaptive Segmentation

[ENEAS：嵌入引导的神经集成，用于自适应分割](https://arxiv.org/abs/2609.03756)

我们提出 ENEAS，一种统一的、可文本提示（text-promptable）的实例跟踪与语义发现方法。包括 SAM 3 等最新基础模型在内的文本提示分割模型，仍存在时间幻觉、空间碎片化和语义误分类问题：当目标离开视野时无法报告目标缺失；在极端特写时只分割局部纹理而非完整物体；并优先依赖视觉特征而非本体论现实，从而把雕像、绘画或倒影等视觉相似的伪影分割为目标实体。ENEAS 用同一套方法支持两种工作模式：对特定实例进行精确跟踪与高质量分割，以及对文本查询所指称的每一个实例进行开放概念发现，后者由语义验证层完成裁决。在跟踪方面，我们扩展了此前仅支持点交互、具有几何鲁棒性的 SeC 架构，加入文本提示适配器并利用其时间记忆，使目标在消失期间仍被保持、不会漂移到干扰物上，并且在填满整个画面时仍保持完整。在发现方面，验证层将高速视觉嵌入匹配与条件式 VLM 精化相结合，仅对模糊候选调用语义推理，从而过滤掉纯视觉模型无法区分的本体论错误，同时保持低延迟。ENEAS 在设计之初即面向 3D 重建场景——其中一个被误分类的干扰物就会破坏整个资产——它实现了对视频、大型素材库以及时间或空间无序数据集合的高质量语义跟踪与分割，并具备区分真实实例与其“冒名者”（看起来相似但并非同一事物）的辨别能力。代码与模型见 https://github.com/speridlabs/eneas
