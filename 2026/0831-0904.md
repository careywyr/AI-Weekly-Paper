## Repo-To-Skill: Distilling GitHub Repositories Into AI4AI Skills

[Repo-To-Skill：将 GitHub 仓库蒸馏为 AI4AI 技能](https://arxiv.org/abs/2609.02749)

DisCo 是一个研究 Agent，其作用是将操作性知识（operational knowledge）蒸馏为可复用技能，从而在多个基准上显著提升自主机器学习（ML）研究性能。自主 Agent 正开始端到端地开展 ML 研究。这类 Agent 将模型主干与负责规划、执行、记忆和验证的框架相结合，但这种架构仍将领域特有的技术诀窍留在 Agent 之外。作者称这一缺失层为操作性知识，即区分“知道某个方法”和“将其跑通”的诀窍。这类知识并非不存在于领域中，它出现在代码仓库和论文里，但形式面向人类读者，且体量过大，无法在任务进行期间加载。这些知识一旦被蒸馏为紧凑且经过验证的技能，就能跨任务复用，而不是在每次运行中重新发现。本文提出 DisCo，一个技能驱动的研究 Agent，在研究过程中创建技能并加以使用。其蒸馏过程以两种互补形式进行：任务无关蒸馏（task-agnostic）将领域内广泛使用的仓库浓缩为可复用技能；任务导向蒸馏（task-oriented）则生成具体任务所需的技能。前者应用于开放生态，产出了 AREX-Skill 技能库，包含从 1,000 个广泛使用的 ML 仓库蒸馏出的 5,000+ 项经过验证的技能，并组织为 20 个领域、178 个能力族。在 GPT-5.5 主干、研究框架和下游执行预算固定的情况下，配备技能的研究 Agent 与未配备技能的同款 Agent 相比，在 MLE-bench 上得分高 134.3%，在 PaperBench 上高 34.4%，在 FrontierCS 上高 9.2%，在 PassNet 上高 14.0%。这些增益来自在固定设置下加入蒸馏后的运行上下文。

## StudentSim: Training LLM-based Student Simulators

[StudentSim：训练基于 LLM 的学生模拟器](https://arxiv.org/abs/2609.01591)

StudentSim 利用稀疏数据训练个性化学生模拟器，以复现学习者反应并适应导师引导，在国际象棋、英文写作和数学领域均优于现有模型。AI 导师只有在适应每位学生的优势、劣势和偏好引导时才最有价值，但从真实学习者身上收集“哪种引导对哪位学生有效”的证据既稀疏、缓慢又昂贵。学生模拟器可作为代理提供此类信号，然而现有方法局限明显：状态跟踪模型能拟合学生行为，却难以处理解释或纠错文本；LLM 角色扮演虽能流畅遵循引导，却不能可靠匹配被模拟学生的真实能力水平。我们提出 StudentSim——一种训练框架，通过先池化训练再逐学生特化的方式，将稀疏的每位学生数据转化为个性化模拟器。生成的模拟器既能复现学生自身反应，又能在导师引导下更新表现。我们还推出 StudentSimEval，一套标准化评估协议，覆盖国际象棋、二语英语写作和数学三大学科的 60 名学生，使用脱敏记录公开共享的学习者数据集。StudentSimEval 同时衡量行为保真度（F，即模拟器与学生反应的匹配程度）与引导响应度（R，即模拟器在导师引导下更新的灵敏程度），所有方法均基于相同记录进行拟合与评估。在全部三个领域中，StudentSim 在两项指标上均超过 GPT-5.4。以国际象棋为例，StudentSim 达到 F=0.51、R=0.91，而 GPT-5.4 为 0.23 和 0.72，Maia2 为 0.45 和 0.27。作为概念验证，将 StudentSim 作为导师强化学习的奖励模型，所训练出的国际象棋导师在专家人工评估中被认为比无 RL 基线和以 GPT-5.4 模拟器奖励训练的导师更准确、引导更佳且更具个性化。代码已开源：https://github.com/microsoft/StudentSim

## Compile by Training: Turning Natural-Language Specifications into Local Neural Functions

[按训练编译：将自然语言规范转化为本地神经函数](https://arxiv.org/abs/2609.04199)

按训练编译（compile by training）通过将教师模型生成的示例蒸馏到小型适配器中，把自然语言规范转化为可复用的神经函数，从而无需远程模型依赖即可高效部署。许多反复出现的文本功能容易描述，却难以用规则实现；而针对每个输入调用大型远程模型则会带来重复的成本、延迟和对提供商的依赖。我们提出按训练编译，它能将自然语言规范变为可复用的神经函数。编译时，教师模型生成任务专属示例，用于为紧凑型解释器训练一个小型适配器。得到的函数无需教师模型即可运行，并且可以像普通软件一样被存储、版本化和组合使用。在 FuzzyBench-Hard（Program-as-Weights 快速编译器在该子集上没有任何精确匹配）上，按训练编译达到 83.6% 的语义准确率。更高的准确率伴随着更高的编译时间成本：约一分钟，而快速编译器只需数秒。我们将该编译器部署于公开交互式服务中，并在一个多站点网页助手、一个语言控制的 3D 化身和一个英语-Claudish 双向翻译器中展示了编译函数的应用。

## Terminal-Universe: Turning Agent Trajectories into Scalable Terminal Environments

[终端宇宙：将 Agent 轨迹转化为可扩展的终端环境](https://arxiv.org/abs/2609.04148)

Terminal-Universe 从 Agent 轨迹中重建可执行工作区，用于合成多样化训练任务，并通过监督微调提升后训练性能。

随着基于终端的代码 Agent 日益普及，Agent 轨迹已大规模积累，但真实可执行的环境仍然稀缺。然而，环境才是 Agent 后训练真正需要的：每个环境都可以被反复查询以产生许多可验证任务，并提供执行反馈，而一条轨迹只是一份固定的示范。与其从零生成环境，不如充分利用现有轨迹中的工具执行历史——它揭示了环境运行时所处的结构与内容，因此我们可以直接从轨迹本身重建这些环境。

为此，我们提出 Terminal-Universe（终端宇宙）框架，将每条轨迹转换为可复用的环境，并利用它合成新任务与持续交互。具体而言，Terminal-Universe 重放轨迹中记录的文件操作，在 Agent 修改文件之前恢复每个文件，从而得到一个部分工作区；随后由补全 Agent（completion agent）补齐缺失的文件和依赖。在此恢复的工作区上，我们同时重建原始意图任务并合成全新任务。

此外，我们还沿两个互补维度扩展任务：广度与深度。在广度上，我们挖掘相关环境间的有向依赖关系，合成跨多个代码库的跨工作区查询，模拟开发者在真实开发中的常见操作；在深度上，我们将初始的单轮查询扩展为多轮会话，通过用户 Agent 捕捉迭代的用户反馈和需求细化。

将 Terminal-Universe 应用于公开的终端 Agent 轨迹后，我们得到 37.3k 个可支撑任务的环境。在该语料上对 Qwen3.5-27B 进行监督微调，可将 Terminal-Bench 2.1 单轮性能提升 11.9 点，并将 EvoCode-Bench v2 MT@4 多轮性能提升 13.8 点。

## HarnessDev: Can LLMs Create and Evolve Their Own Agent Harness?

[HarnessDev：LLM 能否创建并进化自己的 Agent 执行框架？](https://arxiv.org/abs/2609.01437)

HarnessDev 通过衡量智能体构建并迭代改进执行基础设施的能力来评估它们，而不是看最终的基准任务输出；结果发现，自建执行框架的能力和效率参差不齐，并且难以跨模型迁移。

随着智能体从研究原型走向部署工具，其能力日益取决于模型外部的执行基础设施，即通常所称的“Agent 执行框架（agent harness）”。在保持模型权重不变的情况下更换这一执行框架，可以显著改变任务性能。当前的智能体评估通常是在选定执行框架下报告下游任务表现，而较少探究模型自身开发执行框架的能力。

我们提出 HarnessDev，该基准将评估对象从任务输出转向可运行的执行基础设施。HarnessDev 包括两个阶段：在创建（Creation）阶段，智能体从最小种子和少量案例出发，构建完整的执行系统；在进化（Evolution）阶段，智能体以自己创建的执行框架为起点，利用下游执行反馈进行迭代修正，以提升基准表现。随后，我们分别评估每个被构建出的执行框架的能力（在保留基准上的任务成功率）和效率（执行 token 开销）。实验中的 Creation 结果涵盖 6 个创建者 LLM、4 个领域和 5 个下游基准，共包含 2,207 个独立下游实例，同时保留了未参与开发过程的隐藏评估任务。

我们发现，生成的执行框架在代码以及搜索和研究类任务上仍明显落后于成熟的人工设计参考框架，但在写作和机器学习实验类任务上能够匹敌甚至超过所选参考框架，且执行成本差异显著。Evolution 阶段虽然带来了一定的性能提升，但这些提升并不稳定，只能部分迁移到保留任务上。使用固定运行时模型的实验进一步表明，性能提升在很大程度上取决于执行该框架的模型，说明跨模型迁移能力有限。

## LLaDA-Image: Building Strong Image Generators with Fully Open Training Recipes

[LLaDA-Image：构建具有完全开放训练方案的高性能图像生成器](https://arxiv.org/abs/2609.03796)

LLaDA-Image 提出了一种统一框架，将从头训练的 6B 扩散 Transformer（DiT）与基于 LLaDA2.0-Mini 扩散语言模型骨干的冻结视觉-语言理解模块相结合。该方法并未在初期大量依赖图文配对数据，而是先通过仅图像预训练与中期训练建立强大的视觉生成先验。生成流水线包含 2.2 亿个样本，其中 98 个为真实图像。为提升优化效率与可扩展性，研究者在整个 DiT 中使用无参数 RMSNorm，并搭配 Muon 优化器。最终统一模型在生成高度逼真的图像同时，能精确遵循细粒度编辑指令。研究者进一步将 LLaDA-Image 蒸馏为 LLaDA-Image-Turbo，可在 2-4 步采样下实现快速推理。在 Qwen-Image-Bench 上，LLaDA-Image 分别在英文和中文赛道取得 53.53 与 53.38 的总体得分，刷新了开源模型在两赛道上的 SOTA 成绩。为支持高效生成模型的后续研究，作者已开源模型权重、训练代码与详细方案。

## Aspire: Can Models Self-Evolve from Vague Goals?

[Aspire：模型能否从模糊目标中自我进化？](https://arxiv.org/abs/2608.31111)

ASPIRE 提出了一个基准，用于评估 LLM Agent 如何从模糊的自然语言目标中实现自我进化，揭示了目标解读、数据选择以及稳定的权重层面改进等方面的挑战。人类学习的许多重要形式都始于模糊的目标，例如“成为更好的物理学家”或“提升研究能力”。学习者必须解读目标、识别能力差距、决定如何学习，并判断自己是否真正取得了进步。相比之下，现有关于 LLM 自我进化的研究通常以人类设定的任务和评估指标为起点，将自我进化简化为对显式目标的优化，而非自主决定学什么和怎么学。为此，我们提出了 ASPIRE——一个面向模糊目标驱动自我进化的基准。ASPIRE 仅提供自然语言形式的能力目标，而下游评估任务保持隐藏。Agent 必须通过选择数据和更新方法、构建训练与验证信号、并决定何时进行评估来将目标落地。ASPIRE 在统一的交互式环境中同时支持模型权重进化和 Agent 框架进化，并在由专家撰写的、覆盖六个目标的 520 个隐藏条目上对最终系统进行评估。实验表明，模糊目标将搜索努力引向目标解读。当前 Agent 虽能常规性地完成训练和框架编辑循环，但权重层面的提升仍然稀疏且不稳定，最强进化框架仍低于工程化的 Qwen-Agent 参考基线。Agent 经常在不匹配的数据上训练并过度信任狭窄的自我评估，导致局部增益无法迁移到隐藏评估中，而持续的搜索和训练还可能抹除先前取得的改进。

## Random Attention: Rethinking KV Cache Eviction for Efficient Reasoning

[随机注意力：重新思考高效推理中的 KV 缓存驱逐策略](https://arxiv.org/abs/2609.03430)

对推理 Token 进行随机驱逐，其效果可与选择式 KV 缓存压缩相媲美，因为推理轨迹通过冗余实现了自我保护——一旦提示词得以保留，评分便不再必要。大语言模型在需要长程推理的任务上表现出卓越性能，但长链思维使得 KV 缓存成为严重的内存瓶颈。现有 KV 缓存压缩方法遵循同一范式：依据某种对后续重要性的估计为每个缓存 Token 打分，并保留得分最高者。我们证明，这种选择信号几乎没有贡献。随机注意力（Random Attention）保留提示词，并在每个注意力头内均匀随机驱逐 Token，完全不做任何评分；在四个模型和六项推理任务上，它与此前最强的驱逐器表现相当，同时在 vLLM 部署中吞吐量高出 32–43%。受控实验揭示了原因：1）提示词是缓存中最脆弱的部分，而不同选择器之间的差距大多仅在于其选择信号是否恰好保留了提示词；2）推理轨迹通过两个层面的冗余来对抗驱逐——在文本层面（模型在推理过程中会复述其仍需的信息）以及跨注意力头层面（每个头都保留一份自己的轨迹副本）——因此一旦提示词得到保护，随机抽取便能保留足够多的模型所需信息副本，无需任何评分即可选出。我们的代码公开于 https://github.com/SalesforceAIResearch/Random-Attention。

## Knowing When Not to Reuse: Conditional Experience Transfer in Autonomous LLM Post-Training

[知道何时不该复用：自主 LLM 后训练中的条件经验迁移](https://arxiv.org/abs/2608.26730)

边界校准干预迁移通过检查上下文适用性并运行有界试验来选择性地复用过往训练经验，减少有害更新并提升自主后训练中的最终模型质量。大型语言模型虽然具备广泛能力，但使其适应不断演进的领域、工具和需求往往需要反复执行后训练。自主系统通过提出更新、训练候选模型并利用评估反馈选择后续提案来自动化部分流程。随着经验不断累积，一个核心问题浮现：在后续训练改变了父模型之后，哪些过往更新经验仍然可行？一次更新的效果取决于其父模型、数据与训练阶段。将过往成功视为无需上下文的许可会浪费算力，若由此产生的子模型被提升，还可能劣化后续训练轨迹。我们将该问题形式化为条件经验迁移，并提出边界校准干预迁移（Boundary-Calibrated Intervention Transfer, BCIT），一种在权重变更训练之前授权经验复用的方法。BCIT 将观察到的效果绑定到其来源上下文，检查适用条件，否决存在命名硬冲突的候选方案，并在必要时通过有界训练试验获取当前状态证据。完全训练后的候选模型仍须遵循统一的采纳规则，且只有观察到的经验事件才会扩展记忆。在一个基于 4B 模型、横跨金融推理、Text-to-SQL 与函数调用的自适应实验中，候选更新在评估上下文中表现出异质的保留与目标效果。在匹配候选模型、经验与算力的条件下，BCIT 相较对照组批准更少的有害更新，并在相同预算下获得更高的最终模型质量。这些结果支持将经验授权视为自主后训练中的一个独立问题。

## SolarWM: Open Data and Scalable Training for Long-Horizon Video World Models

[SolarWM：面向长时程视频世界模型的开源数据与可扩展训练](https://arxiv.org/abs/2609.02886)

SolarWM 为构建交互式视频世界模型提供了一个全流程开放的基础设施，涵盖从数据准备到长时程推理的完整链路。不同数据源与视频骨干模型之间的联合训练颇具挑战：各数据集在时间尺度、相机几何、视觉质量、运动模式和字幕风格上差异明显，而不同视频生成器又采用各自独立的表征与架构。因此，简单的数据混合与特定模型专属实现会导致监督信号不一致，并使结果难以复现和比较。SolarWM 通过可重构的多源数据引擎和骨干网络原生适配框架来解决上述耦合问题。该数据引擎将来自 10 个数据集的 143 万个标准片段转换为统一的、帧对齐的契约，涵盖视觉观测、度量相机几何、字幕、质量元数据、筛选决策与来源信息，同时将源数据处理与混合构建解耦。在共享的相机条件、训练与推理接口下，我们基于 Wan2.2、LTX-2.5 和 MiniMax-H3 实例化了四个 5B 至 33B 参数规模的模型，同时保留其原生表征和训练目标。统一的三阶段训练方案结合了双向适配、教师强制自回归初始化和分布匹配蒸馏。由此得到的因果模型在仅用 5 秒序列训练后，即可支持从数分钟到数小时的实时交互推演。通过发布对应的数据、流水线、训练方案、权重和框架，SolarWM 为交互式世界模型研究提供了可复现且可扩展的基础。

## Does On-Policy Distillation Really Distill? From Noisy Teacher to Self-Improvement

[同策略蒸馏真的在蒸馏吗？从带噪教师到自我改进](https://arxiv.org/abs/2608.31046)

同策略蒸馏（OPD）通过密集的 token 级监督，成为带可验证奖励的强化学习（RLVR）中稀疏结果级优势外的另一种选择。然而，教师打分的是学生生成的轨迹，而这些轨迹对教师而言本质上属于离策略（off-policy），因而其监督的可靠性、以及学生从中所获提升的来源尚不清楚。我们对 OPD 训练中的教师监督做了定量分析，发现其中含有大量噪声，且噪声普遍程度随教师规模增大而提高。令人意外的是，学生策略对这些噪声并不敏感：无论保留还是移除带噪监督，最终性能均相当。OPD 真的在蒸馏吗？通过分析性能提升的驱动力，我们发现学习集中在低对数概率（log-probability）的 token 上，并且使用单一固定负优势（negative advantage）就能匹配教师提供优势时的表现。这表明 OPD 的收益主要来自对低对数概率 token 的抑制，而这一过程并不需要教师。上述发现催生了同策略自适应（OPSA）——一种免监督方法，采用熵自适应负优势，对高熵位置施加更强的学习信号，以抑制尾部 token，并将概率质量均匀重新分配至头部 token。与基础模型 Qwen3-1.7B 相比，OPSA 在 AIME24 上使 Avg@32 提升了 35.41 分，相当于 263% 的相对提升，同时在全部三个基准上将 Pass@32 翻了一倍以上。在 AIME24 上，其 Avg@32 还比 OPD 高出 16.77 分。跨模型家族与任务的大量实验与分析进一步验证了该方法的有效性和泛化性。

## RoboTok: An Internet-Scale Data Engine for Human Demonstration Retrieval and Dexterous Manipulation Learning

[RoboTok：互联网规模的人类示范检索与灵巧操作学习数据引擎](https://arxiv.org/abs/2609.03199)

机器人学习越来越依赖广泛且多样化的示范数据，但采集机器人数据成本高昂，且难以覆盖真实世界任务的长尾分布。为突破这一瓶颈，我们提出了 RoboTok——一个互联网规模的数据引擎。给定一段人类操作视频作为查询，它能从网络视频中检索出与操作相关的人类示范，用于训练灵巧机器人策略。具体而言，我们从估计的以执行者为中心的参考坐标系中提取 3D 手部轨迹，并学习其潜在运动空间。这一表示能够在摄像机视角、场景外观和人物遮挡等变化下进行比较，同时又足够紧凑，适用于互联网规模视频集合的高效搜索与持续索引。我们在检索基准和下游机器人策略性能上，将 RoboTok 与现有机器人数据检索方法进行了对比。结果表明，RoboTok 能够检索到更相关的操作示范，并提升下游任务成功率，这确立了以手部姿态轨迹感知的检索方法，使网络视频成为机器人学习可扩展且持续增长的监督来源。

## EarlyEval: Cheaper Agent Evaluation via Early Outcome Prediction

[EarlyEval：通过早期结果预测实现更廉价的 Agent 评估](https://arxiv.org/abs/2609.02783)

EarlyEval 通过中间行为预测 Agent 的最终结果，并尽早终止运行，从而在几乎不损失准确率的情况下降低评估成本。评估 LLM Agent 对于指导其开发至关重要，但成本已变得高不可攀：前沿模型在 Agent 基准（agentic benchmark）上的单次运行就可能花费数百至数千美元，并且在迭代开发周期中需要反复支付这一代价。此前的努力主要集中在基准蒸馏（benchmark distillation）上，减少了评估任务的数量，但并未降低所保留任务各自的执行成本。在这项工作中，我们引入了早期结果预测（early outcome prediction），这是一个互补的效率维度，着重削减每个任务内部的成本。我们的关键洞察在于：Agent 的最终结果往往在执行完成之前，就能从其中间行为中明显看出。我们将这一想法实现为 EarlyEval，这是一个轻量级框架，基于行为、文本与参考解特征训练一对 LightGBM 成功和失败分类器，并在任一分类器跨越校准后的置信度阈值时立即终止 Agent 运行，每一步增加的开销可忽略不计。在 SWE-bench Verified、TerminalBench 和 Toolathlon 三个基准上，EarlyEval 可以消除 13%–26% 的 Agent 执行步骤，以及最高 44.1% 的输入 token 和 29.4% 的输出 token，预测准确率达 89%–97%，同时每个 Agent 的解决率（resolve rate）平均仅波动 1–2 个百分点。

## LatentPress: Context Compression Beyond Text and Vision

[LatentPress：超越文本与视觉的上下文压缩](https://arxiv.org/abs/2609.01507)

LatentPress 将对话与文档上下文压缩为连续的记忆令牌（memory tokens），由冻结的解码器直接读取，实现了高压缩比、更快的推理速度，并在准确率上优于文本或 OCR 方法。压缩上下文通常以人类可读的文本或需要解码的渲染图像形式承载，即使其消费方是语言模型也是如此。我们提出 LatentPress，它将对话历史和长文档写入第三种表示：连续的记忆令牌，由冻结的解码器通过其输入嵌入接口直接读取，推理时无需重建文本。一个与解码器匹配的小型写入器可在仅训练适配器（4.2M–26.2M 参数，约为解码器的 0.1%）的情况下实现 4–16 倍压缩。在 LongMemEval 上，LatentPress 在 7.70 倍压缩下达到 0.504 准确率，而未压缩证据为 0.490，优于文本摘要（0.184）和基于 OCR 的压缩（0.426 至 0.312）。在 LongBench-QA 上，域内写入器在 4–8 倍压缩时达到或超过原始上下文阅读的效果，而 16 倍压缩则略逊于原始上下文。每次会话写入耗时 43ms，比文本摘要或 OCR 重建快约一个数量级，读取速度比原始上下文或缓存 OCR 快 5–9 倍。我们在两种迁移设置下验证了该接口：从 UltraChat 零样本迁移到 LongMemEval 记忆问答，以及从 LongMemEval 派生的问答迁移到未见过的 LongBench 文档领域，从而确立了直接软令牌作为一种超越文本与视觉的实用机器面向上下文接口。实验实现见：https://github.com/xuyd16ai/context_softtoken_compress

## Lucida: Parse, Generate, and Place for Composable Real-to-Sim Scene Modeling

[Lucida：面向可组合真实到仿真场景建模的解析、生成与摆放](https://arxiv.org/abs/2608.30821)

Lucida 通过将流程中的需求分散到解析、资产生成与 VLM 引导的摆放三个阶段，改进了可组合室内场景重建，能够从杂乱采集中重建出高保真、可编辑的数字复制品。

可组合场景建模旨在将真实室内场景恢复为完整、可编辑的对象资产，并按观测到的布局排列，从而为机器人仿真和具身 AI 提供面向仿真、可逐对象操作的真实环境复制品。现有流程将任务拆解为三步——把观测解析为实例、为每个实例生成资产、再把每个资产放回原位——但每一步都预设了杂乱采集很难提供的输入：准确的实例几何、无遮挡视角以及与观测精确匹配的资产。我们提出 Lucida，它保持这一顺序，但重新分配需求，使每一步只消费真实采集能可靠提供的信息，并在流程末端达成精度，而不是在起点就要求精度。Lucida 将视频解析为场景图，其节点携带逐实例的多视角证据；再依据证据为每个实例生成完整资产；最后使用 GizmoAct 摆放资产。GizmoAct 是一种 VLM 策略，它将摆放建模为多轮 GUI 交互，以闭环方式操作对象的 gizmo（操纵器），并自行判断何时完成对齐。在场景级 3D 目标检测、目标姿态估计和场景重建实验中，Lucida 在 R2S-Scene 上将 mAP 相对 Boxer 提升了 69%，在 CA-1M 上将 ADD-SB@0.05 从 57.8% 提高到 83.4%，并将场景 F-Score 从 SAM3D 的 0.794 提高到 0.924。

## LoopArena: Benchmarking Models as Runtime Controllers for Loop Engineering

[LoopArena：评测模型作为循环工程运行时控制器的基准](https://arxiv.org/abs/2608.28281)

LoopArena 评测控制器模型如何引导独立编码 Agent 完成长任务，结果显示严格成功率偏低，但推理成本显著下降。循环工程正成为一种围绕编码 Agent 组织开发工作的实践方式。与逐条手工编写提示不同，实践者会设计循环来监控进度、分配任务、运行检查并决定 Agent 下一步该做什么。即使拥有能力很强的编码 Agent，循环也可能轻信过时的进度记录、跳过必要的验证、将预算消耗在错误方向上，或在任务尚不安全时提前终止。然而，单次端到端运行的最终结果无法区分成败究竟来自循环的引导，还是编码 Agent 执行任务的能力。为此我们提出 LoopArena，一个用于评测单个模型能否在长时运行任务中引导独立编码 Agent 的基准。被评测的模型称为控制器（Controller）：每轮编码结束后，它会接收结构化的运行摘要，指示另一个固定的编码 Agent（Worker）下一步该做什么或验证什么，或决定是否停止。LoopArena 在三种互补的设置中评估该能力，三者在执行范围与成本上有所不同。Type I 通过执行验证的问题来评分下一步循环契约（Loop Contract）选择，评测时不运行 Worker。Type II 对完整任务的选定片段执行重复控制，而 Type III 从任务初始状态对配对完整任务进行评估。在完整任务上，最优观测严格成功率为 24.69%，表明长时循环控制在很大程度上仍有提升空间。在所有控制器中，配对后的估算推理成本平均降低 64.4%，且 Type II 在主要 Core 指标下产生相似排序（Spearman 相关系数 ρ=0.9747）。我们在 https://github.com/AMAP-ML/LoopArena 发布基准数据与评测代码。

## DreamX-Creator: Democratizing Native Audio-Video Generation at 2K Resolution

[DreamX-Creator：实现 2K 分辨率原生音视频生成的民主化](https://arxiv.org/abs/2608.31106)

紧凑的 7B 原生联合音视频生成器，通过跨模态注意力、渐进式联合训练、多模态反馈强化学习以及自回归 2K 精炼流程，生成同步的高分辨率输出。近期视频生成器往往忽略音频或将其置于独立阶段合成，从而限制了视觉动态与声学事件之间的相互建模。我们提出 DreamX-Creator 1.0，一个以 7B 生成器为核心的紧凑原生联合音视频生成系统。在首帧与文本提示的条件下，生成器联合去噪模态专属的音频与视频流。这些流在网络前半部分独立处理，在后半部分通过门控跨模态注意力（Gated Cross-Modal Attention）耦合，其中 token 级与 head 级的输出门控调节每个活跃跨模态注意力头的输出。统一的音视频数据系统构建并筛选时序连贯片段，生成结构化多模态标注，并将片段组织为能力导向的数据池。渐进式联合训练包含两个音视频预训练阶段，随后进行高质量微调。音视频强化学习进一步通过模态感知多模态反馈对生成器进行后训练，将视频、音频及跨模态反馈路由至对应流。针对高分辨率输出，我们的自回归单步 2K 精炼流程将双向多步教师模型适配为自回归多步精炼器，并将其蒸馏为每个时间块仅需一次去噪评估的学生模型。总体而言，DreamX-Creator 1.0 实现了原生、同步的音视频生成，性能可与最先进的开源系统媲美。通过发布紧凑的 7B 生成器与 2K 精炼器，我们旨在推动原生音视频生成的民主化，并为未来统一音视频生成建模研究提供可访问的基础。

## SMELT: Scaling Laws for Compute-Matched MoE Looped Transformers

[SMELT：计算匹配的MoE循环Transformer的缩放定律](https://arxiv.org/abs/2609.01343)

在稀疏专家混合（MoE）Transformer中循环中间层，可以在匹配每Token FLOPs、参数和缓存预算的同时，提高训练效率和下游性能。循环Transformer通过迭代共享层块来增加有效深度，但大多数评估都在固定模型尺寸下进行，将架构优势与额外FLOPs混为一谈。我们研究了在MoE Transformer上进行循环，同时紧密匹配每Token FLOPs、总非嵌入参数和KV缓存。通过一系列消融实验，我们总结出一种称为SMELT（Sparse MoE Transformer，middle layers Loop Twice，即稀疏MoE Transformer中间层循环两次）的方法：在严格匹配未循环基线这三项预算的同时，将中间一半的层循环两次。我们将SMELT扩展到四种规模，最大达到54B非嵌入参数，并为每种架构分别拟合了Chinchilla式缩放定律。SMELT的损失随计算量增加而下降得更快，在计算最优前沿上可节省6.8%–18.0%的训练FLOPs。这一优势会传递到下游基准测试中，且效果超出验证损失的预测，尤其在代码任务上最为明显，并会随样本长度和上下文示例数量的增加而进一步增强。机制分析表明，第二次遍历会减少注意力汇聚（attention sink），并将注意力权重重新导向内容相关Token，这种归纳偏置可能正是观察到的性能提升的底层原因。这些结果表明，即使在预算匹配条件下，循环也能改进Transformer，为将深度复用转化为可衡量收益提供了一种实用方法。

## Beyond Data Scaling: Representation-Centric Continued Pre-Training for Vision-Language-Action Models

[超越数据扩展：以表征为中心的视觉-语言-动作模型持续预训练](https://arxiv.org/abs/2608.27550)

VLAct 通过在多样化机器人数据上进行持续预训练，同时保留视觉-语言先验与共享动作语义，从而提升视觉-语言-动作（Vision-Language-Action, VLA）模型的下游任务表现；在有限算力下，它即可在仿真及未见实体（unseen embodiment）上取得强劲结果。扩展机器人数据对构建通用 VLA 模型至关重要，但机器人轨迹比网络规模的图像-文本数据更难扩展，因为具身（embodied）数据采集成本高昂，且对物理世界的覆盖稀疏。这使得表征质量成为核心瓶颈：在固定的机器人数据预算下，持续预训练必须将有限的轨迹转化为可迁移的视觉-动作知识，而非仅仅拟合动作。为此，我们提出 VLAct——一种面向 VLA 的 VLM 主干，在任务特定微调之前，先在大规模、异构、多实体（multi-embodiment）的机器人数据上进行预训练。VLAct 通过 VLM 先验保持、多头连续动作协同监督以及部分统一的跨实体动作布局，既保留了广泛的 VLM 先验，又鼓励跨实体共享动作语义，同时在微调阶段仍允许使用任务特定的动作头。在仿真、真实世界和未见实体迁移三种设定下，VLAct 在固定微调协议下均能持续提升下游性能。在 LIBERO-Plus 和 RoboTwin 2.0 上，VLAct 超越了 ABot-M0、LingBot-VLA 等工业级 VLA 系统，成功率分别达到 82.6% 和 92.5%；在 RoboDojo 上，VLAct 的成功率在全部策略中排名第六，并在两项指标上均优于所有被明确指定为世界-动作模型（World-Action Model, WAM）的参赛方案。最值得注意的是，在未见的人形实体 RoboCasa-GR1 上，仅使用 20% 下游轨迹数据的 VLAct 就超越了使用全部数据的 GR00T-N1.6 基线。上述结果完全基于开源数据，且仅在 16 块 GPU 的训练配置下取得，说明以表征为中心的持续预训练能够在适度的算力预算下带来极具竞争力的性能，是数据扩展之外推动 VLA 进展的重要独立路径。

## DART-SD: Diamond-topology Aware Retrieval and Tuning for Self-Distillation of Multi-Turn Tool-Calling Agents

[DART-SD：用于多轮工具调用 Agent 自蒸馏的钻石拓扑感知检索与调优](https://arxiv.org/abs/2608.18524)

让大语言模型（LLM）具备多轮工具调用能力，是构建自主 Agent 的关键。然而，该方向的进展从根本上受限于对完整轨迹模仿（full-length trajectory imitation）的依赖。对于涉及多个顺序无关子目标的任务，最优解空间会构成庞大的组合钻石格。如果强行将这种丰富拓扑压入单一整体轨迹，会造成严重的拓扑坍缩，无差别地惩罚合理的替代探索，并严重削弱策略多样性。为此，我们提出 DART-SD（Diamond-topology Aware Retrieval and Tuning for Self-Distillation，钻石拓扑感知检索与自蒸馏调优），这是一种将范式从全局强制转向拓扑引导的局部修正的新框架。DART-SD 首先将执行过程建模为收敛的交互状态转移图（Interaction-State Transition Graph，ISTG），忠实捕捉成功与失败探索路径中固有的钻石拓扑。在自主 rollout 过程中，该框架会识别关键拓扑断点（Critical Topological Breakpoint，CTB），并检索有成功案例支撑的恢复参考。最后，我们通过 CTB 引导的局部监督引入一种渐进式自蒸馏范式，确保训练损失仅在生成的恢复步骤上计算，同时严格保护有效推理前缀免受破坏性梯度更新的影响。在复杂多轮工具调用基准上的实验表明，DART-SD 显著优于传统的完整轨迹基线。

## Rethinking On-Policy Distillation of Large Language Models II: One Training Example

[重新思考大型语言模型的在线策略蒸馏（二）：一个训练示例](https://arxiv.org/abs/2609.04172)

在线策略蒸馏（On-policy distillation, OPD）通过快速覆盖教师状态，能从单个查询出发在数百个训练步内持续改进；然而学生模型的对齐依然缓慢，这表明该方法面临的是算法匮乏而非数据匮乏。OPD 将学生生成的轨迹（rollout）与教师提供的密集 Token 级监督相结合。现有工作主要研究了其算法行为，训练数据的作用尚不明确。我们通过在单条查询上训练，在数据最小化极限下考察这一作用。单查询 OPD 能在数百步内持续改进，并在不同任务领域和模型家族中恢复全数据 OPD 的大部分收益。我们通过训练期间访问的状态以及学生与教师对齐的速率来解释这一结果。我们测量了状态覆盖率（state coverage），即查询集的轨迹所能覆盖的全数据 OPD 访问状态的比例。单条查询即可达到 71.5%，且大部分在前 100 步内实现。添加语义不同的查询会同时提高覆盖率与验证准确率；当查询数增至 16 条时，覆盖率可达 98.9%，与全数据训练相当。然而，无论 OPD 是基于单条查询还是全量数据集训练，对齐变慢的速度都相似，即使固定的一组状态也需要数百步才能被吸收。因此，OPD 处于“数据过饱而算法饥饿”（data-overfed but algorithm-starved）的状态：其轨迹能迅速暴露广泛的监督信号，而学生模型吸收这些监督的速度却越来越慢。该状态覆盖率结果同样适用于多教师 OPD（multi-teacher OPD, MOPD）：每个领域 16 条语义多样的查询即可匹配全数据 MOPD。作为进一步的压力测试，内容轻量的模板和领域外的 WildChat 查询也逼近了真实查询基线。因此，任务内容与诱导出的状态覆盖率可以彼此分离。我们希望这些发现能将未来工作引向 OPD 的步效率，并促使人们重新审视相关数据以及 OPD 在前沿后训练中近期成功背后的机制。

## Why Gated DeltaNet Survives 4-Bit Quantization: NVFP4 W4A4 for the Recurrent Half of a Hybrid 27B LLM

[为什么 Gated DeltaNet 能在 4 比特量化下幸存：面向混合 27B LLM 循环部分的 NVFP4 W4A4](https://arxiv.org/abs/2609.04098)

将混合 LLM（包括循环 Gated DeltaNet 层）整体量化到 4 比特 NVFP4，可以通过定位离群值并利用稳健的 delta 规则动态，在长上下文与推理基准上保持准确率。

混合 LLM 将 softmax 注意力与线性注意力层（如 Gated DeltaNet，GDN）结合，后者以固定大小的循环状态汇总上下文。早期社区对 Qwen3.8-27B（48 个 GDN 层、16 个注意力层）的 4 比特量化把 GDN 块保留在 8 或 16 比特精度——尤其是其衰减门和写入强度门——因为直觉上循环中的误差会在长上下文中累积。为验证该直觉，我们构建了 Minima：对全部 496 个线性层（含 GDN）使用 NVFP4 W4A4。实验涵盖 4K/32K 困惑度、MMLU-Pro、GSM8K、AIME'25、GPQA-Diamond、LiveCodeBench 以及最长 64K 的 RULER 检索；Minima 与 BF16 在种子噪声范围内表现相当（5 项任务平均差分 -0.52），同时是我们比较的方案中体积最小（17.5 GiB）、预填充最快（+14-19%）的，其 32K 困惑度差距随位置增大而缩小。

四项机制研究解释了原因：（i）NVFP4 的 16 元素块缩放将残差流中的极端离群值局部化，从而使各层角色的激活误差趋于均衡；（ii）看似脆弱的门控投影实际上最不敏感——softplus/exponential 和 sigmoid 参数化将约 11% 的 GEMM 误差压缩为约 2% 的输出误差；（iii）delta 规则循环在 32K token 范围内将注入噪声保持在一个平坦平台，并能在数百步内遗忘状态脉冲，因为每次写入都会沿当前 key 方向覆盖状态；（iv）逐 token 的量化成本会随上下文增长而被稀释，而不是不断累积。

我们还修复了一个全局尺度失配问题：当按模块校准的 NVFP4 检查点由将这些模块融合为单个 GEMM 的内核执行时会出现该失配；同时表明校准后的 FP8 KV-cache 缩放因子不会带来性能损失。

结果是一个实用配方——全量化，发布 KV scales——并且从机制上解释了为什么混合 LLM 的循环部分是更容易量化的那一半。

## It Takes Two to Match: Co-Evolving Generative Retriever with Reinforcement Learning

[匹配需要双方：基于强化学习的协同进化生成式检索器](https://arxiv.org/abs/2609.00638)

CoGR 训练 LLM 同时为查询（query）和条目（item）生成紧凑的关键词，使检索可直接通过倒排索引完成，并通过协同进化强化学习进行优化。检索是现代搜索与广告系统的第一阶段，负责从海量条目空间中选出候选集合，供下游排序（ranking）与拍卖（auction）使用。近期研究越来越多地借助 LLM，通过查询扩展、数据合成与检索反馈训练来改进检索。然而，生成式组件通常仅用于查询侧增强，最终匹配仍交由下游检索器完成。为此我们提出 CoGR——一种直接训练 LLM 在查询侧和条目侧同时构造检索表示的检索框架。每个生成器产出一组紧凑关键词，直接经由倒排索引进行匹配，从而与现有基于关键词的检索基础设施保持兼容。CoGR 采用两阶段训练流程：首先通过监督微调建立对齐的关键词空间；随后，协同进化强化学习阶段利用 GRPO 交替优化查询侧和条目侧生成器，使其分别针对对方的冻结索引进行优化。两侧优化同一个“查询到条目”的检索 F1 目标：查询侧直接获得检索 F1 反馈，条目侧则收到一个反事实边际奖励，度量其生成的关键词所引起的查询侧 F1 变化。在与 10 个具有代表性的稀疏（sparse）、稠密（dense）与生成式（generative）检索基线的对比中，CoGR 在内部 APP Marketplace 数据集和公开 WANDS 基准上均取得最佳表现，F1 相对最强基线分别提升 10.9% 和 36.1%。进一步分析表明，训练过程中协同进化保持稳定，查询侧与条目侧的关键词空间随训练推进日益对齐。

## GenFirst: Generation Before Reconstruction for Stable End-to-End Latent Generative Modeling

[GenFirst：先生成后重建的稳定端到端潜变量生成建模](https://arxiv.org/abs/2608.29335)

潜变量生成模型的直接端到端训练通过熵保持与非对称动力学避免了隐空间坍塌，并采用“先生成”策略实现了当前最优的图像合成与统一多模态生成。潜变量生成模型通常采用两阶段流程：先训练变分自编码器做重建，再在冻结的隐空间上训练生成模型。由于以重建为优化目标的隐变量未必利于生成，联合训练两种模型是一个颇具吸引力的替代方案。然而，直接端到端训练仍面临挑战——它容易陷入隐空间坍塌，并存在生成与重建的冲突。我们重新审视了该问题，通过分析不同目标如何塑造隐空间，得出两点关键洞察：第一，Kullback-Leibler 散度目标中的熵项对防止坍塌至关重要——重建与先验拟合倾向于收缩后验，而熵则保持非退化的隐空间不确定性；第二，重建与生成展现出非对称的学习动力学——重建快速且受强监督，而生成更慢且更难优化。基于这些洞察，我们首次实现了无隐空间坍塌的直接端到端训练，并提出了 GenFirst——一种简单的“先生成后重建”策略：生成目标先在较弱的重建压力下塑造隐空间，随后逐步加强重建以恢复视觉细节。我们使用具有精确似然的连续自回归先验和具有隐式似然的 SiT 先验验证了 GenFirst。采用我们的端到端目标与 GenFirst 后，SiT 在 ImageNet-256 上取得了 gFID 0.97（带 CFG）和 1.45（不带 CFG）的成绩，MMDiT 在文生图任务上达到 GenEval 0.90 分。除图像生成外，我们还将该框架扩展至共享视觉隐变量的生成与表征学习，以及连续统一文图生成。这些结果证明了稳定端到端隐空间学习在不同生成先验与模态间的通用性。

## Agentic Artifact Creation: Systems, Evaluation, Principles, and Opportunities

[智能体工件创作：系统、评估、原则与机遇](https://arxiv.org/abs/2608.28122)

本综述将智能体工件创作（agentic artifact creation）定义为由 AI 系统执行的有状态（stateful）、反馈驱动的交付物构建过程，并围绕工件族（artifact families）、应用场景与评估实践分析了 259 项工作，进而提出可问责控制（accountable control）的相关原则。生成模型可将自然语言提示转换为图像、文本、代码等内容，降低草稿与组件的制作成本；其实际影响日益取决于这些片段能否最终成为完整、可靠的交付物。所谓“有状态”，是指 AI 系统实际构建或修改交付物，并由中间观测结果不断重定向后续工作。从功能上看，此类系统将工件的可操作表示、构建策略与运行时验证（runtime verification）连接起来，验证反馈可重新引导后续行动。我们审阅了截至 2026 年 8 月 20 日的 259 项工作，其中 230 个系统符合上述定义、29 个为智能体工件构建基准；在比较六个工件族的基础上，将应用场景与评估实践作为独立维度进行剖析。跨工件族来看，构建挑战不仅来自模态差异，也取决于决策之间的耦合强度，以及故障在仍可修复时是否会显现。分解可以降低局部复杂性，但会提高协调与重新组装成本。习得型评审器（learned judges）若与生成器共享偏好或盲区，往往难以提供多少独立的证据。由此我们提出若干原则：让承诺与责任保持明确、将反馈转化为针对性修复、并在修改后重新验证受影响状态。我们还识别出了相应机遇：即便工件、创作者意图与构建系统持续演进，依然能够维持连贯一致且可问责的控制。精选论文列表见 https://github.com/GeminiLight/awesome-agentic-artifact-creation。

## Language Models Can Control Their Own Attention

[语言模型可以控制自身注意力](https://arxiv.org/abs/2609.02737)

声明式注意力（Declarative Attention）让语言模型在推理过程中主动声明需要关注的上下文区域，从而跳过大部分 KV 缓存读取，以较小的精度损失换取参与计算的 Token 数量大幅减少。语言模型将大部分注意力集中在少量上下文上，却仍需要读取整个 KV 缓存才能定位到少数关键 Token。当用户在一个百万 Token 的对话中询问某处细节时，全局注意力层必须扫描全部上下文才能生成回复中的每个 Token。常见缓解方案是通过轻量代理分数预先筛选相关 Token，但这种外部评分方式每一步仍然需要 O(N) 的开销。我们提出一种由内在机制驱动的方法，出发点是一个简单的问题：模型自身难道不知道上下文哪些部分相关吗？为此，我们引入声明式注意力机制，通过协议让模型在思维链中主动声明需要关注的位置，并将生成过程划分为三种模式：＜global＞（全上下文）、＜focus＞（指定区域）和＜local＞（仅限近期输出）。推理引擎像解析工具调用一样解析这些声明，跳过大部分 KV 缓存读取。在 15 个长上下文任务的零样本评估中，DA 应用于现成模型（Gemma-4-31B、Qwen-3.6-27B）可将解码期间实际参与的 Token 总数显著减少（52.0%、31.1%），同时精度损失较小（1.27 个百分点、2.75 个百分点），且该损失随模型规模增大而收窄。DA 开辟了稀疏注意力的新维度，未来基于训练的方法有望进一步挖掘其潜力。

UI-Venus-2 是一个通用多模态 GUI 智能体（multimodal GUI agent），通过统一的推理-行动循环、扩展的环境覆盖和稳健的验证机制，实现可靠的现实世界数字自动化。尽管多模态 GUI 智能体已成为数字任务自动化的可行范式，但由于环境覆盖有限、任务构建脆弱以及奖励验证不可靠，从面向基准的模型转向可依赖的现实应用仍然充满挑战。为此，我们提出 UI-Venus-2，一个通用的基础 GUI 智能体，旨在通过统一的闭环推理-行动框架跨移动端、网页和桌面环境运行。为弥合迈向实际部署的鸿沟，我们联合扩展了三个关键维度：（1）环境：将覆盖范围扩大到 170 多个多语言移动应用和原生桌面操作系统；（2）任务：采用深度研究流水线进行基于功能的指令生成；（3）验证：引入带有视觉关键点的轨迹级和样本级评估器，以及多模型投票机制，以确保可靠的 RL 训练信号。此外，我们集成了安全感知机制，确保高影响操作的可控执行。通过提供功能强大、高效且开源的基础设施，UI-Venus-2 推动该领域朝着更通用、更可验证、更具自省能力的智能体方向发展，以服务于现实应用。

## On the Design of Qwen3.8-Next Architecture: Evaluation, Efficiency, and Training Stability

[Qwen3.8-Next 架构设计：评估、效率与训练稳定性](https://arxiv.org/abs/2608.30320)

Qwen3.8-Flash-Next 是一种稀疏混合专家（Mixture-of-Experts, MoE）架构，将 Gated DeltaNet（GDN）与稀疏注意力层混合，并加入门控残差分支和加速器外的 n-gram 嵌入，以提升效率、能力与训练稳定性。我们介绍了 Qwen3.8-Flash-Next 的架构与消融实验。该模型为稀疏 MoE 模型，总参数 125B，每个 Token 激活 6B 参数，另有 51B 参数的 n-gram 嵌入表存放在加速器之外。在 14 个预训练基准上，该模型在 8 个上领先前代 397B-A17B 模型，在其余基准上最多落后 2.6 个点；而其激活参数仅为前代的 1/3，训练 Token 数为 1/3，训练 FLOPs 约为 1/9。Token 混合采用逐层的 GDN 与全局注意力混合，每四层包含一个全注意力层；在继续预训练阶段，这些全注意力层会被替换为 Qwen 稀疏注意力（Qwen Sparse Attention, QSA），后者通过压缩的轻量级索引器，以微块（micro-block）粒度对上下文进行评分。残差流被拓宽为四个分支，并通过逐元素门控读出，该设计被称为门控残差（Gated Residual, GR）。额外容量通过在主干之外加入单个 n-gram 嵌入层来添加，其嵌入表从主机内存预取。我们从三个维度评估每项候选改动：损失与下游基准表现；改动在训练、预填充（prefill）和解码阶段的开销；以及它对最优超参数和训练稳定性的影响。损失与下游准确率并不总是同步变化：扩大 n-gram 词表会单调降低损失，但下游准确率会趋于饱和。该架构与 Muon 优化器共同将最优学习率和批大小向上偏移，使批大小预热不再必要，并显著提升压力测试下的稳定性。损失、基准、效率与稳定性共同构成一个设计问题；只有联合求解，才能得到一套同时更高效、能力更强、更稳定的方案。

## ZimaBlue: Evolving Generalizable World Action Models through Scalable Video Pre-training

[ZimaBlue：通过可扩展视频预训练演化通用世界行动模型](https://arxiv.org/abs/2609.00188)

机器人操作面临一个根本性的扩展挑战：鲁棒的泛化需要广泛的物理经验，然而带动作标注的机器人轨迹数据收集成本高昂，且多样性天然受限。第一人称（egocentric）视频提供了一种更具可扩展性的具身经验来源，能够在多样环境中捕捉物体交互、接触动力学、工具使用和长程行为。核心挑战在于如何将这种海量但无动作标签的经验转化为有效的机器人控制。我们提出 ZimaBlue，一个从大规模视频中学习可泛化世界行动模型（World Action Models，WAMs）的可扩展框架。ZimaBlue 遵循三阶段训练课程：首先在大规模人类与机器人第一人称视频上进行因果具身视频预训练；随后通过统一动作表征的视频-动作中期训练，将学到的视觉动态锚定到异构机器人轨迹上；最后针对目标机器人进行模型特化以完成部署。为使生成式 WAM 可用于实时控制，ZimaBlue 进一步采用异步“慢-快”双系统架构：高容量的慢速世界模型提供可泛化的时空表征，轻量级快速分支则在 NVIDIA RTX 4090 上实现 30 Hz 的动作预测。在真实机器人零样本评估中，数据规模从仅目标机器人数据扩展到超过 12 万小时具身视频后，成功率从 36.1% 提升至 77.8%。ZimaBlue 在多个基准上均展现强劲性能，在未见任务上的提升尤为显著。

## Normalized Low-Rank Adaptation

[归一化低秩适配](https://arxiv.org/abs/2608.31036)

归一化低秩适配通过归一化下投影矩阵来稳定 LoRA 训练，加速收敛并提升性能，而无需额外参数或推理成本。尽管低秩适配（LoRA）被广泛用于参数高效的模型适配，但如何规范其训练动态以实现稳定有效的优化仍未得到充分探索。由于 LoRA 将上投影初始化为零，其早期优化动态主要受下投影支配。基于这一观察，我们提出了归一化低秩适配（NoRA），一种简单而有效的方法，在训练期间对下投影矩阵进行归一化。我们进一步表明，相同的归一化可以仅在初始化时应用，从而改进标准 LoRA，而无需在整个训练过程中反复归一化。在预训练、监督微调和强化学习中，NoRA 一致地加速收敛、提升性能和训练稳定性，并减轻灾难性遗忘。这些优势既不需要额外的可训练参数，也不需要推理时计算，使 NoRA 成为对 LoRA 的一种简单且广泛适用的增强。

## Code as Worlds: Agentic Discovery of Executable World Representations for Physical Reasoning

[代码即世界：面向物理推理的可执行世界表征的智能体发现](https://arxiv.org/abs/2608.27549)

Code-as-World 将物理环境表示为可执行代码，使视觉语言模型（VLM）能够进行定量推理并获得可扩展的监督。物理理解与推理依赖于形成紧凑且可泛化的世界表征。虽然现代视觉语言模型能够识别并解释多种物理事件，但它们往往缺乏对底层机制——例如对象状态、物理参数和控制动力学——的显式表征，而这些正是可靠推理世界如何演化以及对干预如何响应所必需的。在这项工作中，我们引入了 Code-as-World，这是一种通过可执行世界表征来表现物理世界的范式。通过将物理构成、动态演化和视觉外观表达为可执行代码，Code-as-World 为物理世界提供了一种紧凑、具备定量基础且可控的抽象。为了从多模态观测（如自然语言描述或真实世界视频）中构建此类表征，我们设计了一个受溯因推理启发的智能体发现循环：智能体在此循环中提出、执行、渲染、验证并迭代细化可执行的世界假设。作为一个具体应用，我们使用经过验证的可执行世界，为训练视觉语言模型进行定量物理推理提供可扩展的物理监督。实验表明，Code-as-World-VL 在 QuantiPhy 基准上达到了最先进（SOTA）表现，并超越了领先的专有模型，凸显了可执行世界表征作为物理智能可扩展基础的潜力。

## H3-World: Turning Language Understanding into World Control

[H3-World：将语言理解转化为世界控制](https://arxiv.org/abs/2609.01560)

我们提出了 H3-World，一个高效框架，将 33B 参数的 MiniMax-H3 视频生成器转变为交互式世界模型。我们的关键发现是，随着大型视频生成器能力增强，语言正成为一种自然的控制接口。例如，MiniMax-H3 已经支持通过自然语言指令对角色行为和摄像机运动进行零样本控制。在此基础上，H3-World 将这种粗略的语言接口转变为精确、时间锚定的世界控制，且无需引入专用动作模块。具体而言，我们将每个动作表示为角色指令与摄像机指令的结构化组合，并将其与对应时间区间的视频潜变量对齐。为了实现时间上的精确控制，我们进一步引入了时间注意力路由，将每条指令限制在其预期时间区间内，减少跨动作的控制泄漏。重要的是，H3-World 直接复用大规模视频预训练中学到的语义表示，仅需轻量适配。仅使用 8000 个游戏样本、10000 步 LoRA 优化和 0.199% 的可训练参数，H3-World 便实现了有效的角色与摄像机控制，同时保持了强大的生成质量，还能泛化到未见过的场景。这些结果表明，大型视频生成器中涌现的控制能力可以被高效转化为交互式世界控制。

## Scal3R: Learning Efficient Multi-Relative Pose Query for Scalable Online 3D Reconstruction

[Scal3R：学习高效多参考相对位姿查询以实现可扩展的在线三维重建](https://arxiv.org/abs/2609.04201)

Scal3R 通过使用轻量级 token 与位姿图优化来查询多参考相对位姿，从而改进长视频在线三维重建，无需重新训练骨干网络即可减少漂移。在线三维重建模型在处理长视频时表现不佳。这是因为相对于固定的第一帧锚点回归位姿，会迫使模型外推到远超训练分布的范围。微小的漂移不断累积并放大为严重的几何坍缩。然而，我们观察到在这种失败过程中，逐帧深度仍然保持稳定。骨干网络（backbone）的局部几何结构保持完好，只有全局位姿头（pose head）崩溃。受这种解耦现象的启发，我们提出了 Scal3R。该方法将在线重建重新构建为多参考相对位姿查询。我们使用轻量级可学习 token，其参数约占模型总参数的约 1%，通过非对称注意力将它们注入到完全冻结的骨干网络中。该设置可查询相对多个历史关键帧的位姿。配备闭环（loop closure）的在线位姿图优化系统可抑制长距离漂移。Scal3R 在单个 GPU 上仅需 8 小时即可收敛。与在线基线相比，它在 KITTI 上的平均绝对轨迹误差（ATE）降低了超过 60%。此外，它还在 Virtual KITTI、Sintel、TUM-Dynamic、ScanNet 和 7-Scenes 上达到了最先进的性能。项目主页：https://linjohnss.github.io/scal3r/
