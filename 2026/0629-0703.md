## Orca: The World is in Your Mind

[Orca：世界尽在你的脑海中](https://arxiv.org/abs/2606.30534)

Orca 通过多模态数据的下一状态预测建模，建立了一个统一的世界潜在空间，在下游任务中展现出优于专用基线的性能。我们提出了 Orca，一个通用世界基础模型的初步实例化。Orca 从多模态世界信号中学习统一的世界潜在空间，并通过多模态读出接口将其呈现。不同于孤立的下一 Token、下一帧或下一动作预测优化，我们聚焦于下一状态预测建模，提供了一条理解、预测和作用于世界的统一状态转换建模路径。Orca 通过两种互补范式学习：无意识学习从连续视频中捕获密集的自然状态转换，有意识学习则通过语言描述的事件和 VQA 监督来建模稀疏的有意义状态转换。预训练阶段，我们构建了大规模的世界学习库存数据，包括 125K 小时的视频数据和 1.6 亿条事件标注。预训练后，Orca 学习到统一的世界潜在空间。为检验所学潜在空间是否支持下游任务，我们通过三种代表性下游读出进行评估：文本生成、图像预测和具身动作生成。Orca 的主干网络被冻结，仅轻量级模态专用解码器可训练。实验证明了所提范式的可扩展性，并验证了更强的世界潜在空间能带来更强的下游读出性能。Orca 超越了同等规模的专用基线。这些结果表明，作为通用世界基础模型，Orca 为理解、预测和作用于世界提供了一种有前景的方法。最后，我们讨论了当前局限性，旨在为社区提供有益的见解和启发。

## Agentic Abstention: Do Agents Know When to Stop Instead of Act?

[智能体克制：AI 代理知道何时该停止而非行动吗？](https://arxiv.org/abs/2606.28733)

智能体克制研究的是 AI 代理在不确定情况下何时应停止交互的问题，涉及跨多种环境和任务类型的序列决策。LLM 代理需要在多轮交互中通过搜索、浏览界面和终端工具完成用户目标。然而，并非所有目标都定义明确或在当前环境中可实现。此时，可靠的代理应认识到继续交互无济于事，并主动放弃调用工具。本文定义了智能体克制问题，即代理在不确定条件下决定何时停止行动。与通常作为单轮回答或放弃决策的标准 LLM 克制不同，智能体克制是一个序列决策问题：代理每轮可选择回答、放弃或收集更多信息，而放弃需求可能只有在与环境交互后才变得清晰。我们在网络购物、终端环境和问答三个场景中展开研究，评估了 13 个 LLM 代理系统和 2 个代理框架在超过 28,000 个任务上的表现。结果表明，主要挑战不仅在于代理能否放弃，更在于何时放弃。部分代理在应该放弃时从不放弃，而另一些则是在大量不必要的交互后才放弃。当指令看似可行但环境揭示出相反情况（如无有效结果匹配指令）时，这一差距尤为显著。我们还发现，模型规模、推理能力和代理框架对克制行为有不同影响，更大或更强的模型有时在及时放弃方面表现更差。最后，我们提出 CONVOLVE，一种通过将完整交互轨迹蒸馏为可复用停止规则来改善智能体克制的上下文工程方法。在 WebShop 上，CONVOLVE 在不更新模型参数的情况下显著提升了及时放弃能力，将 Llama-3.3-70B 的及时召回率从 26.7% 提升至 57.4%。数据集和代码已开源：https://lhannnn.github.io/agentic-abstention

## Dockerless: Environment-Free Program Verifier for Coding Agents

[Dockerless：面向编码智能体的无环境程序验证器](https://arxiv.org/abs/2606.28436)

Dockerless 是一种无需执行环境即可运行的智能体补丁验证器，它能够提升代码补丁评估的准确性，并在不产生执行验证成本的前提下实现高效的后训练。程序验证器在编码智能体的训练中扮演核心角色，包括为监督微调（SFT）筛选轨迹，以及为强化学习（RL）提供奖励。传统的基于执行的验证需要在每个仓库环境（如 Docker 镜像）中运行单元测试，这会带来高昂的环境搭建成本。我们提出 Dockerless，一种无需执行环境的智能体补丁验证器，它无需运行代码即可评估生成的补丁。Dockerless 并非简单地将候选补丁与参考补丁进行匹配，而是通过智能体在仓库中自主探索收集证据来判断补丁的正确性。在验证器评估基准上，Dockerless 比最强的开源验证器高出 14.3 个 AUC 点。将 Dockerless 同时用作 SFT 轨迹过滤器和 RL 奖励，可以实现完全无需执行环境的后训练流程。由此得到的模型在 SWE-bench Verified、Multilingual 和 Pro 上分别达到了 62.0%、50.0% 和 35.2% 的解决率，比 Qwen3.5-9B 基线分别高出 2.4、8.7 和 2.9 个百分点，性能与基于环境的后训练相当。

## DOPD: Dual On-policy Distillation

[DOPD：双重同策略蒸馏](https://arxiv.org/abs/2606.30626)

DOPD 通过基于优势差距和概率在教师与学生策略之间动态路由 Token 级监督，解决了同策略蒸馏中的特权幻觉问题，从而提升大模型和视觉语言模型的能力迁移效果。同策略蒸馏通过使用密集的 Token 级信号监督学生采样的轨迹，提供了更优的能力迁移。为提供高质量的监督源并提升蒸馏的性能上限，一个直观方向是将特权信息注入教师或学生自身。然而，这种额外输入会引发一种潜在失败模式——特权幻觉：即混淆了学生本应弥合的可迁移能力差距与只能模仿而无法复现的信息不对称差距。Token 级监督固有的非均匀性进一步放大了该问题，因为只有少量 Token 承载关键的能力信号。为此，我们提出 DOPD，一种基于优势感知的双重蒸馏范式，根据优势差距和相对概率在特权教师与特权学生策略之间动态路由 Token 级监督。每个 Token 从教师或学生自身接收不同强度、目标和策略的监督，在传递可信能力的同时接收辅助信号，以缓解特权幻觉。在大型语言模型和视觉语言模型上的大量实验表明，DOPD 始终优于原始同策略蒸馏及其他对比方法。在稳定性、鲁棒性、持续学习和分布外任务上的进一步结果验证了其优越性。

## Scaling the Horizon, Not the Parameters: Reaching Trillion-Parameter Performance with a 35B Agent

Agents-A1 是一个 35B 参数的混合专家智能体模型，通过长视野轨迹扩展和异构智能体能力扩展，采用三阶段训练方法（包括监督微调、领域级教师模型和多教师蒸馏），达到了万亿参数级别的性能。我们引入 Agents-A1，这是一个 35B 参数的混合专家智能体模型，通过扩展智能体视野达到万亿参数级别的性能。我们从两个角度研究智能体视野扩展：扩展长视野轨迹和扩展异构智能体能力。为此，我们构建了一个长视野知识-行动基础设施，连接外部知识、行动、观察和验证器结果，生成平均长度为 45K Token 的智能体轨迹。在此基础上，我们采用三阶段方案训练 Agents-A1。首先，进行全领域监督微调，使基础模型对齐广泛的智能体行为。其次，训练领域级教师模型，以捕捉每个领域的专业知识。第三，我们提出一种多教师领域路由在线蒸馏方法，结合显著词汇对齐，提高跨领域知识迁移效率，将六个异构领域统一到一个可部署的学生模型中。Agents-A1 在长视野智能体基准测试中表现出强大且广泛的性能。与 Kimi-K2.6 和 DeepSeek-V4-pro 等 1T 参数模型相比，Agents-A1 在 SEAL-0（56.4）、IFBench（80.6）、HiPhO（46.4）、FrontierScience-Olympiad（79.0）和 MolBench-Bind（56.8）上取得领先结果，并在 SciCode（44.3）、HLE（47.6）和 BrowseComp（75.5）上保持高度竞争力。我们希望这项工作为社区提供一条实用路径，即使用 35B 智能体扩展视野，在长视野任务上达到或匹配 1T 模型的性能。

## Formalizing Latent Thoughts: Four Axioms of Thought Representation in LLMs

[形式化潜在思维：LLM 中思维表示的四条公理](https://arxiv.org/abs/2606.27378)

一个公理化的评估框架揭示了 LLM 在多种推理任务中潜在思维表示的系统性失败，表明当前表示在不同模型架构下无法一致地满足基本功能公理。我们为 LLM 中的潜在思维表示引入了一个公理化评估框架，包含独立于下游基准分数的指标，能够揭示基准准确率所掩盖的表示失败。现有评估将表示质量与模型能力混为一谈，因此失败无法归因于表示本身，而非处理它的模型。我们形式化了四条功能公理（因果性、最小性、可分离性和稳定性），并为每条公理定义了定量度量，这些度量直接在表示上计算，独立于下游准确率。我们对 23 个推理任务（如空间推理、事实问答）上的开源权重 LLM 进行了审计。我们发现，没有候选表示能同时满足所有四条公理；表示能可靠地区分任务类型，但无法区分同一任务内的两个问题；并且表示编码的信息几乎不超过输入嵌入中已有的信息。这种失败在密集模型、推理蒸馏模型和 RL 训练模型系列中一致出现，表明该差距是结构性的，而非模型规模或训练过程的属性。

## PhysisForcing: Physics Reinforced World Simulator for Robotic Manipulation

[PhysisForcing：面向机器人操作的物理增强世界模拟器](https://arxiv.org/abs/2606.28128)

PhysisForcing 通过基于 DiT 框架的像素级轨迹对齐和语义级关系对齐损失来强制执行物理一致性，从而增强具身视频生成。视频生成模型已成为具身世界模拟的一种有前景的范式。然而，通用域视频生成器和机器人专用数据微调模型仍可能产生物理上不合理的操作，包括不连续的运动轨迹和不一致的机器人-物体交互，这限制了它们作为世界模拟器的可靠性。通过大量实验，我们发现这种物理不稳定性主要源于两个因素：运动物体的变形以及交互实体之间（尤其是在接触时）不合理的时空相关性。基于这一观察，我们提出了 PhysisForcing，这是一个可扩展的训练框架，通过联合优化像素级和语义级特征，将监督重点放在物理信息丰富的区域，从而增强物理一致性。该框架包含一个像素级轨迹对齐损失（利用参考点轨迹监督 DiT 特征）和一个语义级关系对齐损失（将 DiT 特征与从冻结视频理解编码器中提取的区域间关系对齐）。在 R-Bench、PAI-Bench 和 EZS-Bench 上的大量实验表明，PhysisForcing 在强基线上持续改进了具身视频生成，使 Wan2.2-I2V-A14B 和 Cosmos3-Nano 基模型在 R-Bench 上分别提升了 22.3% 和 9.2%（相较于普通微调提升了 7.1% 和 3.7%），其中 Cosmos3-Nano 变体取得了最佳总体得分。在生成之外，作为 WorldArena 动作规划器协议下的世界模型，它将闭环成功率从 16.0% 提升至 24.0%，并进一步提高了下游策略的成功率，这表明物理对齐的视频模型能为机器人操作提供更强的表征。

## Scenes as Objects, Not Primitives: Instance-Structured 3D Tokenization from Unposed Views

[场景即对象，而非图元：基于无位姿视图的实例结构化3D标记化](https://arxiv.org/abs/2606.29513)

一种前馈框架从多视角图像中将3D场景分解为实例结构化的标记组，无需3D标注即可实现直接的对象级重建、分割和操作。3D场景应通过其包含的对象来理解，而非构成对象的图元。然而，现有前馈重建方法输出的是密集且无结构的点集或高斯体，对象级结构只能在事后恢复。我们提出一种前馈框架，直接从无位姿的多视角图像中将场景分解为实例结构化的3D标记组——紧凑的对象中心单元，重建、分割和操作均可由此实现。每个标记组将一个捕获实体级身份的实例标记与编码局部几何和外观的锚点标记配对，并解码为一组3D高斯体。这种双层分解将对象身份与局部外观解耦，使对象实例成为表示的原生接口而非衍生产物。标记组通过可微渲染结合联合重建与分割监督进行学习，无需任何3D标注。我们的前馈模型在类别无关的实例分割上超越了逐场景优化基线，在新视角合成方面也保持竞争力。除这些指标外，相同的标记组可直接实现实例级场景编辑——通过操作对象组来移除、平移或插入对象——以及高效的开词汇3D实例检索，其中检索复杂度随实例数量而非图元数量扩展。

## Qwen-Image-2.0-RL Technical Report

[Qwen-Image-2.0-RL 技术报告](https://arxiv.org/abs/2606.27608)

一种结合强化学习和在线策略蒸馏的方法，显著提升了扩散模型在图像生成与编辑任务中的视觉质量和指令遵循能力。我们提出了 Qwen-Image-2.0-RL，这是一个后训练流程，通过应用基于人类反馈的强化学习（RLHF）和在线策略蒸馏（OPD），同时改进了 Qwen-Image-2.0 扩散模型的视觉质量和指令遵循能力。为了提供可靠的奖励信号，我们通过微调视觉语言模型，采用逐点评分范式和思维链推理，构建了任务特定的复合奖励模型。对于文生图任务，奖励模型覆盖了对齐度、美学和人像保真度三个维度；对于图像编辑任务，奖励系统则关注指令遵循准确性和人脸身份保持。基于这一奖励系统，我们开发了可扩展的基于 GRPO 的 RL 训练框架，其中包含混合无分类器引导（CFG）策略以保留预训练知识、通过组内奖励范围过滤进行提示筛选，以及按类别进行奖励权重校准。为了融合 T2I 和编辑任务的专用 RL 策略，我们提出将在线策略蒸馏作为最终训练阶段，通过轨迹级速度匹配将多个教师模型整合到单个学生模型中。大量评估表明，Qwen-Image-2.0-RL 在 Qwen-Image-Bench 上取得了 57.84 的总分（比基础模型提升 2.61），在文生图竞技场中获得 1193 的 Elo 评分（提升 78），在图像编辑竞技场中获得 1349 的 Elo 评分（提升 93），在美学质量、提示遵循度和编辑准确性方面均展现出持续提升。

## TUA-Bench: A Benchmark for General-Purpose Terminal-Use Agents

[TUA-Bench：通用终端使用智能体基准测试](https://arxiv.org/abs/2606.28480)

TUA-Bench 提出了一个综合性基准测试，用于评估通用终端使用智能体在多样化数字活动和专业工作流中的表现，揭示了当前前沿智能体之间存在显著的性能差距。随着大语言模型和工具框架的持续进步，在终端中运行的智能体正逐渐能够执行更广泛的通用计算机使用任务，而不仅限于编程。然而，现有基准测试未能充分评估通用终端计算机使用智能体：通用计算机使用基准主要针对图形用户界面，而基于终端的基准则主要强调历史上与 Shell 相关的技术和编程工作流。我们引入了 TUA-Bench，一个面向终端使用智能体的通用基准测试。TUA-Bench 包含跨五个任务家族的 120 个真实世界任务，涵盖日常数字活动——包括文档编辑、电子邮件管理和实时网络信息检索——以及与博士级领域专家共同设计的、需要专业软件的科学与工程工作流。这种广度使 TUA-Bench 区别于以往专注于 Shell 或特定领域的基准测试。每个任务均为手动设计，在真实终端中通过确定性设置脚本运行，并采用基于执行的评分协议进行评估。我们发现，最强的前沿智能体——Claude Code 搭配 Claude Opus 4.8 最大推理努力——达到了 65.8% 的整体性能，但在两个轨道上均存在显著差距。通过提供广泛且真实的终端使用能力评估，TUA-Bench 旨在加速从狭窄、任务特定的助手向能够在多样化数字环境中可靠运行的通用智能体的转变。

## ReFreeKV: Towards Threshold-Free KV Cache Compression

[ReFreeKV：迈向无阈值的KV缓存压缩](https://arxiv.org/abs/2502.16886)

ReFreeKV 解决了依赖阈值的 KV 缓存剪枝方法的局限性，提出了一种无阈值方案，能够自适应分配压缩预算，同时在多种数据集和模型规模下保持全缓存性能。为减少大语言模型推理时的内存消耗，已有多种 KV 缓存剪枝方法被提出。虽然这些技术能在许多数据集上实现无损内存缩减，但它们往往依赖一个未被充分强调的条件：需要预先确定输入或领域特定的 KV 缓存预算阈值，才能达到最优性能。然而，这种输入敏感的设计在实际场景中可能受到很大限制，因为开放领域的输入涵盖不同领域、长度和难度级别，阈值选择缺乏明确边界。因此，对输入敏感阈值的依赖可能成为根本性局限，导致在任意输入上出现大幅性能下降。本文提出一个新目标，通过消除阈值约束实现鲁棒的 KV 压缩，倡导“无阈值”方法，在保持全缓存性能的同时自适应调整预算分配。我们进一步提出新方法 ReFreeKV，作为该目标的首个实例化。在涵盖不同上下文长度、任务类型和模型规模的 13 个数据集上的大量实验证明了其有效性和效率。我们的代码已公开在 https://github.com/Patrick-Ni/ReFreeKV。

## AgenticSTS: A Bounded-Memory Testbed for Long-Horizon LLM Agents

[AgenticSTS：面向长周期LLM智能体的有界记忆测试平台](https://arxiv.org/abs/2607.02255)

针对长周期LLM智能体，一种有界契约方法通过类型化检索组装全新提示，实现对记忆组件的隔离分析，在复杂决策任务中展现出更优性能。传统契约将历史观测、工具调用和反思内容全部附加到每个提示中，虽便于访问上下文，却导致记忆组件混杂难辨。本文提出并实现了一种替代性有界契约：每次决策均基于类型化检索构建的全新用户消息，不附加跨决策原始记录。这使得提示长度在任何运行轮次中保持有界，且可单独消融任意记忆层。我们在《杀戮尖塔2》中实例化了该契约——这是一款封闭规则随机卡牌构筑游戏，单局需完成数百次战术与战略决策。公开基准测试显示，前沿LLM在最低难度下五组配置均未获胜，而开发者报告的人类胜率为16%，任务难度高但未饱和。在我们的测试框架中，固定A0消融实验显示：触发战略技能时差异最大，无存储基线胜率3/10，添加技能层后升至6/10。该样本量下的比较仅具方向性而非统计显著性（Fisher精确检验p≈0.37）；跨骨干网络探测与公开累积上下文基线作为操作性对比呈现，而非对契约变量本身的受控测试。我们发布了可复现测试平台：包含298条带条件标签的完整轨迹、冻结的记忆/技能快照、提示记录与分析脚本——这是一套智能体设计方案及验证过的可复用方法论，用于研究显式记忆层如何塑造长周期LLM智能体的决策行为。
