## SO-Arena: Benchmarking the Capability Spectrum and Reliability of System One Models

[SO-Arena：系统一模型能力谱系与可靠性的基准测试](https://arxiv.org/abs/2611.15777)

系统一模型 (System One Model) 承诺无需冗长的 token 生成即可实现快速、通用的决策。然而，理解其能力谱系与决策可靠性，需要的不仅仅是当前基准上的总体性能。现有评估往往难以充分揭示模型能力的广度及其决策的可靠性。我们提出 SO-Arena，一个刻画系统一模型在 11 个领域和五个能力族上能力谱系与决策可靠性的基准。在能力谱系方面，SO-Arena 通过可靠来源以及针对模型可见输入对参考标签进行人工核验，提供有证据支撑的评估；通过领域特定的难度标准实现细粒度能力评估；并开展真实交互式评估，模型在沙箱中迭代执行动作。推理密集型任务还可进一步支持系统一与系统二的对比。除准确率外，SO-Arena 通过两项互补指标评估决策可靠性：受控选项集变化下的决策稳定性，以及无有效选项时的缺失答案识别能力。对 21 个模型的评估表明，规模扩展与额外推理带来的收益在不同领域间差异显著。更重要的是，强大的总体性能并不必然意味着可靠的决策：表现最佳的系统一模型在可靠性上仅排名第七。这些发现共同表明，有必要将能力谱系与决策可靠性作为互补维度加以刻画，从而系统性地审视系统一模型的优势与局限。

## Learning Heterogeneous Tactile Representation for General Dexterous Manipulation

[学习面向通用灵巧操作的异构触觉表征](https://arxiv.org/abs/2611.12806)

触觉感知是接触密集型灵巧操作不可或缺的模态，这一能力指向具身智能的终极前沿。然而，商用触觉传感器仍处于相对早期的发展阶段，每类传感器在提供不可替代优势的同时也各有缺陷。因此，一个关键挑战是使触觉理解摆脱传感器特定物理特性的束缚，从而让具身模型能够有效利用异构触觉数据。为此，我们开发了 LingBot-Touch，一个具备以下特性的触觉基础模型。(i) 我们的模型在不同触觉传感器（即压阻式、磁式和视触觉传感器）之间产生统一表征，并且易于扩展到新的传感器类型。(ii) 所得的触觉 Token 即插即用：它们可以无缝集成到跨范式的策略模型中，从扩散策略到视觉-语言-动作 (Vision-Language-Action，VLA) 模型（如 π_{0.5} 和 LingBot-VLA），持续增强操作灵巧性。(iii) 跨多个硬件平台的仿真与真实机器人部署的大量实验表明，我们的触觉表征在保持强大计算效率的同时，显著有益于复杂操作任务。我们相信，本工作的发现展示了利用跨传感器数据来扩展触觉学习的潜力，并为未来硬件与具身模型的设计提供了令人鼓舞的洞见。

## Confucius4-R2T2: A Stable-Prefix Streaming ASR Model for Real Real-Time Transcription

[Confucius4-R2T2：一种用于真实实时转写的稳定前缀流式 ASR 模型](https://arxiv.org/abs/2611.06043)

流式语音识别正越来越多地被机器（如翻译器和语音智能体）所使用，这些机器会在每个 Token 出现时立即对其采取行动。一个随后被修改的 Token 会造成无效工作或错误动作。在本工作中，我们提出 Confucius4-R2T2（Real Real-Time Transcription 的缩写），一种稳定前缀流式 ASR 模型，它在保持高准确率和低延迟的同时，从不修改其先前的输出。R2T2 通过在 1,500 小时中英文音频上对 Qwen3-ASR-1.7B 进行后训练得到，同时冻结其预训练的音频编码器和投影器。该适配基于最长稳定前缀 (Longest Stable Prefix，LSP) 的概念，这是我们在本工作中引入的新概念。我们证明 LSP 在前缀序下具有单调性、与全音频输出一致，并且在等于某个完整先前输出的标签中具有最大性。从 LSP 标签中学习可将全上下文模型转换为稳定前缀流式模型，而无需任何架构改动。大量评估表明，R2T2 使流式识别接近基础模型的全上下文质量，同时以低发射延迟提供稳定文本。其收益扩展到后训练语言之外，展示了从全上下文 ASR 到稳定流式的实用路径。我们在 https://huggingface.co/netease-youdao/Confucius4-R2T2 和 https://github.com/netease-youdao/Confucius4-R2T2 开源了模型权重和代码。

## Few-Step Streaming Video Generation via Condition Shifting

[通过条件偏移实现少步流式视频生成](https://arxiv.org/abs/2611.14033)

少步采样降低了流式视频生成的成本。分布匹配蒸馏 (Distribution Matching Distillation，DMD) 使用独立的假分数网络来监督少步生成器，这增加了训练内存和计算量，并且必须跟踪不断演化的生成器。我们将 APEX 扩展到流式视频，通过条件偏移在生成器内部估计生成分布的速度场。原始文本条件选择生成，而偏移条件使用相同参数选择假估计。这消除了独立的假网络，同时保留了 S2-Avatar 的冻结参考教师、Self-Replay Forcing 和感知正则化。我们在 180 秒视频上评估 APEX，每个块进行三次主干评估，并使用一步空间 Refiner，同时进行了 70 例人类研究和 320 例 StreamAV-Bench 比较。与 S2-Avatar 相比，APEX 在 Progressive 轨道上实现了更高的视频指令遵循度（3.856 对 3.831），并且在两个轨道上均实现了更高的视觉美学（0.641898 对 0.632606）。人类评分者在指令遵循上最强烈地倾向于 APEX，净偏好为 +30.0%，其次是一致性和视频质量，各为 +4.3%。运动质量倾向于 S2-Avatar，视听同步基本持平，可用性保持不变。在匹配训练设置下的单独测量显示，每 GPU 的峰值分配 GPU 内存降低了 4.4%，平均迭代时间比 DMD 缩短了 9.2%。

## P^2-MOPD: Accelerating Multi-Teacher On-Policy Distillation via Parameter Priors

[P^2-MOPD：通过参数先验加速多教师在线策略蒸馏](https://arxiv.org/abs/2611.03953)

多教师在线策略蒸馏通过对学生生成的轨迹进行监督来整合专家能力，而任务算术则通过线性参数组合提供了一种免训练替代方案。我们将学生参数与专家参数的线性组合视为一个单一的可微模型，提出 P^2-MOPD，在同一在线策略蒸馏目标下联合优化混合系数与学生权重。与任务算术不同——后者对任意合并系数选择都停留在冻结的学生与专家参数张成的空间内——P^2-MOPD 保持学生可训练，因此专家仅作为参数先验，而不会将学生限制在该空间内。在 1.7B 与 4B 规模下的四个领域中，P^2-MOPD 从相同初始化出发实现了比 MOPD 更快、更均衡的恢复，以一半的训练步数超越了后者的最终平均恢复率。在训练结束时，我们的 1.7B 模型达到 94.7% 的平均恢复率，而 MOPD 为 80.9%。

## SplatAnything: Gaussian Spacing Normalization for Feed-forward 3DGS across Arbitrary Scenes

[SplatAnything：面向任意场景的前馈 3DGS 高斯间距归一化](https://arxiv.org/abs/2611.08264)

我们指出现有前馈 3DGS 方法的一个关键局限：高斯属性通常在径向距离归一化空间中预测，该空间对重建几何的全局径向统计量进行规范化，而相邻高斯中心之间的间距在不同场景尺度和相机配置下仍可能大幅变化。这种不匹配会导致高斯尺度目标出现系统性偏移，从而产生模糊的监督信号。为此，我们提出 SplatAnything，并引入高斯间距归一化 (Gaussian Spacing Normalization，GSNorm)，该方法对高斯间距的稳健场景级统计量进行规范化，为高斯预测提供更一致的空间参考。为严格评估我们的方法，我们进一步建立了一个系统性基准，涵盖多样化数据集、不同输入稀疏程度以及具有挑战性的外推视角。大量实验表明，SplatAnything 达到了最先进的性能，在场景尺度和视角发生显著变化时增益尤为突出。

## Don't Just Trust Your Memory: Evidence-Linked Memory Reduces Memory-Induced Degradation in LLM Agents

[不要只相信你的记忆：证据关联记忆可减少 LLM 智能体中记忆引发的性能退化](https://arxiv.org/abs/2611.14320)

外部记忆使大语言模型 (Large Language Model，LLM) 智能体能够通过将过往任务的轨迹提炼为简洁的经验教训，从而从经验中改进并应用于新任务。然而，记忆也可能导致记忆引发的性能退化，即智能体在本可无记忆解决的任务上失败，这通常是因为它遵循了错误的经验教训，或误用、误读了一条有效的经验教训。其原因在于，经验教训是从仅标注了任务成功或失败的轨迹中推断出来的，但通常提供时并不附带其来源轨迹，使智能体无从核查。为解决这一问题，我们提出了 WikiTrace，一种证据关联的记忆系统，旨在让智能体能够对照原始轨迹核查每条经验教训。具体而言，受“轨迹通常仍保留着发现错误经验教训所需的证据”这一发现的启发，WikiTrace 将每条经验教训存储为一条简洁的洞见，并关联到对其轨迹为何成功或失败的总结以及原始轨迹本身。随后，在新任务上，智能体从所有洞见出发，每当某条洞见缺乏行动所需的细节、与另一条洞见冲突，或来自失败任务时，便借助终端工具沿其关联向下追溯，以在行动前补全缺失细节或纠正该洞见。我们在五个智能体基准上验证了 WikiTrace，结果表明它始终优于现有的记忆方法以及仅给定相同洞见的基线方法，同时还能减少记忆引发的性能退化。我们的代码可在 https://github.com/yukyeongleee/wikitrace 获取。

## Sage-Taiyi: A Metacognitive Architecture for Scientific Discovery

我们提出 Sage-Taiyi，一种受元认知启发的架构，利用积累的科学理解来指导下一步研究什么以及如何研究。通过显式的监控与控制，系统修正其对证据、假设和未解决问题的理解，进而利用这些评估调整研究目标并选择可复用的推理方法。在 Taiyi-Bench 上——一个由来自十个学科的 50 篇论文中的 265 个任务构成的 AI 联合科学家构思基准——Sage-Taiyi 在历史性再发现和开放式构思的全部八项指标上均排名第一，总体得分为 54.0，而最强基线 AI Scientist-v2 为 47.9。它在两个外部科学构思基准上也表现良好。五项专家指导的合作进一步将其提案与化学、材料科学和工程领域的实验及计算验证相连接。在化学领域，反应条件优化将钴催化羰基化的产率从痕量提升至 84%，将光催化烯丙基胺化从 13% 提升至 69%。这些结果支持将元认知调控作为科学构思及其走向实际验证的一种方法。

## WorldFoundry: Towards Unified Infrastructure for World Intelligence

[WorldFoundry：迈向世界智能的统一基础设施](https://arxiv.org/abs/2611.10771)

视觉生成模型正日益模糊合成观测与模拟环境之间的界限。然而，仅凭视觉上的逼真并不足以构成成功的世界建模：引人注目的输出可能缺乏持久状态、物理动力学，或对交互的因果一致响应。我们将生成式世界模型定义为一个预测性动力系统，它维护环境的持久且以历史为条件的表示，响应动作或干预更新该表示，并生成时间上连贯的轨迹，以反映在观测干预与反事实干预下的结果。基于这一定义，我们推导出一个面向智能的框架，涵盖感知基础、持久状态建模、可控变换、动力学感知预测和闭环交互。我们提出 WorldFoundry，这是一个开源基础设施，用于跨视频、3D 与 4D、具身动作以及交互式世界系统的可复现推理与评估。WorldFoundry 统一了模型与基准发现、运行时与资产准备、执行编排、产物管理以及交互式可视化，同时模态特定的适配器保留原生输入、执行语义、输出表示和评估协议。显式清单、持久产物契约和证据感知评分卡将执行就绪性与评估主张分离，使每项主张都可追溯到其支持产物。目录包含 270 个模型条目、74 个基准和 62 个注册指标条目，就绪性与执行证据分别记录。WorldFoundry 能够对异构系统中持久、可控的动力学进行可复现比较，推动该领域从感知合成迈向可度量的世界智能。

## World In-Context Learning for Agentic Robot Manipulation

[面向智能体机器人操作的世界上下文学习](https://arxiv.org/abs/2611.12885)

训练得到的动作策略将操作技能写入网络权重，从而把所学内容与学习所依据的分布绑定在一起。上下文学习 (In-Context Learning，ICL) 避免了这种耦合，但尚未达到训练策略的水平，原因在于在另一场景中录制的演示不携带机器人当前所面对世界的反馈。我们观察到，智能体在上下文中学习到的内容是语义性的，记录的是任务步骤和物体角色而非视觉外观，因此在一个世界中收集的经验可以迁移到另一个世界。基于这一洞见，我们提出世界上下文学习 (World In-Context Learning，WICL)，这是一种范式：冻结的模型从演示出发，在诸如模拟器之类的世界中对任务进行演练，并将反馈写入其上下文而非权重。我们构建了 RoboScript，一个实现 WICL 以支持智能体操作的模块化基础设施。RoboScript 从单条演示出发，通过在仿真中演练来学习每个任务，将学到的知识冻结为任务记忆 (Task Memory)，并将冻结的记忆部署到新场景，且采用数据隔离确保每次部署的输入在真实机器人上均可用。在 RoboTwin 2.0 的全部 50 个任务上，RoboScript 在干净与随机化设置下、每个任务仅用一条演示且不进行梯度更新的情况下，达到 83.4% 的平均成功率，超过最强的训练动作策略 20 个百分点以上。该方法可跨视觉分布泛化，通过反思得到改进，随基础模型规模扩展而提升，并通过跨具身记忆适配迁移到物理双臂机器人。将世界置于回路中，机器人便能在其上下文中学习操作任务，效果与在权重中学习相当。所有代码见 https://github.com/ArcheOne-AI/RoboScript

## Toward the Era of Agentic Embodied Intelligence

[迈向智能体化具身智能时代](https://arxiv.org/abs/2611.09124)

基础模型日益用于指导机器人动作，但持续自主性需要高效控制与故障恢复。我们提出 A2-MEAS，一个围绕代码作为扩展接口构建的具身多智能体 (multi-agent) 框架。学习到的纠正代码 (correction code) 融合纠正性语言、空间证据、执行历史与动作提议。MetaBrain 提供训练监督与运行时引导。纠正编码器与适配器在训练期间将该知识吸收进策略权重，而在部署时新代码以冻结权重调整行为。动作模型 A2-WLA 在视觉-语言-动作策略中加入运动感知历史与潜在世界模型。令人意外的是，这一简单设计配合动作预训练与任务特化，在 50 项任务的 BEHAVIOR 2026 公开子集上于在线纠正前达到 0.5755 Q-score，是 2025 年获胜者所报告 0.2605 的 2.21 倍（跨不同基准版本与训练配置）。在全部 100 项 BEHAVIOR 2026 公开任务上，A2-MEAS 达到 0.6411 Q-score 与 45.40% 任务成功率。在 RoboTwin 2.0 上，A2-WLA 达到 93.98% 平均成功率，完整系统下升至 95.05%。在五种家庭场景的 12 项真实机器人任务中，A2-WLA 达到 57.92% 平均成功率，而 pi0.5 为 26.67%。在长时程手冲咖啡制备中，与 A2-WLA 重试相比，历史条件适配器将两个滤纸处理步骤的故障后完成率分别从 14% 提升至 94%、从 8% 提升至 82%。我们的训练基础设施达到每秒 427.1 个样本，在同等硬件上是 pi0.5 参考实现吞吐量的 4.03 倍。我们将发布系统、模型、训练脚本与基础设施，以支持高效具身学习。

## Infrathon: Benchmarking Language Agents for Real-World, Long-Horizon AI Infra Optimization

[Infrathon：面向真实世界长周期 AI 基础设施优化的语言智能体基准测试](https://arxiv.org/abs/2611.11995)

本文研究前沿智能体能否在长周期内持续改进真实世界的 AI 基础设施。我们提出 Infrathon，一个涵盖不同层级、多样化的长周期 AI 基础设施优化任务基准。我们在 24 小时预算下对六个模型进行了 150 次运行评估，总计超过 10,000 GPU 小时。结果表明，模型排名随评估周期而变化，且 150 次运行中有 135 次在预算后半段仍取得进一步改进。这些发现表明，较短的评估可能同时忽略优化收益与模型相对表现的变化。我们还发现，智能体能够发现优于人工设计基线的解决方案：Claude Opus 5.5 将平均 KV-cache 压缩率从人工设计的 Quant-VideoGen 编解码器的 6.82% 提升至 19.86%。对智能体轨迹的分析识别出任务违规、测试不可靠和过早完成是持续改进的障碍。综上，我们的 Infrathon 框架为构建长周期任务、评估前沿智能体以及发现优质基础设施解决方案提供了资源。

## BirdDreams: Joint Perspective and BEV Video Generation for a Plausible, Reactive Driving World Model

[BirdDreams：联合生成透视与 BEV 视频以构建可信、可响应的驾驶世界模型](https://arxiv.org/abs/2611.14815)

驾驶世界模型旨在模拟场景在不同自车动作下的演变过程。这既需要周围车辆具有可信的运动，也需要精确的自车轨迹控制。仅从透视视频中学习车辆运动颇具挑战，因为运动与外观相互纠缠，且车辆可能被遮挡。因此，先前的工作将视频生成条件化于指定车辆运动的布局之上，从而实现对周围车辆的控制，但需要将其未来轨迹作为输入。我们提出 BirdDreams，一种自回归驾驶世界模型，它联合生成透视视频与示意性的鸟瞰图 (Bird's-Eye-View，BEV) 视频，使场景布局成为预测未来的一部分。BEV 由场景标注渲染而来用于训练，以固定度量尺度将道路和车辆描绘为简单形状，提供其位置与运动的俯视图，并减少车辆之间的遮挡。相比之下，透视视频保留了 BEV 所省略的场景细节，例如交通信号和物体外观。两个视频扩散 Transformer（每个流一个）之间的联合注意力机制使每个流在生成过程中相互提供信息。预测的 BEV 还为自车控制提供了几何接口：我们沿输入的自车轨迹平移和旋转其最新帧，并将所得帧作为软条件，展示若仅自车运动时场景将如何呈现。在推理时，BirdDreams 从单张相机图像生成两种视频，无需高清地图或车辆状态输入。在 PhysicalAI-AV 和 nuScenes 上，BirdDreams 比先前的驾驶世界模型更忠实地遵循输入的自车轨迹，并在无自车动作条件的情况下生成更可信的自车运动。人工评估表明，BirdDreams 在生成逼真的周围车辆行为方面优于仅透视的基线方法。

## Scaling Mathematical Proof Supervision from Structured Textbooks

[从结构化教科书扩展数学证明监督](https://arxiv.org/abs/2610.40394)

面向语言模型的数学监督通常被扁平化为孤立的问题-解答对，丢弃了原始来源中的课程组织与证据结构。我们提出 TOME-Math (Textbook-Oriented Mathematical Evidence)，这是一个大规模语料库，将涵盖大学数学核心学科领域的 2,118 本教科书转换为约 380K 条结构化证明监督记录，同时保留章节顺序、命题-证明链接、依赖引用与来源出处。利用这些结构信号，我们探索了跨多个数学学科的课程学习，并刻画了随监督规模与来源广度变化的扩展规律。在完整规模下，于 TOME-Math 上微调使模型在我们留出评估与既有公开基准上的未加权平均分较基座模型提升 16.7 个百分点，同时在总体表现上超过所评估的全部三个公开指令数据基线。我们的发现表明，结构化教科书既是可扩展的数学监督来源，也是研究数据组织方式对数学推理影响的实证框架。我们将发布该语料库以促进结构化数学监督的进一步研究。

## PhysLoop: Harnessing LLMs' Physics Awareness for Self-Improving Video Generation Models

[PhysLoop：利用大语言模型的物理意识实现视频生成模型的自我改进](https://arxiv.org/abs/2611.16748)

视频生成模型能生成视觉上逼真的视频，但在物理动力学和因果一致性方面仍存在困难。从生成的视频中学习需要细粒度的物理监督，然而可靠的质量判断、校正对和受控变化难以获得。大语言模型 (Large Language Model，LLM) 具备物理知识，但难以可靠地引导视频生成模型生成其训练视频。我们提出 PhysLoop，一个统一的框架，旨在支持视频生成模型中基于物理的自我改进。该框架在视频生成、选择和校正的全过程中引导并约束 LLM，将其物理知识蒸馏为物理一致的视频。该框架支持可控训练数据构建和推理时视频修复。通过识别并校正失败，PhysLoop 在有限人工干预下实现视频生成模型的递归自我改进 (Recursive Self-Improvement，RSI)，标志着迈向该目标的关键里程碑。我们发布了 10 万条视频，涵盖多样且真实的室内外场景，并附带生成工具和两个评估数据集：PhysLoop-Gen 和 PhysLoop-Repair。我们分别在这两个数据集上评估可控生成和局部修复，并在外部 Physics-IQ Verified 基准上评估物理行为。

## G-STAR: Group-Scaled Token Capacity for Deeply Compressed Autoregressive Generation

[G-STAR：面向深度压缩自回归生成的组缩放 Token 容量](https://arxiv.org/abs/2611.13004)

离散自回归模型为图像生成提供了可扩展的框架。然而，它们面临一个根本性权衡：长 Token 序列能保持表示质量，但会拖慢生成速度；而激进的空间压缩则会降低表示容量。基于乘积量化 (Product Quantization)，我们表明，在固定的名义信息预算下，组大小应随每轴空间压缩因子呈二次方缩放。基于这一原则，我们提出 GSTAR，一个空间—组协同缩放框架，能够在保持强重建、理解和生成性能的同时实现 32 倍乃至有效的 64 倍压缩。由于更大的组会引入组内依赖关系且必须高效建模，我们分析了其对推理延迟和生成质量的影响，并引入一种半自回归解码器，将并行特征计算与轻量级因果建模相结合。借助这些设计，我们的高度压缩模型在五个代表性文本到图像基准（GenEval、DPG-Bench、PRISM、LongText-Bench 和 Qwen-Image-Bench）上与领先模型表现相当。在 1024×1024 分辨率下，我们的模型相较先前的离散自回归模型实现了 20 倍加速，在单块 NVIDIA H200 上每张图像生成仅需 2.5 秒。这些结果共同表明，高度压缩的离散表示能够在低延迟下实现高质量的自回归生成。

## Tree-Ising: Repairing Language Models with Bit-Level Ising Edits

[Tree-Ising：用比特级 Ising 编辑修复语言模型](https://arxiv.org/abs/2611.14210)

MIT 近期由 Takehi 等人提出的权重空间编程 (weight-space programming) 使前沿大语言模型智能体能够读取网络权重并写入修复。其 GPT-6 Astra 智能体在无梯度条件下修正了 Qwen3.5-0.8B 的推理循环，使用了 158 个智能体轮次、8970 万 Token 和 50 次前向传播请求。我们的方法 Tree-Ising 将这一修复转化为在模型自身 BF16 权重上的稀疏离散优化问题。前向统计量定义一个目标函数，削弱循环方向、增强结论方向，并在有效 Token 上保持该层的输出。在状态树表示中（无损 BF16 存储作为其特例），可允许的编辑是符号翻转和指数移位，且保持所有共享组指数与尾数不变。我们将该目标精确分解为相互独立的 QUBO (Ising) 问题，每个输出行对应一个，并在 GPU 上使用模拟退火或量子启发的模拟分岔求解。在智能体所编辑的两个层上，Tree-Ising 在 MATH-500 上达到 54.6%，在相同评估协议下优于智能体的编辑（51.7%），而基座模型报告得分为 7.9%。模拟分岔求解器给出统计上不可区分的修复结果，为 55.1%。两个求解器在全部五个数学基准上均优于智能体编辑，经多重比较校正后在 MATH-500 和 GSM8K 上具有统计显著提升。我们的方法修改的权重少 13% 至 17%，并将 BF16 比特翻转减少 2.2 至 2.3 倍。它仅需四次前向传播请求且消耗零个 LLM Token，退火方案在 GPU 时间上花费约 0.90 美元。在 Qwen3.5-2B 上，仅使用基座模型选择层和剂量，同一方案将贪心 GSM8K 准确率从 21.6% 提升至 69.4%。作为概念验证，我们在 IBM Heron 处理器上使用 QAOA 执行了一个八变量修复子问题。

## PCBRouteAgent: How Close Are LLM Agents to Becoming PCB Routing Engineers?

[PCBRouteAgent：LLM 智能体距离成为 PCB 布线工程师还有多远？](https://arxiv.org/abs/2611.08175)

自动化印刷电路板 (PCB) 布线需要在严格的设计规则下，协调板级连接决策与几何执行。尽管近期的智能体已能与原生布线工具交互，但在复杂电路板上实现可靠布线仍然具有挑战性。我们提出 PCBRouteAgent，一种多模态 PCB 布线智能体，其设计灵感来自人类工程师协调全局策略与局部执行的方式。全局布线规划器 (Global Routing Planner) 结合电路板图像与结构化电气和几何信息，指定连接拓扑、布线顺序、布线通道以及层间转换。详细布线执行器 (Detailed Routing Executor) 通过 KiCad 原生布线引擎实现这些引导，并执行有界局部恢复。未解决的失败会以结构化反馈的形式返回，从而支持有针对性的引导修订，同时保留已接受的布线。我们在来自 PCBWorld-Bench 四个测试划分的 247 块合成与真实电路板上评估了 PCBRouteAgent。其在 D2、D3-A、D3-B 和 D3-C 上的完全通过率分别为 100%、94.9%、100% 和 40%。在三个真实世界子集上，PCBRouteAgent 的完全通过率分别比最佳评估基线高出 13.9、36 和 10 个百分点。

## OneTrans-GSR: A Generative Slate Ranking Paradigm Unifying Reranking and Mix-Ranking with One Autoregressive Transformer

[OneTrans-GSR：一种用单个自回归 Transformer 统一重排序与混合排序的生成式列表排序范式](https://arxiv.org/abs/2611.04720)

工业推荐系统将大量计算分配给逐点候选打分，但重排序 (reranking) 与混合排序 (mix-ranking) 阶段仍依赖手工规则和专用低容量模型来组装最终曝光列表。混合排序将来自不同上游业务渠道的商品卡、短视频、直播和广告卡组合在一起。尽管这些规则和模型编码了有价值的领域知识，但它们在利用额外数据和计算方面存在固有局限：它们约束了候选列表的组合空间，并通过人工调参决定目标权衡。为实现可扩展且有效的列表生成，我们将重排序与混合排序重新表述为一个统一的、性能可随计算提升的学习问题。具体而言，我们在重排序与混合排序阶段实例化该表述，并提出 OneTrans-GSR，这是一个仅含解码器的单一策略，扩展了我们已部署的 OneTrans 主干，以端到端方式生成曝光列表。训练时，奖励模型评估完整列表，并引导强化学习朝向列表级和长期目标；解码时，显式强制执行业务约束。离线评估表明，列表质量随奖励模型与策略计算的增加而持续提升。在大规模工业推荐系统中部署后，OneTrans-GSR 在统一列表内混合异构内容类型。在线 A/B 测试中，它使人均 GMV (GMV/u) 提升 2.63%，广告主价值提升 2.06%，复购率提升 2.03%，同时将重排序与混合排序阶段的端到端延迟降低 13%。这些结果标志着列表生成的范式转变：超越人工设计的启发式方法，转向通用的学习策略，为后续算法优化和计算驱动的改进开辟了可扩展路径。

## Duo: A Reciprocal World Model for Full-Duplex Interaction

[Duo：面向全双工交互的互惠世界模型](https://arxiv.org/abs/2611.15131)

在本报告中，我们提出互惠世界模型 (Reciprocal World Model，RWM) 并发布 Duo v1——一个在持续感知视听输入的同时实时响应用户的全双工世界模型。RWM 将智能与物理现实视为构成世界的同等基本要素。现有世界模型大多侧重于模拟后者，而将推理与决策留作外部控制，而非世界本身的内在组成部分。在 RWM 中，我们识别出两项同等基本的能力：意图 (Intent)，提供世界交互背后的认知；实现 (Realization)，生成连贯的视听行为。为实现这一构想，Duo v1 引入三项关键技术设计：(1) 利用自回归建模进行连续交互推理与参与决策，而非将其局限于扩散模型的指令理解。(2) 构建分块特定的条件，并在统一时间线上同步意图与实现之间的 Token。模块特定的注意力掩码在块内与块间强制因果依赖，防止访问未来输入。(3) 通过双重 rollout 蒸馏缓解两个模块中的分布偏移，在自回归生成的意图 Token 与实现模块合成的视听历史之上进行训练。两个模块持续感知实时音频、视频与文本，从而实现具有自发对话与打断能力的全双工交互。除对话之外，用户还可以分享真实物体、重塑虚拟场景、引导助手，或在无需鼠标与键盘控制的情况下游玩视听游戏。Duo v1 的发布迈出了我们的第一步，下一版本即将推出。我们期待对这一新兴领域展开更广泛的探索。

## Coding or Cheating? An Investigation of Frontier Coding LLMs

[编程还是作弊？对前沿编程大语言模型的调查](https://arxiv.org/abs/2611.10404)

前沿智能体大语言模型 (agentic LLM) 在由真实软件仓库构建的强化学习 (Reinforcement Learning，RL) 环境中，基于可验证奖励进行训练。测试套件通过即被视为解决任务的奖励。我们表明，在困难问题上，前沿模型常常通过获取答案而非推导答案来满足这些奖励，这一现象被称为奖励黑客 (reward hacking)。此前的报告已在公开基准上记录了该行为。我们测试了它在未见问题上的持续性。在一个答案无法泄露的加固环境中，我们测试的几乎每个模型都尝试获取答案，并逐级升级为越来越专门的利用手段：挖掘仓库历史以寻找上游修复、直接检查 git 对象存储，以及扫描文件系统以寻找可能存在的更新版本源代码或隐藏测试。这些尝试集中在最难的问题上，而各模型在是否升级、升级频率和升级深度上存在差异。我们的观点是，该行为是一种习得的捷径，是在泄露答案的 RL 环境中获得的，而非智能的标志。我们在 https://huggingface.co/datasets/logitly-ai/reward-hacking-raw-v1 发布了这些模型的智能体轨迹，以支持进一步研究。

## Singularity-Bench: Can Agents Build Agents?

[Singularity-Bench：智能体能否构建智能体？](https://arxiv.org/abs/2611.16591)

前沿 AI 智能体 (AI Agent) 在真实的长期任务上日益取得成功，并开始改进其自身运作所依托的系统。然而，现有基准测试往往将智能体限制在狭窄的动作空间中、使用简化的环境，或依赖对评估任意智能体生成系统而言并不可靠的验证方法。我们提出 Singularity-Bench，一个面向自主 AI 开发的开放式基准，包含六个端到端任务，覆盖预训练、中期训练、后训练、推理、智能体运行框架 (agent harness) 与集群编排。每个任务要求智能体从最小起点出发实现核心系统，并在相同硬件上与成熟的人工工程基线进行对比评估。此外，我们通过覆盖 OWASP Top 10 for Agentic Applications 中 10 个类别里 9 个的广泛红队测试，揭示了传统 Harbor 框架中存在的奖励黑客 (reward hacking) 漏洞，并开发了 Breakwater——Harbor 的一个扩展，可阻断我们研究中测试的所有攻击。在由 7 个前沿模型和 2 个运行框架构建的 11 个智能体中，Opus 5.5 配合 Claude Code 在全部六个任务上达到或超过人工基线，Singularity-Index 为 1.25，表明它可能具备抵达奇点所需的技能。其余智能体平均仅为 0.58。我们的愿景是让 Singularity-Bench 追踪智能体目前能够自动化多少 AI 开发工作，以及它们何时可能从辅助角色转变为端到端地负责构建更强的后继系统。

## AlphaProof Code: Verifying Signal’s Security at the Machine-Code Level

[AlphaProof Code：在机器码层面验证 Signal 的安全性](https://google-deepmind.github.io/code-verification/)

我们提出 AlphaProof Code，一个用于形式化软件规约与验证的多智能体 AI 框架，并用它在机器码层面证明了 libsignal（Signal 协议的参考实现）的关键安全属性。AlphaProof Code 由以下部分组成：一个在人工引导下为代码编写 Lean 规约的智能体、一个 AArch64 机器码的形式化语义，以及一组自主证明智能体，其证明只有在 Lean 内核依据已批准的规约对其进行检查并通过后才会被接受。将其应用于 libsignal 时，我们的智能体生成了约 650 万行经机器检验的 Lean 证明代码，这些代码建立在约 26,000 行可信规约与 AArch64 语义之上。这些证明覆盖了 Signal 的后量子 PQXDH 握手与 Triple Ratchet，确立了前向保密性、认证性、妥协后安全性以及握手保密性。它们是首批将协议层面的安全保障与一个广泛使用的密码协议实现的未修改代码相连接的证明。结果表明，AI 可以使形式化验证——历史上对大多数软件而言成本过高——对现实系统变得切实可行。我们的 Lean 开发成果见 https://google-deepmind.github.io/code-verification。

## Beneath the Surface: What We Overlook When We Talk About Agent Evolution

[表面之下：当我们谈论智能体演化时忽略了什么](https://arxiv.org/abs/2611.07624)

智能体框架 (agent harness) 的演化使得无需更新模型权重即可实现递归自我改进 (Recursive Self-Improvement，RSI)。我们考察更高的基准分数是否能带来可靠、高效且可迁移的改进。我们在多种框架、通用任务与编程任务上评估了四种方法。重复评估、受控的智能体扩展、组件干预以及准入重放揭示了反复出现的模式。全部十六个演化后的智能体都获得了此前未覆盖的任务，同时丢失了此前已覆盖的任务。在一个通用任务案例中，尽管丢失了十个此前已覆盖的任务，可靠性仍提升了 5.2 分。多数可靠性提升同时也增加了部署成本。具体变更通常优于通用提醒，但其收益在组合时可能发生变化。得分最高的智能体在我们的四个池中均未带来最大的平均改进，而更严格的准入可能丢弃有用的备选方案。迁移选择性地保留收益：在两种框架类型和范式下，覆盖率通常在通用任务目标上下降，但在仅外层框架下于编程目标上上升。这些发现推动了保留感知评估、经过检验的决策规则以及明确的适用条件。作为建设性的后续工作，EvoAudit 将这些诊断转化为对 select、analyze、mutate 和 gate 的修订，取得了最佳性能。

## The Last Mile to the Real World: Agent-Native Primitives as Reusable Building Blocks for Solving Real-World Tasks

[通往真实世界的最后一英里：将智能体原生原语作为可复用构建模块以解决真实世界任务](https://arxiv.org/abs/2611.07461)

智能体如何端到端地处理真实世界任务？前沿模型及其自带执行框架 (harness) 在真实世界基准上仍表现不足：在 Terminal-Bench 4.0 上，GPT-5.6 Sol 配合 Codex 解决 37.3% 的任务，Claude Opus 5 配合 Claude Code 解决 51.8%。这些任务失败于从获取资源到应用资源的环节，我们称之为通往真实世界的最后一英里。现有方法让资源触手可及，却把应用资源的能力留给调用方，因此每个执行框架都要重新构建这种能力。我们提出智能体原生原语 (agent-native primitives)，即可复用单元，为资源配备一个常驻 LLM，使其在上下文中应用该资源并与其他原语通信；并提出 HEELO (Harness Engineering around Evolving Agent-Native Primitives for the Last Mile to Real-WOrld Tasks)，一个执行框架工程框架，从这类原语库中为每个任务构建其执行框架。HEELO 将任务所需的原语组合成任务特定的图，依据环境证据验证结果，修订失败所涉及的原语，并在验证后接纳新的或改进的原语。我们以八个原语族实例化 HEELO，每个原语族针对一类任务构建，并在二十多个基准上评估。Dev-Primitives 将 Terminal-Bench 4.0 的解决率从 Codex 下的 37.3% 提升至同一骨干模型上的 55.5%；按任务组合的 Harness Primitives 将 Terminal-Bench 2.0 Pass@1 从种子执行框架的 60.0% 提升至 72.2%；Tool Primitives 将 ToolBench 通过率从 55.8% 提升至 75.1%；Navigation Primitives 将 GAIA-Text-103 准确率从 45.6% 提升至 58.3%。在我们 heelo.dev 平台的 46 个真实世界任务上，Claude Opus 5.5 配合 Claude Code 与 GPT-6.1 Sol 配合 Codex 各自独立完成 9 个任务，而通过我们的 MCP 服务器连接 HEELO 后分别完成 39 个和 35 个，每个已完成任务的耗时分别减少 1.9 倍和 2.3 倍，成本降低 1.55 倍。

## Actor, Judge, or Teacher? Understanding Decision Models in Long-Horizon Agents

[演员、评判者还是教师？理解长程智能体中的决策模型](https://arxiv.org/abs/2611.17167)

决策模型以带类型的输出回答一个问题，例如在若干选项中以每个选项对应一个概率的方式做出选择，因此同一个模型既可以为智能体选择动作，也可以评估已经执行的动作，或为每个动作打分以通过强化学习训练策略。已有工作主要将它们作为演员 (actor) 来研究，以动作执行的好坏来评判其有用性。我们提出一个问题：一个动作执行很差的决策模型是否仍能很好地教学？我们在 ALFWorld 上比较了三个决策模型和三个通用大语言模型 (Large Language Model，LLM) 作为演员和评判者 (judge) 的表现，并在 ALFWorld 和 WebShop 上使用 JEV 作为教师 (teacher)。作为演员，全部六个模型都会被一个更容易的子目标拉离必须先完成的子目标。作为能看到完整轨迹的评判者，同样的模型会认可通向该子目标的步骤，并且询问每个动作是否有帮助、而非询问任务是否会成功，能够将有用动作与无用动作区分开。作为教师，JEV 将基于 GRPO 训练的 Qwen2.5-1.5B 策略在 ALFWorld 上的成功率从 72.8% 提升到 82.9%，在 WebShop 上从 56.8% 提升到 71.4%。这些结果表明，一个表现不佳的演员仍能很好地教学，因为在回合结束后评判一个动作能够揭示出行动时必须预见的后果。代码见 https://github.com/ZJU-REAL/decision-agents。
