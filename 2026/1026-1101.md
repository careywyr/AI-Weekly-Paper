## Trial by Trace: Benchmarking AI Agent Harnesses for Reliability and Failure Attribution

[Trial by Trace：面向可靠性与失败归因的 AI 智能体框架评测](https://arxiv.org/abs/2610.32285)

大语言模型 (Large Language Model，LLM) 智能体正越来越多地用于解决现实问题，其效果既取决于底层模型，也取决于支撑其运行的框架 (harness)。然而，现有基准大多关注模型能力与整体智能体表现，对智能体框架本身的评测关注有限。为弥补这一空白，我们提出 TraceTrial-Bench，将框架可靠性组织为七个组成部分，覆盖上下文、执行、治理、生命周期、可观测性、工具与验证。我们构建了 95 个专家级、面向机制的任务，并配备可执行或基于状态的真值，以支持语义等价比较，同时保留各框架的原生行为。我们设计了轨迹追踪 (Trajectory Tracing，TT) 模块以捕获智能体执行轨迹，并引入分别评估智能体表现与框架可靠性的两层评估框架。此外，我们设计多源证据获取 (Multi-source Evidence Acquisition，MEA) 模块，从智能体上下文、框架与执行环境提供证据以支持基于 LLM 的评估，并开发失败归因 (Failure Attribution，FA) 模块，通过显式机制链支持运行级归因。在 4 个框架、9 个模型与 95 个任务上，我们对 3,420 次运行进行评估，得到框架宏观平均分介于 59.8% 到 72.0%；同时有 31.1% 的运行在任务成功的同时至少未通过一项框架准则。TraceTrial-Bench 为比较智能体框架、诊断其失败，以及研究框架设计与模型行为如何交互，提供了可审计、可复现的基础。

## PDRVLA: A Vision-Language-Action Model with Physical Dynamics Representations

[PDRVLA：带物理动力学表征的视觉-语言-动作模型](https://arxiv.org/abs/2610.37381)

视觉-语言-动作 (Vision-Language-Action，VLA) 模型根据视觉观测与语言指令生成机器人动作，但其对物理动力学的理解仍然有限。视频世界模型 (video world model) 可以捕获场景动力学，但生成未来视频会给控制环引入高延迟。我们提出 PDRVLA，其轻量物理动力学模块 (Physical Dynamics Module) 从视觉-语言特征中提取物理 Token，以在无需在线视频生成的情况下条件化动作生成。该模块通过对未来 RGB、深度与光流特征的直接预测进行学习，并借助冻结的预训练视频世界模型提供辅助监督。训练完全依赖公开可用数据，并通过人到机器人合成、子任务标注以及具身思维链 (embodied chain-of-thought，ECoT) 标注进行扩展。在四个仿真基准上，PDRVLA 的成功率分别为：LIBERO 上 99.3%、LIBERO-Plus 上 89.9%、RoboTwin 2.0 上 93.6%、SimplerEnv 上 81.5%。消融实验表明世界模型监督能改善未来预测，并评估了子任务条件化、未来物体位姿监督与 ECoT 训练如何影响动作成功。

## Hy-Nomas: Towards Free-form Interactive World Generation

[Hy-Nomas：迈向自由形式的交互式世界生成](https://arxiv.org/abs/2610.36729)

交互式世界生成要求模型在多轮指令下跟随相继命令，同时保留相关历史与动作后果。我们提出 Hy-Nomas，这是一个以 8B 扩散骨干构建的视频世界模型，支持自由形式文本指令与连续相机控制，并跨越多个交互轮次。它以当前输入与缓存历史为条件，生成可变长度片段。我们的核心设计将结构化视频字幕与动作感知因果注意力对齐：描述性上下文在片段间保持可访问，而动作指令则限制在其目标时间窗口内。视觉-语言提示增强器 (Prompt Enhancer，PE) 将用户请求与多模态交互历史转化为下一片段的结构化条件。多阶段课程逐步引入因果生成、文本交互、相机控制，以及在模型生成历史上的训练，随后进行扩散蒸馏。在人工评估中，Hy-Nomas 相对现有世界模型表现更优。我们发布模型权重、代码与基准，并提供轻量适配流程，以支持交互式世界生成的可复现研究。

## Work Agents: Systems, Capabilities, and Optimization

[工作智能体：系统、能力与优化](https://arxiv.org/abs/2610.35845)

随着基础模型从信息生成演进到数字工作执行，智能体正越来越能够跨工具、应用与工作流完成复杂任务。然而，现有研究缺乏关于智能体如何可靠完成被委托工作的统一视角。为弥补这一空白，我们提出以工作为中心、系统层面的视角，将工作智能体 (work agent) 视为由基础模型与运行时框架 (harness) 组成的系统，在有状态工作区中执行任务并交付可验证结果。我们引入工作持续性 (work persistence) 与工作开放性 (work openness) 两个互补维度来刻画工作条件，并根据任务范围与组织方式将数字工作划分为五种形态。基于该框架，我们识别可靠工作执行所需的五类核心能力族，并考察模型优化、框架优化及其联合优化的方法。我们进一步从工作结果视角分析现有评估方法与指标。最后，我们讨论未来研究方向，包括持续工作委托、对开放环境的适应，以及工作执行与能力提升之间的交互。本文为理解、优化与评估工作智能体提供了统一框架，以支持能够交付可靠、可验证且具有实际价值的工作结果的系统发展。

## OmniShowcase: Omnidirectional Subject-Consistent Video Generation from Multi-View Images

[OmniShowcase：从多视角图像生成全向主体一致视频](https://arxiv.org/abs/2610.35684)

在仅有少量参考图像时，为特定主体生成视频仍然困难，尤其当相机揭示输入中不可见的表面时。早期主体到视频 (subject-to-video，S2V) 方法以单张参考图像为条件，因此必须在视角变化时推断主体未见的外观与几何。为解决这一局限，近期方法将 S2V 扩展到多个参考视角，从不同视点提供更多主体信息。然而，它们并未显式指定连接这些观测的三维结构。此外，现有训练数据也不能保证视角变化仍对应同一底层三维主体。我们提出 OmniShowcase，由两部分构成：(i) 全自动数据合成流水线，沿多样相机轨迹生成训练视频，视角变化由底层主体几何驱动，甚至覆盖完整 360 度环绕；(ii) 几何条件化方法，向视频模型提供由参考视角重建的表面法线图转台，且无需与生成帧在时间上对齐。我们构建 Showcase-4K，这是一个基于三维资产的视频语料，覆盖十二种相机运动、88 种轨迹配置，并配有重建得到的表面法线条件；以及 ShowcaseBench，一个留出评估集，包含渲染每段视频所用的源网格与相机参数。实验表明，该方法在保持有竞争力的视频质量与运动的同时，取得最先进的主体身份与三维一致性。项目页：justin4ai.github.io/OmniShowcase。

## Efficient Streaming Audio-Visual Target Speaker Extraction for Real-World Acoustic Scenes

[面向真实声学场景的高效流式音视频目标说话人提取](https://arxiv.org/abs/2610.32749)

流式音视频目标说话人提取 (audio-visual target speaker extraction，AVTSE) 对延迟敏感应用至关重要。然而，当前因果系统面临两个相互耦合的缺口。第一，标准基准将说话人数量固定为两人，并忽略真实场景中的近场/远场干扰、混响与突发噪声。第二，高性能因果架构对边缘部署过重。轻量替代方案试图通过反复调用小型分离器来挽回容量，这又抵消了节省。为解决第一个缺口，我们发布 RealSSA，一个现实的 AVTSE 基准，包含 RealSSA-Sim 与 RealSSA-Real。RealSSA-Sim 提供可控仿真场景，含 1--5 个动态近场干扰说话人；带远场干扰的场景额外包含 10--15 个远场干扰说话人。RealSSA-Real 提供留出的真实录制评估集。为解决第二个缺口，我们提出 Falcon，一种因果 AVTSE 方法。其 Separator 在单次编码器-解码器过程中完成多尺度时频分离。我们用编码器空间说话人对比损失训练 Falcon。该损失以零推理成本抑制近场泄漏，并可跨骨干迁移。Falcon 在 RealSSA-Sim、LRS2-2Mix、LRS3-2Mix 与 VoxCeleb2-2Mix 上达到最先进提取质量。相对因果 AV-TFGridNet 基线，参数减少 91.9%，计算量降低 20.2 倍，GPU 推理延迟降低 11.1 倍。代码与演示见 https://cslikai.cn/Falcon/。

## StreamVibe: Proactive Video Agents for Evolving User Intent

[StreamVibe：面向演化用户意图的主动式视频智能体](https://arxiv.org/abs/2610.34662)

视觉语言模型正从离线被动理解转向在线主动交互。然而，现有方法大多依赖显式请求，而忽视隐含用户意图 (例如用户浏览网站时「下一步该点哪里？」)，并且无法在用户意图演化时持续更新理解。这些局限使其不太适合真实场景中的意图感知交互。为应对这些挑战，我们提出 StreamVibe-Bench，一个用于用户意图理解与交互的新基准，包含 4.1K 评估样本与 85K 训练样本，覆盖显式、隐式与动态意图。基于该基准，我们开发 StreamVibe-VL，这是一个流式主动模型，可从连续观测推断隐含用户意图，并随意图演化动态调整交互。我们进一步提出 StreamVibe-Harness，通过层次化记忆将用户意图维护为具有灵活生命周期的持久状态，从而跟踪最新用户意图与环境状态。实验揭示三点关键发现：(i) StreamVibe-VL 在保持强通用视频理解能力的同时，相对现有基线将响应时机与回答质量提升 10.7%；(ii) 现有主动模型在理解用户意图与决定何时响应方面仍有局限，尤其在隐式与动态意图下；(iii) StreamVibe-Harness 进一步改善持续交互中的响应一致性与适应性，使主动交互性能再提升 12.3%。

## Look Only When Needed: Certificate-Guided Visual Routing for Efficient Diffusion VLMs

[只在需要时看：面向高效扩散视觉语言模型的证书引导视觉路由](https://arxiv.org/abs/2610.36671)

扩散视觉语言模型 (diffusion vision-language model，DVLM) 在每一步去噪都会处理全部输入。由于在我们研究的基准上视觉 Token 占输入的 89-97%，大部分解码计算都花在反复处理同一张图像上。视觉 Token 剪枝方法通过去掉部分视觉 Token 部分缓解了这一负担，但会丢失被移除的信息，并且仍在每一步处理剩余图像。为衡量图像实际被需要的频率，我们在每一步解码比较 LLaDA-V 有无图像时的预测，发现去掉图像平均仅在 22.8% 的步骤改变正在被解掩的 Token，最少可低至 7.9%。因此我们提出 LOWN，一种在每一步决定是否处理图像以及解掩多少 Token 的解码方法。LOWN 在不使用图像时预测被掩 Token，仅当该预测与上一次有图像条件的预测不一致时才处理图像。一致则认证较早预测可复用，认证 Token 数量决定该步解掩多少。我们进一步观察到不同基准对图像的需求不同，因此需要 LOWN 的自适应决策而非固定调度。在无需训练或调阈的情况下，LOWN 在十个基准上保留 LLaDA-V 99.6% 的分数，平均仅用 35.3% 的解码 FLOPs。LOWN 也在基于 LLaDA 的 DVLM 上泛化，可与视觉 Token 剪枝正交组合，并在键值缓存下运行以进一步提效。代码与项目页见 https://hyeon9698.github.io/LOWN/。

## DynaFlow: Learning Free-Form Multi-Agent Orchestration

[DynaFlow：学习自由形式的多智能体编排](https://arxiv.org/abs/2610.34467)

多智能体系统常依赖预定义协作结构，限制了其适应多样任务需求的能力。我们提出 DynaFlow，一个将自由形式可执行工作流综合纳入主智能体动作空间的框架。智能体决定何时需要协作，并生成任务特定程序，通过串行或并行执行、结构化信息交换与验证来协调子智能体。执行结果与轨迹为后续动作提供信息，使智能体能在推理推进时调整协作。我们仅通过在蒸馏轨迹上的监督微调训练主智能体，随后在过滤掉不支持前提、有偏验证与信息流缺陷的样本上进一步精炼。所有子智能体保持固定，从而将编排学习与执行器能力提升分离。在覆盖数学推理、科学问答与多跳检索的六个基准上，DynaFlow 在 Forced 模式下达到 88.08% 的总体准确率，在相同 Qwen3.5-27B 骨干下相对最强评估基线高出 10.90 个百分点。工作流分析发现，训练后对上游输出的显式使用、验证与精炼更多，凸显跨阶段信息流是多智能体编排的关键维度。

## Memory Tax: Dissecting the Net Value of Agent Memory

[记忆税：剖析智能体记忆的净价值](https://arxiv.org/abs/2610.34073)

记忆正越来越多地用于长程智能体，但相对直接从原始历史检索，构建记忆的净价值在很大程度上仍不清楚。通过跨多个基准与模型骨干的大规模评估，我们发现许多专用记忆系统在很多情形下不如朴素 RAG，表明净价值为负。以 RAG 为参照，我们将记忆净价值拆解为相对直接检索的收益与损失，分别称为记忆收益 (memory benefit) 与记忆税 (memory tax)。这些收益与损失之所以产生，是因为记忆过程改变了原始信息的组织与访问方式。我们将此类变化视为相对原始历史的双刃偏差。它们最初被设计并引入是为了有利于任务，例如重组事实或蒸馏偏好，但有些也可能移除或遮蔽证据，从而产生记忆税。由于记忆收益反映其设计的预期收益，我们随后更关注被忽视的记忆税，研究其如何从系统与评估两侧产生，并将该概念推广到更多记忆应用场景。我们希望记忆税这一概念提供新视角，把更多注意力从孤立性能转向记忆净价值，从而指导更可靠的记忆设计与评估。我们将向社区开源代码与结果。项目页：https://hexuan21.github.io/MemoryTax/。

## HABIT-Bench: Evaluating Habit Induction from Longitudinal Weak Evidence in Agent Memory

[HABIT-Bench：评估智能体记忆从纵向弱证据中归纳习惯](https://arxiv.org/abs/2610.24520)

在与大语言模型 (LLM) 智能体的长期交互中，用户通过选择与行动暴露习惯。这些习惯捕获智能体必须跨对话推断的隐含用户信息。然而，单次观测可能只提供关于某习惯或其适用时机的部分证据。仅保留过往交互并不能保证智能体能推断习惯并恰当应用。我们提出 HABIT-Bench，评估智能体记忆系统从弱证据中推断习惯并将其应用于后续请求的能力。我们从面向任务的对话数据与受控习惯图构建合成用户历史。这些历史跨越数百个会话，覆盖餐饮、金融、软件与出行。四选一任务评估智能体推断用户习惯并恰当应用的能力，包括临时例外、习惯变化，以及用户尚未接受的建议。抽样任务经过独立人工审阅。我们用 Qwen3-235B-A22B 与 GLM-5.3-Flash 评估八种记忆方法。表现最好的记忆方法在四个领域上的宏观准确率为 33.61%。即便直接提供带标注证据，性能仍然有限。这些结果暴露了「能访问过往交互」与「能推断并恰当使用用户习惯」之间的持续差距。

## Rollback: Experience Backtracking in World Models for Policy Improvement

[Rollback：在世界模型中回溯经验以改进策略](https://arxiv.org/abs/2610.36068)

以动作为条件的世界模型为改进机器人策略提供了相对昂贵真实交互的可扩展替代。然而，现有基于世界模型的方法大多将世界模型当作物理环境的仅前向替代，留下了真实环境所不具备的能力未被利用：回退到过去的决策点以探索反事实未来。我们提出 Rollback，一种策略改进范式，将世界模型从被动模拟器转变为反事实引擎：回退到关键决策点，分支到替代动作，并对比其结果，从而将成功归因到单个决策。这将想象集中在最重要之处，并把反事实结果蒸馏为细粒度、动作级监督，而无需单独学习的价值模型。我们构建可扩展训练系统，统一分布式世界模型搜索与异步真实机器人执行，形成自我强化循环：真实世界经验持续打磨世界模型，更锋利的世界模型反过来驱动进一步策略改进。我们将该循环中世界模型一侧称为测试时物理落地 (test-time physics grounding)，这是手工物理仿真器所缺乏的能力：世界模型作为训练环境，而其训练出的策略所产生的真实转移，通过轻量 LoRA 流水线校正其动力学。在三项具有挑战性的真实任务上的实验表明，Rollback 相对最强基线的成功率绝对提升分别为：积木提取 10.67%、抛球 11.11%、桌面冰壶 11.85%，并在整个训练过程中取得更稳定的改进。尽管从远低于人类水平的遥操作示范初始化，Rollback 在 8 小时训练内在抛球与桌面冰壶上超过了人类玩家的平均成功率。

## ChronoReplay: One Answer Interface Is Not Enough for Streaming Spatial Intelligence

[ChronoReplay：流式空间智能不能只靠一种答案接口](https://arxiv.org/abs/2610.34283)

训练空间视觉语言模型 (spatial VLM) 回答物体在哪一侧，并不要求其保留决定该答案的度量位移；而对距离估计的监督又可能使类别关系大体不受约束。当后训练强调某一种读出时，改进可能集中在该接口上，而对其他接口的迁移仍很弱甚至退化；我们将这种观察到的特化称为接口锁定 (interface lock-in)。ChronoReplay 通过将异质空间监督按时间顺序重放为情节、保留源原生目标，并在各家族间平衡监督来应对这一问题。在相同观测访问下，单个 ChronoReplay 检查点同时提升 OVO-S-Bench、OST-Bench 与 UCS-Bench，其中 OST-Bench 提升 13.41 分，并在本文比较的监督设置中取得最高的三基准均值。同数据控制实验进一步分离该迁移的要素：答案序列化会在 OST 与 UCS 间重新分配收益，家族均衡学习优于普通联合 SFT 与自然轮次加权，时间顺序重放相对移位顺序对照在两个成对种子上高出约 2.41 个 OST 分。自适应帧选择随后在固定训练模型的情况下改变证据访问，以更低视觉成本提供额外推理时增益。流式空间性能取决于监督保留了哪些区分、学习时如何组织异质历史，以及测试时推理使哪些因果证据可用。

## InteractiveWorld: A Verifiable Human-Centric Environment for Building Better Interactive MLLM Assistants

[InteractiveWorld：面向更好交互式多模态大模型助手的可验证以人为中心环境](https://arxiv.org/abs/2610.33966)

人们长期梦想有一个随时引导自己、提醒遗忘事项的助手，从新菜肴到丢失的钥匙。在可穿戴设备上的第一人称 AI 助手由多模态大语言模型 (multimodal large language model，MLLM) 驱动，正使这一梦想变得可及：它们看见用户所见，并在必要时为用户的体力工作给出指令。然而，测试此类协助具有挑战性，通常需要真人参与。昂贵且稀缺的真实交互数据留下一个关键问题：当今的 MLLM 真能在物理世界中帮助人吗？为回答这一问题，我们提出 InteractiveWorld，首个用于人与 AI 助手闭环交互的可验证环境。与现有以机器人为中心的仿真器不同，InteractiveWorld 让助手引导一个观察场景、理解指令并独立行动的人类智能体。它因此真实模拟 AI 助手与人类如何协作：助手发指令，人类行动，环境执行动作并更新他们接下来所见。基于此，我们提出 InteractiveBench，首个面向第一人称 AI 助手的动态基准，含六类共 120 个多轮任务。在每个任务中，助手实时引导人类，每条指令都会塑造结果，并由可验证、基于状态的奖励打分。对 12 个前沿 MLLM 的实验表明它们仍远非可靠助手。即便最强模型 Claude Fable 5.1，在长程 Guidance 与 Planning 任务上分别最多仅达 20% 与 25%。总体而言，我们的工作提供了可验证平台与严格评估集，为真正能在物理世界中帮助人的交互式 MLLM 助手研究奠定坚实基础。

## Youtu-Parsing-Omni: One Encoder, One Schema, All Modalities

[Youtu-Parsing-Omni：一个编码器、一种模式、全模态](https://arxiv.org/abs/2610.39301)

我们提出 Youtu-Parsing-Omni，一个全模态解析器，将文档、图像、音频与视频转化为锚定于空间与时间的结构化记录，为跨模态阅读、定位与引用证据的智能体提供感知层。其设计建立在「每种模态一个编码器、每项任务一种模式」之上。Youtu-Omni-Encoder 从预训练语言模型初始化以强化文本阅读，在统一时空坐标系中用共享权重编码所有模态；少量融合层让视频帧关注并发音频，从而把跨模态融合与时间对齐纳入感知本身。OmniSchema 统一全部十项解析任务的输出，使单一自演化后训练过程——模式感知的同策略蒸馏 (OmniSchema-Aware On-Policy Distillation，OSAD)——能跨任务提供共享的基于 Token 角色的目标。每一轮中，模型在其自身 rollout 上相对来自参考条件化自身副本的 Token 级目标进行训练，随后用训练后的权重刷新该副本，从而使解析器与其监督共同演化。仅用一个 5B 参数检查点，Youtu-Parsing-Omni 在 OmniDocBench v1.6 上达到最先进表现 (Overall 96.96)，并在 OmniParsingBench 上领先所有开源权重模型 (Avg. 75.08)，优势集中在音频与视频。它还取得最佳总体图表解析分数 (95.02) 以及比较系统中最高的精确化学指纹一致率，并在排版乐谱的字符级转录上匹配专用光学音乐模型，同时远超通用系统。代码与模型权重已公开。

## TAO: Tool-Aware Joint Scheduling for LLM-Based Agentic Serving

[TAO：面向基于大语言模型智能体服务的工具感知联合调度](https://arxiv.org/abs/2610.37230)

智能体服务在集群 GPU 上的模型推理与分布式 CPU 上的外部工具之间交替进行。在此场景下，现有系统 (1) 在服务评估中忽视工具返回就绪性，浪费有限资源；(2) 用启发式策略决定 GPU 上的准入与放置，导致次优调度决策。为弥补这一缺口，我们提出 TAO，一个面向基于大语言模型 (LLM) 智能体服务的工具感知联合调度框架。其价值接口结合近期工具就绪性、带时间衰减的节点特定缓存信用，以及 Token 足迹；动态规划在容量约束下联合选择并放置等待中的会话。在所报告的 12 组模型-工作负载-并发设置中，相对各项指标下评估的最佳现有基线，TAO 将延迟最多降低 26.8%，将平均首 Token 时间 (mean time to first token，TTFT) 最多降低 36.3%，并将解码吞吐最多提高 29.5%。

## A-RSI: Adaptive Task Refresh for Zero-Data Multimodal Self-Improvement

[A-RSI：面向零数据多模态自我改进的自适应任务刷新](https://arxiv.org/abs/2610.38568)

递归自我改进 (recursive self-improvement) 不仅要求模型获取有用训练经验，还要决定当前经验何时不再有用。现有方法常关注下一步生成何种经验，而对何时应引入新鲜经验关注较少。许多方法还通过自洽或多数投票构造训练目标，使监督依赖模型自身不确定的预测。我们将这两个问题分开处理：训练动态决定何时获取新经验，而新任务的答案保持可独立核验。A-RSI 监控训练日志中的奖励变化与准确率，在学习信号下降时刷新任务池，且不查阅验证或测试分数。由模型编写的程序构成的静态库生成多模态问题并推导参考答案；我们规定任务生成契约，自动验证奖励与刷新规则的选定性质，并单独审计生成答案。训练循环不使用外部训练样本或人工编写的答案标签。在主要十一基准套件上，A-RSI 用 800 个新鲜任务将性能平均分从 57.77 提升到 61.05。

## UserArena: Benchmarking Interactive User Simulation for Long-Horizon Shopping Agents

[UserArena：面向长程购物智能体的交互式用户仿真评测](https://arxiv.org/abs/2610.30932)

智能体推荐通过一系列依赖上下文的决策追求购物者目标。开发与评估此类策略需要忠实的推荐世界模型，以捕获交互式购物环境以及用户在长交互中的行为响应。现有资源很少提供长程、细粒度的真实用户轨迹，也很少支持轨迹级评估以及相对生产 A/B 结果的离线验证。我们提出 UserArena，一个真实电商交互基准，包含来自 11,010 名用户的 64,729 条会话轨迹，覆盖 566,102 个商品与 13 种动作类型。UserArena 将这些轨迹与交互环境配对，并支持相对受控生产 A/B 测试结果的离线验证，从而启用从输出有效性与局部决策到序列行为、个性化与结果的五级评估。为提升这些长程交互上的仿真器保真度，我们进一步提出同策略轨迹蒸馏 (On-Policy Trajectory Distillation，OPTD)，用轨迹级意图在学生生成的 rollout 上提供稠密教师目标。实验表明，在 UserArena 评估协议下，OPTD 在所评估仿真器中取得最强总体保真度，并在离线仿真中最接近复现生产策略效应。

## ThinkWorld: World Imagination Reinforces Chain-of-Dynamics Reasoning

[ThinkWorld：世界想象强化动力学链推理](https://arxiv.org/abs/2610.37666)

视觉-语言-动作 (Vision-Language-Action，VLA) 模型在机器人操作上取得了实质性进展，但其泛化仍受带动作标注的机器人示范的多样性与覆盖所限。人类视频提供了更广阔的行为与环境经验，而从中学习则面临可扩展数据与显式动作落地之间的根本权衡。我们提出 ThinkWorld，一个将动作推理落地于世界动力学，并通过带世界想象的强化学习加以强化的 VLA 学习框架。ThinkWorld 将每个动作思考表示为动力学链 (Chain-of-Dynamics，CoD)，即一串捕获连接当前世界与未来状态的中间动力学的离散运动 Token，并作为跨本体的共同动作表示。我们先用带动作标注的示范初始化 CoD，再预测每个 CoD 所诱导的未来，并强化那些预测更匹配观测结果的 CoD。这使得无动作标注的视频能从观测到的状态转移提供直接监督，从而让人类与机器人经验共同精炼同一推理空间。仿真与真实机器人实验表明，该方法实现了有效的人到机器人迁移，并对未见任务与环境具有强泛化。

## Proving and Improving the Platonic Representation Hypothesis with JEPAs

[用 JEPA 证明并改进柏拉图表征假说](https://arxiv.org/abs/2610.39302)

在不同模态上训练的模型是否收敛到同一世界表征，是人工智能的核心问题。柏拉图表征假说 (Platonic Representation Hypothesis，PRH) 猜想它们会随规模扩大而如此，但若无证明，则既无保证也无配方。我们将该假说变成定理。第一，我们证明柏拉图表征定理 (Platonic Representation Theorem)：在任意数量模态上分别训练的联合嵌入预测架构 (Joint-Embedding Predictive Architecture，JEPA)，只要其正样本对是同一场景的两次观测——即好视角 (good views)——且否则其失准有界，就会学到相差至多一个旋转的同一表征。第二，我们表明下一 Token 预测是带坏视角 (bad views)——即同一文档的片段——的 JEPA，这解释了为何语言模型仅通过规模才与视觉对齐。第三，我们从 14.5 万条字幕到 9.40 亿网络图像的文本验证该理论，并发现可在种子噪声内预测未见运行的对齐缩放律。相对同一语料上的下一 Token 预测，好视角达到相同对齐所需训练样本少 42 倍；一个 1.09 亿参数的文本 JEPA 与 DINOv2 及 CLIP 图像编码器的对齐，优于我们评估的所有最高达 720 亿参数的语言模型，也优于 CLIP 文本编码器：下一 Token 预测是通往柏拉图表征的显著低效路径。作为展示，一次旋转即可将分别训练的编码器变为图像描述器 (COCO 上 CIDEr 0.838)。即便该旋转也不需要配对：在最新无配对基准上，我们的文本 JEPA 击败所有最高达 80 亿参数语言模型报告的零样本准确率，例如 ImageNet-100 上 top-5 为 64%，而对方最多 56%。因此，正视角而非单靠规模，才是构建柏拉图表征的杠杆。

## When Agents Fail: Model or Harness--Who's to Blame?

[当智能体失败时：该怪模型还是框架？](https://arxiv.org/abs/2610.32483)

大语言模型 (LLM) 智能体将模型与执行框架 (harness) 相结合，因此智能体基准表现反映的是二者的联合行为。我们认为，框架因此应通过其与底层模型的交互来评估。我们提出一个结合五项互补度量的框架：(i) 有效完成率 (Valid Completion Rate，VCR)，衡量智能体无论任务正误如何，正常结束并交付可评估结果的可靠程度；(ii) 模型-框架契合 (Model-Harness Fit)，衡量给定模型下框架通过有效完成支持任务达成的程度；(iii) 跨模型契合 (Cross-Model Fit)，衡量框架在所评估模型上的总体适宜性；(iv) 交互残差 (Interaction Residuals)，揭示被组件级摘要掩盖的配对特定执行强弱；(v) Token 负载 (Token Load)，衡量智能体执行 (含失败尝试) 的 Token 需求。我们在六个覆盖上下文管理、工具使用、长上下文规划、多模态交互与产物交接的基准上，评估四个通用框架 (OpenCode、Codex CLI、Pi CLI 与 DeepAgents) 与四个核心模型，外加两个固定的原生模型-框架系统。计入原生参照与压力条件，111 个评估设置产生 52,168 条轨迹。框架排名随模型与基准变化；任务表现与有效完成可能偏好不同配对，相似任务分数可伴随截然不同的执行画像。OpenCode 在跨模型表现上排名第一，而 DeepSeek V4 Flash Preview 在共享四基准面板上跨框架保持一贯较高的平均 VCR。这些发现支持评估模型-框架交互、在模型中训练可迁移的框架使用能力，以及针对模型与任务适配的框架设计。

## SWE-Shift: Evaluating Coding Agents in Evolving Workspaces

[SWE-Shift：在演化工作区中评估编程智能体](https://arxiv.org/abs/2610.32196)

仓库级编程基准大多假设任务与环境在整个执行过程中保持不变。在软件开发中，代码、依赖、运行时状态与需求可能在智能体仍在工作时发生变化。我们提出 SWE-Shift，一个在此类执行中途变化下评估编程智能体的基准。从同一保存的历史与工作区出发，干净延续 (Clean continuation) 不进行干预，而匹配的偏移延续 (Shifted continuation) 会收到与任务相关的更新。成功要求完成当前任务、保留仍然有效的工作，并满足适用的状态与证据检查。该基准包含跨 12 个变化家族的 120 个场景，每个场景在九个预定干预位置上评估。我们评估了 17 个编程智能体系统，其偏移成功率均低于干净成功率。GPT-6 Astra 从 67.35% 降至 24.79%，成对成功率为 20.34%。工具/会话变化与陈旧证据在所有系统上的成对成功率均为零。晚位置成对成功率对某些系统更低、对另一些更高。这些结果表明，在未变化任务上的成功可以与更新后无法保留工作、恢复状态或刷新证据的失败并存。

## Rethinking Verification in Agent Harnesses

[重新思考智能体框架中的验证](https://arxiv.org/abs/2610.34577)

智能体框架 (agent harness) 使大语言模型能通过工具行动、观察结果，并迭代推进任务目标。验证检查并修订智能体的工作以提高输出质量。然而，关于框架应如何组织这一努力的指导仍然有限。我们将验证作为测试时扩展 (test-time scaling) 的一个轴来研究，考察何时介入、由谁检查工作，以及检查如何导向修订。我们的框架横跨智能体生命周期的四层：初始指令、中途提醒、完成门控与独立审查。我们在 Terminal-Bench (TB) 与 SWE-bench Verified (SWE) 上跨七个前沿编程模型比较 17 种设计，并引入 VisualBench，用于对视觉与交互产物进行专家评估。初始指令与执行时提醒在编程基准上带来适度、依赖模型的平均收益，且不明显增加平均输出 Token 用量。完成门控可带来更大收益，但可能显著增加成本。由评判者进行的独立审查提供了更有利的准确率-成本权衡：在 TB 上将平均准确率提升 5.9-9.5 个百分点，在 SWE 上提升 3.9-6.6 个百分点，成本分别为基线的 1.13-1.25 倍与 1.00-1.04 倍。在 VisualBench 上，独立审查相对基线在四种设计上取得 13.2-23.8 分的净偏好，超过所评估的 L0-L2 设计。额外审查轮次或独立评判者可再将平均 TB 准确率最多提升 3.5 个百分点。综合来看，这些结果为智能体框架中的验证设计提供了经验指导，并支持将独立审查作为测试时扩展的实用轴。

## Your Policy Is Secretly a Harness: The Decision Geometry of Agent Interfaces

[你的策略其实是一套框架：智能体接口的决策几何](https://arxiv.org/abs/2610.37255)

语言模型智能体通过框架 (harness)——向模型呈现任务并执行其输出的提示、工具与控制逻辑——进行后训练与部署。框架常被修改，并依据已训练模型在其下的表现来评判，这假定模型在一个框架下学到的内容可迁移到下一个。我们追问策略从其框架中学到了什么，以及框架改变时什么得以保留。在 KL 正则化控制下，我们表明最优策略的对数几率恢复了其框架对每个动作相对其他动作的偏好强度，因此训练得到的策略携带其框架的偏好。部署回报于是等于框架上限 (harness ceiling，其提供的最佳回报) 减去策略失配 (policy mismatch，因自身次优决策损失的回报)。训练只改变失配，而更换框架会同时移动两项。用固定模型比较框架因此会把各框架所提供的与该模型对其利用得好坏混在一起。在 MiniWoB++ 上，后训练使模型偏好特化于其训练框架。反转观测字段顺序并不改变任何最优决策，却将已训练模型的成功率从 85.0% 降到 19.2%。反之，每个被固定模型比较拒绝、但抬高上限的新框架，在其下继续训练后都优于原智能体，且事先测得的上限与失配可预测这些收益。对 Terminal-Bench Lite 上的编程智能体框架，用更强模型作为最优近似估计的「上限减失配」可复现准确率排名，而单独任一项则不能。代码见 https://github.com/2020-qqtcg/HRP。

## The Trinity: Capability-Driven Recursive Self-Improvement for Multimodal Agents

[The Trinity：面向多模态智能体的能力驱动递归自我改进](https://arxiv.org/abs/2610.36077)

多模态智能可视为在交互中由人类引导的世界与智能体共同演化。然而，扩展这一过程面临两个瓶颈：构建异质、可验证环境成本高昂，而手工迭代框架 (Harness) 无法跟上日益增长的任务多样性与复杂性。一个关键洞见是，不同模态与表面形式的任务可以共享相同的底层能力需求。因此我们提出 The Trinity，一个通过三个角色——Creator、Explorer 与 Evolver——将世界生成与框架演化耦合的递归自我改进框架。基于已验证的执行轨迹，Evolver 将任务组织的基础从表面类别转向共享需求，把原始任务树重组为层次化能力树。我们提出能力驱动的 Real2Sim2Real：对同一节点上的异质任务，Creator 将其共同需求抽象为用于能力学习的简化、可验证仿真世界，而在原始任务上的评估衡量迁移。沿该能力树，Explorer 通过选择性继承逐步演化可复用能力模块，形成在固定拓扑内跨迭代累积经验证更新的框架树。所得框架专精不同能力，从而催生能力感知框架路由器 (Capability-Aware Harness Router)，利用公开任务信息从树中选择兼容的模块配置。我们演化出的框架在 28 个训练基准上将平均表现提升 34 分，在 18 个未见基准 (含两项真实具身任务) 上提升 26 分。

## WorkFactory: Turning Professional Intents into Executable Work for Scalable Agent Training

[WorkFactory：将职业意图转化为可执行工作以规模化智能体训练](https://arxiv.org/abs/2610.37161)

扩展工作智能体的监督训练需要能产生可靠专家示范的多样职业任务。然而，缺失或不一致的任务信息会阻碍教师执行并削弱所得监督。我们提出 WorkFactory，一个用于构建连贯且可执行职业任务的可扩展框架。从职业意图出发，信息级规划构建信息支撑图以指导任务实例化，显式表示目标输出所需信息的依赖与位置。探测执行随后识别支撑失败并指导修复，同时保留预期工作。我们构建覆盖 612 种职业的 112,686 个任务，并用收集的教师轨迹在 4B、27B 与 35B-A3B 规模上微调 Qwen 模型，得到 WorkPilot 系列。三个模型在四个职业工作基准上均相对各自基座提升，其中 WorkPilot-35B-A3B 在 GDPval-AA v2.1 上将 Elo 从 879 提升到 1565。缩放分析揭示依赖模型的收益递减，执行长度先增后减。受控组件分析表明，规划与修复减少由探测诊断的任务环境缺陷，并改善下游表现。数据与模型见 https://github.com/IQuestLab/WorkFactory。

## WebAnything: From the Wild Web to Scalable Agent Environments

[WebAnything：从野生网页到可扩展智能体环境](https://arxiv.org/abs/2610.37786)

网页智能体需要多样、可执行且可重置的网站环境，以进行可复现的训练与评估。人工辅助镜像需要按站工程化，而生成式构建可能偏离指定的真实网站。捕获-回放保留观测，但交互覆盖受捕获内容与回放能力约束。我们提出 WebAnything，一个全自动框架，在初始搭建与授权后，无需按站手工实现或修复，即可从真实 URL 重建有源依据、可复用的网页环境。Explorer-Builder 收集浏览器可观测结构、资源与交互结果；独立验证器检查冻结候选并指导局部修复或针对性源再捕获。我们构建跨 14 个应用领域、53 个类别的 244 个网站产物，支持 12,984 个已执行并被接受的任务。相对人工辅助的 WebHarbor，WebAnything 在三项保真度指标的总分上更高，在盲审中取得 12 胜、2 平、0 负。在固定框架下，用 5,856 条交互轨迹微调 Qwen3.5-9B，将 REAL 成功率提升 9.9 个百分点，将 Odysseys-Easy 的 Rubric Avg 与 Task Avg 分别提升 6.25 与 6.32 个百分点，并将 WebArena-Verified Overall 成功率提升 13.33 个百分点。代码：https://github.com/china-qijizhifeng/Web-Anything。

## Prefix Executability: Evaluating Tool-Using Agents Beyond Final Success

[前缀可执行性：超越最终成功评估工具使用智能体](https://arxiv.org/abs/2610.40444)

工具使用基准常按最终任务成功给智能体打分，但终局结果可能掩盖中间工具调用轨迹是否可执行。我们提出前缀可执行性 (prefix executability)，作为面向工具使用智能体的轨迹级评估协议。该协议衡量预测工具调用序列的每个前缀是否在工具模式、状态前置条件与数据依赖下仍可执行，并用前缀可执行性曲线 (Prefix Executability Curve，PEC)、首次错误深度 (First-Error Depth，FED)、轨迹可执行率 (Trajectory Executability Rate，TER)、视界归一化 AUC-PEC 以及恢复率 (Recovery Rate，RR) 总结可靠性。我们在 BFCL-v3 多轮与 ToolSandbox 的分层样本上，以及 τ³-bench 的完整 Airline/Retail 基础划分上实例化该协议。我们观察到仅看结果与前缀级排名会发生分歧：执行以未经验证的计划为条件的智能体，点估计最终成功率常高于非计划条件基线，却大幅降低 TER 与 AUC-PEC。这些分歧正是前缀可执行性旨在暴露的失败模式：它们揭示表面上的成功是否建立在可执行轨迹上、无效性首次进入何处，以及成功是否来自对更早失败的恢复。作为验证干预，显式的执行前计划检查可在保持有竞争力终局成功的同时改善可执行前缀存活。这些结果表明，仅靠最终成功不足以评估工具使用智能体，而前缀级可执行性为比较智能体、诊断失败与评估验证机制提供了可操作的可靠性信号。

## Matched Capabilities, Different Behaviors: A Controlled Study of MCP and CLI Interfaces for Language Agents

[能力匹配、行为不同：面向语言智能体的 MCP 与 CLI 接口受控研究](https://arxiv.org/abs/2610.34298)

语言智能体越来越多地通过外部工具与交互环境行动，使模型与其可执行能力之间的接口成为决策过程的一部分。模型上下文协议 (Model Context Protocol，MCP) 与命令行接口 (command-line interface，CLI) 可通过显著不同的面向模型表示暴露相同语义操作。我们研究在可执行能力匹配时，这些表示差异是否会改变智能体行为。我们提出匹配接口比较与分析 (Matched Interface Comparison and Analysis，MICA)，它从共享语义动作契约渲染 MCP 与 CLI，并将解码动作路由到同一运行时。跨六个模型与三个交互环境，匹配接口在任务表现与交互成本上产生显著差异。这些效应超出表面有效性，延伸到语义动作选择、失败路径与恢复。匹配状态探针将敏感性定位到能力呈现、实现与反馈。成对自然轨迹在 2,004 个情节中的 94.3% 揭示结构化分歧，并表明早期差异会通过后续交互传播。该分析将接口实现识别为直接干预边界。因此我们提出解耦动作实现与定向修复 (Decoupled Action Realization and Targeted Repair，DART)，在修复接口特定实现的同时保留已验证的语义承诺。DART 在全部六个评估设置上将基准分数最多提升 9.0 分，并在全部三个环境上将 MCP Token 成本每任务最多降低 27.1k。综合来看，这些结果将接口表示确立为塑造智能体行为的闭环决策环境的一部分。

## Continual Learning Exam: Benchmarking Long-Horizon RSI and Experiential Learning in LLM Agents

[持续学习考试：评测大语言模型智能体的长程递归自我改进与经验学习](https://arxiv.org/abs/2610.33956)

持续学习是大语言模型 (LLM) 智能体通过从经验中获取、精炼并应用知识，同时保留有用先验知识，从而随时间改进的能力。它对长时程学习的智能体至关重要，但当前评估大多衡量单项任务表现，而非通过累积经验实现的改进。我们提出持续学习考试 (Continual Learning Exam，CLE)，这是由 50 多名领域专家开发的大规模基准，用于衡量现实职业工作流中的经验驱动改进。CLE 包含 120 个人工编写任务，每个任务组织为五级阶梯，共 600 级，覆盖 12 个职业领域中的 89 个专业角色。智能体必须通过每一级才能解锁下一级，后续级别建立在更早任务中累积的经验之上。评估智能体依据人工编写量规对每次提交打分。我们将单次提交设置与失败后提供诊断反馈并允许一次修订的设置进行比较。在使用前沿 LLM 的 17 种框架-模型配置上，反馈与修订带来中位完成率提升 5.3 个百分点。然而，表现最好的系统仅通过 47.7% 的级别，并仅在 23.3% 的任务中完成全部五级，凸显现有前沿 LLM 从经验中持续学习的困难。因此，该数据集也可用于后训练 LLM，以强化其持续学习能力。
