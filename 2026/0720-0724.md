## TimeLens2: Generalist Video Temporal Grounding with Multimodal LLMs

[TimeLens2：基于多模态大语言模型的通用视频时间定位](https://arxiv.org/abs/2607.17423)

视频多模态大语言模型（MLLM）能够描述视频中发生了什么，但很少能识别支持性证据发生的时间。我们研究通用视频时间定位（generalist video temporal grounding），即单个模型能够跨视频长度、领域、查询形式和视角预测一组可变基数的证据区间。现有训练策略与此集合值任务不匹配：长视频标签通常依赖脆弱的一次性标注，而强化学习奖励要么无法区分不重叠的预测，要么需要脆弱的片段匹配。TimeLens2 在整个监督和优化过程中将时间证据视为区间集合。TimeLens2-93K 通过基于字幕的提议、独立定位、跨智能体共识、语义验证和边界细化构建可靠的多跨度监督。我们的时间 Wasserstein 奖励计算合并区间支撑上均匀分布之间的一维 \(W_1\) 距离，在不等基数和等效碎片化条件下提供密集且无需匹配的反馈；时间 IoU 则通过精确重叠反馈进行补充。在七个基准上，TimeLens2-2B 在每个基准上都优于所有同等规模基线，而 4B 和 8B 变体达到了最先进性能，超越了参数高达 397B 的开源模型。2B、4B 和 8B 变体分别在其 Qwen3-VL 骨干上提升了 14.2、13.0 和 18.1 mIoU 点。

## RAGU: A Multi-Step GraphRAG Engine with a Compact Domain-Adapted LLM

[RAGU：一种采用紧凑型领域自适应大语言模型的多步图检索增强生成引擎](https://arxiv.org/abs/2607.11683)

图检索增强生成（GraphRAG）通过结构化知识增强大语言模型，但现有系统在单次提取中构建知识图谱，产生噪音实体和脆弱检索。RAGU，一个开源模块化GraphRAG引擎，通过将提取与合并分离来解决此问题：实体和关系经过两阶段类型化提取、DBSCAN 支持的去重、LLM 摘要和 Leiden 社区检测。一个关键洞见是：流水线内 LLM 所需的技能——理解、提取、基于上下文的推理——是语言技能，这些技能随模型规模增长很弱，不同于事实性世界知识。因此，我们训练了 Meno-Lite-0.1，一个针对语言技能优化的 7B 模型，它在知识图谱构建上优于 Qwen2.5-32B（相对调和平均数 +12.5%），并在英文 GraphRAG 任务上与之持平。在 GraphRAG-Bench（医疗领域）上，RAGU 在每级事实性上检索到最完整的上下文（证据召回高达 0.84 vs ≤0.76），并在综合任务上超越 HippoRAG2；多跳事实性问答中，HippoRAG2 的明显优势被证明主要是答案格式的假象。RAGU 可通过 pip install graph_ragu 安装，在单 GPU 上运行，并以 MIT 许可发布。源代码公开在 https://github.com/RaguTeam/RAGU，Meno-Lite-0.1 模型可从 https://huggingface.co/bond005/meno-lite-0.1 获取。

技能是软件智能体的一种有用抽象，能够将人类和智能体的经验转化为可复用的过程性知识。然而，现有的技能库大多为手工编写、以文本为中心或从智能体轨迹中派生，导致教程视频和其他多模态人类资源未被充分利用。我们提出 RESOURCE2SKILL 框架，该框架将多模态资源（包括教程视频、代码仓库、文章和参考制品）提炼为软件智能体的可执行技能。RESOURCE2SKILL 将这些技能组织为层级化的多模态技能百科（Skill Wiki），其中每个条目结合了结构化文本、代码、可视化示例、元数据和来源信息。这种设计保留了来自不同资源的互补信号：视频捕捉时序操作和可视化效果，代码捕捉可执行的工具模式，文章或制品提供概念和风格基础。在推理时，智能体从百科中检索并组合相关技能；当覆盖不足时，同一构建算子可在线获取新技能。在七个实际创作领域中，RESOURCE2SKILL 相比无技能智能体平均总得分提升 11.9 个百分点，并在 28 个主聚合模型-领域单元中优于强 harness 基线。消融实验证实了多模态技能格式、层级化组织、来源多样性、选择策略和在线获取的价值。

## AREX: Towards a Recursively Self-Improving Agent for Deep Research

[AREX：面向深度研究的递归自改进智能体](https://arxiv.org/abs/2607.21461)

深度研究要求智能体找到同时满足多个约束的答案。发现这类答案代价高昂，而验证候选答案往往可以分解为易于处理的逐约束检查。这种发现-验证的不对称性表明，研究智能体不应仅仅延长搜索时间，而应递归地改进其当前答案：通过验证中间结果，并利用部分验证的状态来引导后续优化。我们提出了 AREX，一类递归自改进（Recursively Self-Improving, RSI）深度研究智能体。AREX 交替执行内部研究循环（收集证据并构建暂定答案）和外部自改进循环（逐约束审计答案、识别未解决的主张、发起有针对性的后续研究）。为了支持长视界的 RSI，AREX 学习了一个自主的上下文更新工具，该工具将不断增长的交互历史压缩为紧凑的改进状态，其中保留已验证的证据和未解决的约束，无需依赖外部模型。我们通过智能体中间训练和长视界强化学习，在已验证的合成任务和高质量轨迹上训练 AREX。为了缓解长视界学习中稀疏的最终奖励问题，我们强调了关键步骤，即获取决定性证据或纠正错误研究方向时的步骤。我们实例化了密集 4B 模型和 122B-A10B 混合专家模型。在 BrowseComp、WideSearch、DeepSearchQA、人类最后的考试（HLE）以及其他推理和工具使用基准上，AREX 大幅优于同等规模的基线，并且与使用更多激活参数的模型保持竞争力。

## Generative World Renderer at the Speed of Play

[以游戏运行速度实现的生成式世界渲染器](https://arxiv.org/abs/2607.18703)

## SWE-Pruner Pro: The Coder LLM Already Knows What to Prune

[SWE-Pruner Pro：编码 LLM 已经知道该剪枝什么](https://arxiv.org/abs/2607.18213)

对代码 Agent 的长上下文进行剪枝，是高效上下文管理的关键技术。现有方法如 SWE-Pruner 通过附加独立的代码分类器来实现，但我们发现 Agent 自身在读取工具输出时，会编码指示代码上下文相关性的内部表示。基于这一发现，我们提出 SWE-Pruner Pro，直接在 Agent 内部剪枝工具输出。具体而言，一个小型头部网络将 Agent 自身的内部表示转化为每行的保留/剪枝标签，并结合与每个工具输出行数相关的长度感知嵌入。在两个开放权重基座和四个多轮基准测试上，SWE-Pruner Pro 在保持任务质量的同时，节省了最多 39% 的提示与完成 Token，且推理开销有限。值得注意的是，在 MiMo-V2-Flash 上，SWE-Pruner Pro 还将 SWE-Bench Verified 解决率提升了 +3.8%，长上下文 Oolong 准确率提升了 +2.2 个百分点。

## Text Template Tokens Are Implicit Semantic Registers in Diffusion Transformers

[文本模板Token是扩散Transformer中的隐式语义寄存器](https://arxiv.org/abs/2607.19139)

文本到图像扩散Transformer（DiTs）联合处理文本和图像token，但其在去噪过程中的内部计算仍不甚明了。我们为现代大规模DiTs引入了一个因果可解释性框架，该框架结合了注意力分解与跨token跨度、注意力头和层的目标干预。利用该框架将提示内容token与结构模板token分离，我们发现结构token在编码器输出中几乎不携带特定于提示的信息。但令人惊讶的是，它们成为主要的图像到文本注意力汇（attention sinks），并在DiT内部因果性地维护对象身份，充当隐式语义寄存器（implicit semantic registers）。我们表明，它们是通过间接方式获取这一身份的：提示语义首先注入到图像潜变量中，然后被读回模板token，而不是直接从提示token传递过来。受上述发现启发，我们为DiTs设计了一种无需训练的剪枝规则。对提示token关注最强的注意力头是可去除的，剪枝它们可消除20%的注意力FLOPs，而GenEval仅下降1.4个点。我们进一步揭示了DiTs中的生成计算如何跨注意力头和深度进行组织，将语义路由与视觉合成分离，并从身份形成逐步演进到传播和细化。我们的工作不仅揭示了输入时编码语义的token未必是在生成过程中维护语义的token，还为DiTs的内部机制提供了因果视角。

## Loop the Loopies!

[循环循环！](https://arxiv.org/abs/2607.16051)

我们提出了Loopie，这是迄今为止最强大的循环Transformer。Loopie系列包含两个混合专家（MoE）模型：一个200亿参数模型（20亿活跃参数）和一个60亿参数模型（6亿活跃参数）。循环Transformer长期以来面临一个挑战：若预训练计算量增加N倍，通常将参数数量扩大N倍比将模型循环N轮效果更好。Loopie解决了这一难题。大量消融实验（包括与普通30B-A3B模型的对比）表明，Loopie显著优于使用相同计算预算训练的普通Transformer基线。我们新颖的训练后流程赋予了Loopie强大的推理能力。在2025年国际数学奥林匹克（IMO）和国际物理奥林匹克（IPhO）中，Loopie无需工具即可达到金牌水平。

## xHC: Expanded Hyper-Connections

[xHC：扩展超连接](https://arxiv.org/abs/2607.14530)

超连接（Hyper-Connections，HC）将 Transformer 的残差流扩展为 N 个并行流，提供了一种超越模型宽度和深度的记忆缩放方式。流形约束超连接（mHC）在较大规模下稳定了该结构。从 N=1 到 N=4 的显著增益表明残差流扩展是一个有前景的缩放轴。然而，现有 HC 族方法通常止步于 N=4。我们的实验揭示了原因：超出此点的 mHC 缩放会导致性能增益递减且训练成本急剧上升。我们将此限制归因于两个瓶颈：针对不断增加的流数量的写回信息不足，以及残差混合生成的计算成本随 N 呈立方增长。为解决这两个瓶颈，我们提出了 xHC（扩展超连接），这是首个在 N>4 时实现有意义扩展的 HC 族方法。xHC 结合了时间特征增强以实现更丰富的写回，以及稀疏残差流架构——该架构仅更新 N=16 个流中的 k=4 个，同时保留对完整残差状态的密集访问。在 18B 和 28B 的 MoE 模型上，xHC 带来了强劲且一致的下游改进。在 18B MoE 模型上，xHC 相比 mHC 将平均下游得分提升了 4.0 分，同时相较基准仅增加了适度的训练 FLOPs。缩放定律实验表明，为达到相同损失，vanilla 和 mHC 所需的计算量分别是 xHC 的 1.50 倍和 1.19 倍。实际大 N 训练还需要控制扩展残差状态带来的内存流量。因此，我们引入了 xHC-Flash，它将每子层内存流量从 73.5C 降低到 40C，与 mHC 在 N=4 时所需的 34C 相当，同时保留了完整 xHC 的增益。xHC 与 xHC-Flash 共同使大 N 残差流扩展在 LLM 预训练中变得高效且实用。

## AlayaWorld: Interactive Long-Horizon World Modeling -- Full Technical Report

[AlayaWorld：交互式长程世界建模——完整技术报告](https://arxiv.org/abs/2607.18367)

与传统视频游戏开发依赖劳动密集型资产制作、动画、物理和编程管线不同，视频世界模型（video world models）能从用户输入即刻生成可交互环境，使我们能够通过文本、单张图像或视频创建定制化、可探索且持续演变的虚拟世界。实现这一愿景需要四个紧密耦合的能力：交互、持久时空一致性、稳定的长程生成以及高效响应。我们提出了 AlayaWorld，一个交互式长程视频世界模型，可生成 540p 和 720p 分辨率、24fps 的视频。基于 15B 参数的视频扩散 Transformer（video diffusion transformer），AlayaWorld 在相机轨迹和可切换文本提示下自回归地生成短潜变量块（latent chunks）。其有界视觉上下文结合了持久 sink 帧、压缩时序历史、几何对齐的空间记忆以及最近帧条件化。为减少长期漂移，模型使用从自身 rollout 中收集的损坏历史和预测残差进行训练。我们进一步引入了一种离散自回归蒸馏方法，结合了分布匹配蒸馏（distribution-matching distillation）、self-forcing++ 和一致性蒸馏，将每块的推理从约 30 步采样减少到 4 步。在 iWorld-Bench 上，AlayaWorld 在长程生成任务中取得了最佳性能。作为全栈、开源且长期的项目，AlayaWorld 旨在为未来交互式视频世界模型研究提供可扩展的基础。

## ReferTrack: Referring Then Tracking for Embodied Visual Tracking

[ReferTrack：先指代后跟踪的具身视觉跟踪](https://arxiv.org/abs/2607.20061)

具身视觉跟踪要求移动 Agent 仅凭借机载视觉持续跟随一个自然语言描述的特定目标。尽管最近的视觉-语言-动作（VLA）策略统一了目标识别和轨迹规划，但其链式思维（CoT）推理往往在抽象的空间隐变量中运作，难以监督且与显式的图像空间检测结果对齐薄弱。为此，我们提出 ReferTrack，一种先指代后跟踪的范式，利用单前向摄像头将 EVT 锚定于图像空间。模型首先从索引化的边界框集合中选出目标，然后基于这一图像层面的决策解码跟踪航点。为保留目标的运动时序线索，ReferTrack 维护一个滑动窗口队列，存储之前选中的边界框，并通过时序-视角-边界框指示器（TVBI）令牌将其几何特征注入视觉历史。我们还通过在自定义的 Refer-QA 数据集上进行联合训练来增强目标识别能力。在 EVT-Bench 上，ReferTrack 实现了单视角最佳性能：单目标、干扰和歧义跟踪分支的成功率分别达到 89.4%、73.3% 和 74.1%，在识别密集型任务上匹配甚至超越了若干多摄像头基线。最后，在四足和人形机器人上的实际部署验证了其鲁棒的仿真到现实迁移能力。代码开源于 https://github.com/MedlarTea/referTrack。

## FlowMimic: Mask-free Visual Editing and Generation with Pixel-pair Warped Flow Field for Online Video Editing Data Generation and Modality Mimicry

[FlowMimic: 基于像素对扭曲流场的无掩码视觉编辑与生成——面向在线视频编辑数据生成与模态模仿](https://arxiv.org/abs/2607.18227)

遵循视觉研究的主流方向，我们探索在单一模型中集成视频和图像模态的生成与编辑能力。当前收集视频编辑数据的方法通常依赖劳动密集、耗时的整理流程——涉及对象掩码标注、通过I2V模型和类ControlNet引导引入误差的配对合成，以及基于VLM的质量过滤或精炼——且任务可扩展性有限。因此，编辑任务的多样性远不及图像编辑模型。我们开发了一种像素对时间扭曲流场（pixel-pair temporal warped flow field），可直接从图像编辑样本实时生成对应的视频编辑样本，并在多个层次的视频编辑任务上证明，模型仅凭此类数据即可学习视频编辑。我们将图像模态视为视频模态的特殊形式。据此，我们设计了模态模仿生成损失（modality mimic generation loss）和模态模仿编辑损失（modality mimic editing loss），通过相互模仿来相对对齐两种模态的能力，进而对齐其输出分布。此外，基于语言的视觉编辑需要理解编辑指令和参考视觉内容，定位参考视觉内容中与指令对应的区域，并仅修改该区域。现有方法主要依赖外部辅助，例如在推理时微调额外的MLLM或显式提供掩码序列作为辅助输入。相比之下，我们希望模型内化这一能力。为此，我们引入了感知相关任务（例如指代表达分割）以及对应的编辑区域感知潜在层损失和注意力层损失。
