## RealCompanion: Benchmarking Human Understanding from Reasoning over Longitudinal Real-World Conversations

[RealCompanion：基于纵向真实世界对话推理的人类理解基准测试](https://arxiv.org/abs/2610.01780)

一个与某人交谈数月的伴侣应当逐渐理解对方。它应当记住他们说过的话，推断他们是谁，并知道过去何时与眼前的消息相关。测试这一点需要真实人物的记录，而此类记录是私密的，因此基准会生成人物和问题，并预先确定哪些内容重要。我们发布这一基准，收录了十段用户与 AI 伴侣之间的真实交往记录：长达 120 天内的 27,218 条消息，以对话以及由对话衍生的四个文件形式发布，即个人资料（profile）、人格画像（persona）、聊天真实标签（chat ground truth）和问题集（question set），每个文件都引用其所依据的消息。每个聊天标签都带有产生它的推理轨迹，并逐阶段对照对话进行检查。由此得出三个发现。第一，需要调用历史信息的情形很少，而且所需信息往往距当前消息很远。汇总指标会产生误导：近期窗口能为 95.9% 的探针找到所需消息，而对于需要记忆的探针，这一比例仅为 2.2%；按此类情形在真实对话中的自然占比计算，提供历史记录证据所带来增益的 96% 来自不需要记忆的消息。第二，我们尝试的所有检测器都无法判断真实消息何时需要记忆，基于相同历史人工编写的问题会泄漏这一线索，而将相同消息标注为记忆会使其使用率提高 10 到 14 个百分点。第三，三个 Agent 系统重建人格画像时取得了相同的 F1 分数，但成本相差 31 倍。

## Rethinking Cross-Tokenizer On-Policy Distillation: From Alignment Coverage to Supervision Reliability

[重新思考跨 Tokenizer 的在线策略蒸馏：从对齐覆盖到监督可靠性](https://arxiv.org/abs/2610.08448)

在线策略蒸馏（On-Policy Distillation, OPD）让学生模型利用教师反馈在自身生成的文本上进行训练。当师生模型使用不同的 tokenizer 时，比较教师与学生的预测需要在序列和词表两个层面进行对齐。本文考察扩大这种对齐覆盖范围是否能提升学习效果。在数学推理和代码生成任务上的三组异构师生配对中，尽管词表差异显著，严格的 1:1 对齐分组已经覆盖了学生生成的绝大部分 token。在蒸馏前从学生模型采样的回答上，平均而言，共享词表在严格对齐位置保留了几乎全部教师和学生的概率质量。将反向 KL 限制在每个严格对齐位置上由学生选出的共享词表 top-16 子集，其准确率与完整的共享词表 OPD 相当，并优于所评估的跨 tokenizer 基线。在不匹配分组中对 span 对数概率施加均方误差监督可实现完整的监督覆盖，然而却降低了准确率。在仅使用严格损失训练得到的检查点上，span 梯度与严格梯度的方向一致性较弱甚至为负，且其幅度相对于严格梯度不断增大。这些诊断结果或有助于解释加入 span 监督后准确率下降的现象。我们的发现支持一种转变：从最大化对齐覆盖转向优先保证监督可靠性——在严格位置上的紧凑监督，可能比引入弱对齐或相互冲突训练信号的更广覆盖更为有效。

## AgentGarten: Code Worlds for Evolving Agents

[AgentGarten：面向进化型 Agent 的代码世界](https://arxiv.org/abs/2610.12374)

交互式虚拟世界让 Agent 能够通过探索与交互进行学习。但 Agent 能学到什么，受限于它所练习的环境，而这些环境必须同时具备忠实性（faithful）——即拥有一致的状态、规则与动力学，以及真实性（realistic）——即观测遵循真实世界的视觉分布。在多样化的世界中同时实现这两点仍是一个瓶颈。我们提出 AgentGarten，一个将模拟器与游戏引擎同共享神经渲染器（neural renderer）耦合起来的框架，用于构建实时交互式环境。其仿真后端维护持久化的世界状态并执行由程序定义的交互规则，而渲染器则基于通过统一接口导出的结构化条件生成视觉观测。为构建该神经渲染器，我们将预训练视频模型适配到几何条件上，用我们提出的 Adversarial Forcing 对其进行蒸馏，并针对实时交互优化推理。Adversarial Forcing 通过精确重放（exact replay）使 history prefilling 变得可微，从而让后续预测上的损失能够更新渲染器对先前观测的编码方式，并加入真实数据上的对抗监督以提升其视觉质量。在 AgentGarten 中，Agent 通过视觉观测感知世界、与其实时交互，并通过将每一轮经验蒸馏为 playbook（策略手册）来改进自身，后续 Agent 会继承并进一步完善这些 playbook。我们的实证研究展示了学习效率的大幅提升：Agent 仅需 4 轮即可完成学习，而传统 RL 对照方法则需要数百万轮。由于新世界可以以代码形式编写并通过同一接口渲染，环境的数量与难度都能与其 Agent 一同扩展，这是朝着让 Agent 通过交互经验持续进化迈出的一步。

## Kandinsky 6.0 Video: Foundation Models for Synchronized Video and Audio Generation

[Kandinsky 6.0 Video：同步视频与音频生成的基础模型](https://arxiv.org/abs/2610.05608)

我们提出 Kandinsky 6.0 Video，这是一个用于同步文本到音视频生成的基础扩散模型系列，包含 Kandinsky 6.0 Video Lite（30 亿参数）和 Kandinsky 6.0 Video Pro（290 亿参数）。两个模型均可生成 5 秒视频片段，并配有同步的 44 kHz 音频（包括唇形同步），支持文本到音视频（T2AV）和图像到音视频（I2AV）两种模式；内置的超分辨率模型可将输出分辨率提升至全高清（1920×1080）。在 Kandinsky 5.0 视频生成能力的基础上，Kandinsky 6.0 Video 采用双流 CrossDiT 架构，通过双向交叉注意力连接预训练的视频流和新训练的音频流，以实现时序和语义对齐。我们的连续预训练策略首先在大规模音频语料上从零训练音频流，然后在成对的音视频数据上联合训练两个流，同时保持单模态保真度；预训练之后依次进行监督微调、基于强化学习的后训练和蒸馏。在并排人工评估中，Kandinsky 6.0 Video Pro 明显优于其前代 Kandinsky 5.0 Video Pro，并与领先的音视频生成模型保持竞争力，尤其在语音质量方面。为加速多媒体生成领域的开放研究与部署，我们以 MIT 许可证发布了代码、模型检查点和 diffusers 集成。

## Self-Retrospection Distillation: Turning Post-hoc Experiences into Prior Foresight

[自回溯蒸馏：将事后经验转化为事前预见力](https://arxiv.org/abs/2610.08077)

基于可验证奖励的强化学习（RLVR）主要通过交互后得到的标量结果奖励，将智能体经验转化为学习信号。然而对于组相对（group-relative）目标而言，当同一组内所有 rollout 获得相同奖励时，这一信号便会消失，尽管这些轨迹可能揭示了关于任务要求以及智能体如何失败的有用信息。我们提出一个互补的问题：事后之明能否教会智能体它在行动之前本可预见什么？我们引入前瞻式学习（prospective learning），利用事后经验来监督从交互前视角出发的预见预测，并以自回溯蒸馏（Self-Retrospection Distillation，SRD）将其实例化。直观地说，一条已完成的轨迹揭示了本可发挥作用的知识以及应当避免的陷阱；SRD 将这种特权性的后见之明蒸馏为同一策略的、与轨迹无关的预见。预见仅作为训练目标，在推理时无需显式生成。在 10 项工具集成推理与长时程智能体任务上，SRD 与 RLVR 及自蒸馏基线形成互补，最高带来 24.2 个百分点的提升。其优势在奖励对比稀缺时尤为显著：在模型各规模下 37%–98% 的 rollout 组奖励一致，而 SRD 仍能利用采样轨迹中的学习信号。在 2B 规模的设定中，98% 的组为全失败，RLVR 训练最终仅达到 0.0% 成功率，而在相同 rollout 预算下加入 SRD 可达到 60.6%。我们的结果表明，事后智能体经验不仅可用于评估或改进行为，还可用于在可用的交互发生之前塑造预测性表征。

## UltraText Bench: A Comprehensive Bilingual Benchmark for Evaluating Visual Text Rendering in Image Generation

[UltraText Bench：用于评估图像生成中视觉文本渲染的综合双语基准](https://arxiv.org/abs/2610.09823)

密集视觉文本要求图像生成器在多个区域内复现长字符串，并保证正确的位置与可读性。随着短字符串渲染能力的提升，评测必须进一步考察模型在更高难度场景下的持续表现。我们提出 UltraText Bench，一个面向纯提示词生成密集视觉文本的双语基准。它包含 432 条提示词，覆盖 24 个真实世界场景类别和三个难度等级，中英文各占一半。每条经人工审核的提示词都给出四到十二个文本区域的精确字符串，并配有描述其内容、位置与视觉属性的结构化参考。我们使用 Q-Judger 视觉语言模型（VLM）将每张生成图像与完整参考进行比对，报告文本保真度、文本清晰度、空间质量和场景质量四项指标。在 24 种模型配置上，这些维度揭示出不同的优势取向：在所述设置下，Z-Image-Turbo 相比 Z-Image-Base 在清晰度上提升 3.81 分，但保真度下降 14.76 分。性能也随工作负载而变化；Qwen-Image-2512 的英文综合得分从 L1 的 86.50 降至 L3 的 42.86。十名参与者参加了对自动评分的的人工评估。代码仓库：https://github.com/LINs-lab/UltraText_Bench。

## LoGRA: Scaling LLM Reinforcement Learning with Low-Rank Gradient Sketches

[LoGRA：以低秩梯度草图扩展 LLM 强化学习](https://arxiv.org/abs/2610.06647)

强化学习（RL）极大提升了大语言模型（LLM）的能力，但其内存需求仍阻碍着更广泛的应用。我们提出 LoGRA，一种 RL 后训练方法，通过将有用的学习信号保留在低秩梯度草图（low-rank gradient sketches）中来降低内存占用。这些紧凑表示同时支持模型更新与高效的策略同步。为防止过大的更新破坏学习过程，我们在梯度压缩之外引入了预测 KL 步长控制（predicted-KL step control），它在每次更新前估计策略变化并据此调整更新幅度。在各类推理任务上，LoGRA 在不损失性能的前提下将平均训练内存降低最多 45.7%。它还使一个 27B 参数模型能够在单个八 GPU 节点上稳定训练超过 1,100 步，而稠密 Adam 在此场景下会耗尽内存，从而使此前因内存限制而不可行的 RL 训练变得切实可行。代码见 https://github.com/skzhang1/labs-molt/tree/logra/examples/scripts/logra（Molt 库）。

## Learn2Play Bench: How Well Do LLM Agents Learn from Experience in Unfamiliar Environments?

[Learn2Play Bench：LLM Agent 在陌生环境中的经验学习能力如何？](https://arxiv.org/abs/2610.08215)

从经验中学习是 LLM Agent 适应陌生且动态环境的关键能力。因此，评估这一能力对于理解 Agent 如何有效获取和使用新知识十分重要。已有基准尝试评估该能力，但它们主要评估规则已在指令中给出、或对预训练模型而言已熟悉的游戏，因而难以区分基于交互的学习与基于已有知识的推理。为解决这一问题，我们提出 Learn2Play Bench，一个由新设计的文本游戏组成的基准，其规则新颖或反直觉，要求 Agent 通过交互获取知识，而非仅依赖预训练知识。这些游戏提供可复现的反馈和自动评分，支持在多次重复尝试中对学习进行受控评估。我们还变换游戏实例，以测试 Agent 能否将所学应用到新情境。基于此，我们评估了基座模型、自演化方法和 Agent harness 对 Agent 学习能力的影响，并揭示了三项发现：（1）经验留存：保留动作与反馈的完整记录，比将这些经验总结为规则或策略更能支持有效学习。（2）人机差距：表现最佳的人类玩家达到的峰值分数高于所评估的 Agent；人类探索更多样的策略，重复动作更少。（3）Harness 很重要：在基座模型固定的情况下，改变 harness 既能提升性能，又能降低估计推理成本。这些发现共同揭示了 LLM Agent 如何从经验中学习，并为未来提升其学习能力指明了方向。项目网站：https://liushiliushi.github.io/learn2play-bench-website/

## TokenRouter: Efficient Serving System for Token-Level LLM Routing

[TokenRouter：面向 Token 级 LLM 路由的高效服务系统](https://arxiv.org/abs/2610.12242)

大语言模型（LLM）路由将推理工作分配到不同模型之上，从而推进 LLM 服务的成本—质量帕累托前沿（Pareto frontier）。尽管会话级或查询级的粗粒度路由已在生产系统中被广泛采用，但近期的算法工作表明，细粒度的 Token 级路由能够带来显著的效率与质量收益。然而，高效地服务 Token 级路由推理对现有系统提出了重大挑战。当前系统建立在单 LLM 假设之上，在 Token 级路由下会遭遇严重的步调失同步（step desynchronization）与频繁的批次准入延迟，同时还给开发者带来了很高的实现复杂度。为应对这些挑战，我们设计了 TokenRouter，一个高效且对开发者友好的 Token 级路由 LLM 推理服务系统。TokenRouter 遵循“以请求为中心编程、以模型为中心执行”的原则：开发者从单个请求的视角描述路由逻辑，而运行时为每个 LLM 启动一个子服务器（subserver）并异步分发请求。每个子服务器采用延迟批处理（delayed-batching）调度器，其最优超参数由系统的数学吞吐模型推导得出。在多种路由算法、工作负载和模型组合下，TokenRouter 的解码吞吐量比现有系统高出 2.01–64.15 倍，大幅提升了 Token 级 LLM 路由的服务效率。我们的代码可在 https://github.com/thu-nics/TokenRouter 获取。

## FrameMorrow: Future-guided Frame Selection with Prospective Tokens for Long-Horizon Video Generation

[FrameMorrow：面向长时程视频生成、由未来引导的帧选择与前瞻性 Token](https://arxiv.org/abs/2609.38839)

长时程视频生成要求模型能够有效利用不断增长的生成历史。随着生成历史变长，保留全部此前内容会变得越来越昂贵且冗余，因此高效的历史选择至关重要。现有方法通常基于当前内容来判断历史相关性。然而，与当前相关的信息未必对未来生成有用，而看似相关性较低的历史可能在之后变得重要。本文的核心洞见是：历史信息应当依据其与未来信息需求的相关性来进行选择。捕捉这些需求并不需要生成完整的未来；相反，一个关于“接下来什么会变重要”的紧凑表示，就足以引导历史选择。基于这一洞见，我们提出 FrameMorrow，一种前瞻性帧选择器（prospective frame selector）：它预测一小组代表未来信息需求的前瞻性 Token，并利用它们从历史中识别相关信息。FrameMorrow 选择的是显式的历史帧，而非特定于模型的内部状态，因此可以即插即用地集成到多种生成器中，包括闭源模型，且额外推理成本很小。我们在五个基准测试和 11 个生成模型上评估 FrameMorrow，涵盖长视频生成、交互式生成以及动作条件世界模型（action-conditioned world models）。大量实验表明，在多种生成设置下，长程一致性、视觉质量和动作对齐均获得了一致提升。

## STEPQuant: When and Where Errors Matter in Delta-Rule Recurrent State Quantization

[STEPQuant：Delta 规则循环状态量化中误差何时与何处更重要](https://arxiv.org/abs/2609.38169)

线性注意力（Linear Attention）用固定大小的循环状态取代不断增长的 KV 缓存，但在并发服务场景下，这些持久状态可能成为显著的内存瓶颈。直接将循环状态量化到低精度往往会导致严重的精度下降，因为量化误差会随着连续的状态更新而传播。我们发现，这些误差的影响取决于两个互补的维度：在时间维度上，长期存活记忆中的误差会跨越许多解码步骤持续存在；在空间维度上，不同 key 行的误差对模型输出的影响不同，而状态幅值在行和列两个方向上都存在显著差异。基于这些观察，我们提出 STEPQuant，一个面向 Delta 规则循环状态的时空后训练量化（PTQ）框架。STEPQuant 根据误差幅值和记忆生命周期分配精度，并基于状态分布以及 key 行对输出误差的影响，联合拟合 key 行与 value 列的缩放因子。在 Qwen3.8-27B 和 Kimi-Linear-48B-A3B-Instruct 上、覆盖长生成与短生成基准的实验表明，STEPQuant 在标称 6-bit 预算下能够接近 FP32 状态的精度，并且在其 4-bit 配置下优于均匀 INT8。将其集成到 SGLang 并配合优化的 GPU kernel 后，6-bit STEPQuant 实现了超过 5 倍的循环状态压缩，并将总服务内存最多降低 68.7%。我们的代码开源在 https://github.com/Dreamer-Toby/STEPQuant。

## MotorMind: Scaffolding General Vision Language Models for Zero-Shot Robot Manipulation

[MotorMind：为通用视觉语言模型搭建脚手架以实现零样本机器人操作](https://arxiv.org/abs/2609.38078)

视觉-语言-动作（VLA）模型推动了机器人操作的发展，但其在新任务与新环境中的零样本泛化能力仍然有限，且对专门训练的依赖使其无法直接受益于快速进步的通用视觉语言模型（VLM）。与此同时，近期一些智能体式机器人系统借助 VLM 进行高层推理，或使用编程智能体（coding agent）进行机器人控制，但往往依赖大量外部模型与工具，带来额外的复杂性与成本。这促使我们提出一个问题：通用 VLM 本身能否更像人类远程操作员那样操控机器人——直接基于观测进行推理、发出动作，并持续适应执行反馈，而不依赖外部模型，例如学习到的动作专家、编程智能体，或 SAM3 之类的定位（grounding）工具？在这项工作中，我们提出 MotorMind，一种机器人操作执行框架（harness），将 VLM 提出的中层动作连接到确定性的机器人控制与反馈，并配有异步监控与后台记忆更新。无需任务特定的策略训练、编程智能体或 SAM3 等额外定位工具，MotorMind 在基础 LIBERO-PRO 套件上取得 66.7% 的成功率，在扰动条件下取得 53.8%，而我们评估的先前零样本方法分别最高仅为 13.3% 和 19.2%。同一接口在真实 xArm6 机器人上，在直接操作与人类扰动两种设置下平均成功率达到 95%。将骨干模型替换为更强的 VLM 可进一步提升性能，而剩余失败——主要源于视觉定位、具身推理与动作知识——会随着 VLM 能力的提升而减少。这些结果表明，通用 VLM 在配备合适的中层动作表示与异步执行框架后，能够实现有效的零样本机器人操作。

## From Traces to Agentic Worlds: Agentic Language World Models for Interactive Environment Simulation

[从交互轨迹到 Agentic 世界：面向交互式环境模拟的 Agentic 语言世界模型](https://arxiv.org/abs/2610.06100)

逼真的环境副本在训练与评估 LLM Agent 方面正变得越来越有价值，但原始系统可能无法访问，或难以复现。我们探索了 Agentic 语言世界建模（agentic language world modeling）：不再重建可执行环境，而是由一个世界模型 Agent 充当任务 Agent 的环境，并支持忠实且具有状态的模拟。我们以 Trace2Env 实例化这一范式——这是一个免训练框架，适用于原始系统不可用、但历史交互轨迹仍可获取的场景。Trace2Env 将这些轨迹重建为可复用的环境世界手册（worldbook），其中包含环境 schema、有依据的证据以及归纳出的行为知识。在运行时，世界模型 Agent 会主动查阅世界手册，并结合持久化的情节状态（episodic state），推断每个动作所产生的观测以及持久的状态影响。在九个环境中，Trace2Env 在下一观测保真度与长时程交互一致性两方面均优于传统基于提示的 LWM。在多轮交互中，针对 Trace2Env 生成的任务 Agent 动作在真实环境中重放时保持有效的比例更高，这表明其模拟动力学能更好地在连续多轮中保留先前动作带来的后果。这些结果确立了 Agentic 语言世界建模作为一条替代路径，可在不重建原始可执行系统的前提下构建逼真的环境副本。

## Long-WAM: Scaling the Context of World-Action Models

[Long-WAM：扩展世界-动作模型的上下文](https://arxiv.org/abs/2610.10528)

实时机器人控制需要足够的视觉历史来推断运动与任务进展，但处理这些历史会延迟动作输出。我们提出 Long-WAM，一个在实时控制约束下扩展因果世界-动作模型（World-Action Models）上下文的模型-系统框架。我们的核心发现是：能够访问历史并不等同于真正利用历史——当视频基础模型以自回归（autoregressive, AR）方式预训练时，更长的历史带来的收益要大得多。我们首先从机器人视频和第一人称视角视频中学习因果预测，且不使用动作标签，随后在世界-动作适配过程中保留这种“历史到未来”的结构。在 RoboCasa GR-1 上，将上下文从 0.0 秒增加到 19.2 秒，成功率从 63.3% 提升到 78.7%，而以双向方式预训练的初始化则没有净收益；机器人领域的 AR 预训练进一步提升了 GR-1 和 LIBERO-Long 上的峰值成功率。在 LIBERO-Long、RoboTwin 2.0 和 DOMINO 上，Long-WAM 也在所比较的方法中取得了最佳结果。流式观测编码、异步执行以及针对硬件的专门加速，使其能够在 RTX 5090、DGX Spark 和 Jetson AGX Thor 上部署，且不牺牲未来预测能力；在 RTX 5090 上，每个动作块（action chunk，包含未来视频 latent 预测）耗时 107.4 ms。在 Unitree G1 和 YAM 上的实时部署支持动态与长时程操作，包括在动态叠杯任务中达到 95% 的成功率，而 Pi0.5 和 Fast-WAM 在 20 次试验中均未成功。作为一个由记忆引导的执行器，Long-WAM 还能在复合任务中与更高层的规划相辅相成。

## Scaling Trajectories for Complex Tasks through Recursive Self-Rewrite

[通过递归自我重写扩展复杂任务的轨迹](https://arxiv.org/abs/2610.02826)

在困难任务上取得的成功轨迹为模型改进提供了宝贵的监督信号，但专用运行框架（harness）引入的干预手段在部署阶段可能无法获得。我们提出递归自我重写（Recursive Self-Rewrite，RSR）框架，使用单一基础模型 Qwen-3.8-27B，在多种运行框架下发现成功解法，并将其重建为通用运行框架下的训练轨迹。规划器（planner）将流程提取为操作手册（runbook），评论器（critic）筛查验证器与解法泄漏并指导递归修订，执行器（executor）在全新沙箱中依照合格的操作手册执行。在约 3K 条自行整理的终端任务上，三种运行框架共同解决了 759 个任务，比记录池中最强的单一运行框架多出 34.3%。RSR 将 2,001 条成功源轨迹扩展为 11,094 条重写轨迹，用于监督微调。在这些轨迹上训练的效果优于基础模型和直接轨迹 SFT。与基础模型相比，pass@3 在 Terminal-Bench 2 上从 57.0% 提升至 74.2%，在 Terminal-Bench 4 上从 1.5% 提升至 9.1%，在我们自行整理的 Terminal-Bench Hard 上从 39.0% 提升至 63.0%，在我们的 Software Terminal-Bench 上从 3.0% 提升至 6.0%。Long-Horizon Terminal-Bench 上的过程奖励从 0.21 升至 0.29。这些结果表明，多样化的运行框架辅助经验可以被重建为可复用能力，供模型在通用运行框架下使用。

## World Action Modeling with Progressive Visual Planning

[基于渐进式视觉规划的世界动作建模](https://arxiv.org/abs/2610.02508)

世界动作模型（World Action Models，WAMs）已成为机器人控制领域一种颇具前景的范式，它能够从初始观测和指令出发，联合预测未来的视觉动态与动作。然而，现有 WAMs 难以应对长时程（long-horizon）预测，因为生成密集的视频推演（video rollout）效率极低。近期一些 WAMs 通过预测单张未来帧而不生成完整视频来缓解这一问题，但这种方式忽略了如何逐步向目标推进。我们提出 ProWAM，一种渐进式世界动作模型，它联合预测动作以及一个有序的稀疏视觉子目标序列，在整个任务执行过程中提供显式的视觉引导以锚定动作生成。该设计具有天然的可扩展性：子目标预测可以从大规模无动作视频中学习，从而使视频骨干网络（video backbone）能够从动作策略中卸载复杂的视觉规划任务。为实现高效的动作生成，ProWAM 仅执行一次视频骨干网络前向传播以缓存稀疏子目标特征，从而消除了迭代式全视频生成，并在重规划（replanning）时仅需轻量级的动作去噪。在大量评估中，ProWAM 展现出卓越的分布外（out-of-distribution）鲁棒性。在仿真基准上，它在 LIBERO-Plus（85.8%）和随机化 RoboTwin（75.7%）上刷新了 SOTA 结果，相较最强基线相对提升最高达 +35.9%。在 RoboCasa365 上，ProWAM 取得 48.1% 的成功率，在颇具挑战性的 Composite-Unseen 划分上达到 18.2%，总体排名第 4。关键在于，在零样本（zero-shot）真实世界实验中，ProWAM 在新颖场景下取得 70.0% 的成功率，相较最强基线提升 +15.0（从 55.0% 提升至 70.0%，相对增益 +27.3%）。这些结果证明了按进度索引的视觉前瞻（progress-indexed visual foresight）在闭环控制中的价值。我们的项目主页为 https://sii-ferenas.github.io/ProWAM-page。

## TRACE: Rollout-Guided Quantization-Aware Training for FP4 Reinforcement Learning of MoE Language Models

[TRACE：面向 MoE 语言模型 FP4 强化学习的 Rollout 引导量化感知训练](https://arxiv.org/abs/2610.07767)

面向大语言模型（LLM）后训练的强化学习（RL）在 rollout 生成阶段会带来大量计算与内存开销，这促使人们采用低精度 rollout 以实现高效的 RL 训练。然而，现有 FP4 RL 方法存在一个关键局限：它们主要在训练路径和 rollout 路径上分别优化量化精度，而非直接缩小这两条量化执行路径之间的差异。为此，我们提出 TRACE（Train-Rollout Quantization Alignment via Compact GuidancE），一个面向混合专家（MoE）语言模型 RL 训练的 FP4 量化框架，用以解决现有 FP4 RL 方法的上述局限。TRACE 引入 rollout 引导的量化感知训练，利用 rollout 侧的量化结果来指导训练侧的 FP4 舍入决策，从而直接减小训练与 rollout 之间的差异。此外，TRACE 采用一种高效的量化信息缓存方案，选择性保留较深层的尾数和缩放（scale）信息，以降低 rollout 引导所带来的存储与通信开销。我们在四个大规模 MoE 语言模型上，跨越推理、编码和长时程 RL 任务对 TRACE 进行了评估。结果表明，TRACE 能够实现 FP4 权重/激活与 FP4 KV-cache rollout 的联合量化，其 RL 性能与 BF16 rollout 相当，同时实现最高 5.4 倍的 rollout 加速，并且相较于对 BF16 训练策略进行事后 FP4 量化，取得了显著更优的最终 FP4 性能。

## Native Action-Prior Learning from Videos for World Action Models

[从视频中学习世界动作模型的原生动作先验](https://arxiv.org/abs/2610.03391)

世界动作模型（World Action Model）将未来视觉动态与机器人动作预测相结合，但其可扩展性受限于对带动作标注的机器人轨迹数据的需求。纯观测视频（observation-only video）蕴含关于交互动态的丰富证据，但现有方法通常要么用其预训练视觉表征、之后再适配到控制任务，要么用其推断潜在动作（latent action）、再将其落地为机器人指令。我们提出 NAVA-WAM，通过直接从纯观测视频预训练动作策略来引入原生动作先验学习（native action-prior learning），避免了间接的表征到控制迁移，也无需单独的潜在动作模型。我们的训练分为两个阶段。第一阶段，在纯观测视频上预训练，其中对视觉转换的未来视频流匹配（flow-matching）监督通过转换结构化的联合注意力（transition-structured joint attention）传播，以优化 Action-DiT 并学习与动作相关的先验。第二阶段，使用带动作标注的演示数据，通过联合视频—动作流匹配对 Action-DiT 进行机器人控制后训练，同时非对称注意力（asymmetric attention）将视觉分支与迭代式动作去噪解耦，从而实现高效的仅动作推理。大量实验表明，NAVA-WAM 在分布内与分布外设置下均持续优于已有方法，同时展现出很强的动作标注效率与有效的真实机器人泛化能力。这些结果确立了原生动作先验学习是一种从纯观测视频直接预训练动作策略的有效途径，为超越带动作标注的机器人数据提供了一条可扩展的路径。

## On-Policy Parameter Update Direction Underlies Generalization in LLM Post-Training

[LLM 后训练中泛化能力背后的 On-Policy 参数更新方向](https://arxiv.org/abs/2609.36659)

On-Policy 后训练范式所展现出的强大泛化性能，促使研究者对其参数更新行为展开研究。然而，这些研究仅将观察到的行为视为 on-policy 训练中的副产品，忽视了它们作为优化原则、用以提升监督微调（SFT）等其他范式泛化能力的潜力。为弥补这一局限，我们探究是否存在某种特定的 on-policy 更新行为能够实现此类改进。首先，我们的分析揭示：SFT 沿一致的方向更新参数，而 on-policy 范式则在训练过程中持续调整更新方向。这一差异启发我们关注每个参数的累积更新方向，将其视为一种有前景的行为。随后，我们通过提出 On-Policy 方向约束的监督微调（On-Policy direction-constrained Supervised Fine-Tuning，OPSFT）来评估其在提升泛化方面的有效性；OPSFT 将 SFT 的更新约束到由 on-policy 范式所确定的方向上。OPSFT 的强劲表现表明，on-policy 范式的泛化优势可以通过参数更新方向迁移到 SFT。一旦确定了这样的方向，即便是 SFT，只要将其更新约束到该方向，也能获得良好泛化。这一发现通过将 on-policy 范式的强泛化能力与 SFT 的优势相结合，带来了两点实际收益，包括高训练效率以及利用高质量轨迹的能力。在效率方面，我们仅用少量 on-policy 训练步骤即可识别出支持强泛化的更新方向，随后应用 OPSFT 实现高训练效率。在利用高质量轨迹方面，OPSFT 可以利用这些轨迹，沿其更新方向持续改进一个已后训练的模型，而不会破坏从 on-policy 训练中学到的能力。

## Recursive Game Creator: An Agentic Product-Level Experience-Oriented Game Harness

[递归游戏创造者：面向产品级体验的 Agentic 游戏框架](https://arxiv.org/abs/2610.08621)

近期的游戏设计 Agent 在生成可玩游戏方面已取得实质性进展。然而，程序正确性并不能保证玩家获得愉快的体验。我们提出 Recursive Game Creator，一个面向体验的框架（harness），旨在推动 Agent 驱动的游戏开发从粗糙的游戏原型迈向真正有趣的游戏。Recursive Game Creator 围绕四个组件组织递归式开发：Designer（设计者）、Builder（构建者）、Player（玩家）与 Reviewer（评审者）。Designer 将用户指令与 Reviewer 的反馈转化为详细方案。Builder 将这些方案转化为候选游戏。以编程为核心的 Player 通过程序化接口创建并执行可复用策略，从而高效采集多样化的游戏玩法轨迹，缓解基于 GUI 的缓慢采集所导致的评估偏差。Reviewer 使用精心设计的基于轨迹的指标来推断玩家偏好，并结合视觉证据与显式文本偏好，依据游戏特定的标准对游戏进行评估。最后，Reviewer 接受更优版本，并为下一轮提供改进评审意见，从而闭合递归循环。我们的方法在 GameCraft-Bench 上取得 77.89 的 SOTA 综合性能。在 GameASG-Bench 上，它取得 53.2% 的严格任务成功率，相比同模型基线提升 34.1%，并在所有对比方法中取得最高的平均运行时检查通过率 93.4%。用户研究显示，玩家游玩时长更长、评分更高。代码即将发布。

## ALoDLM: Adaptively Looped Diffusion Language Models

[ALoDLM：自适应循环 Diffusion Language Model](https://arxiv.org/abs/2610.04198)

扩散语言模型（Diffusion Language Model，DLM）通过并行预测多个 Token 实现快速生成，但其实际采用仍受限于相较同等规模自回归（AR）模型持续存在的质量差距。我们将这一差距归因于计算与难度的不匹配：在部分可观测的序列中，一些未知 Token 易于预测，而另一些则需要显著更多的计算。然而，现有 DLM 在每个去噪步骤中对所有未知位置施加统一的计算深度。我们提出 ALoDLM，以 Token 自适应的隐状态循环替代统一计算。在每个去噪步骤中，ALoDLM 迭代精炼隐表示，并根据 Token 难度分配计算。已准备好提交的 Token 作为离散上下文被反馈，而未解决的 Token 则通过额外的循环传递保留并进一步精炼其隐状态。为了联合学习 Token 预测与计算分配，我们将 Token 级计算调度建模为隐变量，并推导出条件负证据下界（NELBO）。我们在 1.7B 和 8B 参数规模上训练 ALoDLM。在十一个基准上，ALoDLM 在两个规模下的平均基准得分均优于所有评估的 DLM 以及相应的 AR 基线。ALoDLM 还保留了快速并行解码能力，在优化推理引擎下，于所评估的自回归与扩散模型中实现了良好的质量—效率权衡。

## GRACE: Generation-aware latent compression for efficient video generation

[GRACE：面向高效视频生成的生成感知潜在压缩](https://arxiv.org/abs/2610.10524)

高度压缩的视频自编码器为加速视频扩散模型提供了一种有效途径，因为扩散 Transformer（DiT）只需在远更少的 Token 上运行。然而，此类自编码器训练困难：更高的压缩率会降低重建质量，而恢复质量需要更多通道，已知这会拖慢 DiT 的收敛。压缩后的潜在表示也不同于 DiT 训练时所用的潜在表示，因此预训练 DiT 必须从头重训或以较高成本进行适配。压缩 DiT 训练时所配的自编码器似乎能保持兼容性，但仅针对重建进行优化仍会使潜在表示偏离 DiT 已学到的分布。为解决这一问题，我们提出面向高效视频生成的生成感知潜在压缩（Generation-Aware Latent Compression for Efficient Video Generation，GRACE），这是一个两阶段框架，可在压缩预训练视频自编码器的同时保持其与预训练 DiT 的兼容性。具体而言，我们保留来自预训练编码器的冻结基础潜在表示，并学习一个残差潜在表示以补偿更强压缩下丢失的信息，同时在冻结 DiT 的特征空间中将压缩潜在表示与预训练潜在表示对齐，从而使自编码器针对生成进行优化。随后，我们通过轻量微调与非对称去噪来适配 DiT，其中基础部分先于残差被去噪。GRACE 在 480x832x81 下将 Wan2.1-I2V-14B 的 Token 数量减少 8 倍、延迟降低 11.1 倍，同时在 VBench 上匹配压缩前预训练流程的生成质量。

## DecepEval: A Benchmark for Evaluating Deception in LLM Agents

[DecepEval：评估 LLM Agent 欺骗行为的基准](https://arxiv.org/abs/2610.07967)

随着大型语言模型（LLM）Agent 的自主性不断增强，它们可能通过欺骗来追求任务表现，这引发了对其可靠部署的担忧。现有评估表明 LLM Agent 能够进行欺骗，但往往只考察孤立场景或定义狭窄的条件，限制了对欺骗何时更易发生的系统性理解。为填补这一空白，我们提出了 DecepEval，一个包含 1,532 个实例、涵盖 3 个任务族和 28 个专业场景的基准。借鉴经典欺诈理论，我们提出 LLM 欺骗钻石框架（LLM Deception Diamond），刻画了可能诱发欺骗的四类外部条件：压力、激励、机会与冲突。DecepEval 将每个实例的中性版本与诱导版本配对，以衡量依赖于条件的欺骗率变化，同时借助显式任务事实与可观测的 Agent 行为，将欺骗与能力相关错误区分开来。对九个前沿 LLM 的评估显示，诱导因素会提升各模型和各任务族的欺骗水平，即使在基线欺骗率较低的模型中也是如此。DecepEval 使这些脆弱性变得可度量，为迈向可信人工智能的进展提供了共享基准。

## MiMo-V2.6: Scaling Reinforcement Learning Towards Self-Improvement

[MiMo-V2.6：将强化学习扩展至自我改进](https://arxiv.org/abs/2610.11959)

强化学习（RL）是推动大型基础模型走向自我改进的核心训练范式。本报告介绍 MiMo-V2.6 系列，这是一个全模态（omni-modal）模型家族，通过扩展 RL 算力来推动模型智能的前沿。在 RL 之前，我们在广泛的多模态语料上进行中期训练（mid-training），以提供充足的探索空间，并在预训练的 hybrid-SWA 架构上构建了坚实的基础设施，以支撑后续的规模化扩展。我们从三个维度扩展 RL 算力：（1）更大的批次与更高的吞吐量，采用异步训练，每步消耗 1,568 个样本和 2.7–3.7B Token，上下文长度最高可达 1M；（2）更多样、更复杂的环境，在混合 Agent harness 下覆盖代码、通用、视觉和网络（cyber）领域；（3）更多的评分器（grader）算力，通过分组式 Agentic 评分（groupwise agentic grading）为长时程任务产出更准确的奖励信号，并引导模型走向更短、更节省 Token 的解法。为在规模化下保持训练稳定，我们冻结了 MoE router，并建立了针对奖励黑客（reward hacking）的多层防御。我们进一步构建了混合任务 Agentic RL 的基础设施，包括统一轨迹表示、高并发多框架 rollout、解耦的控制平面与数据平面，以及训练-推理一致性。我们开源了训练动态、RL 环境与 RL 框架，以促进可复现性以及关于规模化 RL 与模型自我改进的进一步研究。

## SuperNav: An Agentic Navigation System for Any Task in Any Scene

[SuperNav：面向任意场景中任意任务的 Agent 导航系统](https://arxiv.org/abs/2610.12126)

通用服务机器人需要能够在陌生环境中处理多样化人类请求的导航系统，结合任务通用性与场景通用性。一些现有方法微调多模态大语言模型（MLLM）来预测导航动作，这使其行为依赖于导航训练数据的覆盖范围，并可能限制对新请求和新环境的泛化能力。我们的关键见解是让 MLLM 专注于解释请求、理解场景和做出决策，同时保留其通用能力，并将运动执行委托给导航工具。为实现这一想法，我们提出 SuperNav，它为预训练的 MLLM 配备专门的 Agent 执行框架（agent harness），而无需对 MLLM 进行导航特定微调。我们的执行框架通过导航技能（Navigation Skills）、面向 Agent 的物理交互工具（agent-oriented Tools for physical interaction）以及任务进度与上下文管理来支持这些决策。统一的视觉点接口（visual-point interface）通过允许模型直接在图像中指定目的地，并根据执行反馈修正决策，将决策与运动连接起来。这些组件共同支持跨不同任务需求和环境的持续导航。SuperNav 在实例级、多物体和需求驱动任务上优于四个评测基线。在 HM3D 上的类别级评估以及在真实四足机器人上的部署进一步证明了其跨环境的适用性。项目页面：https://zju3dv.github.io/SuperNav/

## Questioning the Questions: Sustaining Self-Evolution in Reasoning Models

[质疑问题本身：在推理模型中维持自我进化](https://arxiv.org/abs/2610.04299)

自我进化推理模型从自身生成的问题中学习，然而反复的自我训练可能导致性能崩溃。本文研究了性能为何在连续多轮中逐渐退化，以及如何维持自我进化。我们的分析识别出自我生成问题中反复出现的两类质量问题：无效问题，以及同一数学问题的重复变体。第一，无效问题在各轮次中愈发普遍，而答案一致性过滤又会进一步提高其在训练数据中的占比。第二，现有基于词汇相似度的问题多样性控制手段，可能漏掉以不同方式表述但在数学上等价的问题，从而导致后续训练轮次中问题多样性崩溃。基于这些发现，我们提出 R-Quest，它利用问题有效性与新颖性反馈来引导自我进化。我们首先训练求解器（solver）识别并拒绝无效问题，随后利用其判断来引导提问器（questioner）的奖励并过滤求解器训练数据。为避免问题重复，我们使用一个冻结的基座模型对采样得到的问题对进行比较，并提供新颖性反馈。在实验中，我们的方法在两个模型家族、涵盖数学推理、通用域推理与代码生成的 12 个基准上始终取得最高的平均性能。此外，R-Quest 在十轮自我进化中保持稳定的性能增益，在最后一轮达到峰值，并比 R-Zero 高出 17.32 分。

## Latent-MOPD: Latent Multi-Teacher On-Policy Distillation

[潜在多教师在线策略蒸馏](https://arxiv.org/abs/2610.02381)

在线策略蒸馏（on-policy distillation，OPD）在学生模型自己生成的回复上对其进行训练。现有的 LLM 多教师 OPD 通过输出分布来传递专家模型的预测结果。我们提出 Latent-MOPD，据我们所知，这是首个面向 LLM 的表征级多教师 OPD 方法。它通过现有专家的预测结果以及用于计算这些预测的隐状态来整合这些专家，且无需额外的教师训练。为了协调来自多个专家的表征监督，我们依据教师—学生关系选择后层目标，用共享投影桥接不相等的隐层宽度，并按领域对更新进行分组。每位教师的监督都逐渐从隐状态转向 token 预测，且两条通道使用同一个路由到的专家。在我们的主要同族（same-family）设定中，Latent-MOPD 在数学、代码和逻辑领域的全部九个基准上均优于仅 token、仅表征和均匀平均基线。在参数数量与每位教师相同的情况下，该学生模型在其中大多数基准上也超过了每个基准上的最佳教师。在使用规模更大、独立开发的跨族教师时，Latent-MOPD 在所有基准上均优于两种单通道基线。一个同族、全层、仅表征的对照实验在领域纯净更新下保持稳定，但当教师领域在一次更新内交错时则会崩溃。我们的结果表明，单个学生模型能够同时通过多个专家的输出分布和内部表征来整合其能力。

## LexReward: A Taxonomy-Driven Reward Framework for Legal Language Models

[LexReward：面向法律语言模型的分类驱动奖励框架](https://arxiv.org/abs/2609.39071)

法律语言模型所需的奖励信号不仅要捕捉答案的正确性，还要反映法律回答的多维质量。然而，现有奖励方法往往依赖粗粒度的整体判断，领域特异性和可解释性有限。我们提出 LexReward，一个分类驱动的法律奖励建模框架。LexReward 从三个互补维度刻画法律回答质量：Style（风格），涵盖词汇与句法质量；Element（要素），评估法律主体、事实、法条与裁判；Chain（链条），评估法律推理的顺序、完整性、正确性与非冗余性。针对每个维度，我们制定了明确评估标准与质量等级的评分细则（rubric）。由此得到的奖励被用于构建成对偏好数据，以进行直接偏好优化（DPO）和奖励模型训练。实验表明，基于评分细则的奖励能够可靠区分不同质量的法律回答，且在该偏好数据上进行 DPO 训练可在全部三个维度上提升性能。所学习的奖励模型 LexRM 还能支持有效的下游优化：每个维度专属的奖励模型通过强化学习提升策略在其对应维度上的表现，且在奖励计算时无需参考答案。维度层面的分析进一步支持了所提出分类体系与奖励构建的有效性。

## CheckerBench: Can Long-Horizon Agents Synthesize Static-Analysis Checkers?

[CheckerBench：长时程 Agent 能否合成静态分析检查器？](https://arxiv.org/abs/2610.07557)

静态分析检查器合成（static-analysis checker synthesis）要求 Agent 解读缺陷规范、检查代码仓库、实现特定分析器逻辑，并通过反复的编译与分析反馈来改进检查器。现有的编码 Agent 基准测试主要关注补丁生成或漏洞检测等任务，很少评估 Agent 能否在一个代码仓库中从头到尾开发出一个可用的检查器。我们提出 CheckerBench，这是一个可执行基准，包含 300 个任务，源自 167 个代码仓库、85 个 CWE 以及五个语言生态系统中的 297 个 CVE。每个任务包含存在漏洞的版本与修复后的版本、固定版本的分析环境，以及一个检查器脚手架（checker scaffold）。我们进一步提出 CheckerLab，一个通用评估框架，它独立重建提交的检查器，并衡量漏洞-修复诊断对比度（vulnerable-fixed diagnostic contrast）、补丁定位、误报以及工具使用情况。在 21 种模型-框架（model-harness）配置、每种配置三次独立重复的情况下，平均 Pass@1 为 32.30%，最佳达到 45.33%。这些结果表明，对于当前的编码 Agent 而言，开发可靠、可复用的检查器仍然具有挑战性。

## PointWAM: 3D World Action Modeling for Dexterous Robotic Manipulation

[PointWAM：面向灵巧机器人操作的 3D 世界动作建模](https://arxiv.org/abs/2610.02840)

世界动作模型（World Action Model）联合学习预测世界动态与机器人动作，使学到的内部世界动态能够引导准确的动作。现有方法通常将世界表示为 RGB 帧或隐空间对应形式，同时将动作预测为末端执行器位姿或关节角度，但它们往往难以捕捉灵巧操作核心的 3D 空间结构与接触几何。我们提出 Point World Action Model（PointWAM），一种 3D 世界动作模型，将世界分解为场景（即环境）与手（即动作主体），并在统一的时空坐标系内将二者联合预测为 3D 点轨迹。这种显式、解耦的表示使得在大规模人类演示视频上进行有效预训练成为可能，且无需任何任务特定的物体或关键点选择。给定彩色点云和语言指令，PointWAM 预测场景与手在 3D 空间中随时间如何共同演化，随后将预测的手部运动重定向为机器人动作。在人类视频上预训练使 DexJoCo 平均成功率提升 56.9 个百分点，而场景轨迹监督在仅预测手部的基础上再增加 10.9 个百分点。二者结合后，PointWAM 在十项 DexJoCo 任务上以 11.7 个百分点超越此前的最优方法（SOTA），并在真实机器人上优于强 VLA 模型。

## Pivot-SD: Efficient Self-Distillation for Masked Diffusion Language Models

[Pivot-SD：面向掩码扩散语言模型的高效自蒸馏](https://arxiv.org/abs/2610.03665)

掩码扩散语言模型（masked diffusion language models, dLMs）为复杂推理提供了一种有前景的、可并行处理的替代方案，可取代自回归模型。然而，它们面临着一个独特的信用分配（credit-assignment）挑战：去噪过程中少数几次"确定"（commitment）就会大幅降低其余被掩码位置上的不确定性，并塑造了响应的大部分内容。现有的大多数 dLM 后训练方法并未利用这一信号来决定在哪些 Token 上进行训练：它们通常直接在最终文本上训练，或将奖励分配给整个去噪步骤，而非选择那些塑造了响应的单个确定动作。我们提出 Pivot-SD，一个高效的离线自蒸馏（self-distillation）框架，仅对这些高影响力的确定动作（即"枢纽"，pivots）进行监督。Pivot-SD 使用一种信息增益（information-gain）指标来选取枢纽，该指标衡量的是对剩余被掩码位置不确定性的降低程度。来自成功轨迹的枢纽用交叉熵（cross-entropy）训练，来自失败轨迹的枢纽则用针对性的非似然（targeted unlikelihood）训练，而失败轨迹的其余部分保持不变。仅使用 200 个问题和每个问题四次 rollout，Pivot-SD 就在数学与代码基准上，使 LLaDA-8B-Instruct 相较于全序列 SFT 和预算匹配的扩散 RL 基线均取得了提升。

## Science or Slop?: Benchmarking and Mitigating Scientific Slop in AI-Generated Papers

[科学还是垃圾？：对 AI 生成论文中的科学垃圾进行基准测试与缓解](https://arxiv.org/abs/2610.00531)

AI 生成内容（常被称为 AI slop，即 AI 垃圾）在各处日益普遍，在学术界尤为突出。然而，AI 生成科学论文中的“垃圾”具有更复杂的模式，现有的基于 Token 的 AI 检测器难以识别。这类论文的每一部分看起来都合情合理，但连接各部分之间的科学推理却已崩塌，这会误导读者对工作的评估。我们将此类失败作为“科学垃圾”（scientific slop）进行基准测试，从结构（Structure）、论证（Argument）和产物（Artifacts）三个维度采用六项指标加以衡量。我们构建了 SciSlopBench，包含 390 篇 AI 生成论文，主要来自计算机科学，同时涵盖生命科学、社会科学和自然科学，每篇论文都配有一篇按研究问题和贡献类型匹配的人类撰写论文。我们的指标能以 85.9% 的准确率从每一对论文中识别出 AI 论文，而 Binoculars 的准确率为 68.7%。科学垃圾程度越高，ICLR 评分越低，并且在 2017 至 2025 年的每一年中都能以高于随机的水平区分被拒论文与录用论文。然而，减少这些模式并不像直接优化指标那么简单。因此我们提出了 SciSlopHarness，一个 harness 层面的框架，引导固定的 LLM 仅在实验记录支持该修改时才修订垃圾内容。标准修订会残留垃圾，而直接采用垃圾感知提示会触发奖励黑客（reward hacking），相比之下，SciSlopHarness 在无需人类参考目标的情况下，将剩余的 AI 与人类差距在最强修订基线的基础上缩小了 63%。总体而言，我们证明 AI 生成的科学论文在其全局推理中留下了根本性痕迹，而负责任的缓解措施要求严格的证据基础，而非仅仅是文辞润色。

## PDE-JEPA: Predictive Representation Learning of Latent Dynamics Modeling for Parametric PDEs

[PDE-JEPA：面向参数化 PDE 的隐动力学建模预测性表征学习](https://arxiv.org/abs/2609.34715)

物理轨迹不仅包含系统状态的快照，还揭示了系统状态在控制条件下的演化方式。然而，针对参数化偏微分方程（PDE）的表征学习在很大程度上依赖基于重建的目标，这类目标侧重于恢复观测到的物理场。本文研究了预测性表征预训练作为基于重建学习的一种替代方案。我们发现，预测性表征保留了丰富的物理信息，但仅凭这一优势并不能确保准确的场演化。基于这些观察，我们提出了用于参数化 PDE 动力学的 PDE-JEPA。具体而言，我们首先使用掩码隐变量预测训练一个编码器，以捕捉 PDE 动力学的潜在规律。为了显式地将预训练表征调整到更符合动力学的状态空间，我们随后引入一个几何投影器（geometry projector），将隐轨迹几何与物理场的演化几何对齐。最后，在这个几何对齐的隐空间基础上，我们进一步开发了一个物理结构化的隐预测器，将动力学分解为参数无关的演化分量和参数相关的响应分量。在九个广泛使用的 PDE 基准上的大量实验表明，我们的框架在分布内平均优于现有最先进方法 33.4\%，而在外推到未见控制参数时平均提升 51.4\%。项目页面见 https://tanpig-x.github.io/PDE-JEPA/{here}。

## VeriHarness: Scaling Agentic Verification for Long-Horizon Tasks

[VeriHarness：为长时程任务扩展智能体验证能力](https://arxiv.org/abs/2610.00972)

随着 LLM Agent 承担愈发复杂的长时程（long-horizon）任务，验证其输出也变得愈发困难。我们研究了在固定基础模型、且测试时无法获取参考答案或评分标准的情况下，如何增强验证能力。重复采样会产生多条 rollout，其中可能包含互补的正确论断，但我们需要一个可靠的验证机制来判断哪些论断值得信任。我们首先发现，分歧往往能暴露正确的备选方案，而共识则可能掩盖错误。这些观察促成了 VeriHarness：它通过为生成方所用的底层 LLM 提供工作区、证据工具和可复用的验证技能，将其转变为智能体验证器（agentic verifier）。分歧消解器（disagreement resolver）依据环境证据检验相互竞争的论断，共识挑战器（consensus challenger）则测试共同论断并搜索被遗漏的需求。二者的发现指导最终产物的选择与修订。在五个长时程工作区基准和两个前沿模型上，VeriHarness 在所评估的基线中取得了最高的选择分数。基于证据的修订进一步提升了平均性能，相较单次 rollout，在 Gemini 3.5 Flash 上带来 6.2 分的增益，在 Claude Opus 4.8 上带来 6.4 分的增益。我们进一步表明，验证技能可以从失败反馈中自我改进，证明 VeriHarness 是一种用于扩展长时程智能体验证的新颖且关键的方法。我们发布了覆盖全部五个基准和两个模型、约 26,000 条 rollout 的完整池，其生成成本超过 100,000 美元，以支持未来关于智能体验证的研究。

## Memadapter: Counterfactual Adaptation Against Memory-induced Sycophancy

[MemAdapter：对抗记忆诱发谄媚的反事实适配](https://arxiv.org/abs/2610.05162)

长期记忆使基于 LLM 的 Agent 能够跨任务与会话保留并复用信息，从而支持个性化与长程交互。然而，持久化的记忆也可能诱发谄媚（sycophancy），使 Agent 过度迎合用户的历史信念，即便这些信念不准确、已过时或与客观证据相矛盾。现有的缓解方法假设记忆诱发的谄媚源自带有偏见或错误的记忆，并试图通过在记忆流水线的不同阶段过滤此类记忆来降低风险。但在现实世界中，客观且正确的记忆同样可能诱发谄媚，且同一记忆在不同语境下应具有不同的影响权重。为此，我们提出 MemAdapter，一个新颖的框架，能够自适应地整合检索到的记忆，以支持客观、可靠的推理。具体而言，MemAdapter 由三个组件构成：(i) 反事实归纳（Counterfactual Induction），利用反事实推理揭示检索记忆的潜在风险；(ii) 上下文感知反思（Context-Aware Reflection），通过自我反思，结合当前任务校准每条检索记忆的推理影响；(iii) 基于证据的推理（Evidence-Based Reasoning），在保留记忆合理影响的同时，使最终回复建立在恰当证据之上。在三个基准上的大量实验表明，MemAdapter 在多种场景下持续提升记忆可靠性。我们的代码见 https://github.com/DEEP-JLU/MemAdapter。

我们提出 HyperBrowseComp，一个多语言、多模态浏览基准，包含 423 道由母语者或高水平使用者人工编写并经过人工验证的问题，覆盖 13 种语言。这些问题被设计得极具挑战性。每道题都指向一个简洁、可公开验证的答案，而要找到答案，需要定位冷僻证据、追踪多步线索链，或检查视频、扫描文档、图像、地图等异构来源。为降低仅凭参数化知识即可作答的可能性，我们使用无互联网访问的模型对问题进行评估，以此过滤掉较简单的问题。我们在统一的 Agent 协议下，使用模型厂商原生搜索以及一套共享的外部检索工具链对多个模型进行了评估。为给模型表现与投入程度提供参照，我们还抽取部分问题进行人工评估。HyperBrowseComp 为跨语言、跨证据模态的持续性信息检索提供了一个极具挑战性的测试平台，其难度源于在开放网络上发现并串联证据。

## Spatial Memory Intelligence: Endowing World Models with Understanding-Driven Long-Term Memory

[空间记忆智能：赋予世界模型理解驱动的长期记忆](https://arxiv.org/abs/2610.02521)

长视频生成与世界模型已展现出在交互式娱乐与具身模拟（embodied simulation）方面的强大潜力，其做法是以用户动作与历史记忆为条件预测未来观测。然而，随着记忆序列不断增长、其结构日益复杂，管理长程空间上下文变得愈发困难，这要求一种更智能、更系统的记忆管理策略。基于多模态大语言模型（MLLMs）不断进步的空间推理能力以及统一模型的更广阔愿景，我们提出空间记忆智能（Spatial Memory Intelligence, SMI），这是首个系统性地将理解模型用于长视频世界模型中空间记忆管理的框架。SMI 引入四个协同的原子操作：空间聚类、簇内稀疏化、动作感知检索与可靠性感知过滤。在多个基线、基准与世界模型骨干网络上的大量实验证明了 SMI 的有效性与泛化能力，在记忆稀疏度、生成稳定性与空间一致性方面实现了全面提升。

## EditHero: A Benchmark for Long-Horizon Part-Level 3D Editing and Vibe Modeling

[EditHero：面向长程部件级 3D 编辑与 Vibe Modeling 的基准](https://arxiv.org/abs/2610.02298)

3D 编辑方法通常只在单次编辑上进行测试，但一个资产是通过一长串修订逐步构建而成的，每一次修订都必须实现所请求的改动，同时保持其他所有内容不变。我们提出 EditHero，据我们所知，这是首个面向长程（long-horizon）、部件级（part-level）3D 编辑的基准，同时提供自然语言指令以及针对几何与纹理的目标图像。一个确定性装配引擎在每次编辑后生成精确的目标结果，并且每条编辑序列都经过人工审核。我们使用 EditHero 来比较两种截然相反的 3D 编辑方法。非 Agent 方法采用自顶向下的方式，从学到的 3D 表示重新生成对象，并推断哪些部分需要保留。相比之下，LLM/VLM Agent 采用自底向上的方式，通过代码进行编辑：检查网格（mesh），并仅重写指令所要求的部件。非 Agent 方法常常遗漏所请求的改动，并扰动本应保持固定的区域。大多数 LLM 更严格地遵循指令，且所有 LLM 都能更好地保留未编辑的部分，但它们的每次编辑都需要数分钟。我们将发布该引擎与编辑序列，以支持可靠的迭代式 3D 编辑研究。

## SimuVerity: Benchmarking Agents for Engineering-Grade Simulink Model Generation

[SimuVerity：面向工程级 Simulink 模型生成的 Agent 基准测试](https://arxiv.org/abs/2610.02304)

现有的 Simulink 基准测试主要评估生成的模型能否编译、执行，或是否与参考模型相似。这些标准无法判定模型是否满足其工程需求。我们提出了 SimuVerity，一个包含 101 个文本到可执行 Simulink 模型生成任务的基准测试，覆盖十个工程领域。对于每个任务，可执行系统配置（executable-system profile）为工程规格说明以及四类原生仿真场景提供依据。一个分层评估器首先检查产物交付、原生可执行性和工程合格性，然后在六个维度上对合格模型打分，涵盖准确性、输出质量、机理保真度、控制与因果完整性、工作域鲁棒性以及动态响应。我们用 SimuVerity 评估了六个 Agent 系统。最佳系统的总分仅为 42.86。结果表明，结构相似性是工程性能的糟糕代理指标：能力瓶颈既出现在产出合格实现的过程中，也出现在实现合格后满足多维需求的过程中。与此同时，一些高分模型仍然表现出严重的视觉布局混乱。SimuVerity 为评估 Agent 的工程能力、诊断可执行 Simulink 模型生成中的失败，提供了系统化的依据。

## UniWAM: Unified World-Action Model

[UniWAM：统一世界-动作模型](https://arxiv.org/abs/2610.02054)

视觉-语言-动作模型（Vision-Language-Action Model）受益于预训练视觉-语言模型的理解与推理能力，但仅以动作作为监督信号，难以充分建立对世界动态的 grounding。反过来，世界-动作模型继承了视频生成模型的时空先验，但在分布偏移下的语义理解与推理能力仍然受限。我们提出 UniWAM，一种统一架构，集成物理推理器（physical reasoner）、世界生成器（world generator）与动作预测器（action predictor），联合学习对物理世界的语义理解、视觉生成与动作预测。为确保训练数据质量，我们为人类第一视角数据与机器人数据开发了严格的数据清洗与标注流程。为使视觉-语言组件适应具身任务，同时保留其继承的语言能力，我们用自然语言表示低级动作，并引入一套预训练方法，将来自视觉问答（VQA）数据、人类第一视角数据与机器人演示的互补监督信号分配给相应的模型组件。在后训练阶段，未来视觉噪声增强降低了对精确未来预测的依赖，而历史条件化流匹配（history-conditioned flow matching）则利用编码后的动作历史来初始化动作生成。这些设计共同显著减少了去噪步数，同时保持性能。UniWAM 在多项评估中取得 SOTA 性能，包括分布内性能、鲁棒性、泛化能力、指令遵循以及长时程任务执行。此外，我们揭示了统一人-机器人协同训练的 log-linear 缩放定律，证明了在人类与机器人数据混合上进行大规模预训练的有效性。

## VepAgent: Bridging Causal-Transition via Tool-Augmented Reinforcement Learning for Video Event Prediction

[VepAgent：通过工具增强强化学习架起因果过渡桥梁，用于视频事件预测](https://arxiv.org/abs/2610.06293)

多模态大语言模型（MLLMs）在视频理解方面展现出显著潜力，但其对回溯式摘要和以文本为中心的先验的依赖，往往限制了其在视频事件预测（VEP）中跨越未观测因果过渡的能力。为解决这一问题，我们提出 VepAgent，一个将因果过渡推理与工具增强强化学习（RL）相结合的 Agent 框架，以实现稳健的 VEP。与以往从历史依赖中被动外推未来轨迹的方法不同，我们的方法显式建模从终端观测状态到未来事件的逻辑演进过程。具体而言，我们首先构建 FutureBench-4K，这是一个高质量的思维链数据集，用于监督微调（SFT），通过结构化地推演未观测中间状态，有效弥合因果逻辑鸿沟。随后，我们开发了一个诊断工具库，集成状态跟踪、帧检索和区域放大功能，使 Agent 能够在推理过程中借助外部工具动态增强推理，以恢复缺失的时空证据并消解视觉歧义。此外，我们提出一种复合奖励机制，联合优化预测准确性、因果连贯性和可靠先验，促使 Agent 依赖真实的视觉 grounding，而非表面的文本相似性。在 FutureBench 和 NEPBench 数据集上的大量评估表明，我们的方法达到了 SOTA 性能，显著优于更大的 MLLM，并验证了我们这一 Agent 式、面向未来的推理范式的实际有效性。

## SGF+: Decoupling Gradient Flows for Autoregressive Video Generation

[SGF+：解耦自回归视频生成的梯度流](https://arxiv.org/abs/2610.10429)

自回归视频生成需要在去噪当前帧的同时，将其键值表示（key-value representation）写入，作为未来预测的上下文。然而，这两种角色通常共享参数，而我们发现它们的梯度呈现出不同的模式，并存在系统性的负对齐（negative alignment），从而阻碍了视觉质量与时间一致性的联合优化。为此，我们提出了 Self Gradient Forcing Plus（SGF+），它为上下文写入与去噪分配独立的参数，同时通过因果注意力（causal attention）保留二者的交互。两种角色均使用原始生成目标进行联合优化，无需辅助损失，其中上下文写入通过其对未来预测的贡献来获得监督。这一简单改动在所评估的基线上，于逐帧（framewise）和分块（chunkwise）生成两种设定下均提升了视觉质量与长时程一致性，且无需额外的视频训练数据或更长的训练周期。SGF+ 仅在 5 秒的 rollout 上训练，即可支持长达 24 小时的连续生成，无需长视频微调。这些结果表明，角色特定的参数化是面向高质量自回归视频生成与原生长时程外推（extrapolation）的一种有效设计原则。

## World Embedding Benchmark

[世界嵌入基准](https://arxiv.org/abs/2610.03632)

物理保真度在世界模型和视频生成中受到越来越多关注，但视频表征如何编码物理信息仍缺乏充分理解。我们提出了世界嵌入基准（World Embedding Benchmark），包含来自 80 个家族的 8,000 个受控仿真案例，覆盖流体力学、固体力学、动力学以及光学与电磁学。每个案例将一个渲染视频与仿真导出的物理标注配对，支持三项互补任务：文本-视频检索、物理属性回归，以及视频-描述配对的多选题分类。我们利用这些任务区分跨模态物理对齐与定量物理信息的可恢复性。对预训练全模态嵌入模型的评估显示，其检索能力较弱，家族内配对分类接近随机水平，而轻量探针可从冻结的视频嵌入中恢复出有用的物理信息。使用物理专用视频-文本对进行持续对比训练可提升检索与配对分类性能，但会降低物理属性回归性能，揭示了对齐与定量信息可恢复性之间的权衡。最后，我们使用这些嵌入为 MiniMax-H3 的检索增强生成检索参考视频。检索到的参考视频提升了生成视频的物理保真度，在我们的实验中，检索能力更强的模型带来的增益更大。综上，这些发现凸显了联合评估物理对齐与属性可恢复性的必要性，并展示了物理表征在改进视频生成方面的效用。

## Multi-Agent Egocentric World Model with Fine-Grained Embodied Interaction

[具有细粒度具身交互的多智能体自我中心世界模型](https://arxiv.org/abs/2610.12299)

自我中心世界模型（Egocentric World Model）以智能体动作为条件预测第一人称观测，但多数只关注单一智能体。真实的具身场景往往涉及多个智能体在共享环境中行动与交互。现有多智能体世界模型依赖运动、相机控制或离散指令等粗粒度动作，使细粒度具身交互仍未被充分探索。我们将多智能体自我中心世界建模形式化为：多个智能体在共享世界中通过细粒度动作交互时，同步生成各自的自我流（ego-stream）。这要求跨视角动作一致性、共享环境一致性，以及交互引发状态更新的一致性传播。我们提出多智能体自我中心世界模型（Multi-agent Egocentric World Model，ME-World），它在共享 Token 序列中联合去噪多条自我流，将每条流以所有智能体的目标视角位姿为条件，并借助共享环境记忆为生成提供依据。我们在真实与合成多智能体数据上训练和评估，并提出面向环境、更新与身份一致性的共享世界一致性指标。实验表明，ME-World 在共享世界一致性、动作控制、身份保持和视频质量上均优于现有方法。

## EVISKILL: Grounding Skill Evolution in Replayable Evidence

[EVISKILL：将技能演化建立在可回放证据之上](https://arxiv.org/abs/2610.05030)

持续技能演化使 LLM Agent 能够从交互经验中积累并精炼可复用的程序性知识，而无需更新模型参数。其有效性不仅取决于确定要改变什么，还取决于判断某项变更为何合理，以及它何时应成为持久性的指导。然而，现有的经验驱动方法可能会丢失支撑编辑的行为证据与任务上下文。此外，全局验证结果对其组成部分的变更给出的判断并不完整：局部有支撑的修正可能随被否决的修订一同被丢弃，而某些证据可能需要进一步的经验才能形成有用的更新。为此，我们提出 EVISKILL，一个证据驱动的框架，它将执行观测组织为可回放证据卡（Replayable Evidence Card），并在合成编辑时显式关联其支撑上下文。定向回放通过重新执行来验证这些编辑，并提供用于修正的反馈。在不同轮次（epoch）之间，EVISKILL 保留证据，并暂时保留有支撑的编辑以供进一步精炼，同时由全局验证决定其是否并入最终技能。在三个交互式基准、六个 LLM 主干模型上的实验证明了该方法的有效性。

## Multilingual GSM-Symbolic: What determines capability transfer across languages?

[多语言 GSM-Symbolic：是什么决定了跨语言的能力迁移？](https://arxiv.org/abs/2610.03367)

我们对于在一种语言中获得的能力如何迁移到另一种语言、以及是什么主导了这种迁移，仍知之甚少：现有评测依赖不可比较且容易饱和的数据集，并且很少联合考察其决定因素。若能识别出预测迁移的因素，我们就可以避免在所有语言对上做穷尽式评测，并让开发者能够针对制约低资源语言性能的因素发力。为评估跨语言能力迁移，我们提出了 Multilingual GSM-Symbolic，这是一个可扩展的多语言数学数据集，涵盖 30,000 个条目配对的问题-答案对，覆盖 15 种语言。它利用符号模板来防止过拟合，并通过允许从单个样本生成数百万个高质量变体来确保泛化性。使用 Multilingual GSM-Symbolic，我们量化了能力的最主要决定因素：模型规模（β= 1.77）、语言资源水平（β= 0.77）、推理（β= 0.67）以及类型学距离（β= -0.25）。这种联合估计使得这些决定因素可以相互换算：一个 32B 模型在马拉地语上的表现相当于一个 10B 模型在英语上的表现。我们的发现对模型开发者具有重要意义，表明模型规模和推理能够缩小低资源语言与高资源语言之间的性能差距（分别为 β= -0.27 和 β= -0.20），而类似的杠杆对类型学上距离较远的语言则几乎没有影响或毫无影响。总体而言，我们的分析框架解释了 92% 的语言间差异，但仅解释了 23% 的模型×语言交互差异，并能在 6.0pp 以内预测模型在未见语言上的性能（r=.96）。仅纳入目标语言中 10 个模板的测量结果，即可将这一误差降至 4.19pp，从而在很少甚至没有下游数据集的情况下实现对性能的合理估计。

## In-Distribution Forcing for Long Video Generation at Test Time

[测试时长视频生成的分布内强制](https://arxiv.org/abs/2610.03120)

现代自回归（AR）视频扩散模型在短时长视频生成方面表现出色，但由于漂移（drifting）问题——颜色和纹理发生偏移、运动动态衰减——生成长视频仍然具有挑战性。现有工作主要依赖 KV 条件化（KV conditioning），即选择或修改缓存的键值（KV）条目以缓解漂移。然而，我们观察到仅靠 KV 条件化并不充分，因为它假设缓存的 KV 条目仍处于分布内（in-distribution）。这一假设在超出训练时域（training horizon）后便不再成立：在 rollout 过程中，没有任何机制约束 KV 条目的构建，从而引发了 KV 来源（KV-provenance）问题，即缓存条目本身变为分布外（OOD）。为解决这一问题，我们提出 In-Distribution Forcing（ID-Forcing），一个在测试时使 KV 缓存与 KV 条件化均与训练配置对齐的框架。其关键机制——自缓存（self-caching）——从源头上防止了 OOD KV 条目的产生。每个 chunk 在缓存时不关注先前的 KV 条目，从而使滚动窗口严格保持在分布内。因此，ID-Forcing 能够将短时域模型无缝扩展到分钟级视频生成。大量评估表明，我们的方法在标准视频生成基准上仍具竞争力，同时在缓解漂移方面显著优于先前工作，这一点得到了我们的漂移指标与用户研究的双重验证。

## Does Learning Protein Folding Generalize to Broader Reasoning?

[学习蛋白质折叠能否泛化到更广泛的推理？](https://arxiv.org/abs/2609.38879)

大语言模型高度依赖人类文本，而人类文本往往只传达表层答案，而非其背后的空间与结构逻辑。蛋白质折叠是一个天然的测试平台，因为一个已解析的结构可以产生数千条可精确检验的空间与拓扑陈述。我们提出：学习折叠蛋白质能否教会通用模型可复用的推理能力？为回答这一问题，我们构建了 FoldingCorpus——一个由蛋白质衍生的问答数据集，以及 Fold2Reason——一种在其上进行后训练的方法，通过两种互补信号实现：一是经由模型原生语言头预测的离散结构答案，二是从同一共享表征中解码出的连续三维几何。在 FoldBench 上，Fold2Reason 的结构预测得分达到 Qwen3.5-9B 的 2.7 至 3.5 倍。除蛋白质结构预测之外，它在涵盖空间、图、科学与通用推理的 10 个基准上全部取得性能提升，将宏平均准确率从 45.09% 提升至 48.33%（+3.23 个百分点），且 10 个基准均呈正向增益，而由随机、合成与打乱结构构建的匹配对照组则增益显著更小甚至为负。我们的工作表明，非语言、结构密集的科学数据能够系统性地提升语言模型的广泛推理能力，使一个已解决的科学问题成为后训练监督的实用来源。

## In-context Robot Learning Made Simple: A Democratized Recipe for Manipulation Tasks

[上下文机器人学习简明指南：面向操作任务的民主化方案](https://arxiv.org/abs/2609.38173)

我们研究机器人上下文学习（in-context learning，ICL）——一种新兴范式，使机器人能够从视觉演示中推断并执行任务。尽管其前景日益广阔，该问题本身仍缺乏明确定义：一个视觉演示同时传达了动作轨迹、物体语义、操作可供性（affordance）、空间关系和任务目标，这使得机器人究竟应当遵循哪些信息变得不清晰。在本工作中，我们首先给出机器人 ICL 的清晰问题定义，明确其学习目标并解决这一根本性的提示（prompt）歧义。基于该定义，我们开发了一个极简且可复现的 ICL 框架（SimpleICL），包含视觉提示编码器和低成本数据采集协议。无需大规模预训练或专门的数据基础设施，我们的框架在仿真和真实环境中均取得强劲性能。大量实验进一步揭示了机器人 ICL 的若干关键特性，包括动作、语义、组合和可供性判别能力。我们将完全开源我们的数据和训练流程，以促进机器人 ICL 的系统性、可复现研究。项目页面见 https://simpleicl.github.io/simpleicl。

## Kinematic MeanFlow: One-Step Action Generation Policy for Robotic Foundation Models

[运动学 MeanFlow：面向机器人基础模型的一步动作生成策略](https://arxiv.org/abs/2610.00864)

本文研究如何在机器人基础模型（Robotic Foundation Models，RFMs）中实现一步动作生成，以克服多步流匹配（flow matching）推理延迟高的问题。MeanFlow 为实现这一目标提供了有前景的框架，但其直接应用会导致性能崩溃。我们发现，这源于 RFM 速度场中表现出的两种独特动力学特性：(1) “局部加速度”在早期表现出稳定性，但在去噪过程接近尾声时急剧上升；(2) 其幅度在样本间的离散程度随着去噪推进而增大。为解决这些问题，我们提出了运动学 MeanFlow（Kinematic MeanFlow，K-MF），一种专为 RFM 设计的新型一步动作策略。具体而言，K-MF 基于一个运动学恒等式，将 MeanFlow 公式中的时间导数项解耦为以中间点为界的两段子区间项。这种解耦形式使两项能够分别捕捉早期和晚期去噪动力学，同时缓解整个过程中的误差放大。因此，我们的 K-MF 使 RFM 能够在从零训练和微调两种范式下、跨多种任务实现一步动作生成，并在大多数设置下优于多步流匹配。在推理效率方面，K-MF 在 L40 和 Jetson Orin 上、eager 与编译模式下将 GR00T-N1.6 的动作头延迟降低了 67.5%~74.4%，端到端延迟降低 30.3%~54.9%。代码将发布于 https://github.com/IntelChina-AI/K-MF。

## Source Preference in the Wild: How LLM Agents Favor Items by Source, and How to Reduce It

[真实环境中的来源偏好：LLM Agent 如何按来源偏向条目，以及如何减少这种偏好](https://arxiv.org/abs/2610.03195)

当 LLM Agent 代表用户决定购买哪件产品、预订哪家酒店或引用哪篇论文时，对来自某些来源（即这些条目所属的网站或服务）的条目的偏好，会影响用户收到什么以及哪些来源被选中。我们在三个领域中、使用 12 个 agent 模型研究端到端搜索中的来源偏好。比较来自不同来源、满足相同要求且处于相同位置的条目，我们发现每个模型在每个领域中都偏好某些来源并回避其他来源，且各模型在偏好哪些来源上大体一致。这种偏好可能压过条目满足请求的程度：当一件少满足一项要求的条目来自偏好来源，而更好的条目来自非偏好来源时，该较少满足要求的条目被选中的概率约为三分之二；但在相反情况下几乎从不被选中。标识条目来源的信息本身就会影响选择：隐藏该信息会削弱偏好，而将条目重新标记为来自偏好来源会提高其选择率。我们测试了这种偏好的两条形成路径：奖励更好条目的训练可能使来源成为满足要求的捷径，而缺失信息可能触发对来源的先入之见。提供缺失信息或使用提示词对抗这些先入之见，可以减少来源偏好。

## Tetris3D: 3D Scene Generation With Objects That Fit Together

[Tetris3D：可相互契合物体的 3D 场景生成](https://arxiv.org/abs/2610.10539)

我们提出 Tetris3D，一种单图像 3D 场景重建的生成式框架，能够恢复出在场景中具有物理与几何一致性的物体。现有方法通常独立生成物体，或以隐式方式耦合物体，难以为相互作用的相邻物体之间确保细粒度空间兼容性提供充分引导。为此，我们显式地以周围物体的几何结构及其物理关系作为每个物体生成的条件，引导其形状与位姿在场景中保持几何与物理上的合理性。此外，我们引入 ComOb，一个基于物理模拟的数据集，包含 120 万个场景，涵盖多种物体类别之间的物理交互，并提供逐物体网格与成对物理关系标注。在合成场景与真实场景上的全面实验表明，即便交互区域被遮挡，Tetris3D 仍能恢复出一致的物体形状与位姿，并在生成质量与物理稳定性两方面均达到 SOTA 性能。

## From Evidence to Action: How Tool-Using Agents Fail

[从证据到行动：工具使用型 Agent 为何失败](https://arxiv.org/abs/2610.07753)

使用工具的 Agent 会对 外部状态产生具有后果性的变更，但正确的结果并不能保证其行动是由事先已确立的证据所支持的。我们研究了当 Agent 从决定是否行动，转向执行单个动作以及有依赖关系的工作流时，这条“证据—行动”链路在何处断裂。在十种模型—执行框架（model-harness）配置中，强大的静态动作评估能力可以与弱得多的交互式执行能力同时存在。失败往往在执行之前就已开始：Agent 会在调查不完整时停止，或在所需证据尚未确立前就采取行动。一旦获得了所需证据，单动作执行通常是可靠的，而多动作工作流还会额外暴露出未解决的前置条件和执行不完整的问题。为开展这项分析，我们引入了 SafeActBench，它包含 656 个案例，覆盖六个运营领域和五种协议，并从静态动作判断、经调查后的不行动，逐步推进到单动作与多动作工作流。一个与来源绑定的 Evidence Ledger 和确定性轨迹评估器会追踪：哪些信息已被确立、行动在何时发生，以及下游依赖关系是否得到满足。这些结果表明，失败不仅源于信息缺失，也源于 Agent 在决定和执行行动时如何使用已确立的证据。

## Science Utopia? Closed-Loop LLM Simulation of Academic Research Ecosystems

[科学乌托邦？学术研究生态系统的闭环 LLM 模拟](https://arxiv.org/abs/2610.01257)

科学进步源自一个纵向生态系统，在该系统中，研究人员、机构、资助机构、合作网络和科学文献共同演化。随着 AI 日益参与科学研究周期的各个环节，理解这些相互关联且不断演变的过程变得愈发重要。我们提出了 SciUtopia，一个用于研究学术研究生态系统的持久闭环 LLM Agent 模拟框架。SciUtopia 对相互关联的科学过程进行建模，例如研究方向选择、合作、投稿、同行评审、再投稿、引用、资助和研究人员流失，同时在模拟年份之间维护不断演变的状态。其可配置的机构机制和信息渠道为匹配的反事实实验和有针对性的干预提供了一个受控测试平台。在 61 个模拟世界中，SciUtopia 模拟了来自 8,000 个机构的超过 40,000 名研究人员，产生了约 400,000 项发表决策和 120 万条由 LLM 生成的同行评审意见。利用这些纵向模拟，我们发现，由拒稿驱动的再投稿会大幅放大审稿人负担，其程度超出仅由人口增长所能解释的范围；谨慎探索能够在引用影响力与职业成功及长期主题多样性之间取得平衡；即使未检测到早期以微弱优势获得资助所带来的累积优势，资源不平等仍可能出现。代码可在 https://github.com/Ahren09/ScienceUtopia 获取。
