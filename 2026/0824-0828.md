## WarpSAC: Towards the Pinnacle of Scalable Off-policy RL by Rethinking Exploration and Exploitation

[WarpSAC：重新思考探索与利用，迈向可扩展离策略强化学习巅峰](https://arxiv.org/abs/2608.24479)

离策略强化学习（off-policy RL）的稳定器效果随数据可用性而变化，这促使我们提出一种感知数据环境的算法，通过自适应归一化与 Q 函数裁剪，在 CPU 与 GPU 并行训练中提升效率。大规模并行仿真改变了离策略强化学习的训练数据分布，对为数据受限回放设计的稳定器提出了挑战。通过在八个基准家族上的受控实验，我们发现这些稳定器具有数据环境依赖性：参数归一化在回放覆盖狭窄时有益，但在数据充足时会限制价值函数拟合；而裁剪双 Q（clipped double-Q）在高吞吐操作场景中可以放宽。年龄偏置回放加权（age-biased replay weighting）在不同数据环境下均能提升学习效率，尤其在网络容量有限时更为显著。基于上述发现，我们提出了 WarpSAC，一个感知数据环境的离策略强化学习算法家族。WarpSAC 使用样本权重衰减（Sample Weight Decay）实现高效利用，并提供两种变体：面向数据受限 CPU 规模训练的 WarpSAC-L（启用归一化，裁剪双 Q），以及面向数据充裕 GPU 并行训练的 WarpSAC-A（关闭归一化，单 Q）。在九个 CPU 规模环境中，WarpSAC 相比 FlashSAC 将归一化分数-步数 AUC 提升了 4.5%；在十四个 GPU 并行环境中提升了 23.1%。它还将 UnitreeG1TransportBox-v1 的成功率从 19.8% 提升至 96.4%，在 MuJoCo Playground 上将平均归一化墙钟时间 AUC 提升了 19.1%，并在 Unitree G1 上实现了比 FlashSAC 快 36.4% 的仿真到现实部署。这些结果表明，可扩展离策略强化学习应当根据可用数据环境调整其稳定器。

## JIT-Agent: Scaling Harness Intelligence via Just-in-Time Harness Evolution

[JIT-Agent：通过即时载体进化扩展载体智能](https://arxiv.org/abs/2608.25593)

JIT-Agent 是一个可训练模型，能够为现成的 LLM 合成自适应 Agent 载体，在不同模型和任务上提升性能。Agent 能力并非仅由模型本身决定。Agent 载体涵盖记忆管理、规划策略、动作协议以及工具/技能编排，其对最终表现的贡献可能超过底层基础模型。然而，载体设计目前仍依赖人工、针对特定任务，且从根本上难以扩展。我们提出 JIT-Agent，一种载体智能模型，经过训练可为任意现成的 Agent 型 LLM 即时合成任务自适应的 Agent 载体。我们将 Agent 载体形式化为一种可组合、可由机器生成的构件，其受固定四模块协议支配，并训练 JIT-Agent 为手头任务定制载体、修复载体以保证稳定可靠执行，以及通过从不断扩大的历史载体配置存档中提炼性能信号来实现自我进化。将 JIT-Agent 作为载体助手后，DeepSeek-V4-Flash 在 DeepSearchQA（+9.1）和 OdysseyBench（+4.3）上超越了 GPT-5.6，而本身已很强的 GLM-5.2 又提升了高达 +20.2 分。在受控评估中，JIT-Agent 生成的载体在性能上与 OpenCode、Claude Code 等成熟 Agent 运行时相当，并能持续改进 DeepSeek V4、Mimo-V2.5 和 Qwen3.6 等多规模模型家族。据我们所知，JIT-Agent 是首个专为即时载体生成而构建的模型，将载体智能确立为一种可训练、可迁移、可叠加的 Agent 能力维度，与模型规模化正交。

## Annotations as Rollouts: Efficient and Scalable Reinforcement Learning for Video MLLMs

[注释即展开：面向视频MLLMs的高效可扩展强化学习](https://arxiv.org/abs/2608.20492)

OraRL 通过将 oracle 展开与解耦优势估计和符号平衡剪枝相结合，改进了视频多模态语言模型的强化学习后训练，在不进行思维链生成的情况下实现了更高的样本效率和可扩展性。多模态大语言模型（MLLMs）已成为统一视频感知的主流范式。然而，在大规模多任务数据集上进行后训练仍然具有挑战性，因为现有的强化学习方法即使采用代价高昂的思维链（CoT）生成，也仅能在采样同策略组时获得少量高质量展开。在本文中，我们研究了视频 MLLMs 的强化学习后训练的样本效率和可扩展性，并提出了 OraRL。我们发现注释一个被忽视的作用：除了对展开进行评分外，每个注释还可以作为 oracle 展开进入其同策略组，成为一个直接的正向优化目标。然而，直接集成 oracle 并非易事：高奖励的 oracle 会提高组基线，从而反转原本为正的策略优势，我们将这种失败称为“优势反转”（advantage inversion）。OraRL 的核心是一个解耦优势估计器：策略展开确定一个无 oracle 基线，而 oracle 与策略的差距则同时调节方向增益和独立的分离 oracle 优势。符号平衡剪枝提高了效率：通过只保留 oracle 和每个符号最强的展开，OraRL 的步进时间仅为 SFT 的 2.2 倍，不到 GRPO+CoT 所需 4.9 倍的一半。OraRL 随模型大小和数据规模扩展，在 0.8B 到 9B 参数规模上超过其骨干模型，并在多达 10 万提示词上超越 GRPO。无需思维链，Video-ORA-9B 解码仅需 130 毫秒，而原来需要 4,780 毫秒。与各自先前最佳模型相比，它将时间 mIoU 从 62.5 提升至 66.0，跟踪 AO 从 73.0 提升至 78.2，分割从 64.3 提升至 70.4，三个基准的空间智能宏平均从 51.0 提升至 56.1；在 VSI-Bench 上，它获得 73.1 分，而 GPT-5 为 55.0 分，Gemini-3-Pro 为 55.1 分。

## PAWBench: How Far Are We from Probabilistically Aligned World Modeling?

[PAWBench：我们离概率对齐的世界建模还有多远？](https://arxiv.org/abs/2608.27345)

该研究将世界模型的概率对齐（probabilistic alignment）形式化，引入了 PAWBench 和 PAWEval 来评估视频生成器作为随机采样器的表现，并发现当前模型无法匹配参考行为分布。近年来的视频生成模型越来越多地被视作世界模型。许多物理过程可以以不止一种有效方式展开。因此，世界模型不仅应当重现一条合理的轨迹，还应重现相同初始观测和动作下可能行为的分布。我们将这种分布层面的要求称为概率对齐。然而，现有评估大多考察单个视频的合理性，并未测试重复生成是否恢复了正确的分布。这引出了一个核心问题：当前的视频生成器距离概率对齐的世界建模还有多远？为回答该问题，我们将概率对齐形式化为世界模型的分布性标准，并引入 PAWBench——一个用于评估视频生成器作为世界动力学随机采样器的基准。我们进一步提出 PAWEval，一种结果层面的评估协议，将重复视频滚动（rollout）转换为可能物理行为上的经验分布。在 50 个场景和 11 个当前系统的测试中，没有任何模型能在恢复有效行为范围的同时持续匹配参考概率。在确认了这一差距之后，我们测试了语言提示（prompt）、初始噪声采样或模型训练是否能重塑模型的预测分布。我们相信这项工作可以为未来迈向概率对齐世界建模的努力奠定基础。

## EchoWM: Open and Enterable Omnimodal World Models

[EchoWM：开放且可进入的全模态世界模型](https://arxiv.org/abs/2608.23189)

EchoWM 是一个全模态世界模型（omnimodal world model），可在遵循连续 6-DoF 导航轨迹的同时，跨第一人称和第三人称视角生成同步的高分辨率视频、声音、音乐和语音。我们提出 EchoWM，这是面向可进入式生成媒体的全模态世界模型，可响应连续导航，并联合生成 720p 视频、环境声音、音乐和语音。我们围绕相机意图组织交互：在第一人称场景中，相机意图指定观察者运动；而在第三人称场景中，相机与角色的动态从数据中学习，无需特定视角的控制器。离散命令和连续姿态被映射到共享的度量尺度相对 6-DoF 轨迹，并通过数据集级校准来保持异构数据间的运动幅度。为联合学习音视频生成与轨迹控制，我们构建了互补的数据引擎，并采用渐进式训练，随后进行自回归后训练以支持长时程生成。广泛评估表明，EchoWM 在公开世界模型基准上实现了强大的轨迹跟踪和高质量视觉输出，支持跨不同主体的第一人称与第三人称交互，并在长时程生成中保持环境声音和语音的同步。

## UrbanGround: From Local Perception to Spatial Agency in a Real-Scale City

[UrbanGround：从局部感知到真实尺度城市中的空间能动性](https://arxiv.org/abs/2608.27456)

UrbanGround 评估了多模态语言模型智能体能否在逼真的 3D 城市复刻中维持可靠的导航与空间推理，结果显示局部感知能力无法组合成延展的目标导向行为。多模态大语言模型（MLLM）能够解读街景，但城市层面的能动性取决于这类局部证据在智能体开始移动后是否仍然有用。本文探究了当前 MLLM 智能体在复杂的真实尺度城市中能将局部城市感知转化为可靠行动到何种程度。我们提出 UrbanGround，这是首个在基于全域三维地理空间数据构建的香港物理约束复刻中让该问题可测试的沙盒环境。UrbanGround 支持第一人称视角的闭环交互，并提供用于导航的交互式地图。智能体可以直接进入三维城市并以第一人称视角探索。我们的分析通过三个研究问题追踪空间问题的增长过程。首先测试智能体在主动观察后能否充分锚定局部场景以回答空间问题；随后考察当目的地变得更远、更不明确时，这种锚定是否仍能支持导航；最后检验所得行为在路线可用性和行人运动发生变化时能否存续。当代 MLLM 智能体通常在视觉识别和短程空间推理上表现出有用的原子能力，但朝向判断和行人感知运动仍不可靠。其核心失败出现在延展探索过程中：局部能力无法组合为持续的目标导向行为，且误差在缺乏有效校正的情况下不断累积。我们希望 UrbanGround 能够支持更广泛的研究，探索当前 MLLM 智能体在复杂、开放的城市环境中能可靠探索到何种程度。

## TTPO: Test-Time Policy Optimization

[TTPO：测试时策略优化](https://arxiv.org/abs/2608.27448)

测试时策略优化通过非对称地蒸馏一致轨迹并惩罚不一致轨迹，实现了数学推理的无标签测试时训练，性能可与有监督训练相当。近期主流的后训练方法，如强化学习（RL）和同策略自蒸馏（OPSD），推动了大语言模型数学推理的快速发展，但由于依赖真值标签，无法进行测试时训练（TTT）。将真值替换为多数投票伪标签是一种自然替代方案，但存在脆弱性：错误的投票会污染教师模型并误导每个Token。我们观察到这种失败模式是非对称的：与伪标签不一致的轨迹通常是错误的，无论投票本身是否正确。基于这一观察，我们提出测试时策略优化（TTPO），一种非对称目标，通过OPSD蒸馏一致轨迹，并通过Grouped RL惩罚不一致轨迹。Token级选择进一步优化两个分支：蒸馏降低已收敛位置的权重，而RL仅惩罚高置信错误。即使在伪标签频繁出错的情况下，两种更新仍都有充分依据，并且随着模型改进，多数投票路由产生更紧致的自监督。在无任何标签的情况下，TTPO在五个竞赛级基准上媲美标签监督的OPSD，将Qwen3-1.7B在TTT中从38.0%提升至45.2%，在无思考设置下获得+25.2%至+36.4%的提升，并展现出强大的跨任务泛化能力。

## Self-OPD: On-Policy Distillation for Flow Matching Models without Teacher

[Self-OPD：无教师的流匹配模型在线策略蒸馏](https://arxiv.org/abs/2608.26872)

Self-OPD 通过使用自探索随机分支和归一化优势优化速度场以实现多目标对齐，从而在流匹配中无需任务特定的教师模型。在线策略蒸馏（On-policy Distillation, OPD）利用预训练的专业教师模型提供密集监督信号，在大型语言模型（LLM）中取得了显著成功，并最近被应用于流匹配模型。然而，这种范式存在两大问题：首先，为每个新目标训练单独的任务特定教师模型会带来高昂的计算成本；其次，教师与学生分布之间的差异常常导致生成轨迹上的误差累积。在本文中，我们提出 Self-OPD，一种用于流匹配模型的无教师 OPD 框架，将学生自身的自我探索转化为逐步监督。在每个时间步，Self-OPD 将确定性下一状态预测分支为 K 个随机 SDE 候选，使用 ODE 采样器进行 rollout，并将它们的奖励与确定性自参考基线比较以获得归一化优势。速度场通过全分支拉推目标进行优化，其中高优势分支吸引学生，低优势分支在方向感知衰减和 SDE 方差归一化下排斥学生。对于多目标对齐，Self-OPD 在奖励层面融合归一化分数，避免直接梯度冲突。在单一和混合奖励基准上的实验表明，Self-OPD 在无需任务特定教师的情况下优于先前的强化学习（RL）和 OPD 方法。

## WeMM-Embedding: WeChat Multi-Modal Embedding Technical Report

[WeMM-Embedding：微信多模态嵌入技术报告](https://arxiv.org/abs/2608.24053)

WeMM-Embedding 是一系列通用多模态嵌入模型，可在共享空间中对齐文本、图像、视频和交错输入，在公开基准测试与大规模微信应用中取得了领先的检索与推荐性能。通用多模态嵌入正成为现代 AI 系统的核心组件，使异构内容能够在共享空间中表示，用于检索、推荐、分类和智能体（Agent）系统等场景。本报告介绍了 WeMM-Embedding，这是一系列通用多模态嵌入模型，支持文本、图像、视频、视觉文档以及任意交错的多模态输入，并支持灵活的输出维度。该系列包含 2B、4B 和 9B 三种规模，采用两阶段训练：先进行大规模多模态对齐，再使用精选数据、细粒度相关性监督和跨尺度知识迁移进行精调。在广泛评估中，WeMM-Embedding 在多个公开基准上取得领先性能。值得注意的是，2B 变体在 MMEB-v2 上已超越此前领先的 8B 开源基线，而 9B 变体进一步取得了 80.6 的全新 SOTA 总分。WeMM-Embedding 在微信业务中也展现出强劲的实际效果，在包含 26 个任务的内部基准上取得显著提升，并在 14 项在线 A/B 测试中实现持续改进。该模型已大规模部署于推荐与搜索场景，覆盖视频号、公众号、朋友圈和电商服务。我们已开源模型权重和代码，以促进后续研究，地址为 https://github.com/Tencent/WeMM-Embedding。

## On-Policy Self-Distillation in Diffusion Models

[扩散模型中的同策略自蒸馏](https://arxiv.org/abs/2608.24646)

DiffusionOPSD 采用同策略自蒸馏（on-policy self-distillation），将图像级奖励转化为扩散模型显式的中间目标，从而提升对齐效率，并能够分别分析目标构建与策略拟合。强化学习可以将扩散模型与人类偏好和特定任务目标对齐，但终点奖励并未指定中间去噪预测应如何改变。我们提出 DiffusionOPSD 作为一种同策略自蒸馏框架，将图像级奖励引导转化为采样查询处干净输出预测的显式目标。在每个外部迭代中，冻结的行为策略生成轨迹并提供查询状态和锚点。奖励梯度在每个锚点周围构建有界的正负目标。可训练策略通过有限次数拟合将这些目标作为分离监督进行拟合，随后指数移动平均更新刷新行为策略。这一设置使我们能够分别衡量目标构建和有限实现。受控同查询实验表明，更大的目标构建增益在单次拟合更新后未必能转化为更大的实际增益。在 SD 3.5-M 和步进蒸馏的 Z-Image-Turbo 上，我们的方法在跨越两个骨干网络和十个评估器的 20 个奖励匹配设置中的 19 个取得了最佳最终留出分数。与最强竞争方法相比，它最高提升 44.0%，并且与 DiffusionNFT 相比，在 SD 3.5-M 上减少了 40% 的训练 GPU 小时数，在 Z-Image-Turbo 上减少了 63%。这些结果支持同策略自蒸馏作为一种高效且可分析的扩散模型后训练方法，通过将图像级奖励引导转化为显式且不断刷新的中间监督，为更高效和可诊断的对齐开辟了道路。

## AutoSaddler: Automatic Harness Optimization with Durable Updates from Agent Execution Traces

[AutoSaddler：基于智能体执行轨迹的持久化自动 Harness 优化](https://arxiv.org/abs/2608.23041)

AutoSaddler 通过离线失败驱动优化自动改进 LLM 智能体的 harness，提升长时程基准测试上的性能。LLM 智能体在长时程任务中仍不可靠，局部小故障会在长时间交互中不断累积，最终导致整体任务失败。虽然外部 harness 能显著提升鲁棒性，但 harness 设计仍是手动且昂贵的过程，需要在大量提示词（prompt）、工具配置和控制逻辑组成的巨大搜索空间中进行探索。我们提出 AutoSaddler——一个自动 harness 优化框架，将 harness 改进形式化为离线学习问题，并利用小批量（mini-batch）中的失败信号迭代更新 harness。AutoSaddler 结合了失败轨迹诊断、将 harness 视为代码的结构化补丁生成，以及基于验证的更新选择。在 GAIA2、SWE-Bench Pro 和 Terminal-Bench 2.0 上的实验表明，AutoSaddler 相比对应基础 harness 显著提升智能体性能，分别获得 9.0、9.6 和 10.0 个百分点的增益。消融研究进一步表明，有效的 harness 优化受益于三个要素：深度调试而非浅层反思、定向修改而非无约束编辑、以及泛化感知的选择而非针对特定轨迹的修复。综合来看，这些结果表明自动 harness 优化是构建更强大、更可靠智能体系统的有前景路径。

## What Makes Good Agentic Data? An ACE Lens on Data Generation for LLM Agents

[什么样的 Agentic 数据才是好的？——LLM Agent 数据生成的 ACE 视角](https://arxiv.org/abs/2608.27260)

Agentic 数据生成被建模为对因子化经验元组的受限分布设计，强调执行落地准确性、相对于学习者的复杂度和多样性，而非单纯规模。LLM Agent 日益依赖生成的交互数据来学习如何与外部环境交互。Agentic 数据生成必须在环境、任务、交互和成功信号之间保持一致性，同时生成有用而非仅仅丰富的经验。现有工作覆盖了许多 Agent 领域，但以领域为中心的组织方式和异构评估常常掩盖共同的生成机制，并将候选构建与验证和选择混为一谈。本文为该领域开发了一个两层框架。首先，我们将 Agentic 数据表示为一个公共的因子化对象 (E,q,τ,v)，包含环境规范、任务信号、交互实现和可选验证器。我们按照主要锚点和依赖结构对生成范式进行组织。其次，我们通过“准确性—复杂性—多样性”（Accuracy-Complexity-divErsity，ACE）视角将生成形式化为受限分布设计。准确性确立了有根据且内部一致的数据的可行支撑集。在该支撑集内，复杂性相对于所声明学习者和执行配置的能力分配学习重点，而多样性则控制数据的覆盖范围和冗余度。利用该框架，我们探讨了以往工作如何验证生成的经验、构建和校准难度，以及扩展行为覆盖。文献显示，研究正转向执行落地准确性、相对于学习者的复杂度，以及超越表面变化或数据集规模的多样性。我们进一步通过 ACE 视角讨论了 Agentic 数据生成中更广泛的方向和新兴趋势，包括它们对扩展、数据来源、训练方案和自适应学习的影响。总体而言，核心挑战不仅是生成更多数据，而是随着 Agent 和环境演化，持续分配有效、信息丰富且非冗余的经验。

## Graph Engineering in the Era of LLM Agents: From Individual Intelligence to System Intelligence

[LLM Agent 时代的图工程：从个体智能到系统智能](https://arxiv.org/abs/2608.21156)

Graph Engineering 通过动态图结构组织多 Agent LLM 系统，以协调专用 Agent 并管理复杂、持续演变的任务。LLM 已从语言生成器进化为能够执行复杂长周期任务的自主 Agent。这一进化催生了多种范式，包括用于激发模型能力的提示工程（Prompt Engineering）、用于管理信息访问的上下文工程（Context Engineering）、用于组织外部工具与资源的工具链工程（Harness Engineering），以及支持持续反思与自我改进的循环工程（Loop Engineering）。然而，随着任务日益复杂，个体智能面临根本性局限：许多任务需要异构专业知识、相互依赖的子任务、并行执行、独立验证和持久状态，这超出了任何单一 Agent 的组织能力。增强单个 Agent 的能力或上下文无法解决这种架构性错配；智能必须分布在多个专用 Agent 之间，并在系统层面进行组织。我们称之为系统智能（System Intelligence）：即 Agent 系统将多个智能组件组织并协调成一个连贯、自适应整体以追求共同目标的能力。实现系统智能不仅需要添加 Agent，还需要显式结构来组织工作、协调异构 Agent 并维护不断演化的执行状态。为此，我们提出图工程（Graph Engineering），作为下一代 Agent 系统的新兴范式。与以往主要优化个体交互或 Agent 级行为的范式不同，图工程构建显式、动态、演化的图结构，用以表示任务、Agent 和系统状态。这些抽象为组织复杂目标、编排异构 Agent、建模系统动态以及支持可扩展的 Agent 进化提供了统一基础。我们系统性地综述了面向 LLM Agent 的图工程原则、方法论与应用。相关论文、开源数据和项目收录于 https://github.com/DEEP-JLU/Awesome-Graph-Engineering。

## TLive-Omni: An Omni-Modal Understanding Model for E-Commerce Live Streaming

[TLive-Omni：面向电商直播的全模态理解模型](https://arxiv.org/abs/2608.20958)

TLive-Omni 是一款面向直播电商的全模态（omni-modal）模型，通过带时间戳的 Token 分组、分阶段监督训练和基于可验证反馈的强化微调，将图像、视频、音频和文本统一建模，从而实现准确的实时理解。电商直播需要对嘈杂且时间跨度较长的流式内容进行全模态理解，商品事实信息分散在语音、视频帧、商品图片、叠加文字和用户查询中。我们提出 TLive-Omni，一个针对直播电商场景定制的全模态理解模型，将图像、视频、音频和文本输入映射到统一表示空间。针对长时直播流分析，我们引入 Per-vGrid——一种带时间戳的 Token 组织形式，将每个视频网格与其时间上对应的音频组合在显式边界 Token 内，以促进时间对齐。我们设计了一套三阶段监督训练方案，从全模态感知到指令跟随响应，逐步建立直播电商理解能力；随后提出 Faithful-RFT 强化微调阶段，在满足实时性要求的同时进一步提升答案忠实度和表达质量——直接以任务可验证反馈对最终响应进行评分，而非在 rollout 过程中优化推理式探索。此外，TLive-Omni 依托面向场景的原子能力分类体系和紧凑型数据生产引擎，后者可将直播电商的音频、图像和视频流转换为语音识别、说话人分析、商品视觉定位（visual grounding）、文字识别、时间定位（temporal grounding）、视频密集描述（dense caption）和全模态问答（omni-modal QA）等任务的训练信号。在可扩展训练方面，同步长度分组采样器在保持各 worker 负载相当的同时减少填充（padding）；轻量级动态采样策略以近零奖励方差重新生成 rollout 分组，从而为 GRPO 维持有意义的相对优势。在电商直播基准上的实验表明，该模型在直播电商领域任务上表现强劲，同时在通用基准上也展现出优异的泛化能力。

## Unlocking the Potential of Image Editing via Concept Scaling and Dense Supervision

[通过概念缩放与密集监督解锁图像编辑潜力](https://arxiv.org/abs/2608.16812)

一种分层分类体系（hierarchical taxonomy）和密集监督（dense supervision）策略，通过细粒度概念、大规模配对数据和粒度化评估，改进了基于扩散的图像编辑。现有图像编辑框架主要遵循文生图扩散模型的训练范式。然而，将这一范式扩展到图像编辑时，暴露了两个固有差异：一是对编辑概念粒度的关注不足，二是稀疏监督信号导致的训练效率低下。为解决这些问题，我们构建了一个包含 1000 多个细粒度编辑概念的全面分层分类体系，并通过改进的合成框架建立了 ConceptEdit-12M——一个包含 1200 万高质量编辑配对的大规模数据集。这种库驱动的方法有效纠正了生成数据的分布坍缩，同时保证了较高的数据保真度。此外，我们提出了一种密集监督训练策略，将多个互不干扰的概念合成为单个图像配对。通过提供更丰富的学习信号，该策略显著提升了训练效率和整体模型性能。训练结果验证了我们的策略，显著优于先前工作。最后，我们提出了 ConceptEdit-Bench，一个粒度化评估套件，用于在各种真实世界场景中诊断模型能力。

## Prime Agent: A Self-Improving RLM Harness

[Prime Agent：自我改进的 RLM 框架](https://arxiv.org/abs/2608.23552)

Prime Agent 是一个开源框架（harness），利用递归子代理（recursive subagent）、持久化计算和代理间协调，扩展语言模型在编码与推理任务中的长时程（long-horizon）能力。语言模型本质上是顺序处理器，但长时程代理行为需要模型权重与活动上下文之外的外部信息与计算支持。Prime Agent 面向长时程评估与编码代理工作流：持久化 IPython REPL 遵循递归语言模型（Recursive Language Model）抽象，实现程序化上下文处理与测试时计算（test-time compute）；Continual Harness 跨轨迹保留历史记录、记忆、技能、提示词与子代理规格。递归子代理通过直接的代理间通信进行协调，Agents View 让人类可以检查和管理由守护进程（daemon）支持的会话。Prime Agent 将执行、恢复、验证与资源核算标准化，同时将策略构建留给模型自主完成。这层低摩擦、高表达力的边界可防止框架故障演变为模型故障，并将评测推向模型真实的最大底层能力。Prime Agent 将 ARC-AGI-3 RHAE Best@1 从 30% 提升至 95.5%，并在长上下文编码、GPU 内核生成、模拟器构建及自主 nanoGPT 速通任务上达到或超越原生与主流框架的表现。在 Factorio 中，细化（refinement）机制支持技术持续推进，专用子代理则实现并行化工作。代码已开源：https://github.com/PrimeIntellect-ai/prime-agent。

## Training Agents to Evolve with Their Harness: TaoLive Digital Avatar Agent Technical Report

[训练智能体随其控制框架进化：淘Live数字人智能体技术报告](https://arxiv.org/abs/2608.15763)

控制框架感知训练（Harness-Aware Training, HAT）使紧凑模型能够以低延迟和高精度适应不断演进的数字人控制框架配置。AI 驱动的数字人主播必须实时回答产品问题、吸引观众并执行营销策略，这要求低延迟、频繁的策略更新以及准确而有效的响应。可演进控制框架（Evolvable Harnesses）中的技能（Skills）、钩子（Hooks）、提示词（prompts）和工具（tools）可独立于模型权重进行更新，从而支持快速迭代，但也暴露了一个权衡：大模型可以零样本适应但速度过慢，而紧凑模型能满足延迟目标却会过拟合固定的控制框架配置。我们提出了控制框架感知训练（HAT），训练紧凑模型适应变化的控制框架。其关键组件控制框架状态增强（Harness-State Augmentation, HSA）对技能标识符和内容、工具模式、提示结构以及钩子函数施加保持任务不变的变换。训练分三个阶段进行：HSA-SFT 从多样化环境中的强模型轨迹学习推理和工具使用；通用同策略蒸馏恢复监督微调（SFT）中丢失的泛化能力；HSA-RL 通过在增强环境中进行强化学习（RL）提高对变化控制框架的鲁棒性。在四个评估集上，HAT 在直播问答（Live-Stream QA）上取得 94.8（基线：80.3；最强通用大语言模型：93.0），在控制框架变体问答（Harness-Variant QA）上取得 94.6（基线：75.4）。与将 IFEval 从基础模型降低 7.7 分的固定控制框架 SFT 不同，HAT 避免了这一退化并达到 83.5。在单块 NVIDIA H20 GPU 上，优化后的系统实现了 P50 和 P95 延迟分别为 3.4 秒和 8.1 秒。该系统已部署在淘宝直播的数字人服务中，并在 GMV 和商品页浏览量方面取得了正向的在线 A/B 测试结果。

## Let's Scale Step by Step: Compute-Efficient Hyperparameter Transfer for Large-Scale Mixture-of-Experts

[逐步缩放：大规模混合专家模型的高计算效率超参数迁移](https://arxiv.org/abs/2608.20061)

一种两步超参数迁移框架通过跨宽度和 token 预算的缩放来预测大规模混合专家（Mixture-of-Experts, MoE）模型的最优学习率，从而无需昂贵的扫参即可高效预训练。MoE 架构显著扩展了模型容量，而计算成本不会成比例增加。然而，在模型规模和 token 预算均达到极端尺度时，通过扫参来优化其超参数（尤其是学习率）在计算上仍然难以承受。本文提出一种计算高效的两步超参数迁移框架：先跨模型宽度迁移，再外推至万亿 token 规模，以此估计训练大规模 MoE 模型的最优学习率。首先，我们为采用多头潜在注意力（Multi-head Latent Attention, MLA）和 Muon 优化器的 MoE 架构制定了最大更新参数化（Maximal Update Parameterization, μP）适配方案，证明最优学习率在宽度缩放模型间能够一致迁移。其次，我们通过建立预测缩放律，将这种可迁移性沿 token 维度扩展。通过对有限预算下小型代理模型得到的最优值进行线性回归，我们成功地将理想学习率外推至大规模训练场景（如 10 万亿 token），且拟合优度极高（R²=0.95）。这表明，基于小模型的代理训练足以确定大规模 MoE 广泛训练的最优学习率。我们将所提方法应用于从零预训练基础模型（总参数 155B，激活参数 17B），稳定的训练和评估结果验证了：全尺寸目标模型的最优配置只需极小的消融成本即可准确预测。
