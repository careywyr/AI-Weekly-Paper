## Raven: The Harness of Harnesses for Composable Agentic Intelligence

[Raven：面向可组合智能体系统的“框架之框架”](https://arxiv.org/abs/2609.33439)

随着大语言模型（LLM）的进步，AI Agent 正从孤立的、特定领域任务走向长时程、跨领域工作流。这一转变暴露出两大挑战：智能体运行框架（harness）复杂度的上升使人工设计难以规模化，而对特定领域的紧密耦合又限制了单一运行框架的通用性。因此，核心问题从“如何为某一领域设计更强的运行框架”转变为“如何自主构建专用运行框架、通过经验持续改进，并在跨领域间进行编排”。我们提出 Raven——框架之框架（The Harness of Harnesses），一个开源多 Agent 生态系统，可针对特定模型与领域自动构建并演化模块化运行框架，将每个“可执行模型—运行框架”组合视为可组合的智能单元。为支撑全域协作网络（All-Domain Collaboration Network），其宿主 Agent 负责分解目标、将子任务匹配到专用 Agent、协调执行依赖并整合结果；宿主归档与 EverOS 跨任务保存经验，Skill Forge 则将这些经验转化为可复用的流程。我们的理论给出了充分条件：在共享资源预算下，这种组合能够将可靠任务覆盖范围扩展到超过可用单个 Agent 的水平。在复杂与长时程任务上，Raven 显著优于当前最先进的 Agent 系统，拓展可组合智能体系统的能力边界。

## The Teacher Is a Direction, Not a Destination: Extrapolating RL-Induced Representation Residuals in On-Policy Distillation

[教师是一个方向，而非终点：在在线策略蒸馏中外推 RL 诱导的表征残差](https://arxiv.org/abs/2609.36484)

在线策略蒸馏（on-policy distillation, OPD）训练学生模型在学生自身轨迹上匹配教师模型的下一 Token 分布，并已取得显著的经验收益。广义变体允许学生通过在输出空间中外推隐式奖励来超越教师。然而，语言模型头会以各向异性的方式衰减这种变化：教师隐藏状态中编码的许多变化在到达 logits 时仅保留其权重的一小部分，而输出空间外推所依赖的采样 Token 对数概率比会引入噪声，外推又会放大该噪声，导致训练不稳定。我们观察到，强化学习（RL）会使模型的内部表征相对于其基础检查点发生偏移，并且这种偏移的方向可以在每一层被测量。受此观察启发，我们提出 RIDE（RL-Induced Direction Extrapolation），它直接在表征空间中外推 RL 诱导的变化：在每一层和每个 Token 位置，RIDE 计算教师模型与其 RL 前检查点之间的残差，并将学生隐藏状态回归到沿该残差方向、超越教师的目标位置。以采样轨迹为条件，这种回归等价于在以教师为中心的二次惩罚下最大化由残差定义的线性方向奖励，从而明确刻画了该目标如何使学生在 RL 诱导方向上移动，同时限制其与教师的偏离。在四组涵盖不同规模、架构和预训练谱系的基础/RL 教师配对上，RIDE 在每一对上都接近或超过经 RL 训练的教师，并且是唯一在均值上做到这一点的方法；它持续优于输出空间外推——当教师接近其基础模型时，后者会使学生性能退化。项目页面：https://github.com/xixixixixxxx/RIDE。

## MaLiang-Harness: A Programmable Path to Image and Video Generation

[MaLiang-Harness：通往图像与视频生成的可编程路径](https://arxiv.org/abs/2609.34309)

可执行程序为图像与视频的构建方式提供了显式控制，但生成可运行代码仅仅是视觉创作的起点。程序可以正确执行，却违背所要求的构图、外观或运动。我们将这一偏差定义为程序到视觉（Program-to-Visual，P2V）鸿沟，并提出 MaLiang-Harness——一个统一框架，将 MLLM 驱动的视觉生成组织为构建、检查与修订的持续过程。其核心设计是让不断演化的视觉程序、其构建历史与验证过程共享同一修订参照。我们定义持久可执行生成（Persistent Executable Generation，PEG）状态以保存程序与任务上下文；可追溯生成过程（Traceable Generation Process，TGP）将编辑与渲染证据相连接；修订感知编辑与验证（Revision-aware Editing and Verification，REV）支持恢复，并在完成前检查当前修订。这些机制协同工作，跨渲染后端协调规划、执行与视觉反馈。我们在 MaLiang-IBench 上评估了 11 个强大的闭源 MLLM，在 MaLiang-VBench 上评估了 4 个，衡量生成成功率、视觉质量与计算成本。GPT-6-Astra 在两个基准上均达到 100% 生成成功率，其中 96.0% 的图像任务与 76.9% 的视频任务满足全部质量阈值。对比还揭示了通用能力得分与视觉生成表现之间的错配：得分相近的模型在满足视觉要求的能力上差异显著。MaLiang-Harness 为研究 MLLM 如何将可执行代码转化为视觉结果提供了系统性基础，既展现了可编程生成的潜力，也暴露了通用基准作为该能力预测指标的局限。项目地址：https://github.com/gulucaptain/MaLiang-Harness。

## LoopVL: Recurrent Visual Intelligence

[LoopVL：循环视觉智能](https://arxiv.org/abs/2609.38426)

我们提出 LoopVL，用于研究 Loop Transformer 能否有效扩展到视觉-语言模型。LoopVL 结合模块循环（Module-Loop）与模型循环（Model-Loop）计算，通过共享模块迭代更新统一的视觉-语言状态。我们从零开始训练 LoopVL，经历语言预训练、多模态训练和后训练阶段。在多模态理解与视觉推理基准上，LoopVL 的表现优于一系列规模相当乃至更大的非循环模型。我们还在 LoopVL 中观察到“视觉顿悟时刻”（Visual Aha Moments），其特征是视觉注意力在不同循环轮次间出现显著转移。LoopVL 为循环式视觉-语言建模提供了实践证据，并就共享参数如何支持在持续演化的视觉-语言状态上进行更深层的多模态计算，给出了直观的视角。

## False Frontiers: Diagnosing and Mitigating Co-Cheating in Self-Evolving Search Agents

[虚假前沿：诊断与缓解自进化搜索智能体中的协同作弊](https://arxiv.org/abs/2609.39102)

自进化搜索智能体通过联合优化生成问题的出题器（proposer）与回答问题的求解器（solver）来构建自身的训练课程。这种闭环引入了一种失败模式，我们称之为协同作弊（co-cheating）：出题器与求解器越来越在共享错误上达成一致，使内部奖励提升，但外部正确性并未获得相应增益。基于源证据的事后审计表明，随着自进化轮次增加，协同作弊愈发严重，即使环内训练信号改善，伪标签正确率也停滞甚至下降。最直接的缓解方式是在训练前验证提案：我们引入多样本验证（MSV），对同一模型分别在有源文档和无源文档条件下各查询三次，以决定任务是否准入并替换不可靠伪标签。MSV 部分减少了虚假一致，但仍留下大量残余协同作弊，且每个候选需要额外六次标注器生成。这些局限促使我们提出主要方法 CrossFit：它将出题器的源文档划分为 A、B 两组；由 A 生成的问题由仅在 B 上训练的辅助求解器评分，反之亦然。交叉拟合一致性决定出题器奖励，因此同源伪标签无法通过反馈求解器复现，而原求解器的更新规则保持不变。使用 Qwen3.5-4B 和 Qwen3.5-9B 重新运行该循环，MSV 将虚假一致质量从 6.1% 降至 5.7%、从 8.8% 降至 7.2%，而 CrossFit 将其降至 3.0% 和 3.7%。用排除源文档的反馈重放相同提案，可进一步将虚假一致降至 0.4% 和 0.1%，从而将反馈来源与课程变化隔离开来。在七个下游搜索基准上，CrossFit 在 4B 和 9B 规模下，相较标准耦合自进化平均性能提升 8.8 和 8.4 分，相较 Search-R1 提升 8.7 和 7.8 分。

## In-Context Learning for Robots: Methods and Applications

[机器人的上下文学习：方法与应用](https://arxiv.org/abs/2609.36012)

通用机器人必须推断新任务的要求，并将这种理解转化为适当的物理动作。机器人的上下文学习（In-Context Learning，ICL）通过利用演示和交互来引导已有能力，并在部署期间保持神经参数固定，从而支持这一过程。本综述围绕连接上下文证据与执行的接口展开，区分了四类方法：上下文条件策略、几何演示迁移、基于世界模型的控制，以及基于技能和 Agent 的执行。比较这些接口有助于厘清它们的迁移假设，以及训练、对应关系和记忆在使上下文发挥作用中的角色。在操作与导航领域，我们考察了当物体、环境和执行条件发生变化时，这些机制如何保持已教授的要求。该分析将方法设计与评估实践联系起来，以区分对教学的响应性、物理迁移能力，以及从保留经验中获得的收益。由此形成的议程将组合式任务获取、忠实迁移与物理递归自我改进联系起来，其中经验提升了学习后续任务的能力。

## Scaling Properties of Same-Family On-Policy Distillation

[同系列在线策略蒸馏的缩放特性](https://arxiv.org/abs/2609.32722)

强化学习（RL）能够为大型语言模型（LLM）注入强大的推理能力，但这种能力在不同模型规模之间能迁移多少、迁移速度多快，仍不清楚。我们研究了在线策略蒸馏（on-policy distillation, OPD）在弱到强、同基座、强到弱三种师生设定下的缩放特性。我们发现，早期 OPD 训练动态一致地表现出一种规律性的有效迁移阶段：在该阶段，留出集准确率（gold score，G）随 d=√(KL(π_θ‖π_ref)) 近似线性上升，其中 d 是相对于学生初始化时 token 级反向 KL 散度的平方根。在所有观察到的弱到强配对中，学生的峰值 gold score 都超过其教师自身的峰值，因此一个紧凑的 RL 专家可以通过 OPD 将能力迁移给规模大得多的学生。为估计 OPD 的结果，我们拟合了幂律，描述 G_peak 以及有效迁移阶段的斜率如何随学生和教师的参数量以及教师 gold score 缩放。这些规律表明，峰值 gold score 随教师规模提升仅持续到大约学生规模为止；在 gold score 相同时，较小的教师迁移效果更好，因此仅凭教师分数无法界定其监督价值。我们还研究了两种 OPD 变体的缩放效应：自举弱到强 OPD，以及在线策略监督的程度。

## Omni-IO Skills: Harnessing Your Agent Omni-Native

[Omni-IO Skills：让 Agent 实现全模态原生能力](https://arxiv.org/abs/2609.31847)

通用 Agent 能够进行长时程的规划、推理与执行，但其生产级能力仍分散在文本、图像、音频、视频、文档、3D 资产和代码等多种模态中。将基础模型扩展到更多模态，意味着能力增长受制于高昂的模型更新成本；而组合专用模型与工具，又无法解决流程、依赖关系、中间资产以及跨轮次修订之间如何协调的问题。本文提出 Omni-IO Skills，一种即插即用的 Agent Harness，通过分层 Skills、标准化多模态执行接口、依赖感知编排以及持久化 Asset Registry，使现有 Agent 具备全模态原生能力。多资产工作流被表示为 Declare Execution Graphs（声明式执行图），可并发调度相互独立的操作，并将成功输出注册以供下游及跨轮次复用，且支持可替换的执行后端。其 27 个 Skills 覆盖 38 项代表性任务，横跨七种产物模态与四类能力族：理解、生成、推理和检索。在 UniM-90 上，该 Harness 将 GPT-5.6 Sol 与 Claude Sonnet 5 的输入支持率分别从 40.00% 和 38.89% 提升至 100%，同时将相对 Semantic--Quality Coupled Score 分别从 26.99 提升至 74.94、从 27.82 提升至 77.78；Strict Structure Score 达到 100.00 和 99.78。这些结果表明，Harness 层面的能力组合是一条可行路径，可在不改变宿主 Agent 推理核心的前提下，构建广泛且可持续演进的全模态系统。

## UniEvo-VL: An On-policy Self-Distillation Training Recipe for Multimodal Model Self-improvement

[UniEvo-VL：面向多模态模型自我改进的在线策略自蒸馏训练方案](https://arxiv.org/abs/2609.38721)

现代多模态模型将生成与理解整合到单一统一系统中，使其能够提供并利用自身反馈进行学习。受这种统一能力启发，我们提出 UniEvo-VL——一个面向多模态模型的自演化框架，使其在测试时计算（test-time compute）过程中从这种建设性的自我纠错反馈中学习。该方法不依赖独立且往往规模更大的教师模型，而是将模型自身的自我批判作为特权信息（privileged information），让单个多模态模型在不同上下文下同时充当教师与学生。学生仅看到原始问题，教师则以特权批判为条件。训练目标是在学生自身的采样轨迹上，最小化二者去噪扩散分布之间的逐状态散度。实验表明，UniEvo-VL 提升了多模态模型的图像生成能力，同时保持其对额外反思信息的敏感性。具体而言，我们基于开源模型 Qwen-image-2512 构建，在 GenEval 上从 0.747 显著提升至 0.808，在 GenEval2 Soft-TIFA 上从 32.97 提升至 35.53。此外，使用更强大的外部评判者（如 GPT5.6-Luna）的尝试表明，具备强评判能力的多模态模型有望达到更高的自演化上限。最后，混合文本渲染结果表明，我们的自我改进在不同任务之间可能并不均匀。本研究旨在为当前热门的递归自我改进研究路线提供启示，在无需外部监督或指导的情况下提升用户使用多模态模型的体验。

## Post-Training Leaves Behavioral Shadows on Unrelated Decisions

[后训练在不相关决策上留下行为影子](https://arxiv.org/abs/2609.29233)

我们发现语言模型能够通过任务无关的文本来迁移能力。后训练通常利用任务特定数据来改进语言模型。此前关于潜意识学习（subliminal learning）的研究表明，有关这些更新的信息可以经由无关的生成内容传递，但大多聚焦于依赖大量教师输出的特质或偏好。我们提出主动无任务蒸馏（Active Taskless Distillation，ATD），每个 prompt 仅使用教师模型产出的一个词即可实现能力迁移。ATD 通过挑选那些教师模型与学生模型共同的公开祖先模型在两个普通词之间几乎无差别的 prompt，来探查后训练的行为影子。以该祖先模型初始化的学生模型，仅从由此得到的 prompt-词对中学习，无需目标任务的样例、教师 logits 或教师参数。在 Qwen2.5-1.5B 上的主要编程实验中，5,664 个样本在 HumanEval+ 上相比严格匹配混淆因素的对照组（该对照组打乱 prompt 与响应的配对关系）取得 5.34 个百分点的提升。实验还显示，该迁移效应在科学知识、常识推理与阅读理解上同样成立，并覆盖更多模型代际、规模与家族。功能性分析表明，所习得的这种副作用具有可组合性，且其强度与教师模型的更新强度同步。

## YuE2: Unifying Symbolic and Audio Music Generation at Frontier Quality

[YuE2：以前沿质量统一符号音乐与音频音乐生成](https://arxiv.org/abs/2609.33757)

符号模型能够显式表达旋律、和声、节奏与曲式，但通常止步于成品录音之前；音频模型则产出完整歌曲，却将作曲过程隐含其中。我们提出 YuE2，通过符号规划以前沿质量统一符号音乐与音频音乐生成。单个 AR-NAR Mixture-of-Transformers（MoT，混合 Transformer）首先写出可读的乐谱，明确旋律与和声，再将其扩展为语义音乐 Token，并最终实现为完整歌曲音频。在使用同一检查点的对比中，专家更偏好带有符号规划的生成结果，其整体质量与音乐性更佳，整体偏好率为 49.3%，而无规划时为 34.6%。专家也偏好统一模型，胜过单独的语言模型与扩散 Transformer。在 WildSongBench 上，YuE2 的 SongBench Global Avg 得分为 6.73，超过所有已评估的公开基线。从八个候选中择优（best-of-8）时，YuE2 达到 6.96，为所有已评估系统中观测到的最高均值。专家听测进一步确立了其与专有歌曲生成器的竞争力：best-of-8 优于 Suno v4.5，并在与 Suno v5 的对比中取得接近均衡的偏好。为在无对齐乐谱的情况下从录音中学习这一生成过程，我们引入 MERT2 与 SheetSage2，分别提供语义监督与符号监督。MERT2 在音乐表示学习上树立了新的 SOTA，在 15 项 MARBLE 指标中的 14 项上超越此前最佳结果；SheetSage2 在我们的主旋律谱转录对比中于 15 个基准—指标组合中的 12 个领先。同一检查点能够遵循乐谱编辑，同时大体保留未编辑的音乐内容，并可在无翻唱专门训练的情况下生成零样本翻唱。其可读乐谱还支持 Agent 式音乐编辑，由外部语言模型将用户反馈转化为对作品的修改。

## VisionHOPE: Visual Backbones as Self-Modifying Learning Systems

[VisionHOPE：将视觉骨干网络作为自修改学习系统](https://arxiv.org/abs/2609.33325)

视觉骨干网络已从具备局部聚合能力的卷积神经网络（CNN），演进到拥有全局交互的 Vision Transformer（ViT）、具有输入依赖状态转移的状态空间模型（SSM），以及能在处理图像的同时适配内部学习器的测试时训练（TTT）层。在这一演进过程中，视觉计算对每个输入的适应性不断增强，但支配这种适应的规则在很大程度上仍由训练完成的骨干网络预先设定。我们提出 VisionHOPE，这是首个将通用视觉骨干网络形式化为自修改学习系统（self-modifying learning system）的工作，使模型“记住什么”与“如何学习”在单张图像内部协同演化。基于嵌套学习（Nested Learning，NL）的自指构造，VisionHOPE 通过五个耦合记忆实现这种协同演化，这些记忆分别负责存储内容、生成键与值表示，并调控学习率与保留率。随着视觉上下文沿每次扫描不断累积，这些记忆联合演化。然而，将无约束的自指更新直接应用于视觉骨干网络会导致不稳定。为此，我们推导出一种稳定性匹配的步长控制方案，将自指注入的软上限与对保留记忆转移的谱钳制相结合，并证明由此产生的记忆动力学在每次扫描中均是非扩张的。对于二维特征图，我们通过将分块与图像的行、列在四个方向扫描中对齐，适配了 NL 的分块形式。所提出的 VisionHOPE 在 ImageNet-1K、COCO 与 ADE20K 上取得了有竞争力的结果，确立了自修改学习系统作为通用视觉骨干网络实用基础的地位。代码见 https://github.com/PSRben/VisionHOPE 。

## Rethinking Latent Visual Reasoning: Grounding Latent Reasoning in Visual Evidence

[重新思考潜在视觉推理：将潜在推理锚定于视觉证据](https://arxiv.org/abs/2609.34563)

潜在视觉推理（Latent Visual Reasoning，LVR）使多模态大语言模型（MLLM）能够在连续潜在 Token 中执行中间计算，而不必将每个推理步骤都用文字表达出来。然而，与文本 CoT 不同，潜在推理无法被直接观测，因此难以对潜在 Token 所学内容进行监督。本文首先对潜在 Token 的行为展开深入分析，发现了一个“潜在证据—信用差距”（latent evidence-credit gap）：当图像扰动改变正确答案时，潜在 Token 仅产生微弱响应。我们推测该问题源于 GRPO 训练过程中缺乏显式监督。这些发现表明，仅靠最终答案奖励，对应当保留哪些视觉证据、以及如何在各潜在 Token 之间分配信用，提供的指导过于不足。为弥合这一差距，我们提出 ReaLVR，将视觉证据监督引入模型自身自由运行的潜在轨迹。ReaLVR 通过对比正确答案与模型生成的错误答案，确定何处需要更强的监督；并通过对比相关视觉证据与不匹配的视觉证据，明确应当保留的内容。在三个模型系列上，ReaLVR 均持续优于所评估的 LVR 基线，在 Qwen2.5-VL-7B 上取得五项任务平均 63.7% 的最高成绩。更重要的是，我们首次实现了潜在空间视觉推理的规模化，表明该框架在前沿模型规模（最高达 235B）下仍能持续带来稳健提升。进一步分析显示，潜在 Token 位置对问题更加敏感，与相关视觉区域的对齐更强，且对最受关注的潜在 Token 表现出更强的固定上下文依赖。

## Beyond Teacher Assignment: Domain-Normalized Multi-Teacher On-Policy Distillation

[超越教师分配：领域归一化的多教师同策略蒸馏](https://arxiv.org/abs/2609.35347)

强化学习可以把一个语言模型训练成多个专家模型，每个专家精通单一技能，如数学、编程或指令遵循，但用户需要的是一个同时具备这些技能的模型。多教师同策略蒸馏（Multi-Teacher On-Policy Distillation，MOPD）通过让各专家共同教导一个学生模型来融合这些能力：学生模型回答每个提示，而该提示所属领域的专家对每个 Token 给出反馈。这种路由机制决定了由哪位专家教学，却未决定其反馈对学生模型的影响强度。在三种规模的 Qwen3.5 模型上，我们发现 MOPD 训练出的学生模型并未超过由最佳单一专家教导的学生模型，并且几乎没有获得数学专家的优势。反馈是不均衡的：指令遵循反馈的离散程度是数学反馈的数倍，并主导了学生模型的更新。我们提出领域归一化 MOPD（Domain-Normalized MOPD，DN-MOPD），它保留原有路由，并按各领域实测的反馈离散程度对反馈进行重新缩放。在六个公开基准上，DN-MOPD 在每种规模、三个随机种子以及两种答案长度限制下，平均得分均优于 MOPD，并恢复了大部分损失的数学能力增益。固定领域权重的对照实验表明，增益主要来自降低指令遵循反馈的强度，而非单独提高数学反馈，并且采用接近 DN-MOPD 实测值的固定权重也能取得相当的效果。因此，融合多个专家不仅需要决定由哪位专家教学，还需要决定其反馈的权重有多大。

## PanoVLN: Towards Effective Panoramic Vision-and-Language Navigation

[PanoVLN：面向高效全景视觉–语言导航](https://arxiv.org/abs/2609.34759)

近期视觉–语言模型（VLM）的进展推动了视觉–语言导航（VLN）的发展，使模型能够根据视觉观测和语言指令预测导航动作。本工作探索基于全景观测的 VLN，并提出 PanoVLN。其动机十分直接：更完整的视觉上下文应当有助于做出更明智的导航决策。例如，全景图可以揭示透视相机视场之外的通道，使模型无需额外探索即可识别目标路线。然而我们发现，仅将透视图像替换为全景图，带来的收益十分有限。我们的诊断表明，要充分利用更广阔的可见范围，需要改进动作预测、训练监督和视觉表征。第一，更广的可见范围支持更长时程的动作规划。我们让模型预测更长的动作序列，从而能够仅凭单张全景图完成更大的转向及后续移动。具体而言，我们引入置信度引导执行（confidence-guided execution, CGE）策略，动态决定在重新规划前执行多少个预测动作。第二，更广的可见范围也带来更复杂的路线选择。因此，我们构建包含频繁分岔点和清晰指令的训练路线，为路线选择提供有针对性的监督。第三，全景导航需要理解跨视角方向的空间关系，而不仅是识别单个地标。我们融合 RGB 全景图的语义与几何特征，在不增加视觉 Token 的情况下同时捕捉场景内容和空间布局。在 4B 主干网络与仅 RGB 输入的条件下，PanoVLN 在 R2R-CE 和 RxR-CE Val-Unseen 上的成功率分别超越此前 SOTA 11.9% 和 8.7%。在四足机器人上的真实世界实验进一步表明，相比此前的 VLN 方法，其导航更快、停顿更少。

## On-Policy or Off-Policy Learning? A Systematic Study of Distillation Dynamics

[在策略学习还是离策略学习？蒸馏动态的系统性研究](https://arxiv.org/abs/2609.35259)

在策略（on-policy）学习被认为可以减少灾难性遗忘、产生更稀疏的参数更新并提升泛化能力。然而，现有的监督微调与强化学习之间的比较往往同时改变多个因素，使得 rollout 策略本身的贡献难以被单独分离。我们在一个受控的强到弱蒸馏（strong-to-weak distillation）设定中研究 rollout 策略的影响，独立地改变 rollout 策略、Token 级 KL 方向和学习率，覆盖 Llama3 与 Qwen2.5 模型系列，以及横跨科学、医学和算术领域的推理任务。我们的分析揭示了蒸馏动态的更细致图景：rollout 策略未必扮演核心角色。相反，Token 级 KL 方向更明显地塑造任务性能和输出覆盖范围，而学习率则主导遗忘与更新稀疏性。对 KL 梯度的分析以及沿连续学生—教师 rollout 策略谱系的实验解释了这一模式：前向 KL 对 rollout 策略表现出显著的鲁棒性，即使 rollout 策略发生变化，其性能依然稳定且强劲；而反向 KL 则敏感得多，并偏好由学生生成的 rollout。尽管如此，在两种 KL 方向下，在策略数据都能提升对更难 Countdown 算术任务变体的泛化能力，不过这一优势在后续 RLVR 之后并不能可靠地保持。我们的主要结论在去除梯度裁剪、使用采样式 KL 估计器以及在需要更长推理链的任务上训练时依然稳健。总体而言，我们的结果挑战了“在策略 rollout 天然更优”的观点，并表明其价值关键取决于目标函数、评估设定和优化超参数。

## OneStreamer: Unifying Perception, Memory, and Proactive Response in Streaming Video Interaction

[OneStreamer：统一流式视频交互中的感知、记忆与主动响应](https://arxiv.org/abs/2610.01762)

流式视频 LLM 必须在尚不清楚未来任务相关性之前就保留证据，并在证据充分时作出响应。其挑战在于：在不损害实时感知的前提下形成可复用的事实记忆。我们提出 OneStreamer，通过共享的主动生成（proactive generation）过程，联合学习与查询无关的证据记录和任务响应。其主动式分层字幕记忆（Proactive Hierarchical Caption Memory，PHCM）生成带时间定位的局部细节字幕与已完成事件的摘要。流式字幕目标在训练中监督模型对已观测视频前缀的解读。推理时，模型生成的记录补充近期视觉窗口，提供可复用的事实上下文，而无需重新访问历史视觉特征。主动状态转移学习（Proactive State Transition Learning，PSTL）通过在全部输出锚点保留监督，并选取具有代表性的状态变化与状态保持 Token，降低重复等待状态的主导性。我们进一步开发了流式数据合成流水线，使输出内容与时机同可用证据对齐。将由此得到的流式字幕和问答数据与清洗后的开源数据结合，得到 OneStreamer-1M——一个覆盖广泛、包含超过一百万条记录、涵盖多种任务的流式视频交互数据集。我们的 4B 模型在全部八个评测流式视频理解基准上均取得优于对比方法的最佳结果。消融实验表明，保留生成的字幕能够提升历史问答性能，且不会降低实时感知能力。PSTL 在仅监督 27.5% 的标注状态 Token 的情况下，仍优于稠密状态监督。这些结果共同支持将主动生成作为共享学习接口，连接流式视频交互中的感知、记忆形成与及时响应。

## FuseReg: Regularizing Layer Fusion Mitigates the Reconstruction-Generation Gap in Representation Autoencoders

[FuseReg：通过正则化层融合缓解表征自编码器中的重建-生成鸿沟](https://arxiv.org/abs/2609.31620)

表征自编码器（RAE）复用预训练视觉编码器的特征作为重建与扩散隐变量，从而将强视觉表征引入图像生成。然而，RAE 仍需确定哪些编码器层构成生成器与像素解码器共享的隐空间。这一选择涉及权衡：较浅层往往更好地保留细粒度像素细节，而较深层往往带来更好的生成指标。因此，固定的启发式层融合会把受益于不同信息的两个阶段耦合在一起。我们提出 FuseReg，以在编码器层的随机子集上进行训练来替代启发式特征选择。我们从理论上分析了其内在机制：子集采样显式地惩罚了对跨层不一致性的敏感度。在 ImageNet-256 上使用 DINOv3-L，单个 FuseReg 解码器无需重新训练即可从完整、稀疏和单层融合中重建，PSNR 高于专用于固定融合的解码器。这种灵活性同样有益于生成：在 RAEv2 DiT-XL 生成器不变的情况下，仅替换解码器即可将无引导 gFID 降低 27%。同一正则化原则可扩展至扩散训练，对两个阶段进行联合正则化可在 DiT-Base 上将无引导 gFID 降低 29%。这些结果表明，为层融合鲁棒性训练下游模型能够在不修改预训练编码器的情况下缩小重建-生成鸿沟。

## VoxMem: Benchmarking Multimodal Memory in Large Audio Language Models

[VoxMem：大型音频语言模型中的多模态记忆基准测试](https://arxiv.org/abs/2609.32607)

口语对话系统必须能够从先前交互中恢复信息（即记忆），但语音中的相关信息不止于说了什么，还包括谁说的、如何说的以及有哪些可听声音——这些信息仅存在于音频信号中，无法从文字转写中恢复。除了记住什么，记忆还要求多样化的操作：检索单一事实、跨轮次整合证据、跟踪不断演变的状态。真实交互还会跨会话展开，这意味着信息是在不同片段中逐步累积，而非存在于单一连续录音中。现有基准在以上三个维度上均存在不足：它们主要关注词汇内容，采用有限且临时设定的记忆操作，并将记忆视为单会话问题。我们认为，有原则的记忆评估需要同时刻画所需保留的声学证据以及施加于其上的操作，并据此提出一个沿这两个轴线的分类体系。基于该分类体系，我们提出 VoxMem：包含 34,743 个语音会话（177 小时）上的 3,196 个评估实例，覆盖四类声学证据（语音语义、说话人身份、副语言线索、环境声音）与四种记忆操作（信息抽取、多会话推理、时间跟踪、答案拒答），以多会话历史为基础，并按 8K 至 64K Token 的上下文预算进行分层。对 15 个 LALM 的评估显示，在 32K 下没有任何模型超过 40%。模型对“说了什么”的保留远好于“谁说的”“如何说的”或“有哪些可听声音”，这一差距在复杂操作中进一步扩大，并随历史长度增长，同时在不同证据类型上表现为性质不同的失败模式。VoxMem 旨在提供一个基础，用以衡量并推动口语对话记忆全范围研究的进展。

## GraphForge: Training Working Agents with Graph-Anchored Workspace Synthesis

[GraphForge：以图锚定工作区合成训练可干活的 Agent](https://arxiv.org/abs/2609.38923)

工作型 Agent 需要读取各类文件、协调工具调用并产出交付物。训练这类 Agent 需要基于大量真实文件构建、且结果可验证的任务，但目前能合成此类数据的流程很少。现有流程要么用模型生成文件，缺乏真实性与多样性；要么在真实文件上构建任务却没有任务专属的验证器，导致结果质量无法核查。为此我们提出 GraphForge，一个以证据图（evidence graph）为基础的框架，将任务与其验证过程同时锚定在真实文件上。该方法从以职业为基础的种子（seed）出发以控制多样性，为每个种子汇集一个由真实文件组成的工作区，并在文件间关系之上构建证据图。由于任务描述与评分标准（rubric）均从该图推导而来，任务要求都有工作区文件作为支撑，且每一条评分准则都锚定到验证它所需的文件。一次初始 rollout 进一步检验任务的可执行性，随后由一个修订 Agent 对照原始文件修复任务与评分标准，之后才开始采集轨迹。用 2,169 条 GraphForge 轨迹微调 Qwen3.6-27B，在 OpenHands 下将 GDPVal 提升至 1445.7（+65.7），在 Claude Code 下将 Workspace-Bench-Lite 与 SpreadsheetBench II 分别提升至 63.7（+7.7）和 24.0（+13.7）。在 SFT 模型自身的 rollout 上做拒绝微调（rejection fine-tuning），并以证据锚定的评分标准筛选候选样本，可在三个基准上取得进一步提升，说明这些评分标准提供了有用的筛选信号。数据与模型已公开。

## LEGO-Anything: Coding Agents for 3D Scene Reconstruction

[LEGO-Anything：用编码智能体实现三维场景重建](https://arxiv.org/abs/2609.36380)

从单张图像重建三维场景时，最有用的表示形式不是渲染结果或固定的三维输出，而是一个显式的场景程序，其执行结果可被检视、编辑和查询。我们提出 LEGO-Anything，一个 Image-to-Code 框架，其中编码智能体迭代地编写并执行 Blender 代码、检查场景与渲染结果，并修订程序。为评估端到端场景恢复，我们提出 LEGO-Bench，一个基于模拟器的基准，包含来自 104 个多样室内外场景的 208 张图像。LEGO-Bench 分别对产物有效性、可见表面几何和渲染外观进行评分；其基于模拟器的设计支持可扩展性和精确的自动评估。在受评智能体中，GPT-6-astra 总体表现最佳，室内得分 53.4%、室外得分 39.6%，但在生成有效场景产物与忠实恢复场景几何和外观之间仍存在显著差距。对智能体构建轨迹的分析揭示了三个反复出现的问题：场景初始化薄弱、迭代过程中的退步性编辑，以及自评估不可靠。这些发现促成了 LEGO-Plugin——一个无需训练的 harness 插件，用于更可控的迭代式场景构建，它改善了全部六个受评模型，总体得分相对提升最高达 62.7%。最后，我们测试了重建场景能否表示自然图像并支持视觉任务。在 LEGO-World 中，我们将目标检测、实例掩码和相对深度作为确定性查询，在 GPT-6-astra 重建的场景上导出。这些读出结果在三项任务上均表现出非平凡的性能，但远逊于专用视觉模型，表明当前编码智能体通过程序构建的场景是一种有前景但尚不够精确的自然图像表示。

## What Makes World Action Models Generalize? An Empirical Study of Test-Time Future Modeling

[世界动作模型为何具备泛化能力？测试时未来建模的实证研究](https://arxiv.org/abs/2609.34981)

世界动作模型（World Action Models, WAMs）在训练过程中同时预测未来与动作。由于视频去噪的计算开销很大，推理阶段是否仍需生成未来一直存在争议：显式 WAM（Explicit WAM）会将未来去噪为清晰帧，并与每个动作块一同输出；而隐式 WAM（Latent WAM）则完全舍弃未来以加速推理。我们发现，隐式 WAM 尽管在分布内任务上与显式 WAM 表现相当，却无法保留最初促使 WAM 诞生的泛化优势。为证明这一点，我们从三个维度评估泛化能力：环境扰动、数据效率和任务泛化。在主干网络、训练数据和预算均匹配的受控对比中，当动作专家不再以未来表征为条件时，三个维度均出现一致的性能退化。进一步分析表明，这一差距几乎完全来自去噪的第一步：收益源于对未来进行准备，而非生成未来。因此，我们提出 Simple-WAM，将未来建模简化为对完全加噪视频 Token 的一次前向传播，并使训练时的噪声调度适配这一推理行为。在仿真与真实世界任务中，Simple-WAM 实现了两全其美：泛化性能优于显式 WAM，效率则与隐式 WAM 相当。项目主页：https://zrporz.github.io/Simple-WAM-Web/

## Groupwise Agentic Grading and Advantage Redistribution for Code Agent RL

[面向代码 Agent 强化学习的分组式智能体评分与优势重分配](https://arxiv.org/abs/2609.32577)

代码 Agent 的强化学习（RL）通常借助可执行测试提供二值奖励。在此类奖励下，组相对策略优化（GRPO）会为同一 rollout 组内所有通过测试的轨迹分配相同优势，忽略了它们在实现质量与任务要求遵循度上的差异。这使得策略缺少一种学习信号，无法偏向于干净、聚焦的实现，而非包含多余或超出范围改动的实现。我们提出 GAGAR，一个面向代码 Agent RL 的质量感知信用重分配框架。该方法基于动态采样，保留同时包含通过和失败轨迹的分组；随后将每组的所有轨迹放入共享工作区，由经 SFT 训练的智能体评分器联合检查它们并对通过测试的候选进行排序。基于该排序，我们降低排名较低轨迹的权重，并按比例重新缩放所有通过测试轨迹的优势，使其总和恢复原值。这种保和重分配在保留基于质量降权所确立的相对权重的同时，将信用向更高质量的实现倾斜。我们使用 MiMo-V2.6-Flash（总参数 310B）和 MiMo-V2.6-Pro（总参数 1.02T）的 RL 前 SFT 检查点，在工业规模上评估 GAGAR。受控的纯代码 Flash 实验显示，代码 Agent 性能提升、轨迹长度增长减缓、训练更稳定。我们进一步将 GAGAR 应用于 Flash 和 Pro 的大规模混合任务 RL。结果表明，将基于测试的验证与分组式智能体评分相结合，可提升代码 Agent RL 的质量与稳定性。

## AREX-2: Advancing Self-Improving Agents through Long-Horizon Reflective Tasks

[AREX-2：通过长时程反思任务推进自我改进 Agent](https://arxiv.org/abs/2609.38288)

我们提出 AREX-2，旨在提升 LLM Agent 的自我改进能力，即测试时迭代优化解决方案的能力。该能力依赖两个互补要素：反思（reflection），即生成优于当前解的新方案；以及长时程执行（long-horizon execution），即在多轮迭代中保持有效性。我们假设这两种能力均与领域无关，因此可在适合监督学习的场景中习得。为此，我们从机器学习与算法编程任务中合成长期改进轨迹，这两个领域可提供可验证反馈并激励持续迭代。基于 Qwen3.8-27B 构建的 Agent 在此数据上训练后，在 MLE-bench Lite 上达到 81.8，在 Frontier-CS 上达到 70.7，并迁移至深度研究任务：BrowseComp 84.0、HLE 52.6、GAIA 92.2、DeepSearchQA 93.8，且随轮次预算增加持续提升。结果表明，长时程反思数据是通向自我改进 Agent 的有效路径。

## Adaptive Reward Routing: Dynamic Multi-Reward Optimization for Joint Audio-Video Diffusion via Forward-Process RL

[自适应奖励路由：通过前向过程 RL 实现联合音视频扩散的动态多奖励优化](https://arxiv.org/abs/2609.37200)

多奖励引导的强化学习（RL）为联合音视频扩散模型在多个互补目标上的改进提供了有前景的途径，这些目标包括模态特定质量、跨模态语义对齐以及时间同步。然而，其有效性取决于训练过程中不断变化的两个量：奖励驱动的更新应当作用于何处，以及竞争性奖励应如何组合。现有方法往往依赖固定的路由与奖励权重，无法跟踪模型功能的演化。为解决这些局限，我们提出自适应奖励路由（Adaptive Reward Routing），在联合音视频扩散模型的前向过程 RL（即 DiffusionNFT）中联合自适应调整更新位置与奖励协调。方法包含两个组成部分：(i) 跨模态影响引导路由（定位更新）：我们使用双向交叉注意力响应作为演化中跨模态影响的高效代理，动态重加权 Token 感知损失，并在跨模态层间缩放梯度，无需额外的模型干预。(ii) 保留偏好的模态感知重加权（协调奖励）：我们保留预定义权重作为偏好先验，并在预热后使用分支特定的奖励梯度交互作为残差修正。这解决了演化中的冲突，同时避免主导奖励压制微弱但至关重要的目标。大量实验表明，在模态质量、语义一致性和音视频同步方面，相较强 RL 基线均取得一致提升。消融与机制分析进一步验证了自适应更新路由与奖励协调的互补收益。

## Mid-Harness: Scaling Actions Between Model and Harness for Terminal Agents

[Mid-Harness：在模型与执行框架之间扩展终端智能体的动作空间](https://arxiv.org/abs/2609.39982)

终端智能体（Terminal Agent）通过随机性的模型生成来执行动作，但能够生成有用的动作并不意味着它能被可靠执行。一条糟糕的命令（例如安装错误的软件包）可能以妨碍后续进展的方式改变环境，即便模型本可生成更好的替代方案。我们研究在模型与执行框架（harness）的边界处分配测试时计算（test-time compute）能否提升动作可靠性与轨迹成功率，以及这种分配为何有效。为研究这些问题，我们提出 Mid-Harness：它在将某个候选动作转发执行之前，先对候选动作进行采样与验证，同时保持生成器与执行框架不变。使用 TMAX-9B 生成器时，在弱验证条件下增加动作采样几乎无收益；而一个能力强的验证器则能从同一生成器中挖掘出有用的替代动作。在 TerminalBench-Lite 上，GPT-5.6 Sol 验证器将 Pass@1 从基础智能体的 50.00% 提升至采样 8 个动作时的 68.03%。当由同一个 TMAX-9B 模型充当验证器时，成对验证（pairwise verification）在所评估的验证机制中表现最佳。将更强验证器的响应蒸馏到 TMAX-9B 中可进一步提升 Pass@1，而动作生成器保持不变。在 TerminalBench-Lite 上使用 TMAX-9B 时，结合动作扩展与轨迹扩展，相比仅生成更多轨迹，能以更低的估算 Token 成本达到更高的成功率。Mid-Harness 还在更多模型、基准与执行框架上带来性能提升。这些发现表明，动作扩展是终端智能体测试时计算扩展的一个有前景的方向。

## Beyond the Timeline: Augmenting Long-Video Memory with Grounded Entity Biographies

[超越时间线：用接地实体传记增强长视频记忆](https://arxiv.org/abs/2609.38155)

回答关于长视频的问题，往往需要跨数小时甚至数天，把涉及同一物体的事件关联起来。按时间顺序的描述以及从文本中抽取的实体，可能无法解决物理身份（physical identity）的归属问题：不同物体可能共享同一描述，而同一物体的多次观测则在各个事件之间彼此割裂。因此，即便检索到相关事件，也未必能还原问题所关注的那个特定实体的“传记”（biography）。为解决这一问题，我们提出“接地实体传记”（Grounded Entity Biographies, GEB）——一种长视频记忆框架，它把跨片段中对同一物理实例的视觉接地（visually grounded）观测归组为可检索的传记，同时保留每个时刻的上下文。在问答过程中，传记会与情节证据（episodic evidence）一同被检索，使模型能够借助记忆构建阶段建立的身份链接，跟随某一实体经历各个事件。在四个基准（包括长达一天和长达一周的录制视频）上的评估表明，该框架在多项选择与开放式问答上均优于此前的记忆框架。在 EgoLifeQA 上，GEB 达到 72.0% 的准确率，比已发表的最佳结果高出 4.4 个百分点。消融实验表明，接地的身份关联与传记阅读都对性能提升有所贡献，而仅靠额外描述并不能完全弥补这一差距。

## Self-Evolving Coding Agents: From Digital Programs to Physical-World Intelligence

[自进化编码智能体：从数字程序到物理世界智能](https://arxiv.org/abs/2609.35432)

视觉-语言-动作（VLA）模型与世界-动作（WAM）模型将观测和指令直接映射为机器人动作。这种直接性使策略与训练数据紧密绑定：布局或视角的微小变化即导致失败，指令泛化能力也很差。根本原因在于表征：任务需求、条件、进度与失败恢复都被隐式编码在动作序列中，难以检查或修正。数字编码智能体提供了一个先例：LLM 调用工具、验证结果，并依据反馈以可执行代码的形式进行修正。显式状态、可控执行与可修正流程这一相同的工作模式，正是物理世界中泛化与长时程执行的基础，使物理经验能够以可复用程序、记忆或证据的形式回流。我们提出 Physical Coding，将任务状态与执行表征为代码。Code as World 记录对象、关系、约束与进度；Code as Policy 组织规划、验证、恢复与执行。我们构建了 HexaAnything，它调用感知、规划与控制工具（包括 VLA/WAM 策略），并依据外部反馈在环内做出决策。经过验证的执行轨迹转化为数据与记忆，使进化得以从工具与 Harness 延伸到模型权重、架构，最终到硬件与任务设计。在 RoboCasa365 上，HexaAnything 相比 XR-1 VLA 提升了 Composite-Unseen 与整体成功率，而其经 Harness 训练的 HexaModel 在每个划分上都优于基座模型，表明代码轨迹内化了物理执行能力。在 PhyBench 和双臂 AgileX 机器人上，该智能体自主完成物理实验与大多数桌面任务，且往往快于已发表结果。我们观察到数据、模型与工具的自进化；未来工作将聚焦于权重内化、架构/语言/表征/任务的自主重设计，以及在制造业与科学领域的部署。

## EvoDuet: Bilevel Co-Evolution of Web Searching and Task Solving for Scientific Discovery

[EvoDuet：面向科学发现的网络搜索与任务求解双层协同演化](https://arxiv.org/abs/2609.40340)

基于大语言模型（LLM）的演化搜索在进展依赖模型所缺乏的外部知识时可能陷入停滞。提供相关文档虽有所帮助，但单纯添加网络搜索工具会导致在解不断变化时反复返回相同页面。我们提出 EvoDuet，一种在模型参数固定条件下协同演化解与搜索查询的双层优化方法。在每次迭代中，检索门控让 LLM 评估自身知识缺口，并选择检索新文档、复用已存储文档或不使用文档继续。内循环根据文档预测可带来的解得分来优化查询并对文档排序；外循环基于这些文档并行生成候选解，并记录评估结果以供后续搜索使用。在 21 项每次迭代仅生成一个候选解的优化任务中，EvoDuet 将 OpenEvolve 的归一化发现增益从 74.1% 提升至 78.0%（GPT-5.6-Luna），从 61.3% 提升至 82.3%（Gemini-3.8-Flash），而 Qwen3.5-9B 未从中获益。我们最佳运行结果在八项任务上超越了此前报告的最佳分数，包括 Q20 和 Rosetta 上的 Swap Reduction，并在另外三项任务上持平。EvoDuet 在 Sums/Diffs 和 Denoising 任务上也能与其他脚手架（如 Top-K、EvoX）结合并获得提升，表明其可适用于多种演化搜索脚手架。

## Think Before You Score: Thinking Reward Model for Visual Generation

[评分前先思考：面向视觉生成的思维奖励模型](https://arxiv.org/abs/2609.37372)

视觉奖励模型对于评估和改进视觉生成模型至关重要，但现有方法通常将任务条件和候选输出直接映射为标量奖励，未明确每个具体样本应当评估什么。我们提出“评分前先思考”（Think Before You Score）范式，在判断候选输出表现好坏之前，显式确定每个样本的关键评估要素。基于这一原则，我们提出思维奖励模型（Thinking Reward Model，TRM），它构建自适应于具体样本的评分细则（rubric），执行细则引导的评估，并输出细粒度的逐点奖励。我们进一步发现，传统的成对偏好优化会引发分数极化，为此提出成对双组相对策略优化（Pairwise Dual-Group Relative Policy Optimization，PD-GRPO），利用成对监督提升奖励判别能力，同时保留细粒度的逐点评分。在图像生成与编辑奖励建模基准上的大量实验表明，TRM 在开源奖励模型中达到 SOTA 性能，并与专有方案相比极具竞争力。此外，将 TRM 用作强化学习奖励可稳定提升多种视觉生成模型，表明其细粒度、样本自适应的奖励能够转化为视觉生成的有效优化信号。

## Periodic Weak Spots: Phase Sensitivity from Chunked KV-Cache Compression

[周期性弱点：分块 KV 缓存压缩带来的相位敏感性](https://arxiv.org/abs/2609.36322)

分块 KV 缓存压缩通过以固定步长将连续 Token 窗口压缩为更少的缓存条目，降低长上下文推理的内存与注意力开销。这种压缩同时引入了一个新的位置坐标：Token 的相位（phase），即其相对于压缩窗口边界的位置。我们发现，使用此类压缩的模型存在系统性的不对称：同一信息在某个相位下易于检索，在另一个相位下却难以检索。我们将这种检索性能的周期性波动称为相位敏感性（phase sensitivity）。在采用该压缩的大型开放权重模型中，长上下文检索准确率在不同相位间的差距最高可达 40 个百分点，揭示出平均基准分数所掩盖的周期性弱点。为研究这一行为，我们从零开始预训练了一组涵盖多种 KV 压缩设计的 Transformer，并在各变体中复现了相位敏感性。通过因果干预进行的机制分析揭示了相位特化（phase specialization）：不同注意力组件在检索不同源相位信息时的贡献并不对称。我们进一步分析理想化检索模型，表明梯度流动力学可能倾向于形成尖锐的相位特化。因此，评估采用分块 KV 缓存压缩的模型需要在各压缩相位上分别测量：高平均准确率可能与系统性的位置失效并存。

## WorldAuditBench: Interactive 3D World Auditing with Multimodal Agents

[WorldAuditBench：面向多模态 Agent 的交互式 3D 世界审计](https://arxiv.org/abs/2609.40325)

随着交互式 3D 世界越来越多地被用于研究智能行为，构建高效流程以识别这些模拟环境中的异常（例如悬浮物体、可穿越的墙体，或与周围场景不一致的物体）变得十分重要。多模态 AI 系统，包括视觉语言模型（VLM）和视觉语言动作模型（VLA），已展现出将这一任务自动化的潜力。然而，3D 世界审计较为复杂，需要两类不同能力的紧密耦合：一是动作能力，用于在 3D 世界中导航并系统、高效地搜索异常；二是视觉推理能力，用于理解环境并从多模态观测中识别异常。多模态 Agent 能否有效耦合这两种能力——利用视觉推理识别潜在异常，同时通过动作加以验证——在很大程度上仍未被探索。本文提出 WorldAuditBench，一个用于 3D 世界审计的基准，包含基于 Unreal Engine 5 和 Three.js 构建的 13 个环境中的 213 项异常任务，覆盖五个异常类别。我们在固定探索预算下，采用两种审计范式评估五个前沿模型：先基于 VLA 探索、再基于 VLM 识别异常，以及由视觉推理直接指导动作选择的端到端 VLM Agent。在所评估的模型和两种范式下，成功率介于 6.6% 至 42.3% 之间，远低于人类表现（83.4%）。通过世界审计这一任务，WorldAuditBench 提供了一个测试平台，用于研究多模态 Agent 如何在交互式 3D 环境中耦合动作与视觉推理，同时凸显了它们当前在探索过程中收集和解读证据能力上的局限。

## Follow the Entities: A Corpus Map for Agentic Search

[跟随实体：面向 Agentic Search 的语料地图](https://arxiv.org/abs/2609.37226)

在大型文档集合上回答问题、完成任务，往往需要串联散落在多份文档中的证据，例如项目的审批记录在一份文档中、需求在另一份中、最新状态又在第三份中。近期的 LLM Agent 通过迭代搜索整个语料库来应对这一问题，而非只读取固定的一批高排名文档。然而，当语料仅以扁平的文件集合形式暴露时，一份相关文档不会提示它与其他文档有何关联，Agent 因此必须为每个查询重新发现这些关系，常常遗漏互补证据，同时消耗大量额外 Token。为解决此问题，我们提出 CorpusMap，一个围绕语料中反复出现的实体（entity）来组织语料的导航层；这些实体可从文档自身识别出来，并能将单份文档与跨来源的许多其他文档关联起来。具体而言，CorpusMap 将每个反复出现的实体表示为一个实体页面（Entity Page），汇总关于该实体的信息，并链接到所有提及它的文档，从而形成实体与文档之间的图，Agent 可沿此图遍历，收集原本彼此孤立的证据。此外，由于 CorpusMap 是在离线阶段通过消解（resolve）跨文档的同一实体提及构建而成，其链接可在多个查询间共享，而无需在推理时反复重新发现。我们使用 7 个不同模型、3 个基准数据集进行实验，表明 CorpusMap 在证据发现与答案质量上均优于基于原始语料的 Agentic Search，同时平均使用更少 Token，并且进一步优于 4 种替代导航层，说明实体可作为导航大型文档集合的有效锚点。

## SAKI: Maximal-Coupling-Routed Teacher Supervision for On-Policy Distillation

[SAKI：面向同策略蒸馏的最大耦合路由教师监督](https://arxiv.org/abs/2609.36601)

同策略蒸馏（On-Policy Distillation，OPD）通过在学生自身生成的轨迹上训练，降低训练与测试的状态不匹配，但较弱的学生可能访问到与教师不对齐的前缀，导致监督信号代表性不足。为此，我们提出 SAKI（Supervision Allocation with KL-constrained Interpolation，KL 约束插值的监督分配），将 KL 约束的教师引导 rollout 与最大耦合（maximal coupling）相结合，并复用实际发生的接受/纠正事件来路由 Token 级监督。在接受位置上保留对采样 Token 的反向 KL 监督，而在纠正位置上则直接对教师概率最高的 Token 施加监督。在最大耦合下，纠正概率恰好等于 TV(p_t, q_t)，因此同一个信任域半径既能控制 rollout 偏移，又能上界约束干预与专门监督的发生频率。我们还实现了一个常驻推理引擎的推测验证器（speculative verifier），在保持精确 q 轨迹分布与耦合语义的同时，将匹配负载下的 rollout 吞吐量提升 4.22 倍。在七个数学推理基准上，SAKI 在 1.7B 与 0.6B 学生模型上均较匹配的教师引导基线提升了 Mean@8 与 Pass@8。位置控制和固定前缀分析进一步支持将纠正触发的路由作为一种冲突自适应的监督信号。

## Disaggregated Quantization: Specializing LLM Prefill and Decode

[解耦量化：面向 LLM 预填充与解码的专门化](https://arxiv.org/abs/2609.26333)

预填充（Prefill）与解码（Decode）适合不同的量化策略：低精度算术可加速提示处理，而紧凑权重能减少生成阶段的内存流量。我们提出“解耦量化”（Disaggregated Quantization，DQ），针对这两个阶段分别专门化计算格式、权重与存储放置。在 Qwen 3 和 Gemma 3 上，仅在解码阶段移除激活量化，可在不增加推理成本的前提下提升解码密集型任务的准确率。训练独立的、面向计算原生的预填充权重，相比仅权重量化可加速提示处理，同时在 2-3 bit 解码下于解码密集型和预填充密集型任务上达到或超过其准确率。基于已发布的 Qwen3.8-27B GGUF 解码器，训练一个 NVFP4 预填充器（prefiller）可在不修改解码检查点的情况下，将 1-bit 准确率在 MMLU-Pro 上提升 32.5 个百分点、在 MMMU-Pro 上提升 35.3 个百分点。为在单设备上容纳额外检查点，卸载式解耦预填充（Offloaded Disaggregated Prefill，ODP）从 SSD 流式加载其权重，将加载开销按提示长度摊销。在同一 27B 模型上，ODP 在 llama.cpp 中以 8K 提示长度实现了相比仅权重量化基线 1.78 倍的首 token 时间（TTFT）加速。我们在 vLLM 中评估了解耦服务下的准确率，并通过对最高 2.8T 参数模型的后训练量化，进一步验证了共享权重格式的解耦。

## Duplex-MPE: Benchmarking Multi-Party Interaction in Full-Duplex Dialogue

[Duplex-MPE：全双工对话中的多方交互基准测试](https://arxiv.org/abs/2609.31948)

实时全双工语音模型能够边听边说，从而在无需严格轮次边界的情况下实现自然交互。现有基准测试评估了轮次切换、打断处理和多轮对话，但大多以指定用户为中心，而非以参与多人共享对话的助手为中心。我们提出 Duplex-MPE，用于评估此类助手应当在何时回答、保持沉默或停止说话。该基准包含 2,000 个场景，每个场景由三到四名人类说话者和一名助手组成，并针对同一请求分别配对显式指派与隐式指派两种情形。模型接收的是连续对话音频，不提供转录文本或给定的轮次边界。四项评分分别衡量全新应答的发起、回答准确性、沉默保持，以及当人类自行解决请求时停止说话的能力。我们评估了五个开放权重语音系统：MiniCPM-o 4.5、Moshi、FLM-Audio、Voila 和 Freeze-Omni。MiniCPM-o 4.5 在三项计分能力上领先，而其他系统的频繁发言可能与答案不准确或无法保持沉默同时存在。基于转录文本的 Gemini 3.1 Pro 参考模型对显式请求的回应频次比隐式请求高出 64.3 个百分点；配对检验未发现各语音系统在响应率上存在显著差异。

## Learning Meta-Skills for Agent Harness Design in Test-Time AI4AI

[学习用于测试时 AI4AI 中 Agent Harness 设计的元技能](https://arxiv.org/abs/2609.38143)

Agent 的表现既取决于推理能力，也取决于其所处的执行环境。本文研究测试时 AI-for-AI，探讨在双方模型权重均保持固定的前提下，Builder 如何学会为 Target 构建更优的执行环境。为使 Builder 的经验可复用，作者提出 Meta-Skill（元技能）：即规定何时需要支持、以及应提供何种资源的原则。Builder 从 Target 在开发集上的执行反馈中学习这些原则，再利用冻结的技能库为未见任务构建 harness。在 Harness-Bench 和 NewtonBench 上，使用完整技能库的元技能相较无技能构建，将宏平均性能提升 8.95 个百分点；相较把同一技能库直接交付给 Target，提升 12.02 个百分点。这些结果凸显了将经验转化为可执行支持的价值。同一模型同时承担两种角色时仍能取得增益，这进一步表明，通过学会构建更好的环境，有望实现系统层面的自我改进。

## Beyond Memory: Harnessing Long-Horizon Agents with Explicit Belief States

[超越记忆：以显式信念状态驱动长时程 Agent](https://arxiv.org/abs/2610.01415)

大语言模型（LLM）Agent 如今能够承担日益复杂的任务，但其将交互历史组织为记忆的方式，并不能保证对当前世界形成连贯的理解。我们提出 PoS，一个推理时框架，用于构建并持续维护显式信念状态（belief state），作为 Agent 的决策上下文。每个信念将当前世界状态的估计与尚未解决的任务需求结合起来，从而明确 Agent 仍需了解什么、完成什么。为使该信念保持可靠且可执行，PoS 会校验其一致性，并监控任务进展，以检测“信念陷阱”（Belief Trapping）——即 Agent 持续行动却未向目标取得实质进展的情形。随后，恢复策略会依据陷阱模式与未解决任务需求的类型进行针对性设计。在涵盖执行与诊断的四个基准上，PoS 在三种 LLM 底座上均取得了每个基准的最高综合表现。消融实验表明一致性校验与恢复机制的重要性，而上下文扩展实验则显示出对上下文增长的韧性。这些结果共同支持将信念构建与持续维护作为长时程上下文管理的基础，超越单纯的历史保留与压缩。

## Hierarchical Continuous Diffusion Language Models

[分层连续扩散语言模型](https://arxiv.org/abs/2610.02193)

离散扩散语言模型为需要双向推理和全局约束满足的任务提供了一种颇具吸引力的自回归生成替代方案。然而，它们存在一个结构性瓶颈：并行解码时，每个 Token 都从其边缘分布中独立采样，从而割裂了同时解码的 Token 之间的统计依赖关系。连续扩散语言模型通过对共享的连续状态去噪来规避这一问题，但其去噪器只能看到该状态，因此在最终解码之前，没有任何东西将该状态与合法的 Token 配置绑定起来。为解决这一问题，我们提出分层连续扩散语言模型（HC-DLM），它在单一且原理化的去噪过程中，将离散 Token 生成与连续隐变量轨迹耦合起来，其训练目标由 Token 似然的变分下界推导而来。与近期那些将连续上下文附加到自包含离散链上的方法不同，HC-DLM 让隐变量成为唯一持久存在的生成状态：每一步都从中读出 Token，并将其作为下一步隐变量更新的支架反馈回去。在结构化推理（数独）、数学规划（Countdown）和语言建模（LM1B）任务上，HC-DLM 在模型规模匹配的情况下，于数独和 Countdown 的谜题准确率以及 LM1B 的生成困惑度方面均优于离散与连续扩散基线。项目主页：https://hc-dlm.github.io/。

## RSIGame: Autonomous Agentic Game Development with Recursive Self-improvement

[RSIGame：面向自主智能体游戏开发的递归自我改进框架](https://arxiv.org/abs/2609.39045)

近期大语言模型（LLM）的进展使自动游戏生成日益可行，但要在可玩版本之上可靠地提升生成游戏的质量仍具挑战。朴素的迭代式精修很容易在少量测试用例上过拟合，产出的游戏较为脆弱，存在未修复的缺陷、缺失的行为，且难以泛化到更广泛的玩家交互。我们提出 RSIGame，一个具备递归自我改进能力的自主智能体（Agent）游戏开发框架。RSIGame 将开发过程组织为互补的局部循环与全局循环。具体而言，局部“探索—诊断—改进”循环广泛探索可执行游戏，对发现的问题进行诊断与优先级排序，并执行有证据支撑的修订，其中不断演进的检查清单会持续累积新的测试与改进指导。全局循环则跟踪整体质量、保留最佳检查点（checkpoint），并检测长周期开发中的饱和或性能回退。除测试时改进外，RSIGame 还通过训练将成功的开发经验内化到生成器中。在 140 个 GameCraft-Bench 任务、两种游戏引擎与五种生成器上，RSIGame 在相同开发预算下持续提升游戏质量。值得注意的是，经验内化使 Qwen3.8-27B 在 Godot 上达到 61.38、在 Phaser 上达到 58.53，超过 GPT-5.5 的单次（one-shot）得分，同时将 Qwen 的生成 Token 量减少 11 倍。

## LLMs are General Asynchronous Agents

[LLM 是通用异步智能体](https://arxiv.org/abs/2609.35427)

现代 LLM 作为自主智能体的能力日益增强，但其运行仍遵循顺序交互循环：读取、思考、回复或调用工具，如此往复。然而许多真实场景并非顺序式：语音助手、具身智能体和监控系统会在思考或执行其他任务的同时接收新输入。现有 LLM 通过专用架构应对这类需求，例如面向语音交互与视频流的专门设计、用于机器人控制的 VLA（视觉-语言-动作模型）、面向 API 调用的异步工具调用等。本工作从各类异步任务出发，将其推广到能够适应不同类型并发的通用异步智能体。为此，研究者提出了一个异步 LLM 框架，允许用户（或智能体自身）定义具有重叠内存状态的推理协程（inference coroutine）。实验表明，Qwen 3.x 系列模型无需任务特定训练，即可在流式视频理解、电子游戏和监控等场景中实现异步运行。

## Sharpening Tax in Post-Training

[后训练中的锐化税](https://arxiv.org/abs/2610.01509)

关于大型语言模型（LLM）的强化学习（RL）后训练，一个新出现的假设是：它仅仅锐化了基础模型已有的行为，在提高单次准确率的同时牺牲了解覆盖率。尽管这种权衡已在数学和编码任务中被观察到，但它未必会延伸到 Agent 任务（agentic tasks）；在 Agent 任务中，多轮工具使用和交互可能需要后训练期间新获得的能力。我们令人惊讶的发现是，预训练的 LLM 在配备轻量推理框架（inference harness）后，可以作为有能力的 Agent。尽管准确率（pass@1）低得多，但在给定充足的测试时预算时，它们在解覆盖率（pass@K）上往往超过经过后训练的对应模型。我们进一步分析其底层机制，并表明后训练将任务推向两个极端：要么总是被解决，要么从未被解决，从而在牺牲解覆盖率的情况下提高了采样效率和一致性。为了衡量这一代价，我们提出锐化税（Sharpening Tax），这是一个诊断性指标，用于量化后训练之后测试时可扩展性的损失。在来自四个模型家族的 14 对基础/后训练模型以及三个 Agent 基准（共 42 个案例）上，该税在大多数设置中普遍存在，可以从少量 rollout 中估计，并且与其他指标相关性良好。最后，我们提出后验温度分组采样（PTGS），这是一种简单的即插即用贝叶斯采样器，可根据每个提示的估计难度调整其采样温度。在两个 Agent 环境中的 RL 训练期间应用时，PTGS 相比固定温度基线缴纳更小的税，在重复采样下解决更多任务，同时提高单次准确率。

## MassAlloc Attention: Let Attention Allocate Its Own Compute

[MassAlloc Attention：让注意力自行分配其计算量](https://arxiv.org/abs/2609.32712)

FullAttn 往往对因果分数空间中很大一部分只赋予可忽略的归一化质量（normalized mass），然而稠密核（dense kernel）在形成每个 QK 分块（tile）之后仍需执行完整的分数后计算路径。我们提出 MALA，一种融合注意力原语（fused attention primitive），它保留对每一个合法因果交互的分数访问能力，并利用归一化贡献来分配分数后计算。前向传播使用其不断演化的在线 softmax 归一化因子（online-softmax normalizer），反向传播则复用最终确定的归一化因子，仅凭标准注意力状态推导出嵌套保留支撑集（nested retained support）。统一的容差（tolerance）同时管控训练与推理，从而实现计算量的自适应保留。MALA 减少了低贡献的分数后计算。在 8K 长度下开展的等功量研究（matched-work study）分离出分布自适应分配带来的收益：在总分数后计算量完全匹配的条件下，MALA 逼近逐实例的参考质量 oracle，平均被省略质量为 0.0188%，而 oracle 为 0.0182%。在 1K 至 32K token 的上下文长度范围内，同一容差始终将输出误差与梯度误差相对于参考维持在较低水平。在更广泛的可控联想召回（associative-recall）对比中，随着上下文增长，MALA 紧密跟随 FullAttn，在 8K 时达到 89.67% 准确率，FullAttn 为 89.97%。在 128K token、启用张量并行（tensor parallelism）的注意力算子基准测试中，相对于 FullAttn，MALA 在训练中将前向与反向延迟分别降低 2.2 倍和 3.0 倍，在推理中将解码延迟降低 1.6 倍。在 0.6B 至 14B 参数的缩放律（scaling-law）训练中，MALA 的困惑度（perplexity）紧密跟随 FullAttn，同时减少总训练 FLOPs。由此得到的 14B 模型，以及经单独继续训练得到的 32B 模型，在知识、推理与长上下文检索得分上与 FullAttn 相当。这些结果表明，依据归一化注意力贡献来分配分数后计算，能够在减少注意力计算的同时保持 FullAttn 在各项评估中的能力。

## Agent Priors-guided Policy Learning

[Agent 先验引导的策略学习](https://arxiv.org/abs/2609.35690)

从少量演示中学习的机器人通常需要两种形式的泛化能力。组合泛化（compositional generalization）通过重组技能来求解新任务，技能泛化（skill generalization）则让每个技能背后的策略在新情境下依然有效。二者相互依赖，但在组合过程与其调用的技能之间会丢失信息。技能在何处有效取决于其策略训练时所依据的结构，而组合只能通过一个独立描述（如名称、指令或符号算子）来了解该技能，这类描述恰恰省略了该结构。我们的核心思想是将每个策略的结构先验（structural prior）作为组合与技能之间接口的一部分。结构先验说明了某个行为依赖于什么，例如抓取只依赖于夹爪相对于物体的位姿。将其内置于训练中，它决定了策略泛化的范围；用语言表述出来，它则告诉组合过程该策略适用于何处。我们在 Agent 先验引导的策略学习（APPL）中实现了这一思想：一个构建 Agent 将完整演示分割为可复用技能，为每个技能提出若干结构先验，并针对每个先验训练和验证一个策略；随后一个运行时 Agent 在这些针对特定先验的策略中进行选择，并利用它们的接口将其组合以达成新的任务目标。在 MetaWorld 和长时程 ManiSkill 任务上，APPL 提升了分布外（out-of-distribution）技能泛化能力，并实现了此前未见的技能组合；消融接口信息会显著降低性能。这些结果支持将训练时的结构假设作为技能学习与技能组合之间的桥梁。

## TraceDance: An Automated System for Building Agent Behavior Benchmarks from Real-World Agent Deployment Traces

[TraceDance：从真实世界 Agent 部署轨迹自动构建 Agent 行为基准的系统](https://arxiv.org/abs/2609.33295)

Agent 能在完成任务的同时，在执行过程中表现出不期望的行为。开发者需要的不仅是固定的基准套件，而是针对部署中实际遇到的具体行为的测试。我们提出了 TraceDance，一个能从部署轨迹中针对用户指定的不期望行为构建定向基准的 Agent 系统。为实现高效构建，Anchor-and-Confirm 方法将可编程检索与由 Flash 大语言模型（LLM）进行的候选级确认相结合，而 Anchor Synthesis Loop 则为自定义行为生成并修订规范。这些基准采用决策点续写（decision-point continuation）方式，在记录下来的决策点上用行为专属评分标准评估 LLM 的下一轮回复，无需参考答案，也无需环境重放。在编程和通用工具使用场景中的实验基于 252,557 个会话，生成了 107 个基准、共 4,125 个实例，满足了 95.3% 的构建目标请求。两位人工标注者在 84% 的抽样实例中确认了所请求的行为，自动评分器与人工通过/失败判断的一致性与标注者之间的一致性相当。九个前沿 LLM 的平均通过率仅为 26.7%，表明它们在所评估的决策点上仍难以做出恰当回应。对行为专属基准的进一步分析还揭示了当前 LLM 作为 Agent 时的行为弱点。通过将部署中的问题转化为定向基准，TraceDance 有望成为递归自我改进（RSI）闭环的关键组成部分。

## World Observer: Joint Actor-Observer Generation for Persistent World Modeling

[World Observer：面向持久世界建模的联合 Actor-Observer 生成](https://arxiv.org/abs/2610.02162)

世界模型如何持续观测 Actor 当前视野之外的区域？视频世界模型能够模拟环境随 Agent 动作的演变，但仍以 Actor 为中心。一旦物体离开 Actor 视野，模型便失去其演变的直接证据，往往无法在物体重新进入视野时保持其状态与动态。为此，我们提出 World Observer，通过将观测与行动解耦，在生成以 Agent 为中心的视角 Actor 的同时，联合生成一个或多个全景 Observer，对选定的世界区域进行观测。这样，离开 Actor 视野的物体仍会在 Observer 中持续视觉演变，从而在重新进入视野时体现其更新后的状态。我们通过从共享全景源进行变形（warping）来为 Actor 与 Observer 建立显式几何对应关系，并引入 Observer Sink，利用高分辨率透视参考在物体重新进入视野时恢复精细外观。由于 Observer 与 Actor 解耦，它们可自由布置于场景各处，可扩展至多个位置以实现更广覆盖，并可由控制信号驱动以引导视野外的演变。为评估视野外演变，我们进一步提出世界空间指标以及覆盖真实与合成场景的基准。World Observer 显著提升了视野外动态表现，同时在视觉保真度、相机控制与 3D 一致性方面保持竞争力。

## A Missing Piece for Trustworthy AI Reviewers: From Benchmarking Rhetorical Robustness to SciCore Review

[可信 AI 审稿人缺失的一环：从修辞鲁棒性基准测试到 SciCore Review](https://arxiv.org/abs/2609.39027)

AI 审稿人可能对报告相同科学内容但措辞不同的稿件给出不同评价，从而有可能奖励修辞优化而非科学改进。我们将修辞鲁棒性（Rhetorical Robustness）定义为跨内容保持型改写保持稳定、同时跨论文保持区分度的联合要求。我们提出 RobustReview，一个受控的全稿件基准，包含 1,260 个稿件版本，并评估了 30 种审稿人配置。该基准揭示出虚假鲁棒性（false robustness），即低改写敏感性与跨论文评分坍缩同时出现，并表明人类对齐与修辞鲁棒性对审稿人的排序并不一致。此外，所评估的以内容为中心的提示协议并未在不同骨干模型上稳定提升鲁棒性。受这些发现启发，我们提出 SciCore，一种双分支审稿人，将对全稿件的判断与基于提取出的结构化科学核心的判断进行平均。该设计将稿件级评估与旨在降低修辞敏感性的内容归一化视角相结合。在我们主要的 GPT-5.5 对比中，SciCore 在基准审稿人中取得领先的稳定性—区分度联合表现，同时保持具有竞争力的人类对齐。这些结果将修辞鲁棒性识别为一个独立的评估目标，并展示科学核心审稿在提升该目标方面的潜力。

## EVOKE: Eliciting World Knowledge in Agents for Transferable Decision-Making

[EVOKE：在 Agent 中激发世界知识以实现可迁移决策](https://arxiv.org/abs/2609.38334)

大语言模型（LLM）正越来越多地被用作多步决策的 Agent，但在未见环境中的迁移能力较差。世界模型方法通过训练 Agent 预测未来观测来应对这一问题，代价是额外的训练开销，以及预测用于规划时误差的累积。然而，对于在数字环境中运行的 LLM Agent 而言，大量此类世界知识已在预训练阶段内化，这使问题从“获取知识”转变为“激发知识”。我们认为，典型的后训练几乎没有提供这种激发的压力，因为在每个访问状态上仅针对单一目标进行监督，会无意中促使策略依赖表层的上下文习惯。我们提出 EVOKE，一种通过在固定状态下引入目标多样性来施加这种压力的后训练方法。理论表明，一个能在多样目标下胜任的 Agent 必须编码出可从其动作偏好中恢复的世界模型；受此启发，EVOKE 固定环境状态与交互历史，并在不同目标下对同一组候选动作进行排序，迫使动作偏好发生变化，从而使依赖上下文习惯或单一目标相关性的策略无法正确排序。这隐式地激发策略的预训练世界知识来指导决策。我们在三种主干模型上跨多种任务评估 EVOKE，结果表明任务性能、未见环境泛化能力和数据效率均有提升。我们进一步开展受控分析，以更好地理解这些收益的来源。这些发现为通过直接决策监督激发内化世界知识以实现可迁移行动提供了新视角。

## CoWindow Attention: Full Causal Coverage Is a Collective Property

[CoWindow 注意力：完整因果覆盖是一种集体属性](https://arxiv.org/abs/2609.32704)

FullAttn 会反复把完整的因果历史暴露给每一个注意力头，即使采用 IO 高效的稠密 kernel，也会造成大量冗余计算与显存流量。为此，作者提出 CoWA——一种结构化注意力架构，将因果历史的访问权分散到各 KV 头上：所有头共享近对角窗口与前缀汇聚窗口（prefix-sink window），而互补的长距离窗口则划分剩余的历史。各头虽对远端 Token 仅作稀疏关注，但其并集提供了完整的因果覆盖。这种由位置定义的注意力模式无需学习式 router 或 indexer，训练与推理阶段保持一致，并且与 KV 头张量并行相契合。在 8K 上下文下进行的窗口匹配消融实验分离出互补长距离分配的效果：达到 100% 集体覆盖的 CoWA 取得 89.73% 的准确率，而 FullAttn 为 89.97%，重复长距离窗口的配置则显著更差。在 Token 预算匹配的更广泛受控联想回忆（associative-recall）对比中，随着上下文增长，CoWA 的表现紧贴 FullAttn，而其他稀疏模式则丢失了相当一部分联想。在 128K Token、启用张量并行的注意力算子基准测试中，相较 FullAttn，CoWA 将训练时的前向与反向延迟分别降低 7.4 倍和 8.6 倍，将推理解码延迟降低 3.0 倍；训练时单卡算子峰值显存与 FullAttn 持平，解码时则低 7.6 倍。在从 0.6B 到 14B 参数的缩放定律训练中，CoWA 的困惑度紧贴 FullAttn，同时减少了总训练 FLOPs。由该方案得到的 14B 模型以及经额外继续训练得到的 32B 模型，在知识、推理与长上下文检索分数上与 FullAttn 相当。这些结果表明，完整的因果覆盖可以是头集合的集体属性，而非每个头各自重复具备的属性。

## Beyond Dyadic Memory: Interaction-Aware Multimodal Memory with Adaptive Agentic Retrieval for Multi-Party Spoken Conversations

[超越二元对话记忆：面向多方语音对话的交互感知多模态记忆与自适应 Agentic 检索](https://arxiv.org/abs/2609.32522)

长期记忆使 Agent 能够跨会话累积信息并进行推理，但现有研究主要聚焦于二元文本或图文对话，多方语音对话中的长期记忆仍鲜有探索。该场景要求保留对话内容、跨会话识别参与者，并记录谁与谁交谈。为此，我们提出 VoxPolyMem——一个交互感知的多模态记忆框架，将增量式说话人识别与由交互记忆、事实记忆和参与者画像构成的记忆层级相结合。我们将检索建模为序贯决策过程，Agent 根据累积证据重写查询、选择检索工具与记忆层，以填补信息缺口。我们进一步提出 Evidence-Gain GRPO（EG-GRPO），通过按轮次的信用分配鼓励获取互补证据。我们还构建了 VoxPolyBench，用于评估多方语音对话中的记忆演化、个性化回答、记忆检索与推理，以及交互推理与归属。VoxPolyMem 在 VoxPolyBench 上取得 85.0 的总体得分，超出评估中最强基线 23.6 分；在 Mem-Gallery 和 H2HMem-Multi 上分别得分 89.6 和 74.4，均比评估中最强的公开记忆基线高出 8 分以上。这些结果凸显了其在多方多模态交互中提供持久、个性化辅助的潜力。代码与数据集见 https://voxpolymem.github.io/VoxPolyBench/demo/

## How Far Are We from Removing the Visual Encoder? Scaling Laws for Encoder-Free Multimodal Pretraining

[我们距离移除视觉编码器还有多远？无编码器多模态预训练的缩放定律](https://arxiv.org/abs/2609.35457)

当前大多数多模态大语言模型（MLLM）都建立在预训练视觉编码器之上，以获得强大的视觉先验。无编码器 MLLM 则直接从原始像素学习视觉表示，架构简单统一，但其缩放行为尚未得到系统性刻画。为填补这一空白，我们对比了无编码器与基于编码器的 MLLM 的缩放定律，并给出三项主要发现：(1) 移除视觉编码器会使多模态目标的计算最优分配向更大的模型偏移，而文本目标的最优分配几乎不变。(2) 两种架构在文本目标上的损失—计算前沿几乎重合，但在多模态目标上出现分歧：无编码器模型在小规模下表现较差，但预计在约 10^{22} FLOPs 时可追平，而这远在实际预训练预算之内。(3) 在没有视觉编码器的情况下，语言模型通过视觉特有的适应机制接管其角色：随着训练算力增长，视觉 Token 之间的双向交互越来越有益，视觉处理向更早的层迁移，视觉 Token 的专家路由也变得更加集中。总体而言，我们的结果表明，预训练编码器所提供的视觉先验优势会随规模增大而减弱，使无编码器架构成为多模态预训练的一个有前景的方向。

我们提出 LongCat-DeepResearch，一个深度研究系统，将增强的 LongCat 模型与多 Agent 工作流相结合，用于生成全面且以证据为基础的（evidence-grounded）报告。该工作流将全局规划与细节调研相分离，并在章节层面协调修订。多个规划 Agent 首先探索外部信息源，并细化出一份可执行的研究计划，称为 ResearchSpec。随后，研究 Agent 并行调研并起草各自负责的章节，在分析推进过程中于独立上下文中收集更多证据。章节汇总完成后，由全局审阅指导有针对性的局部修订，减少对整份报告反复重写的依赖。该工作流还支持为 LongCat 通用模型的中期训练与后期训练构建研究任务与轨迹。LongCat-DeepResearch 在 DeepResearchBench 上取得 55.25 分，在 DeepResearchBench II 上取得 51.35 分，在 ResearchRubrics 上取得 79.83 分。在一项内部基准上，其得分为 76.04，在四个对比系统中位列第二。开发集分析表明，融合多种规划视角能够带来收益，而进一步的规划细化则效果不一。额外的编辑处理提升了两个基准上的平均自动可读性偏好，但在各基准上的趋势有所不同。

## Transformers Stop Thinking Too Early, and a Tiny LoRA Fixes It

[Transformer 过早停止思考，一个小 LoRA 就能修复](https://arxiv.org/abs/2609.36585)

预训练 Transformer 在上下文中跟随引用时，只动用了其深度的一小部分。13 个基础模型只能可靠地跟随 1.4–3.6 行，而额外叠加预训练循环也收效甚微。在某一早期层上训练一个 rank-8 的任务专属 LoRA，即可在全部模型权重冻结的前提下扩展这一计算。在 24 行链条任务上，Qwen3-8B 的精确准确率从 15.5% 提升至 99%；训练更久的 LoRA 可扩展到 50 行。Ouro-1.4B 在四次循环后达到 60 行，八次后至少达到 160 行。该 LoRA 启动了一种接力机制：程序行通过一小段中间层逐层传递自身的链条身份（chain identity）。冻结的注意力头会逐步读取链条中更靠后的位置，而去除父行注意力（parent-line attention）则会使接力中断。用冻结模型做一次测量，就能在四个留出模型中的三个里，将最后一个有效干预层定位到容差范围内。任务专属 LoRA 同样能提升 MuSiQue 的表现。因此，默认答案低估了通过一次微小修改即可触达的计算量。代码与交互式演示见 https://lunamos.github.io/stop-thinking-too-early/

## Thinking Outside the Box: Can Language Models Rely on External Guidance Selectively?

[跳出框框思考：语言模型能否选择性地依赖外部指导？](https://arxiv.org/abs/2609.39578)

Agent 编排框架（harness）常通过人工设计的工作流提升语言模型表现，但随着模型能力增强，不可靠的指导可能越发限制其执行。我们将“既能从有用指导中获益，又能覆盖不可靠指导”的能力称为“跳出框框思考”（thinking outside the box）。为此我们提出 Box^2-Bench，在固定模型与任务的前提下改变工作流可靠性，从而分离出模型调节自身对指导依赖程度的能力。在该基准上，前沿模型通常能受益于可靠指导，但当指导具有误导性或变得不可靠时仍然脆弱。为检验这种能力是否可学习，我们用“坏工作流”训练了两个开放权重模型，并保留“好工作流”用于评估。我们探索了两种互补的训练策略：反事实监督微调（counterfactual supervised fine-tuning）可提升鲁棒性，而基于结果的强化学习（outcome-based RL）则可将平衡转向更多使用有帮助的工作流。我们进一步发现，这种行为可扩展到工作流之外的其他形式外部信息，改善同伴纠错（peer correction）以及对被污染记忆的鲁棒性。总体而言，我们的结果将有选择地依赖易出错的外部信息，识别为一种仅靠任务表现无法捕捉的 Agent 可靠性维度。

## Learning Beyond What You Sample: Off-Policy-Aware Cross-Model Trajectory Exchange for RLVR

[超越采样范围的学习：面向 RLVR 的离策略感知跨模型轨迹交换](https://arxiv.org/abs/2609.37868)

基于可验证奖励的强化学习（RLVR）方法（如 GRPO）依赖模型自身生成的成功轨迹，但有限的 rollout 预算可能导致全失败组，从而无法提供基于奖励的策略梯度信号。增加 rollout 次数虽能提高成功概率，但成本更高；而某个模型 rollout 中缺失的成功轨迹，可能已被另一个模型发现。我们观察到，异构模型往往在互补的提示上取得成功，这为无需指定更强教师模型的相互学习创造了机会。为利用这种互补性，我们提出 GRAFT（Gated Replacement of Answer-Failed groups with peer Trajectories），一种离策略感知框架，用信息量更高的同伴组替换全失败组。GRAFT 迁移同伴模型生成的成功与失败响应及其同伴计算的优势值，同时通过序列级兼容性加权和 Token 级重要性比率裁剪来控制跨模型失配。在三组异构模型对和五个数学推理基准上，GRAFT 在每模型 rollout 预算相同的情况下，持续优于 GRPO，模型级平均性能平均提升 2.1 分，最高提升 4.5 分。存储的同伴轨迹可保留大部分收益，在无需同步协同训练的情况下，相较 GRPO 平均提升 1.8 分。

## Imagine3D-LLM: Teaching MLLMs to Imagine 3D Scenes Before Answering

[Imagine3D-LLM：让 MLLM 在回答前先想象 3D 场景](https://arxiv.org/abs/2609.38177)

从多视角图像推理 3D 世界，仍是多模态大语言模型（MLLM）面临的一项基础性挑战。尽管现代 MLLM 能有效处理单图输入，却难以跨视角整合证据，形成连贯的 3D 理解。越来越多工作试图弥合这一差距，或增强细粒度像素级跨视角对应，或融合 3D 几何基础模型的特征，但距离人类推理仍有显著差距。本文重新审视人类空间推理：人类并非依赖细粒度几何线索，而是大致识别跨视角的共同物体，推断视角间的相对几何关系，并拼装出场景的粗略 3D 布局。受此过程启发，我们提出 Imagine3D-LLM，一个学习拼装类似紧凑 3D 场景表示、并以其为条件生成答案的 MLLM。具体而言，我们在图像 Token 后附加一小组可学习的 summary Token，将其解码为紧凑的 3D Gaussian Splatting 表示，并以光度重建损失进行监督，同时与标准的下一 Token 预测目标联合训练。值得注意的是，尽管只有 summary Token 接受直接重建监督，该目标仍在 LLM 底层图像特征中诱导出更强的跨帧对应，表明学习重建会把 3D 感知信号传播至整个模型。因此，Imagine3D-LLM 在多个空间推理与 3D 理解基准上持续优于既有方法，说明“想象场景”可能比直接被告知像素级几何更为有效。

## ROWBench: Do Video Models Render What the Program Specifies?

[ROWBench：视频模型能否渲染出程序所指定的内容？](https://arxiv.org/abs/2610.02205)

可编程世界模型将可执行动力学与视觉生成分离，为下一代游戏引擎提供了有前景的基础。然而，它们对显式规则和交互的视觉遵循程度仍未得到充分评估。现有基准测试评估视觉质量、可控性以及指令或物理遵循性，但很少检验对细粒度、程序指定的世界事件的保真度。我们提出了 PROWBench，包含 170 个程序化构建的片段和 600 个代理视频，覆盖多样场景与交互。PROWBench 将实体状态和时间戳事件（包括相机视野之外的事件）记录为可重放的世界记录，并据此渲染同步视图和代理表示。这使得生成视频可以与程序执行的可观测结果进行核对。一个可扩展框架能够构建场景、控制行为，并以不同表示（如粗略 3D 和边界框）渲染每个相机视图。该基准涵盖第一人称和第三人称视角，并为部分片段提供同步多视图观测。基于这些记录，PROWBench 评估实体控制、长时程记忆，以及通过两个基于 VLM 的指标——逻辑-渲染对齐度（Logic-Render Alignment）和交互成功率（Interaction Success Rate）——评估对规定时间线的遵循程度以及时间戳引擎记录事件的视觉实现情况。

## Improving Test-Time Scaling with Adaptive Looped Transformers

[用自适应循环 Transformer 改进测试时扩展](https://arxiv.org/abs/2609.35748)

循环 Transformer（Looped Transformer）通过复用层进行潜在计算，展现出诱人的参数效率。既有研究通常在参数量或每 Token FLOPs 匹配的条件下比较循环与非循环模型。然而据我们所知，当输出变得更长时，循环是否能改善测试时扩展（test-time scaling）仍缺乏探索。我们通过后训练循环 Transformer，研究了精度-计算斜率，即测试时解码 FLOPs 每翻一倍所带来的精度增益。我们发现，现有循环 Transformer 往往比非循环基线具有更陡的斜率，但在计算量匹配时表现不及基线。固定深度循环会在每个 Token 上花费额外迭代，而我们的分析表明，许多 Token 并不能从额外迭代中获益。因此我们提出 TaH2，让模型把额外迭代集中在能从循环中获益的 Token 上。它通过前瞻深度监督（lookahead depth supervision）联合后训练主干网络与迭代决策器（iteration decider），该监督使用在线标签指示进一步迭代是否能改善预测。TaH2 同时提升了测试时扩展的效率与可达精度。在具有挑战性的 AIME 基准上，TaH2 相比非循环基线将精度-计算斜率提升 53%（2.74 对 1.79），在测试时计算量匹配时超出基线峰值精度约 3.4 个点。随着最大迭代深度增加，现有循环模型大多趋于平台期，而 TaH2 相对非循环基线的增益持续增长，从深度 2 时的 +2.8 个点提升到深度 8 时的 +3.9 个点。我们的代码见 https://github.com/thu-nics/TaH。

## E-MoE: Enhanced Mixture-of-Experts for Non-Factorized Diffusion Language Models

[E-MoE：面向非因子化扩散语言模型的增强型混合专家](https://arxiv.org/abs/2609.37533)

掩码扩散模型（Masked Diffusion Model，MDM）通过在每一步去噪中逐步解掩码若干个 Token 来生成序列，但其反向过程通常按位置因子化，这限制了少步采样（few-step）场景下的样本质量——而少步采样恰恰是扩散模型相对自回归解码的速度优势最关键的场合。近期一系列工作引入连续高斯隐变量，并将其作为变分自编码器进行训练，以捕捉位置间的相关性，但此类方法容易出现后验坍缩（posterior collapse），即隐变量被悄然忽略。为此，我们提出增强型混合专家（Enhanced Mixture-of-Experts，E-MoE）：它将反向过程构建为因子化分布的混合，其混合成分由混合专家（MoE）主干网络的专家路由决策所给出的离散共享隐变量决定，同时不增加相对因子化基线的激活参数量。在合成多模态基准、二值化 MNIST 以及 LM1B 上，E-MoE 相较因子化基线提升了少步生成效果。

## ActiveSaddler: Automated Curriculum Learning for Agent Harness Optimization

[ActiveSaddler：面向 Agent Harness 优化的自动化课程学习](https://arxiv.org/abs/2610.00906)

自动化 harness 优化能够通过基于执行反馈迭代更新 LLM Agent 的提示词、工具接口和控制逻辑，显著提升其表现。然而，现有方法主要优化 harness 的更新方式，却基本固定了哪些训练场景用于产生驱动这些更新的反馈。随着 harness 不断演进，对进一步优化最有价值的场景也会发生变化，这表明训练课程本身应当与 harness 协同适应。我们将 harness 优化中这一缺失的维度形式化为自动化课程学习问题，并提出 ActiveSaddler。ActiveSaddler 将不断演变的课程建模为具有动态实例化优化目标的非平稳赌博机（non-stationary bandit）。它把反复出现的失败抽象为可复用的失败模式臂，估计继续针对每种模式所能带来的潜在学习进展，并自适应地平衡对已知弱点的重访与对未见场景中新失败模式的探索。优化结果会持续更新已发现的失败模式集合及其优先级，使课程能够与 harness 共同演化。在 GAIA2 和 Terminal-Bench 2.0 上的实验表明，ActiveSaddler 能够稳定发现更强的 harness，相比使用优化前固定场景顺序的同一 harness 优化器，测试 Pass@1 分别提升 4.4 和 7.5 个百分点。消融实验进一步表明，这些收益依赖于动态构建优化目标、估计其不断演变的效用，以及平衡持续优化与新失败发现。这些结果共同确立了自动化课程学习作为 harness 优化中一个新的关键优化维度。

## RayOrch: Programming and Executing Lineage-Controlled Multi-Grain Dataflows for Foundation-Model Data Preparation

[RayOrch：为面向基础模型的数据准备而编程并执行谱系受控的多粒度数据流](https://arxiv.org/abs/2609.18703)

为基础模型准备高质量训练数据，需要可扩展的流水线，将异构文档和视频转化为结构化记录。此类流水线把每个父项扩展为一个有序且依赖输入的序列，其子项数量的分布可能是长尾的。GPU 应当跨父项对子项进行批处理，同时保留父子关系、子项顺序、完成状态以及结果路由。现有系统要么把并行性隐藏在粗粒度作业之后，要么暴露扁平记录，迫使应用自行管理谱系与重新分组。我们提出 RayOrch，一种在执行全程保留父子关系的编程模型与分布式执行引擎。程序声明有序的可变基数扩展与与之匹配的归集（gather）。编译器校验每一对声明，运行时则记录子项归属、直接父项、不可变序号和终止状态。按调用 FIFO 的就绪队列（Ready Queue）跨父项批量聚合就绪子项。归集依据所声明的归属关系与序号重建结果，而不是依据批次边界或完成顺序。只要所有必需子项进入终止状态，父项即可推进。类型化的父项作用域失败会抑制失败父项尚未派发的兄弟子项，同时允许无关父项继续执行。在 NVIDIA H20 GPU 上，RayOrch 将 MinerU 从 4 块 GPU 扩展到 64 块 GPU 时取得 15.14 倍加速，将视频流水线从 8 块扩展到 64 块 GPU 时取得 7.82 倍加速。在 MinerU 上，相较 Ray Data 端到端时间减少 13.1%，相较 Daft 减少 29.0%；在 Docling 上，相较 Ray Data 减少 16.0%。代码见 https://github.com/OpenDCAI/RayOrch 。

## More Choices, Fewer Decisions: Ordinal-Scale Bias in JEV-like Direct-Decision Models

[更多选择，更少决策：类 JEV 直接决策模型中的序数尺度偏差](https://arxiv.org/abs/2609.38827)

直接决策模型（Direct-decision model）将文本转换为低延迟的结构化标签与分数，因而在分类和自动评估任务中颇具吸引力。然而，可靠性不仅要求准确率，还要求模型忠实使用用户提供的序数决策尺度。我们分析了 JEV 1.13 以及三个开源 KEV 模型。研究从 ANLI 入手：尽管 JEV 的准确率为 74.95%、金标标签近乎均衡、候选位置也保持平衡，它仍将 38.8% 的预测和 51.3% 的错误分配给 Neutral。在 36 个序数数据集上，最终决策仅使用了有效金标支撑度的 67–76%，而在四个名义型任务上这一比例为 87–102%。随机化候选顺序会削弱这种压缩，但无法将其消除。在固定条目与源分数、同时平衡金标支撑度和位置的情况下，我们将尺度从 K=2 细化到 14；所有模型的利用率均下降，在 K=14 时降至 26–75%，不过多数模型的候选概率分布仍然较宽。针对性的 BA-LoRA 后训练在两种 KEV 规模下的八个监督尺度上，将相对金标利用率从约 47% 提升至 86%，表明这种压缩是习得的、可修改的，而非不可变的架构限制。我们将此称为序数尺度利用率偏差（ordinal scale-utilization bias）：一种发生在决策阶段的候选空间压缩现象，它不同于准确率、金标不平衡、固定位置或单纯的候选数量问题。代码与数据见 https://github.com/Glax147/jev_ordinal_scale_bia

## OSWorld-Science: A Benchmark of Computer Use Agents for Learning and Using Scientific Software

[OSWorld-Science：面向学习和使用科学软件的计算机使用Agent基准](https://arxiv.org/abs/2609.39903)

科学软件对基于视觉语言模型（VLM）的计算机使用Agent提出了严苛考验：完成科研工作流需要解读专用界面、操作科学对象并产出可验证结果。为此，我们提出OSWorld-Science——一个集科学意义任务、基于产物的评估与高效Agent测试框架于一体的基准与评测环境，用于研究科学领域的计算机使用。该基准涵盖12个VLM和146个高质量任务，横跨多个科学领域与软件配置，覆盖分子绘制与逆合成、病理图像分析、统计计算、物理仿真等工作流。任务通过专家提案与人机迭代协同设计开发，并以科学价值和难度为筛选依据。任务专属的执行式评估器会检查应用状态与生成产物，包括分子结构、分割掩码、图表和数值结果，并对未完成结果给予部分分数。我们的专用测试框架集成了模型适配器、交互循环控制与轨迹日志，支持比较不同模型和交互策略。结果表明，当前SOTA VLM即便搭配强测试框架，在解决科学领域关键问题上仍面临挑战。我们还从多语言、推理投入、上下文长度等因素对基准结果进行了分析，得出若干重要结论与方向，以助力未来发展。总体而言，我们提供了一个连接专家定义的科学目标与可验证软件产出的集成框架，支持对科学工作流中的Agent能力与测试框架设计进行系统性评估。

## OmniTaskonomy: When Does Visual Generation Improve Visual Understanding?

[OmniTaskonomy：视觉生成何时能提升视觉理解？](https://arxiv.org/abs/2609.38079)

训练模型生成视觉内容，可以促使它学习与几何、空间关系和物体性相关的丰富感知能力；然而，这种训练对视觉理解的益处仍不明确。我们提出的问题是：视觉生成监督何时以及如何提升视觉理解？我们研究了受控配对的图像到图像（I2I）生成任务与图像到文本（I2T）理解任务，它们以不同的输出模态表达同一底层问题。我们发现，在正确的训练配方下，I2I 训练能够提升下游 I2T 性能，且随着 I2I 训练数据量的增加，增益更大。接下来我们追问：哪些生成任务有益于哪些理解能力？为了研究配对任务之外的迁移，我们提出了 OmniTaskonomy，一个统一分类体系，涵盖 19 个 I2I 生成任务和 25 项 I2T 理解能力。由此得到的迁移图谱揭示了选择性的、依赖任务的收益。有些符合直觉上的对应关系，例如深度预测提升度量 3D 推理、物体指向提升计数、拼图重建提升 2D 排序。有趣的是，我们还发现了意外的联系：2.5D 分割提升类别识别，Z 深度预测提升定位。为探究这些模式，我们分析了生成任务与理解任务之间的梯度对齐，发现更强的对齐与更大的下游迁移增益相关。总体而言，我们的结果凸显了视觉生成作为视觉理解监督的丰富来源，并提供了一条通过正确训练课程与任务选择来释放其收益的路线图。项目页面：https://omni-taskonomy.github.io/。

## Make Sparse Rewards Count: Density-Aware Reward Aggregation for Multi-Reward RL

[让稀疏奖励发挥作用：面向多奖励 RL 的密度感知奖励聚合](https://arxiv.org/abs/2610.00574)

多奖励强化学习（RL）旨在训练大语言模型同时满足多种行为目标。GDPO 中采用的按奖励归一化（reward-wise normalization）能够在 rollout 组内保留各奖励自身的相对信息，但不同目标的学习进度仍可能不均衡。我们通过**优势能量**（advantage energy，即某奖励在一个 batch 内平方优势之和）来研究这一现象。在理想化的 GDPO 归一化下，我们证明该能量正比于**活跃组密度**（active-group density），即该奖励能提供非零相对优势的 rollout 组所占比例。这揭示了残余的 batch 级信号不均衡，并为校准各奖励的贡献提供了依据。基于该关系，我们提出**密度感知奖励聚合**（Density-Aware Reward Aggregation，DARA）。我们推导出反平方根密度校正，使出现频率较低的奖励信号获得更大权重。DARA 根据每个 rollout batch 计算权重，从而在训练全程自适应奖励活跃度的变化，且不改变底层策略优化目标。在工具调用和数学推理上的实验表明，DARA 相比 GDPO 更快学到目标行为：在工具调用上以最多减少 26% 的训练步数达到高格式合规率，在数学推理上以最多减少 65% 的步数接近长度合规饱和，同时在最终性能上仍具竞争力。代码见 https://github.com/zhaihaotian/DARA。

## AutoGUIWorld: Image Generators as Visual World Models for GUI Agent

[AutoGUIWorld：将图像生成器作为 GUI Agent 的视觉世界模型](https://arxiv.org/abs/2610.01215)

GUI Agent 需要高质量交互轨迹来学习软件环境如何响应动作、维护状态并支持多步工作流。然而，现有轨迹的多样性受限于底层环境中可访问的应用、界面状态和工作流。要扩展覆盖范围，就需部署日益多样且复杂的软件，而专用应用还会带来额外的安装、配置与运行时成本。我们提出 AutoGUIWorld，一个数据生成框架，它将图像生成器的视觉先验与规划器的任务知识相结合，无需部署或运行相应软件环境即可合成 GUI 交互轨迹。AutoGUIWorld 从操作系统上下文、视觉外观和界面状态的结构化规格中采样初始 GUI 场景，并基于这些场景生成任务。随后，规划器指定原子动作及其预期的视觉结果，图像生成器则迭代编辑当前截图以生成后续观测。通过动作定位与转换级质量过滤，该框架在 Ubuntu、Windows、macOS 和 Chrome 上共获得 79,266 个带空间标注的步骤级训练样本。在 AutoGUIWorld 轨迹上微调 Qwen3.5-35B-A3B，使 OSWorld 上的平均任务得分从 33.0% 提升至 40.8%，ScienceBoard 上的任务成功率从 14.0% 提升至 32.2%。这些结果表明，生成的轨迹能够提升 GUI Agent 在真实桌面与科学任务上的表现。

## AIM: Agentic Idea Management for Automated Research

[AIM：面向自动化研究的智能体化想法管理](https://arxiv.org/abs/2609.38445)

前沿 LLM 正越来越多地被用于通过迭代搜索实现科学研究自动化。本文将“想法驱动型搜索”与“方案驱动型搜索”加以区分，并指出三大核心挑战：组织不断演进的研究想法、筛选有前景的方向、以及维持想法与其实现之间的一致性。为此，作者提出 Agentic Idea Manager（AIM）——一个完全自主的框架，用于在想法驱动的自动化研究中管理和探索研究方向。受贝叶斯优化（Bayesian optimization）启发，AIM 采用智能体代理模型（Agentic Surrogate）与智能体采集机制（Agentic Acquisition）来组织已发现的想法并引导其筛选。解决方案审计器（Solution Auditor）负责维护想法—方案的一致完整性，资源规划器（Resource Planner）则在并行的搜索分支之间自适应地分配剩余实验预算。在 10 项 AutoLab 基准任务上的实验表明，AIM 在系统优化类任务上超出最强基线 1.6 个百分点，在长周期模型开发与 CUDA 任务上超出 4.9 个百分点。值得注意的是，AIM 达到最佳基线性能所需的实际耗时最多可缩短至 3.1 倍。作者进一步对“在想法层面进行搜索何时有益”给出了理论分析：分析表明，显式的想法级分配使语义覆盖度可直接调控，而当众多可行备选中真正具备竞争力的研究方向较为稀疏时，更广的覆盖度会变得愈发重要。项目主页：https://imhgchoi.github.io/agentic-idea-manager/

## Learning Native Reflection in Unified Models with Interleaved Reinforcement Learning

[在统一模型中以交错强化学习实现原生反思](https://arxiv.org/abs/2609.35767)

统一多模态模型既能观察图像也能生成图像，因此原则上可以修复自身生成的内容：诊断图像哪里出错、进行修改、观察结果、再次诊断。然而，修改是否有效只有在渲染之后才能知道，因此反思文本与图像生成必须在整个循环中联合学习。基于反思轨迹的监督微调（SFT）能提供冷启动，但无法找到高成功率的修复路径；仅优化渲染器或仅优化单个头的朴素 RL 则会遗漏大部分收益。我们提出 UMM-Reflection，在一个统一模型内部对完整反思轨迹应用强化学习（RL）：同组轨迹共享同一初始图像，因此组相对优势（group-relative advantage）可以比较不同反思策略，而单一的轨迹级优势同时更新反思 Token 与基于流的修改，避免了逐轮信用分配的组合爆炸。与单轮编辑或使用外部评论器的流水线不同，这里的信用跨轮次流动，并同时传递给同一模型的两种角色，且推理时无需验证器。在 BAGEL 上，UMM-Reflection 相较 SFT 将 GenEval 提升 12.05 个点，且增益可迁移至 WISE（+10.97）、OneIG-Bench（+3.48）和 T2I-CompBench++（+4.63），而这些基准均未用于训练。

## Agent Error Dataset: Scaling 50,000 Error--Diagnosis Pairs for Failure Analysis and Error-Aware Post-Training

[Agent Error Dataset：扩展 50,000 条错误—诊断对，用于失败分析与错误感知后训练](https://arxiv.org/abs/2609.40111)

一次失败的 LLM Agent 轨迹（rollout）所包含的信息远不止其最终奖励：还包括 Agent 可获得的观测、它选择的动作以及环境的响应。要将这些经验复用于学习，就需要找出一个待修正的决策，并测试一个具体的替代方案。我们提出 Agent Error Dataset（AED），包含 50,228 条错误—诊断对，源自 33 个环境、19 个 harness 家族和 23 个策略模型在文本型 Agent 系统中的 9,961 个源任务。我们保留源轨迹与执行元数据，以支持跨设置失败分析和重新诊断，而无需重复原始 rollout。我们的五阶段 Agentic Error-to-Training（AET）流程收集自然发生的失败，生成诊断与拟议修正，并依据记录的证据对其进行校验。在支持重放的情况下，我们在匹配的执行设置下，将修正与同一 checkpoint 的原始动作重试进行对比。随后，我们分别为诊断和 actor 恢复构建独立的训练视图。在 3,062 对匹配重放对中，首次提案修正将验证器通过率从 18.4% 提升至 51.1%，提升 32.7 个百分点。使用单独冻结的诊断版本，在 1,656 个源任务上进行全诊断微调，使 Qwen3-8B 与内部教师标签的精确步骤一致率从 47.2% 提升至 63.6%，这是在 943 个案例的留出集上对三个随机种子取平均的结果。该比较中最强的提示参考得分为 54.7%，且平均一致率在四个递增的训练集规模上均有所提升。在 actor 训练配方的单种子比较中，仅动作修复训练在 WebShop-lite 上比仅成功训练高出 6.67 个百分点。

## ROSS: Relearning from Self-Generated Rollouts through Selective Supervision

[ROSS：通过选择性监督从自生成轨迹中重新学习](https://arxiv.org/abs/2609.35954)

大语言模型后训练通过强化学习和同策略蒸馏（on-policy distillation）生成自生成轨迹，但一旦策略前进，这些经验往往被视为过时。历史轨迹可能与后续策略保持兼容，同时保留该策略不再稳定表现出的行为。然而，它们也可能包含错误、被放弃的尝试以及冗余动作，这些都不应被模仿，因此需要更细粒度的选择性监督。我们提出 ROSS（通过选择性监督从自生成轨迹中重新学习），它保留完整历史轨迹作为上下文，仅对选定的模型生成续写部分施加损失。在领域特定强化学习、多教师同策略蒸馏和智能体强化学习（Agentic RL）中，ROSS 持续提升上游检查点，并在数学、代码生成、指令遵循和软件工程任务上优于基线。在 Qwen3.6-35B-A3B 上，ROSS 将六基准 MOPD 平均分从 58.40% 提升至 62.20%，并将 SWE-bench Verified 从 64.20% 提升至 68.40%。这些结果表明，自轨迹训练留下了可复用的行为经验，可通过离线监督微调（SFT）带来进一步收益，且无需额外的策略轨迹采样。

## EgoTools: Towards Tool-Centric Reasoning in Real-World Egocentric Videos

[EgoTools：面向真实世界第一视角视频中以工具为中心的推理](https://arxiv.org/abs/2609.39378)

真实世界的具身任务——从日常活动到专业操作流程——要求智能体在物理约束下行动，同时持续追踪不断变化的对象状态与任务状态。工具使用是这类任务的核心，因为大量日常与专业活动都以工具为中介。要理解这些活动，需要推理可供性（affordance）、手—工具—物体的几何关系、流程进展以及对目标物体的因果影响。然而，尽管当前多模态视频模型在描述生成、通用视频问答等以感知为导向的任务上表现强劲，在这类以工具为中心的具身推理上仍然受限。该方向的进展受制于缺少真实世界第一视角数据和诊断性基准。为填补这一空白，我们提出 EgoTools，首个面向第一视角工具使用理解的全方位套件，由两个互补部分组成：EgoTools-Data，一个大规模语料库，包含 100 小时以工具为中心的第一视角录制视频，配有同步音频、密集描述、推理密集型叙述以及补充的 3D 信息；以及 EgoTools-Bench，一个诊断性基准，包含四个赛道共 1,000 对问答，覆盖从感知、几何到流程与因果推理的工具使用理解。实验结果显示，当前模型仍难以将工具使用建立在视觉证据之上：Gemini-3.1-Pro 总体准确率达 66.9%，但在感知与定位（Perception & Grounding）赛道仅为 51.7%。除评测之外，我们还验证了 EgoTools-Data 作为训练资源的价值。在严格源视频隔离条件下，于完整 1,000 题基准上，全监督微调使 Qwen3-VL-8B-Instruct 从 50.0% 提升至 60.9%。这些结果共同确立了 EgoTools 作为真实世界第一视角工具使用理解的统一资源，可同时用于训练与诊断性评测。

## Retrieval-Augmented Skill Optimization via Cross-Harness Adaptation

[通过跨 Harness 适配的检索增强技能优化](https://arxiv.org/abs/2609.38024)

Agent 技能（skill）是一种可复用、可执行的自然语言产物，用于指导 Agent 在给定 Harness 下高效完成任务。近期研究已开始探索 Agent 技能的优化，推动形成了覆盖多样任务、领域与 Harness 的公开技能集合，且规模持续增长。然而，尽管已有数以百万计的公开共享技能，现有技能优化方法在很大程度上忽略了这些积累的知识，仅依赖成本高昂的 Agent rollout 来为目标任务迭代精炼技能。为此，作者提出检索增强技能优化（Retrieval-Augmented Skill Optimization，RASO）框架，在整个技能优化过程中将外部技能语料库作为先验知识加以利用。RASO 从已有技能中检索相关知识，并通过跨 Harness 适配（Cross-Harness Adaptation）将其迁移到目标任务与 Harness，以应对领域与 Harness 两方面的不匹配。RASO 包含两个互补阶段：检索增强技能初始化（RASI）无需 Agent rollout 即可构建有知识支撑的初始技能；检索增强技能更新（RASU）则以执行反馈为引导检索外部知识，迭代精炼技能。在四个 Agent 基准与两个模型上的大量实验表明，RASO 持续优于未采用检索增强技能初始化与更新的基线方法。

## LANTERN: Illuminating Hidden Mathematical Knowledge in Language Models

[LANTERN：照亮语言模型中隐藏的数学知识](https://arxiv.org/abs/2609.32264)

语言模型如今已能证明定理，但选择研究哪些问题仍然由人决定。本文探讨模型的内部表示能否帮助识别有前景的数学关联。作者开发了 LANTERN——一条快速、低成本的流水线：先基于预训练模型激活值训练分类器对候选关系排序，再经过分阶段过滤、假设生成、可执行验证与解析检查。将该方法应用于整数序列在线百科全书（OEIS），LANTERN 在 10,000 个高频引用序列之间对 5000 万对序列进行排序，并产出 62 条经证实的关系，而这些序列对在 OEIS 中原本并无交叉引用。经内容筛查后保留 13 条值得呈现的关系，其中 9 条具有信息价值或洞察力，包括 4 条据作者所知完全新颖的关系：它们既未出现在 OEIS 中，也未出现在针对性的文献检索中。整个端到端流程——包括分类器训练、候选排序、过滤与验证——耗时不到 8 小时。

## APM-Bench: Benchmarking Cross-session Persistent Memory for Egocentric Streaming Video Assistants

[APM-Bench：面向第一视角流式视频助手的跨会话持久记忆基准测试](https://arxiv.org/abs/2609.37559)

要让流式视频模型成为现实世界的个人助手，就需要具备持久记忆，以保留过往经历供后续使用。然而，现有流式基准与方法往往聚焦于单段连续视频或短片段，忽视了现实交互通常是间断性的，且记忆需要在中断之间持续保留。为填补这一空白，我们提出 APM-Bench，将现实世界的流式交互重新表述为多会话的生活轨迹。该基准包含 549 个会话、104 条轨迹和 2,719 个候选样本，覆盖客观题与开放式问题。每个会话都是一段带有细粒度标注的视频，而同一轨迹内的会话围绕相关活动展开。模型随后利用持久记忆回答关于过往会话的问题，并在保持实时交互的同时提供主动响应。这带来了若干挑战：持久记忆必须可存储、能有选择地保留信息、在恰当时机注入，并且保持高效。此外，有限的存储空间可能导致所需证据不可用，因此助手应当能够识别证据缺失。为此，我们在不同记忆协议下系统评估了通用视频模型以及多种专用流式记忆系统，并测试模型是否会承认证据不足。我们的评估揭示出明显的效用—延迟—存储权衡：现有方法仍难以同时实现可靠的长期回忆、低开销以及跨会话的有效主动协助。APM-Bench 提供了一个全面的测试平台，用于在贴近真实的流式条件下开发和比较持久记忆系统。我们希望它能推动未来工作同时兼顾效用、延迟与存储，朝着更实用的现实世界流式助手持久记忆方向发展。

## HybridCUA: Learning to Orchestrate GUI and CLI for Computer-Use Agents

[HybridCUA：学习为计算机使用智能体编排 GUI 与 CLI](https://arxiv.org/abs/2609.38008)

计算机使用智能体（Computer-Use Agent，CUA）在完成数字任务方面已展现出强大能力。然而，现有 CUA 要么仅依赖图形用户界面（GUI）交互，这种方式往往效率低下且容易出错；要么在 GUI 交互之外引入应用专属 API 或工具，而这需要大量工程投入，难以跨应用扩展。我们认为，下一代 CUA 应当将 GUI 交互与命令行界面（CLI）结合起来，兼取 GUI 的通用性与 shell 命令的高效性。但一个关键挑战在于，当前模型并不知道在任务执行过程中何时以及如何使用 CLI。为应对这一挑战，我们开发了一套数据构建流水线，可生成三类轨迹：纯 GUI、纯 CLI，以及 GUI 与 CLI 交错执行的轨迹。该流水线产出了 HybridCUA-8K，其中包含 5K 条混合轨迹和 3K 个经过验证的 RLVR 任务。基于这些数据，我们提出了一个两阶段训练框架：先在构建的轨迹上进行监督微调，随后使用我们设计的 CLI 感知奖励进行强化学习，以鼓励智能体有选择地、可靠地使用 CLI。实验表明，HybridCUA-9B 在 OSWorld 上取得 53.6% 的准确率，较基座模型提升 14.8 个百分点，并在 WindowsAgentArena 上提升 4.0 个百分点。这些结果验证了面向计算机使用智能体的 GUI 与 CLI 混合范式的有效性及其跨平台泛化能力。
