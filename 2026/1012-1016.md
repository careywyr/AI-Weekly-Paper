## Waypoint-OPD: Transferring RL-Induced Policy Shifts via Gated On-Policy Distillation

[Waypoint-OPD：通过门控同策略蒸馏迁移 RL 引发的策略偏移](https://arxiv.org/abs/2610.21601)

策略偏移蒸馏（policy-shift distillation）利用教师在强化学习（RL）前后对数概率的差异，作为对学生生成轨迹的监督。然而，这种端点策略偏移无法揭示局部动作偏好（action preferences）在教师训练过程中是否一致演化。相同的端点偏移可能由早期和晚期偏移相互强化或部分抵消而产生。我们研究早期与晚期教师策略偏移之间的一致性是否能够指导选择性迁移。我们提出 Waypoint 引导的同策略蒸馏（Waypoint-guided On-Policy Distillation，Waypoint-OPD），它使用同一 RL 运行中的中间教师检查点，在学生访问的前缀（student-visited prefixes）上比较早期和晚期偏移在相对动作偏好上的差异。我们根据早期和晚期偏移之间的方向一致性对端点偏移进行门控，当二者方向相反时抑制该偏移。与仅端点迁移相比，我们的方法仅需额外进行一次冻结教师评分过程。使用经 RL 训练的 Qwen3-4B 教师，我们在数学和代码推理中以 Qwen3-8B、Qwen3-14B 和 Qwen3-30B-A3B 作为学生模型评估我们的方法。在所有六个领域—学生设置中，Waypoint-OPD 在所比较的蒸馏方法中取得了最高的领域平均分。使用 Qwen3-8B 学生进行的消融实验表明，移除或打乱门控会降低数学推理性能。这些结果支持在学生训练期间使用早期和晚期教师策略偏移之间的方向一致性来对端点偏移进行加权。

## OmniCompass: A Holistic Benchmark for Omni-Modal Video Grounding and Understanding

[OmniCompass：面向全模态视频定位与理解的综合基准](https://arxiv.org/abs/2610.18829)

随着多模态大语言模型（MLLM）的快速发展，评估其视频理解能力变得愈发重要。现有视频理解基准仅覆盖部分评估维度，限制了对全模态视频理解进行系统性诊断。为此，我们提出 OmniCompass，一个面向全模态视频定位与理解的综合基准。OmniCompass 定义了两个评估赛道：OmniCompass-VL 评估视觉语言模型在需要视觉证据的任务上的表现，OmniCompass-AV 评估全模态模型在需要联合音视频证据的任务上的表现。每个赛道包含三个互补任务：时间定位（TG）、空间定位（SG）和问答（QA），分别评估被引用目标何时出现、位于何处以及发生了什么。在 OmniCompass-VL 中，QA 覆盖五类感知和三类推理类别；在 OmniCompass-AV 中，QA 覆盖三类感知和两类推理类别。OmniCompass-VL 包含 820 个视频和 2,460 个实例，覆盖多个领域以及短、中、长三种时长类型。一个叙事和音频丰富的子集构成 OmniCompass-AV，包含 240 个视频和 720 个实例。每个实例均在两种配对设置下评估：纯文本和文本+图像，分别通过文本和视觉语言引导指定同一目标。所有实例均经人工标注并经过多轮质量验证。对 50 个 MLLM 的评估表明，开源模型仍落后于专有模型，尤其在音视频理解方面。即使对领先模型而言，精确的时间定位和空间定位仍然具有挑战性，且其预测在配对的目标指定方式之间仍表现出不一致性。

## Jeva: System One Models from First Principles

[Jeva：从第一性原理构建 System One 模型](https://arxiv.org/abs/2610.18773)

System One 模型能够实现直接、低延迟的决策。然而，近期从序列化文本中预测答案的做法本身并未遵循决策问题的结构。我们认为，当前设计低估了四项重要的结构要求：(i) null-aware（空值感知）：模型应区分答案缺失与候选之间的不确定性；(ii) permutation-invariant（排列不变）：重新排序备选项不应改变决策；(iii) option-scalable（选项可扩展）：候选集增长不应要求重新定义输出空间；(iv) cacheable（可缓存）：对重复出现的备选项进行与请求无关的计算应能跨请求复用。我们提出 Jeva，一种决策原生架构，联合解决这些要求。共享编码器独立表示请求和每个选项，紧凑的决策栈仅针对不可变选项记忆细化请求状态。对称聚合产生排列等变概率；共享评分适应可变大小的候选集。单独的覆盖率估计区分答案缺失与候选竞争，从而支持显式空结果。与请求无关的选项表示和层投影支持在新组装的集合中复用。这些机制统一了 Choice、Noul 和 Score 输出。在评估中，Jeva 将出色的类型化决策表现与近乎完美的空值检测相结合，并在任何测试的排列下均无决策翻转。它可扩展至数千个候选，并通过跨请求复用显著降低延迟，且不改变决策。

## VideoJev: System One Model for Video Understanding and Interaction

[VideoJev：面向视频理解与交互的 System One 模型](https://arxiv.org/abs/2610.18615)

视觉 Agent 必须将视频观察转化为及时决策，以跟踪进展并选择下一步行动。基于新兴的 System One 范式，我们提出 VideoJev，一系列将视频理解与交互转化为结构化决策任务的模型。我们改造预训练多模态大语言模型（MLLM），用共享头替代自回归答案解码；该共享头依据视频证据对时间区间和文本选项进行打分。这些分数产生事件片段或答案选项，从而统一时间定位与多项选择视频问答。这将 MLLM 的语义灵活性与 Agent 可直接使用的高效决策结合起来。随着交互展开，新目标和中间结果会促使针对同一视觉历史提出进一步查询。因此，VideoJev 通过 Cached inference 在查询到达时复用视觉计算，并通过 Joint inference 在单次前向传播中处理多个查询。在三个时间定位基准上，VideoJev-4B 和 VideoJev-35B-A3B 相比各自骨干模型分别将平均 mIoU 提升 6.7 和 10.8 个百分点，实测推理加速为 2.8–3.1 倍。在四个视频问答基准上，两者在 Thinking 模式下达到与各自骨干模型相当的性能，实测推理加速超过 100 倍。这些结果为将结构化视觉判断组合成复杂、开放式工作流提供了统一且可复用的决策接口。

## MJev-Spatial: System One Spatial Intelligence via Native Attention Matching

[MJev-Spatial：通过原生注意力匹配实现系统 1 空间智能](https://arxiv.org/abs/2610.22276)

空间智能使 Agent 能够感知物理世界并在其中行动，其许多判断必须在交互速率下完成：存在何种空间关系、物体距离多远，或应将其放置在何处。视觉语言模型（VLM）通过自由形式的文本生成给出这些答案，为此付出自回归解码和答案解析的代价，尽管输出空间很紧凑：几个选项之一、一个标量或一个 2D 点。鉴于此，我们提出 MJev-Spatial，一个 System 1 多模态决策模型，在统一分类框架内处理全部三类空间理解任务。具体而言，MJev-Spatial 将每个候选视为一个类别，并使用主干网络预训练的查询和键投影对其进行评分，不增加参数。候选对于选择任务为给定选项，对于数值和点预测则分别为通过由粗到细分类细化的数值分箱和图像区域。推理时，每个分类决策只需一次前向传播，且不生成答案 Token。为了高效地训练异构空间数据，我们在一次前向传播中通过教师强制联合监督所有由粗到细阶段，并将其与长度感知的全局批处理和跨 GPU 负载均衡相结合，使训练吞吐量比原始批处理策略提高 30.8%。MJev-Spatial 基于 Qwen3.5-4B，在由现有空间数据集转换而来的 1230 万问答对上训练，在八个被测模型中取得最高总体得分（65.64%），在十二个基准中的七个上排名第一，并在全部十二个基准上优于未经修改的自回归基座模型，同时运行速度达到最快自回归基线的 2.5 倍、基座模型的 5.6 倍。

## Any Time, Any Space: A World-State-Centric Framework for Agentic Video Generation

[任意时间、任意空间：一种以世界状态为中心的智能体视频生成框架](https://arxiv.org/abs/2610.20571)

长篇智能体视频生成必须将剧本转化为在非连续请求之间保持空间与时间一致性的镜头。在镜头之间传递 prompt 或近期帧，既无法为重新访问某个场景提供共享空间框架，也无法为回放早前事件提供按时间索引的记录。我们提出 Any Time, Any Space（ATAS），它将剧本编译为带有显式位置、相机和事件时间引用的镜头请求。生成前，ATAS 从由配准静态几何构成的场景记忆，以及按场景、事件和时间索引的动态观测事件记忆中检索相关证据。生成后，ATAS 重建并配准该片段。仅当审查与状态检查接受该观测时，它才更新记忆，而成片交付仍独立于记忆准入。在四种视频生成器上，ATAS 改善了所有报告的跨镜头一致性指标，并在每个骨干模型上取得最高综合基准分数。它还在目标图像空间重访上优于所比较的 Agent 和 3D 引导方法，在三个事件重捕获指标上领先，并在全部六项标准上获得最高人工评分。视频结果和代码见项目页面：https://lhmd.top/atas/。

## Player-1: Learning to Play from Synthetic Experience

[Player-1：从合成经验中学习游戏操作](https://arxiv.org/abs/2610.20584)

Computer-use Agent 已展现出强大的屏幕解读与键盘鼠标操作执行能力。然而，游戏世界视觉丰富、机制多样，仍是极具挑战性的场景，也是迈向通用数字控制的关键一步。当前游戏 Agent 的学习流程往往依赖大规模演示数据，而这些数据对动态游戏状态的覆盖有限，同时用于交互训练的可扩展环境也难以获得。为此，我们提出 Player-1，一个通过合成经验在演示之外学习游戏控制的训练后（post-training）框架。我们扩展了 computer-use 动作空间，加入相对指针移动、持续输入和复合动作。在监督初始化阶段，我们在 6,044 条精选游戏轨迹上微调 computer-use 模型，这些轨迹将录制的动作与任务指令和视觉推理配对。我们构建了 Player-1-Gym，包含十六个合成 2D 和 3D 环境，围绕游戏间共享的控制需求设计。可程序化验证的奖励以及随机化的观测和控制动态，支持使用 PPO 进行多环境强化学习。所得 Player-1-9B 和 Player-1-35B-A3B 在 MineDojo-300 上的成功率分别较其 SFT 策略提升 27.8 和 17.7 个百分点。Player-1-9B 达到 38.33% 的成功率，而表现最强的评测基线为 12.63%；在 ViZDoom-10 和 GameWorld 上，它相较 SFT 也取得进一步提升。进一步分析表明，更广泛的合成环境覆盖能改善迁移效果，而在 RL 过程中，组合多个键盘和鼠标输入的复合动作使用有所增加。我们证明，从合成经验中学习能够显著提升游戏控制能力，超越监督初始化，且这些增益可泛化到 RL 训练套件之外。

## GroundingPI: A Grounding Foundation Model towards Physical Intelligence with Visual Primitives

[GroundingPI：面向物理智能、以视觉基元实现接地的基座模型](https://arxiv.org/abs/2609.39601)

精确接地（grounding）至关重要：它要指明目标是哪个物体、该物体位于何处，即使在杂乱场景和微小目标下也要做到；同时，其速度必须足以支撑闭环控制。然而，视觉-语言-动作（VLA）模型与世界-动作模型（WAM）的感知能力来自通用视觉-语言骨干和视频生成骨干，而这些骨干在上述场景中仍会失败。为此，作者提出 GroundingPI，这是一个 4B 参数的接地基座模型；它把点和框作为量化坐标生成在共享词表中。训练过程结合了多模态与空间预训练、监督微调，以及使用 GRPO 的强化学习，所用监督来自公开数据集和专门的数据引擎。在覆盖 11 种感知能力的 34 个接地基准上，与 44 个基线相比，GroundingPI 建立了新的 SOTA，平均达到 73.68%，高于规模更大的 GPT-6 Astra（71.54%）。作为下游视觉骨干，GroundingPI 提升了机器人操作和自动驾驶的性能。在 RoboTwin 2.0 上，它在全部四种分布外设置中均优于所评估的每个主流骨干，相对最强骨干最高提升 24.8%。在 RoboCasa-GR1 上，GroundingPI 仅用 50% 的演示训练，就优于用 75% 演示训练的基线。在 nuScenes 上，作为视觉骨干时，GroundingPI 取得 0.296 m 的平均开环 L2 误差。作者还从规模和数据类型两个维度系统分析了 GroundingPI 的预训练：随着预训练规模扩大，下游自动驾驶和机器人操作性能随之提升；对这 11 种感知能力的数据配方分析显示，密集接地对这两类下游任务都有显著收益，而 OCR 有潜力成为促进感知学习的催化剂。这些结果支持将接地作为感知基础，也表明专门的感知预训练是通向物理智能基座模型的一条有前景的方向。

## DiffusionART: Efficient, Stable and Scalable Reinforcement of Diffusion Models

[DiffusionART：高效、稳定且可扩展的扩散模型强化学习](https://arxiv.org/abs/2610.12572)

在线强化学习（RL）利用黑盒奖励微调扩散模型，但 Flow-GRPO 等逆向过程方法因信用分配不佳而效率受限；DiffusionNFT 等前向过程方法虽然高效，却需要仔细调优指数移动平均（EMA）的离策略训练才能保持稳定。我们表明，NFT 风格目标包含一种隐藏的前向—反向一致性力，联合正—负训练只能部分抵消该力；EMA 通过恢复而非离策略 rollout 来稳定训练。我们提出 DiffusionART（Diffusion Reinforcement with Aggregation-First Reward Tilting，聚合优先奖励倾斜的扩散强化学习），它将每个 prompt 的奖励聚合为反向过程状态共享的奖励提升方向，从构造上消除一致性力，并加入带信任域掩码的第二次更新，以实现无需 EMA 调优的漂移自适应恢复。它不需要可微奖励模型，在每个 prompt 样本更少时仍有效，并支持成对奖励模型（DiffusionART-Pairwise）。在图像和视频生成中，DiffusionART 无需逐任务调优即可高效、稳定地训练。特别是在 HunyuanVideo-13B 上，在视觉和运动质量奖励等权重的设置下，DiffusionART 达到 DiffusionNFT 和 Flow-GRPO-Fast 后期平均奖励水平所需的 GPU 小时分别少 12.02 倍和 11.72 倍，同时平均训练奖励分别高 28.8% 和 53.0%。

## OpenGCUA: Toward a Fully Open Stack for Generalist Computer Use

[OpenGCUA：迈向通用计算机使用全开放技术栈](https://arxiv.org/abs/2610.22200)

计算机使用正处在一个转折点：关注点正从仅限 GUI 的交互，扩展到通过视觉与程序化接口在用户计算机上完成任务的系统。我们将通用计算机使用 Agent（generalist computer-use agent，GCUA）定义为一类系统：由模型决定如何跨视觉与程序化接口进行观察、行动并组织其工作。然而，前沿实现（例如 GPT-6 Astra 的计算机使用系统）在很大程度上仍为闭源，限制了对它们设计的系统性研究。我们提出 Open Generalist CUA（OpenGCUA），这是一个持续进行的项目，旨在与社区共同开发和开放 GCUA 的全栈。本报告呈现 OpenGCUA 的首个版本。代码执行是我们 Agent 设计的一项关键特性：它让中间结果决定后续操作，并使模型能够将其已有的编程能力直接应用于计算机交互。我们还提出从执行框架到模型的决策转移（harness-to-model decision transfer），将选定的观察和任务状态决策从固定的执行框架规则转移到模型。在 OSWorld-v2 上，我们的完整配置提升了全部八个被评估模型的任务得分，包括 GPT-6 Astra 和 Claude Opus 5；相对于批量化的仅 GUI 执行，平均部分得分提高了 +19.6 分，每任务报告步骤数平均减少了 53.0%。我们发布了实现与提示词、全部八个模型的评估轨迹，以及真实设备执行框架和跨设备 SDK 的初步版本。该执行框架应对基准测试未能完整覆盖的真实设备挑战，而 SDK 则提供跨计算机、移动设备和浏览器的通用编程接口。在我们的真实设备执行框架下，针对四个真实 macOS 任务，选定的 Qwen3.8-Max 运行所使用的报告推理 Token 数是 GPT-6 Astra 的 19.4 倍，凸显了模型之间在真实设备执行效率上的显著差异。

## S-Space: Exploring Spatial Workspace in Multimodal Language Models

[S-Space：探索多模态语言模型中的空间工作区](https://arxiv.org/abs/2610.13527)

多模态语言模型（MLLM）展现出颇具前景的空间推理能力，但支撑这些能力的内部机制仍鲜有理解。我们发现了 S-Space，即一个线性表示子空间：在其中，对象 Token 表示沿水平、垂直和距离轴编码连续坐标。尽管我们是通过对对象 Token 激活求空间答案分数的微分来识别这些轴的，但 S-Space 是内在固有的，而非由特定数据或提示诱导产生，在非空间问题下仍可读取。我们表明，S-Space 充当 MLLM 的内部空间工作区。感知将对象位置编码进该空间，形成可直接读取的空间表示，以支持准确的空间判断。内部推理会对其进行变换，以适应视角变化。言语回答则有选择地访问该空间，因果干预实验证明了这一点：干预会改变空间判断，同时在很大程度上保留非空间回答。案例研究进一步表明，S-Space 会为未见实体和观察者分配位置，并将物理方向与抽象语言含义联系起来，这既揭示出大规模语言训练的能力，也揭示出其局限。最后，我们将 S-Space 用作诊断空间推理失败的工具。方向词读取揭示出基本方位参照系与图像相对参照系之间存在系统性耦合。更重要的是，一种感知—计算分解暴露出关键瓶颈：MLLM 能够形成有能力的空间表示，但在跨视角变化进行可靠推理所需的spatial transformations上仍存在不足。

## FDE-Gym: The Last Mile of AI Delivery

[FDE-Gym：AI 交付的最后一公里](https://arxiv.org/abs/2610.22350)

现有 Agent 基准（benchmark）通常评估的是由 issue 报告、规格说明或任务工单定义的、界定清晰的任务。而真实世界的客户交付有所不同：前置部署工程师（FDE，forward-deployed engineer）必须澄清模糊的需求、在运行中的真实系统里工作，并发现未被明确说明的约束条件。我们提出 FDE-Gym，这是一个包含 95 个端到端交付任务的基准，涵盖 18 个行业、20 个客户场景，由行业专家从真实交付项目中改编而来。在模拟的客户环境中，Agent 与预先设定脚本的利益相关者（stakeholder）互动，并操作类生产系统（production-like system），从而交付可用的解决方案。FDE-Gym 按交付对客户自身成功指标的提升程度评分，并在 0（系统未改变）到 1（参考解决方案）之间归一化，同时对利益相关者交互（消息、试运行和等待时间）扣分。一个在线平台让人类在相同评分标准下练习 FDE 技能。我们评估了来自 7 家提供商的 13 种模型配置。在需要发现未明确说明约束条件的真实设定下，最佳配置的平均 FDE-Gym 得分为 0.56，并且仅解决了 95 个任务中的 14 个（得分至少 0.8 且未发生事故）。发现未明确说明的约束是主要瓶颈：当模型必须在没有明确指引的情况下自行发现这些约束时，性能会急剧下降。然而，仅靠信息发现并不能解释这一差距：即使是在最佳配置从利益相关者处获得全部关键事实的 23 个任务上，它也只在其中 10 个任务上达到 0.8 或以上的归一化业务提升。这些结果揭示了解决界定清晰的任务与为真实客户交付有效 AI 系统之间存在显著差距。

## Thinking Inertia: LLMs Keep Thinking When Told Not To

[思维惯性：LLM 在被要求停止思考时仍会继续思考](https://arxiv.org/abs/2610.11765)

大型语言模型（LLM）越来越多地配备显式的“思考模式”，但其对应形态“不思考”（no-thinking）受到的关注少得多。本文从两个维度研究 LLM 的不思考行为。a. 如何衡量不思考？已有工作通常通过禁用思考模式或缺少长轨迹等代理指标来定义不思考，但这些代理指标并不可靠：禁用思考模式后模型仍可能输出推理，而长轨迹可能包含填充内容而非真实推理。本文将每个响应规范化为作答前轨迹（pre-answer trace）与最终答案，并从三个层面评估：（i）空思考率（Empty-Thinking Rate），用于衡量严格仅输出答案的遵循程度；（ii）指令感知的问题-作答前轨迹相关性（Question-Pre-answer Relevance），用于衡量问题与作答前轨迹之间的相似度；（iii）LLM-as-judge 显式推理率（Explicit Inference Rate），用于衡量可见的显式推理。这些指标共同区分仅答案输出、相关但非推理的文本以及显式推理。b. 不思考在不同任务和模型间如何变化？本文在布尔型、多项选择和开放式问题上，对六个 LLM 评估六种提示干预。研究发现，显式的不思考控制无法可靠消除可见推理。模型反而表现出“思维惯性”（Thinking Inertia）：即使受到严格控制，显式推理仍然存在，并且随着答案空间变得更加开放而更加普遍。在布尔型和多项选择任务上准确率保持稳定，而开放式任务揭示了仅答案遵循度与任务准确率之间的权衡。在相同问题上跨答案空间改写后表明，提供候选答案会使仅答案响应更容易产生。这些发现确立了不思考是一项非平凡能力：不能仅凭模型设置或指令就假定模型会停止显式推理，它值得与推理能力一起被系统评估。

## Beyond Domain-Routed Supervision: Cross-Teacher Guarding for Multi-Teacher On-Policy Distillation

[超越域路由监督：多教师策略内蒸馏中的跨教师守卫](https://arxiv.org/abs/2610.13521)

多教师策略内蒸馏（MOPD）通过把领域特定数据路由给专门教师来扩展策略内蒸馏（OPD），并通过对学生生成的轨迹施加密集的 Token 级监督来整合各教师的能力。然而，域路由只区分不同领域的监督来源；所有领域的更新仍然作用于共享参数。当教师在回答风格和领域专长上差异显著时，单独有效的监督在联合优化过程中仍可能导致持续的梯度冲突和能力退化。为应对这一挑战，我们提出面向 MOPD 的跨教师守卫（Road MOPD），将非路由教师作为同一学生轨迹上的辅助跨域评判者（critic），并通过 Token 级信用分配和梯度更新来协调多教师监督。具体而言，跨教师引导的信用分配利用教师间一致性来强化教师共同支持的 Token 级修正，并衰减冲突信号；预防性多教师梯度投影利用同一轨迹产生的辅助梯度约束潜在冲突更新，并自适应控制投影强度以保留目标领域的学习信号。实验表明，Road MOPD 缓解了劣势领域的退化，在高冲突下获得超过 5 个百分点的提升，并在低冲突和三个领域设置下改善整体性能。

## AgentSWE: Can Coding Agents Build the Agent You Actually Want?

[AgentSWE：编码 Agent 能构建你真正想要的 Agent 吗？](https://arxiv.org/abs/2610.13361)

随着软件生产逐渐交由软件自身完成，编码 Agent 正越来越多地被委派去构建适配用户自身工作流的 Agent。这种委派隐含着一个不易察觉的假设：交付的 Agent 将忠实服务于其构建时所针对的需求，而不仅仅是表面上如此。现有基准均未检验这一假设。我们提出 AgentSWE，一个面向 Agent 软件工程的基准，覆盖 Agent 开发生命周期的三个阶段：从自然语言需求创建完整 Agent、编辑生产级 Agent 代码库，以及面向可度量目标进行优化。其 25 个任务均被设定为一项委托而非一场考试：构建者针对少量示例用例进行迭代，而验收则在为覆盖完整需求而设计的留出用例上运行冻结后的提交，在硬性通过/失败门槛下，依据需求衍生的评分细则对行为进行评分；对于优化任务，则依据源基准自身的目标进行评分。我们评估了跨模型和运行框架（harness）的一系列编码 Agent，发现没有一个能接近交付需求所要求的内容：构建者演示的内容与其实际交付的内容之间的差距是常态，而非边缘情况。伴随的失败轨迹实证分析识别出反复出现的失败模式，包括对可见用例的过拟合、看似完整代码背后的空壳运行时，以及无依据的完成声明；每一种都是编码 Agent 可以学习以构建所需 Agent 的信号。

## Agent-Reflex: Teaching Language Agents to Act Reflectively

[Agent-Reflex：教语言智能体进行反思性行动](https://arxiv.org/abs/2610.17953)

大型语言模型已从单轮聊天机器人发展为能够进行长时程推理的交互式 Agent。在实际部署中，MCP 工具服务可能返回带噪声的反馈，用户也可能介入以纠正 Agent，但现有方法对反思学习和失败恢复提供的监督有限。为弥补这一空白，我们提出 Agent-Reflex，一个用于激励 Agent 主动反思的通用训练框架。具体而言，Agent-Reflex 包含三个阶段。首先，环境反思技能发现（Environment Reflection Skill Discovery，RSD）将基于真实工具反馈的扰动注入环境扩展过程，从能力多样的 LLM 池中采样，挖掘匹配的成功-失败对，并总结可复用的反思元技能。基于该技能库，我们随后应用反思监督微调（Reflective Supervised Fine-Tuning，ReSFT），将每项技能转化为对自我反思、技能恢复和以用户为中心的纠正的监督，从而强化互补的反思行为。最后，我们提出同策略反思策略优化（On-Policy Reflective Policy Optimization，ORPO），将噪声交互下的 Agentic RL 与反思引导的同策略蒸馏相结合，以进一步激发主动反思。基于 Qwen3-8B，Agent-Reflex 在五个长时程工具使用基准上达到 58.6 的总体成绩，在 AgentNoiseBench 上达到 29.1，超过强环境扩展和反思基线。在六个具有挑战性的 Agent 基准套件上的实验证明了 Agent-Reflex 的有效性。进一步分析表明，Agent-Reflex 在保持稳定训练动态的同时提升了 Agent 对噪声的鲁棒性，支持可扩展的 Agent 训练。我们的代码可在 https://github.com/RUC-NLPIR/Agent-Reflex 获取。

## RoTA-Bench: Evaluating 3D Spatial Reasoning through Interactive Projection Alignment

[RoTA-Bench：通过交互式投影对齐评估 3D 空间推理](https://arxiv.org/abs/2610.17665)

视觉语言模型能否将 2D 观测转化为支持精确动作的 3D 理解？这需要推断物体几何、预判旋转效果，并通过视觉反馈改进动作。我们提出 RoTA-Bench，通过交互式 3D 到 2D 投影对齐来评估这些能力。给定目标轮廓，模型观察一个旋转后的物体，并在有限动作预算内选择连续旋转，以恢复目标投影。我们的自动化流程从 2D 图标构建保留轮廓的 3D 物体，并使用可逆初始化保证任务可解，最终生成 674 个任务以及一个分层抽样的 100 任务测试集。实验发现：(i) 人与模型之间仍存在显著差距：GPT-5.6-Sol 仅成功完成 17% 的任务，而 20 名本科生参与者合计完成测试集四次，成功率达 100%；(ii) 图像空间与姿态空间的进展可能背离：在匹配状态下，模型比人类更常出现轮廓重叠提升但姿态对齐变差的情况（19.4% vs. 10.9%）；(iii) 细粒度控制对交互历史敏感：移除该控制后，模型 96.8% 的动作停留在 30 度的粗粒度步长，观察到的任务成功率也急剧下降。这些发现凸显了将视觉证据转化为精确 3D 控制的挑战，其难度超出了识别或匹配单张图像。

## Self-Evolving Agent Harness

[自演化 Agent Harness](https://arxiv.org/abs/2610.18813)

Harness 自演化是指在保持模型权重不变的前提下，修改 Agent 的软件脚手架，包括提示词、记忆、工作流和可执行组件。我们将这一过程形式化为反馈驱动过程，其中被接受的修订会在多次运行之间持续保留。该框架把更新目标与提议机制、准入机制区分开，并区分对解释型状态的修改与对工具和代码、仓库级控制逻辑以及插件组合的修订。我们通过演化优化刻画搜索过程，并通过持续 PAC 学习考察其可靠性。在明确假设下，该分析给出了期望泛化界、以历史回归预算为条件的保留界，以及使用全新独立验证数据的高概率准入规则。我们考察持久性 Harness 修订如何影响知识共享和组织工作流，并讨论其对科学可靠性、物理安全和机构问责的影响。先前工作中的案例说明了模型—Harness 协同设计、分布式执行和插件复用。可靠部署要求随着任务分布和评估器变化进行持续验证，并为学习、运行时权限和后果性操作设置独立保障。我们在 https://github.com/zgcagi/Harness-RSI 提供了一份 66 页的综合讨论，涵盖相关工作、理论、算法、评估、应用以及 Harness RSI 的更广泛影响，并附有持续更新的代码和补充材料。

## Scaling Agentic Data for Long-Horizon Terminal Intelligence

[面向长时程终端智能的 Agentic 数据扩展](https://arxiv.org/abs/2610.13166)

终端 Agent 正在从本地操作迈向完成真实世界的专业任务。短轨迹能够展示命令和工具调用，但无法充分体现 Agent 如何通过探索积累证据、利用证据支撑判断、根据反馈持续调整策略，并将中间结果转化为最终交付物。高质量的长时程轨迹能够捕捉这些 Agent 行为模式及其在单一问题解决过程中的关联，为持续自主工作提供更丰富的经验。然而，环境合成可能提前完成或简化这些模式所依赖的关键工作，从而消除了本应由 Agent 执行的探索、实现与验证需求。为解决这一问题，我们提出 TerminalHorizon，一个面向长时程终端 Agent 的全自动数据合成引擎。它从真实世界专业工作出发，通过独立执行识别构建过程中被省略的关键工作，并利用由此获得的证据指导环境重建。为将这些模式扩展到多个阶段，它在同一目标下逐步扩展任务，引入基于先前结果的新需求，并要求进一步探索与改进。借助该引擎，我们构建了 1.5K 个任务环境，并在所得数据集上对 Qwen3.5-27B 进行监督微调，得到 TerminalHorizon-27B。我们在涵盖编码 Agent 任务、真实生产环境中的 Agent 任务以及通用推理的 12 个基准上均取得显著性能提升。多个 RSI 案例研究（每个拥有 12 小时研究预算）进一步表明，该模型能够超越初始方案继续实验，根据反馈改进方法，并在最终交付物中保留有效改进。

## MAI-Gym: An Open All-in-One Platform for GUI Agent Evaluation and RL Training across Mobile and Computer Environments

[MAI-Gym：面向移动端与计算机环境的 GUI Agent 评估与 RL 训练开放一体化平台](https://arxiv.org/abs/2610.20939)

基于可验证奖励的在线强化学习（RL）已推动数学、编程和工具使用领域的快速进展，但要将这一成功扩展到 GUI Agent 仍面临挑战，原因在于交互环境成本高昂且真实训练任务稀缺。我们推出 MAI-Gym，这是一个开放的一体化平台，统一了跨移动端、计算机和 Web 环境的 GUI Agent 评估、数据收集与在线 RL 训练。通过共享的 rollout 流水线，MAI-Gym 确保 Agent 在评估与训练中行为一致，支持十个成熟基准，并可扩展到 20,000 个并行环境实例。除可扩展基础设施外，MAI-Gym 还能自动合成多样化 GUI 应用和具有挑战性的任务，包括可重置的模拟应用，以及具有执行验证任务验证器的连贯跨应用世界。利用 MAI-Gym，我们训练了 MAI-Gym-9B，这是一个面向移动端和计算机使用的统一 9B Agent，在参数量低于 10B 的开放 GUI Agent 中达到 SOTA 性能：MobileWorld 上 78.4%，OSWorld-Verified 上 76.2%。重要的是，在模拟火车票预订应用中进行的 RL 可迁移到真实世界对应场景，使物理手机上的任务成功率从 28.8% 提升到 48.1%。我们发布该框架、合成技能、模拟应用、2,000 个经过验证的任务以及模型检查点，以支持可复现研究和可扩展 GUI Agent 训练的进一步进展。

## Reflex: Visually Grounded Reactive Humanoid Control

[Reflex：视觉 grounded 的反应式人形机器人控制](https://arxiv.org/abs/2610.12772)

人类能毫不费力地对周围世界作出反应：熟练地回击网球、接住掉落的杯子、侧身避开经过的手推车，或在卸货时接住抛来的箱子。这些日常动作要求预判移动目标，并在约一秒内以全身反射式响应。这种基于视觉的反应式全身控制对人形机器人而言仍具挑战性，因为机器人必须（1）协调全身控制，（2）实时响应物体动力学，（3）将感知建立在第一人称视觉（egocentric vision）上。我们以接住抛来的箱子作为代表性任务，它同时要求上述三项能力；现有系统只覆盖其中一部分，依赖末端执行器、动作捕捉或带标记的物体。我们提出 Reflex，一个三阶段框架，逐阶段学习这些能力，并通过物体动力学的紧凑表示将它们连接起来。首先，基于状态的策略通过强化学习（RL）学习全身接物。其次，该策略学习从延迟且不完整的观测中推断移动箱子的动力学。第三，第一人称 RGB-D 编码器学习直接从视觉观测中恢复该动力学表示，同时保持全身控制器固定。这种分解为每项能力提供了直接训练信号，并使视觉学习显著更具可扩展性。在仿真中，Reflex 仅凭第一人称 RGB-D 达到 85.7% 的接物成功率，而给定特权箱子观测时为 87.9%。时间视觉历史至关重要：移除它会使居中抛掷和侧向偏移抛掷的成功率分别下降 35.6 和 39.8 个百分点。在真实的 Unitree G1 上，Reflex 在 2.5 米和 5 米处接住人类抛出的箱子，成功率分别为 65% 和 40%，达到人类接物者在相同距离下成功率的 76% 和 59%。

## Learning Where to Split: Dynamic Band Splitting for Audio Source Separation

[学习在哪里切分：用于音频源分离的动态频带切分](https://arxiv.org/abs/2610.14993)

音频源分离模型必须保留精细的频谱结构，同时将分离器的计算成本控制在可接受范围内。频带切分（Band-split）架构通过人工将频谱划分为预定义的频带，并将每个频带编码为一个 Token，从而降低这一成本；但同一组边界会用于每一个混合信号。由于具有信息量的频谱结构会随源内容变化，固定边界可能把具有判别性的分量合并在一起，也可能在几乎不需要分辨率的区域耗费 Token。我们提出动态频带切分（Dynamic Band Splitting，DBS），这是一个端到端框架，能够在固定的频带 Token 预算下，为每个混合信号自适应调整边界位置和频带宽度。DBS 在频率块内预测由内容条件化的边界分数，使用硬 Top-K 选择指定数量的边界，并应用内容相关的池化以获得紧凑的频带 Token。分离之后，它将这些 Token 平滑并扩展到原始 STFT 网格，沿频率维度进行细化，并使用频率共享头解码复数掩码。在 DnR v2、MUSDB18-HQ 和 EchoSet 上，DBS 相比对应的静态模型提升了分离性能；其中 DBS-BSRNN 在 DnR v2 上的平均 SI-SDR 取得 29.0% 的相对增益。这些结果以及 DnR v2 上的边界分析表明，在固定频带 Token 预算下，内容自适应频率划分能够使多种分离器骨干网络受益。代码和音频演示见 https://cslikai.cn/Dynamic-Band-Splitting

## AesCode: Aesthetic Code Generation with Decoupled Cross-Modal Rewards

[AesCode：具有解耦跨模态奖励的美学代码生成](https://arxiv.org/abs/2610.18860)

以代码形式生成幻灯片、海报和仪表盘等信息丰富的视觉制品具有吸引力，因为输出是结构化、可编辑且可验证的。然而，代码模型无法看到其布局和颜色选择在画布上如何组合，这往往限制了空间规划与美学质量。图像生成器擅长视觉设计，但可能错误呈现所要求的内容，使其输出难以作为直接复现的可靠目标。因此我们提出 AesCode，它在以内容提示为 grounding 生成代码的同时，使用由同一提示生成的图像作为美学引导。为此，AesCode 将目标表示为一个设计图（design graph），它描述整个画布并使每个属性可归因。从该图出发，我们导出互补的跨模态奖励：确定性验证器对可从代码和渲染中解析的属性打分，而 VLM 评判器则借助与图元素和关系绑定的、样本特定的视觉图评分标准（Visual Graph Rubric，VGR）评估不可解析的属性。我们通过带逐通道归一化的强化学习优化这些解耦奖励，以共同提升空间规划、美学质量和可验证正确性。为评估该设定，我们构建了一个基准，分别对可验证正确性和视觉质量打分，其视觉分数与人类判断高度一致。我们发现参考图像能显著提升现有模型所生成代码的视觉质量，消融实验表明 AesCode 同时受益于将参考图作为模型输入以及作为视觉奖励来源。相对于在相同参考下同规模的 Qwen3-VL 基线，AesCode-8B 和 AesCode-32B 的视觉质量分别提升 31.1 和 22.4 个百分点，达到与 GPT-5.5、Claude Opus 4.8 等闭源前沿模型相当的水平。

## Tev: Scaling Long-Horizon Agentic Environments with Dense Progress Rewards

[Tev：用密集进度奖励扩展长程 Agent 环境](https://arxiv.org/abs/2610.18868)

长程 Agent 因能自主工作数小时至数天、完成具有经济价值的任务而受到越来越多的关注；这种能力对自动发现和递归自我改进（RSI）至关重要。然而，开源模型在长程任务上仍表现不佳，主要原因是缺乏训练数据和可用的训练方法，而同时扩展两者又很困难：长而复杂的任务难以整理和验证，并且奖励稀疏。我们同时解决这两个问题。首先，我们推出 Tev-Gym，这是首个带有可验证、密集、渐进奖励的长程 Agent 训练数据集，覆盖 7 个领域、包含 1,170 个经验证的任务环境。它基于“潜世界优先”方法构建：先构造一个潜世界，即对任务领域、工作流以及每一步之后的预期状态给出完整且正确的隐藏规范。随后，每个任务都从这份规范逐步渲染为面向 Agent 的环境，从而实现可控的复杂度，并提供自然的进度度量。其次，我们把这个度量转化为训练方法：通过进度势能奖励塑形（PPRS），我们将进度转换为密集的每步奖励，从而提高训练效率，并使原本难以训练的任务变得可训练。用这一方法训练得到 Tev-27B，它在 Agents' Last Exam 的计算与数学科学领域（ALE-CM）上取得显著提升，在 Pass@5 上追平 GPT-6 Astra 和 Claude Opus 5。尽管只在 ALE 相关数据上训练，它仍能泛化到 Terminal-Bench（TB）3.0 和 4.0 子集，超越 GLM 5.2 和 Gemini 3.7 Flash，并在 TB 2.1 等中等长度任务上达到 Claude Opus 4.8 级别的表现。

## Harness^2: Recursive Agent Harnessing for an Open World

LLM Agent 的能力不仅取决于其底层模型，也取决于其执行框架（harness）。递归自我改进（RSI）为自动演化这些执行框架提供了一条有前景的路径。然而，在开放世界环境中部署 RSI 仍面临两个关键挑战。第一，开放世界任务通常在执行框架设计阶段未曾出现，并且在测试时是新颖的，因此没有真值验证器（ground-truth verifier）来可靠指导在线的执行框架编辑。第二，RSI 过程仍然高度任务特定，无法泛化到新场景。我们提出 Harness^2，一个即插即用的递归式 Agent 执行框架构建框架，通过两个相互关联的递归层级应对这些挑战。任务级递归使用对比式 Propose-Probe-Compose 步骤来改进当前任务的执行框架，在没有真值验证器的情况下可靠指导编辑，并可通过并行或串行递归进一步扩展。构建级递归随后从这些编辑中提取经验，以更新一个持续改进执行框架，使 Agent 能够更好地适应未来任务。在三个专业基准和四种模型-执行框架配置上，单步即可持续提升 GLM-5 和 Gemini 3.5 Flash 相对于其基础执行框架的表现，在 WorkBuddy-Bench 上最高提升 11.5 分，在 JobBench 上提升 4.5 分，在 LAB 上提升 11.8 个百分点，且随着任务级递归预算增加，增益进一步提升。

## Doc2Harness: Benchmarking LLMs on Long-Horizon Harness Engineering of Coding Agents

## GreenWAM: A World Foundation Model for Robotics

[GreenWAM：面向机器人领域的世界基础模型](https://arxiv.org/abs/2610.18774)

机器人既需要世界模型来预测自身动作将如何改变场景，也需要策略来选择这些动作。现有模型通常只针对其中一种角色进行构建和评估，而且每台机器人记录动作时都采用自己的格式。我们研究的是：单个机器人世界模型能否在不同本体上同时承担这两种角色，以及是什么让这一点成为可能。我们提出 GreenWAM，这是一个面向机器人领域的世界基础模型，并给出产生它的方法：(1) 共享的解剖动作空间，用统一的关节坐标描述 20 个机器人系列，从双臂机械臂到灵巧人形机器人；(2) 在这些机器人系列上以视觉、动作条件和世界-动作三种模式进行联合训练；(3) 将动作专家从生成器中分离出来形成策略。作为世界模型，GreenWAM 在 WorldArena 1.0 上取得顶尖的轨迹、深度和 3D 准确率，在我们比较的所有世界-动作模型和视频生成器中均领先。作为策略，它进入 RoboTwin 2.0 排行榜前列，在所比较方法中取得最高的零样本 LIBERO-plus 成功率，并在 CALVIN 和 LIBERO 上与专用视觉-语言-动作策略和世界-动作策略具有竞争力。我们进一步将 GreenWAM 适配到真实人形机器人上，其成功率高于从 $\pi_{0.5}$ 和 Cosmos 3 Edge 适配得到的策略，并将其蒸馏为单步策略以实现实时控制。受控实验得出三点发现：机器人专门化同时提升世界预测和控制；动作专家在适配开始时分离出来会有帮助；在策略适配期间保留世界模型模式可保持对场景变化的鲁棒性。

## VIS-Ground: Video Interactive Storytelling with Contextual Grounding

[VIS-Ground：基于上下文依据的视频互动叙事](https://arxiv.org/abs/2610.09326)

视频互动叙事让观众能够主动引导视频如何展开。然而，一旦允许观众在生成过程中介入，就会出现一个新挑战：观众的请求可能同时潜在地依赖于依据来源（grounding source）和当前已渲染的视频状态。这些依赖可能不会在任何单一输入中被明确表达，只有在将来源、已渲染历史与新的观众意图联合考虑时才会浮现。现有互动视频生成系统主要强调遵循观众指令，而基于来源的视频生成方法则侧重于让生成内容与外部叙事或知识来源对齐。这使得一个根本问题仍未得到充分探索：在互动续写过程中，生成模型应当依据什么上下文，以及如何将异构、非结构化输入转化为这种依据上下文？在本工作中，我们将上下文依据（contextual grounding）定义为将异构输入上下文转化为可执行约束模型以用于视频生成的过程。为应对这一挑战，我们提出 VIS-Ground，它执行结构化上下文抽象（Structured Context Abstraction）以恢复依据状态与跨上下文依赖，进行生成约束归纳（Generation Constraints Induction）以将相关依赖投影为候选特定的约束，并通过约束视频生成（Constrained Video Generation）借助规划、验证、修订和渲染来强制执行这些约束。在三个视频生成骨干模型上，VIS-Ground 始终取得最高的总体综合得分，相较各骨干模型的最强基线平均绝对提升 10.3 分。详细分析进一步显示，其在叙事依据和知识依据两方面均有收益，并揭示了在依赖提取以及视频渲染过程中的忠实实现方面仍存在的挑战。

## GroundAnything: Reconciling Parallel Decoding with Precise Visual Grounding at Flash Speed

[GroundAnything：以极速协调并行解码与精确视觉定位](https://arxiv.org/abs/2609.39600)

自回归（AR）定位模型将空间预测序列化，这既引入了顺序延迟，也对输出 token 施加了因果顺序。我们将定位视为视觉证据提取：对象、位置和空间关系由图像与查询共同约束，但这些依赖关系并不意味着存在内在的从左到右生成顺序。这一区别使双向扩散成为自然选择，让空间假设能够并行产生，并通过迭代去噪联合细化。我们提出 GroundAnything，一个 4B 参数的定位基础模型，通过分块去噪（blockwise denoising）协调快速并行解码与精确定位。训练结合了基于公共数据集和专用数据引擎的定位预训练、带联合 AR 与扩散目标的直接 AR-to-diffusion 转换、监督微调，以及基于 GRPO 的强化学习后训练。在 30 个定位基准上，我们的自回归变体 GroundAnything-VLM 以 72.42% 在同等规模模型中建立新的总体 SOTA，并与 GPT-6 Astra（71.35%）保持竞争力。借助熵引导解码，GroundAnything 在该规模下也超越了先前 SOTA，平均达到 61.75%，而基于 MTP 的快速 LocateAnything 模型为 53.32%。我们进一步探索了解码策略，表明可选的自推测（self-speculative）模式相比 AR 对应模型实现 4.51 倍加速，COCO F1mIoU 仅下降 0.74 个百分点。基础设施实验表明，渐进式推理优化可将并行解码转化为实际加速。这些结果支持延迟敏感的真实系统中的高效视觉定位。

## TPPO: Tracking-Value PPO For Language Model Reasoning

[TPPO：用于语言模型推理的跟踪价值 PPO](https://arxiv.org/abs/2610.16794)

近端策略优化（PPO）广泛用于语言模型推理中带可验证奖励的强化学习。虽然沿轨迹的价值演化刻画了相对的 Token 级信用分配，但标准 critic 在稀疏终端奖励下往往无法跟踪这一演化。为建模该演化，我们分析相邻前缀价值之间的关系，并证明它们具备在 log-odds 空间中以加性更新实现的贝叶斯分解。我们利用这一加性结构构建 Tracking-Value PPO（TPPO），一种累积价值参数化方法，将逐位置的标量输出求和为价值 logits。这些输出通过重构价值上的终端结果监督进行学习。TPPO 在 Qwen3-4B-Base 和 Qwen3-8B-Base 上分别将聚合数学推理分数较 PPO 提升 7.0 和 8.4 分，同时提升分布外泛化能力。增益还扩展到 Qwen3-4B、Qwen2.5-Math-1.5B、Qwen3.5-9B 以及 countdown 和科学编程任务。进一步分析显示，其能更准确地跟踪价值演化，并提供更可靠的优势估计。我们的代码公开于 https://github.com/LINs-lab/TPPO。

## ExeWorldBench: Benchmarking Code-Based Executable 3D World Modeling

[ExeWorldBench：面向基于代码的可执行 3D 世界建模的基准测试](https://arxiv.org/abs/2610.15166)

Coding Agent（编码智能体）正日益超越“复现世界看起来是什么样”的阶段，转向构建能刻画“世界如何运作”的可执行世界。这一转变需要可执行世界建模（executable world modeling），它整合两项核心能力：世界理解，即推理世界底层的结构、力学与因果原理；可执行实现，即把这种理解转化为基于代码的系统，使其行为由物理交互涌现。然而，现有基准只提供围绕物理推理、视觉保真度或行为正确性的碎片化评估，对这些能力的整合评估不足。为弥补这一空白，我们提出 ExeWorldBench，据我们所知，这是首个通过基于代码的 3D 世界构建来综合评估世界理解与可执行实现的基准。ExeWorldBench 包含三个难度递进的任务：机制可执行性（Mechanism Executability），评估从视觉观察中实现单个机制的能力；组合可执行性（Compositional Executability），扩展到具有空间、力学和因果依赖关系的多阶段系统；意图驱动的可执行世界合成（Intent-Driven Executable World Synthesis），要求从高层目标和物理需求出发构建可执行世界。对前沿模型的大量实验揭示了可执行世界建模方面的显著局限，为开发更具物理基础、因果一致的世界构建系统提供了洞见。

## WorkRover: Scaling Long-Horizon Cowork Agent Training Via Recursive Environment Evolution

[WorkRover：通过递归环境演化扩展长时程协作 Agent 训练](https://arxiv.org/abs/2610.18067)

扩展交互式环境对于通过强化学习训练长时程 Agent 很重要。这类环境在初始生成后通常还需要进一步测试与改进，而修正任务中的缺陷也可能需要更新其工作上下文（work context）和验证器（verifier）。然而，现有构建流程在保持这些组件对齐的同时，对这种迭代改进的支持有限。我们提出 WorkRover，一个通过递归环境演化训练长时程协作 Agent 的框架。其由执行框架（harness）驱动的合成机制使构建型 Agent 能够联合构建并验证语义对齐的工作上下文、可执行任务和基于证据的验证器，并根据工作区状态与执行反馈调整其动作，而不是遵循固定的构建流程。为支持环境演化，我们引入因子兼容性回放（Factorial Compatibility Replay, FCR），它利用 rollout 反馈，通过依赖闭包回放评估组件修订的组合，并在测试过的候选中选择最小的已验证修复，同时保留任务要求和评估约束。为提供更细粒度的训练信号，我们提出验证器到轮次信用分配（Verifier-to-Turn Credit Assignment, VTCA），它用来自确定性工作区进度检查的信号增强轨迹级 GRPO 优势，并利用记录的工具输出和产物依赖，将正进度信用中有界的一部分分配给前置轮次。使用 WorkRover，我们对 Qwen3.5-35B-A3B 进行后训练，得到 WorkRover-35B-A3B，并在多个协作 Agent 基准上对其进行评估。其报告分数在 JobBench 上超过 Qwen3.5-35B-A3B 26.27 个百分点，在 OfficeQA Pro 上超过 29.32 个百分点，在 GDPval v2 上超过 413.25 Elo 分。这些结果表明，WorkRover 为可扩展地训练长时程协作 Agent 提供了有前景的基础。

## Vela: User Behavior as Supervision Sparks LLM Intelligence

[Vela：以用户行为作为监督信号激发 LLM 智能](https://arxiv.org/abs/2610.14709)

大语言模型（LLM）正越来越多地部署在需要基于用户长期行为历史进行决策的应用中，从个人助理到推荐系统和广告系统。这些应用要求 LLM 智能具备用户维度：即从数周到数年的行为数据中推断一个人的偏好、意图以及未来可能采取的行动。然而，当前模型是在静态文本或合成数据上训练的，二者都无法捕捉用户行为随时间演变的过程。真实世界的行为记录已在内容平台和个人助理 Agent 上大规模可得，提供了一种天然的监督信号。我们提出以用户行为作为监督，并引入 Vela，一个将真实用户行为数据转换为可训练任务与轨迹的框架。基于 10 万名用户的匿名化行为记录，Vela 在 91 个真实世界任务模板上生成了 10 万个任务；通过基于难度的过滤和轨迹接受标准，最终保留约 7.5 万个任务及选定的训练轨迹。在这些轨迹上微调 Qwen3.6-35B-A3B，使其在用户相关任务上相比基座模型最高提升 11.5 分，在通用基准上平均提升 4 分。使用更多用户行为数据训练可进一步提升用户相关性能，且微调后的强化学习（RL）相比从基座模型开始的强化学习最高提升 7.7 分。这些增益表明，真实世界用户行为是一种可扩展的监督来源，既能提升以用户为中心的能力，也能提升 LLM 更广泛的智能。

## More Methods, Better Agents? A Reality Check on Self-Distillation in Agentic Reinforcement Learning

[更多方法，更好的 Agent？Agentic 强化学习中自蒸馏的现实检验](https://arxiv.org/abs/2610.19789)

Agentic 强化学习中的自蒸馏已经衍生出越来越多方法。然而，现有评估往往在不同实验条件下复用已发表的基线分数，很少对同期方法进行直接比较，并且对训练稳定性和计算成本的关注有限。这些局限掩盖了已报告增益的来源，也掩盖了竞争方法的实际优势与不足。昂贵的 Agent 训练进一步促使我们建立共同比较基础。为弥补这些缺口，我们在 ALFWorld、ScienceWorld、Search-QA 和 WebShop 上，跨三种模型规模，将十种代表性方法与 GRPO 进行比较。我们的研究包含 132 次训练运行，总计记录 12,124.4 H800 GPU-hours，并对预训练骨干网络和全部十一种训练方法重复进行八次 rollout 种子评估。除最终任务性能外，我们还考察训练进展、稳定性和实测计算成本。我们的评估得出三个关键发现。第一，相对 GRPO 的增益范围仍然有限，没有任何方法在所有设置下持续优于 GRPO。第二，强大的最终性能可能掩盖训练不稳定。第三，额外训练成本并不总能转化为更好的性能。我们建立该基准，以支持公平、全面的比较，并引导未来研究走向可靠且高性价比的 Agent 训练改进。项目页面：https://aim-uofa.github.io/Self-Distillation-AgentRL/

## SCOPE: Semantic Bounded Credit Optimization for Prompt Engineering in Text-to-image Generation

[SCOPE：面向文本到图像生成提示词工程的语义边界信用优化](https://arxiv.org/abs/2610.22264)

强化学习（RL）使语言模型能够通过为冻结的图像生成器重写提示词，来改进文本到图像（T2I）生成。现有方法通常将源自图像的单一信号施加到各个子词 Token 上，尽管对象、计数、属性和关系构成连贯的语义片段（span）。我们提出 SCOPE，一种基于组相对策略优化（GRPO）的目标，使更新权重与该结构对齐。重写器联合生成增强提示词及其语义划分。SCOPE 在每个片段内对策略对数概率的变化进行池化，为其 Token 损失推导共享系数，同时为每个补全保留单一优势。它既不需要单独的片段奖励，也不需要额外的图像渲染。在 Qwen-Image、SD3 和 FLUX.1-dev 上，SCOPE 相较于原始 GRPO 的平均相对增益为 GeneVal 上 9.48%、T2I-CompBench 上 7.62%。消融研究表明，语义边界和片段内池化均对这些增益有贡献，支持语义结构作为 RL 提示词工程中实用的归纳偏置。

## Recovering Reliable Supervision via Critique-Guided On-Policy Distillation

[通过批评引导的在线策略蒸馏恢复可靠监督](https://arxiv.org/abs/2610.20572)

在线策略蒸馏（OPD）利用教师模型的 Token 级监督，在学生模型自身生成的 rollout 上训练学生模型，其假设是教师模型能够从学生写出的任意前缀出发得到正确答案。我们将这一性质称为教师模型的可恢复性（recoverability），并表明它在错误 rollout 上会失效：教师模型虽然能识别学生错误，却会跟随这些错误。我们提出 CriticOPD，利用错误识别来恢复可恢复性。教师模型对错误的 rollout 进行批评（critique），使学生模型能够在错误之后重写其解答。所得输出包含作为特权信息的批评，由教师模型评分，而学生模型在训练时使用不含批评的修订版本。在两个 Qwen3 学生模型和六个数学推理基准上，CriticOPD 改进了 OPD，并在竞赛题上取得最大增益。

## X-Ragent: Tool-Augmented Reinforcement Learning for Evidence-Grounded Chest X-Ray Reasoning

[X-Ragent：面向基于证据的胸部X射线推理的工具增强强化学习](https://arxiv.org/abs/2610.16811)

胸部X射线（CXR）解读通常需要将视觉发现与任务特定证据相结合，而不能仅依赖直接的视觉识别。尽管工具增强的医疗 Agent 可以通过外部模块提供此类证据，但它们往往缺乏明确机制来学习何时需要辅助证据，以及防止不适用的定量证据进入诊断推理。为解决这一问题，我们提出 X-Ragent，这是一个用于工具增强强化学习的后训练框架，它将学习式辅助证据寻求与有效性门控的定量测量获取解耦，以支持基于证据的 CXR 推理。我们构建了 Rad-CoT，这是一个包含 7.7K 个样本的语料库，将因果排序的工具增强轨迹与报告式诊断推理相结合，并通过 Agent 化监督微调（SFT）用它初始化 Qwen3-VL-8B。随后，我们使用组相对策略优化（GRPO）优化策略，采用准确率门控奖励，该奖励仅对正确轨迹应用针对测量一致性和辅助工具成本的过程级项，从而防止看似合理的流程行为掩盖错误诊断。在三个 CXR 基准上，X-Ragent 取得了最强结果，包括在完全留出的 ChestAgentBench 上提升 8.6 分。通过选择性寻求证据并仅接纳有效测量，X-Ragent 支持更忠实且基于证据的 CXR 推理。

## DoSA: Dots Sparse Attention

[DoSA：点稀疏注意力](https://arxiv.org/abs/2610.13990)

稀疏注意力只访问少量 key，但找到这些 key 仍可能需要每个 indexer 头对每个 key 打分。我们提出 DoSA（Dots Sparse Attention），一种使该计算按条件执行、同时保持精确 token 选择的无损方法。其核心观察是：Top-K 选择只需要足够证据来拒绝候选，而不必知道其完整分数。种子集合给出获胜阈值的下界。非负头投影和联合残差界给出正贡献的上界，而激活感知聚合则限制负头所减去的幅度。该证书将完整打分导向仍然符合条件的候选；精确分数过滤进一步减少回写和选择工作。我们建立该证书及其精确选择条件，并分析几何结构与选择裕度如何决定其有效性。我们的 GPU 实现将完整 Indexer 在英文、中文和代码负载上相较 SGLang 最高加速 2.74 倍，相较 LiteTopK 最高加速 1.69 倍。在 GLM-5.2 和 DeepSeek-V3.2 上的端到端评估相较两个基线分别实现最高 1.94 倍和 1.50 倍的首 token 时间加速。

## Speculative Forcing for Efficient Autoregressive Video Generation

[用于高效自回归视频生成的 Speculative Forcing](https://arxiv.org/abs/2610.22347)

少步自回归视频生成器支持流式生成，但它们会让每个 token 都经过最终去噪步骤，而不管其需要多少细化。我们发现这种统一计算通常是不必要的：许多 token 在初始步骤中就已经与其最终的全步输出非常接近，而另一些 token 则需要一直细化到最后。我们提出 Speculative Forcing，一个将中间干净估计视为草稿并预测单个 token 何时可以被安全地提前接受的框架。一旦被接受，该 token 就被冻结为其最终输出，不再进行进一步去噪，同时其缓存的键和值（keys and values）仍可作为其余 token 的上下文使用。我们探索了两种替代的验证器设计：一种无需训练的验证器，基于与干净内容的相似性以及跨步骤的稳定性；另一种是学习型验证器，读取冻结生成器的中间特征来估计每个 token 与其全步输出之间的剩余差距。在短视频、长视频和世界生成中，Speculative Forcing 保持了全步采样的质量，同时大幅减少了计算量。在 LongLive 上，它以每个 token 约 1.7 个去噪步骤匹配四步生成器，在 41.7 和 37.8 fps 下运行速度提升超过 1.5 倍。在 Lingbot-World 2.0 上，相机运动不断改变可见内容，它以每个 token 约 2.5 个去噪步骤保持质量，并在 24.5 fps 下运行速度提升 1.35 倍。

## LeWAM: End-to-End World and Action Modeling with JEPAs

[LeWAM：基于 JEPA 的端到端世界与动作建模](https://arxiv.org/abs/2610.12818)

联合嵌入预测架构（JEPA）无需像素重建即可学习紧凑的潜在世界模型。现有 JEPA 流程通常先训练视觉表示和以动作为条件的动力学模型，然后再加入控制策略或求解器。我们提出 LeWAM，一种用于控制的端到端 JEPA，其特点包括：(1) 面向下一潜在状态预测和动作流匹配的联合训练目标；(2) 对潜在状态施加各向同性高斯约束，使单一模型既能直接执行策略，又能利用其学到的潜在动力学评估采样动作，从而实现高效规划。与先前用于视觉规划的 JEPA 相比，LeWAM 在接触密集任务上将成功率从 28.6% 提升至 89.7%，在长时程任务上从 10.9% 提升至 46.2%，规划速度提升 32.3 倍。在仿真和实体机器人上的行为克隆任务中，LeWAM 也与已有方法相比具有竞争力。可解释性分析表明，LeWAM 学到了与控制相关的表示和动作分布，能够有效指导测试时的规划与控制。

## EmbodiedCLBench: Evaluating Continual Learning for Self-Evolving Embodied Agents

[EmbodiedCLBench：评估自进化具身智能体的持续学习能力](https://arxiv.org/abs/2610.13021)

持续学习要求模型积累过往经验，并将其迁移到新任务。尽管持续学习已有大量研究，但现有工作在很大程度上仍局限于非具身（non-embodied）环境，尚未扩展到具身环境。为填补这一空白，我们提出了 EmbodiedCLBench；据我们所知，这是首个在具身仿真中评估自进化 Agent 持续学习能力的基准。该基准以组合泛化（compositional generalization）为核心评估原则，评估 Agent 能否先从基础任务中学习，再重组已获得的技能来解决复杂且未见过的高级任务。基于 EmbodiedCLBench，我们在多种 Agent harness 和学习方法上开展了大量实验，揭示了持续存在的一致局限与独特行为。结果表明，高级任务在零样本（zero-shot）设置下很难被解决，而来自基础任务的经验能够带来持续改进。即使任务复杂度增加，这种来自经验的收益仍保持稳定。然而，这种改进并不会随学习样本数量成比例扩展，当前 Agent 无法从额外经验中提取有意义的信息。总体而言，我们的发现凸显了持续学习是一项基础但尚未被充分探索的能力，而我们的基准为在具身环境中设计有效的自进化 Agent 提供了有价值的资源。我们的代码与数据集可在 https://pku-value-lab.github.io/EmbodiedCLBench-homepage 获取。

## Last Secure Code Benchmark: Is the Code You Vibe Secure?

[Last Secure Code Benchmark：你“氛围编程”出的代码安全吗？](https://arxiv.org/abs/2610.14766)

AI 编程 Agent 如今编写了大量最终交付的代码，但这些代码是否安全仍不明确。我们推出 Last Secure Code Benchmark，对编程 Agent 的安全代码生成能力进行全面评估。该基准基于 150 个真实漏洞构建，包含 450 个任务，覆盖七种广泛使用的语言（Java、C、C++、JavaScript、Python、PHP 和 Go）；涵盖 24 个 CWE，其中包括 2025 年 CWE Top 25 中的 21 个，以及 Top 10 KEV 弱点中的 8 个；在我们对比的基准中，覆盖范围最广。它还包含三种 vibe-coding 场景：补全一个函数、编写一个文件，以及从零构建一个仓库的源码树。每个任务只要求实现功能，其规格说明从不提及安全，结果由隐藏的功能测试和安全测试评分。在六个前沿 Agent 上，73.6% 至 91.3% 的任务通过功能测试，但即使是最强的 Claude Fable 5，也仅能在 25.1% 的任务中生成既功能正确又安全的代码，其他 Agent 则为 16.4% 至 24.7%。在所有 vibe coding 设置中，最佳模型也仅通过 12% 的漏洞场景，这引发了对 vibe coding 所编写代码安全性的强烈担忧。

## Many Right Answers, One Training Example: Removing Responder Noise from GRPO for LLM Recommenders

[多个正确答案，一个训练样本：为 LLM 推荐器移除 GRPO 中的回答者噪声](https://arxiv.org/abs/2610.17771)

Reddit 上的一个推荐请求会引来若干条回复，每条回复给出的标题各不相同。当用强化学习（RL）在这样的帖子串上训练 LLM 推荐器时，生成的列表应当以哪些回复为奖励依据？当前最先进的做法 Rank-GRPO 为每个训练样本只挑选一条回复，因此其优势值（advantage）主要记录的是抽到了哪条回复（占其方差的 85%），而不是列表本身有多好。我们认为 RL 应当针对请求进行训练，而不是针对每一条答案，并提出 ReMaRk：它将每个列表一次性对所有回复标题的并集进行打分，并对每个请求等概率采样。这使得 RL 的成本更低。在七个骨干模型和三个数据集上，ReMaRk 在 25% 至 53% 的步数内就达到了每条回复式 RL 训练 2,000 步时的验证召回率，并在该预算下领先；若训练到两者都不再提升为止，ReMaRk 从未显著落后于 Rank-GRPO，且在七组对比中的四组里以更少的 GPU 时长达到了 Rank-GRPO 的最佳效果。同样的奖励机制在 ProtoQA 上同样有效，该数据集中每个问题约有 100 人作答，这指向一条针对存在多个有效人类答案的 RL 的简单规则：对它们联合给予奖励。

## Multics: Generative Multi-Player World Model with Hierarchical Communication

[Multics：具有分层通信的生成式多玩家世界模型](https://arxiv.org/abs/2610.17201)

多玩家交互式世界模型旨在从多个玩家的视角模拟共享环境，但要在扩展到更多玩家的同时实现稳健生成仍然具有挑战性。现有方法依赖全连接通信（如 Solaris），随着玩家数量增长会产生二次注意力开销；而集中式方法（如 γ-World）则因共享全局表示中不相关事件之间的干扰而受影响。为解决这些挑战，我们提出 Multics，一个具有分层通信的多玩家视频生成框架，在玩家、组和全局三个层级上组织信息交换。该层次结构将组 Token 作为中间组级表示引入自注意力，用于聚合局部相关的玩家信息。这些 Token 连接全局 Token 以进行跨组通信，而分层拓扑限制了不相关局部事件之间的直接混合。组 Token 参数在各组槽位间共享，使同一通信模块能够适应不同数量的玩家，而无需引入新的组特定参数。我们进一步提出基于近期相机轨迹的预算约束动态分组，能够自适应地对相关玩家进行分组，同时限制不必要的通信。实验表明，Multics 在 4 玩家和 6 玩家设置下达到 SOTA 性能，并提升了跨玩家一致性、玩家特定动作与相机可控性以及抗干扰鲁棒性。此外，Multics 可从 4 玩家训练泛化到 6、8、10 玩家推理而无需重新训练，同时相比全连接通信减少了自注意力计算量。

## UltraBERT: Beyond the Limit of BERT Pre-Training

[UltraBERT：超越 BERT 预训练的极限](https://arxiv.org/abs/2610.15028)

近期双向编码器借助因果大语言模型（LLM）的创新实现了现代化升级。然而，预训练配方本身仍沿用源自小规模时代的惯例，导致编码器优化不足，且没有任何单一模型能在分类与检索任务上同时具备竞争力。本文通过重新审视训练中的核心设计选择，探究编码器性能可被推至何种程度，并揭示三项关键发现：（1）编码器在超过数万亿 token 后会在下游任务上饱和，表明超过该点后增加计算量并无帮助。（2）在不同模型规模下，较低掩码比例有利于分类，而较高掩码比例有利于检索，这与先前工作提出更大模型应使用更大比例的建议相矛盾。（3）带剪枝的蒸馏在低掩码比例下提升分类性能，但在高掩码比例下会降低检索性能。基于这些发现，我们提出 UltraBERT，这是一种单一编码器，在同一批次内为低掩码比例和高掩码比例分配独立的 LM 头，并将蒸馏目标限制在低比例上。据我们所知，UltraBERT 是首个在分类和检索任务上均达到 SOTA 的编码器，在 GLUE 上达到 91.0，在 BEIR 上达到 47.7。这些结果共同展示了编码器性能可被推至何种程度，并为双向模型中的计算分配、掩码比例设计和知识迁移提供了原则性基础。

## VisionWeave: Weaving Elastic Visual Representations as a Native Capability of MLLMs

[VisionWeave：将弹性视觉表示编织为多模态大模型的原生能力](https://arxiv.org/abs/2610.07987)

多模态大语言模型已成为视觉理解的主流范式，但将输入编码为稠密、固定尺寸的 patch token 会带来显著成本。然而，视觉信息分布并不均匀：部分区域需要细粒度细节，另一些区域则可采用紧凑表示。下采样会牺牲这些细节，而现有的 token 剪枝与自适应方法在内容自适应粒度、任务泛化性以及与现有多模态大语言模型和服务基础设施的集成方面仍存在局限。克服这些局限，需要基础模型能够端到端地学习在何处、以何种粒度分配视觉表示，我们将这一原生能力称为弹性视觉表示编织。我们提出 VisionWeave，通过大规模训练在前沿级多模态大语言模型中建立这一能力。它结合两个组件：门控空间池化器在共享 MRoPE 坐标内构建粗粒度表示与原生细粒度表示，而粒度路由器学习其内容自适应分配。仅通过自蒸馏，我们在 Qwen3.5-4B 上验证了该能力，并扩展到 Qwen3.8-27B，消耗超过 30K A100 GPU 小时。基于 Qwen3.8-27B，VisionWeave 根据视觉内容自适应调整 token 节省量，在八个基准上平均节省 43.0% 的 token，同时保留 98.9% 的原生性能；相比之下，固定 50% 节省目标的 token 剪枝基线仅保留 88% 的性能。大量评估确认了其在不同任务、分辨率和视频帧上稳健的效率—质量权衡。部署在 SGLang 服务引擎上时，我们的方法实现 2.3 倍吞吐提升，同时将平均 TTFT 降低 54.4%，平均 TPOT 降低 60.6%。我们相信，这些结果使弹性视觉编织成为下一代多模态模型的一项有前景的能力。

## SwarmRSI: Recursive Self-Improvement through Evolving Scientific Agent Swarm

[SwarmRSI：通过进化科学 Agent 群体实现递归自我改进](https://arxiv.org/abs/2610.20431)

科学研究中的递归自我改进（RSI）旨在让 Agent 借助自身的实验经验提升研究能力。科学 Agent 群体能够整合来自不同研究方向的证据与实现，以指导 Agent 后续实验。然而，实验效果不佳时，难以判断应当修改假设还是修改其实现；而整体程序分数也可能掩盖对其他 Agent 有用的组件。为应对这些挑战，我们提出 SwarmRSI，一个通过进化科学 Agent 群体实现递归自我改进的框架。我们设计了反馈引导的群体变异（Feedback-Guided Swarm Mutation），利用其他 Agent 的实验反馈来改进假设及其实现。我们还提出互补群体重组（Complementary Swarm Recombination），跨 Agent 复用保留的假设与互补程序组件，使部分结果能够支撑新的研究。递归群体进化（Recursive Swarm Evolution）将这两种机制整合为反馈循环，利用新的实验证据指导后续研究。在 OpenProblems、NatureBench 和 MLE-Bench Lite 上的实验表明，SwarmRSI 取得了 SOTA 性能。进一步评估显示，积累的研究经验提升了在留出任务上的表现。生物学家也复现了其程序，用于后续生物学分析。

## Scoring Higher, Answering Worse: Mitigating Reward Hacking in Rubric-Based RL via Protocol-Level Rubrics

[得分更高，回答更差：通过协议级评分标准缓解基于评分标准的强化学习中的奖励黑客行为](https://arxiv.org/abs/2609.38847)

基于评分标准（rubric）的强化学习（Rubric-RL）在没有验证器的情况下训练语言模型。评判器检查评分标准的每个条目，并将判定结果聚合为奖励，最常用的是加权求和。我们表明，这种加性聚合正是薄弱点。在求和之下，各条目会相互补偿：一个漏掉唯一关键决策的策略，可以用没人要求的建议把分数补回来。在临床咨询中，这样的策略得分更高，回答却更差。评分标准覆盖率上升，但在留出的医师标准上的适当性低于未训练模型。问题不应归咎于医学标准。将这些标准分组，使其必须同时成立，完全相同的标准（一字未改）能挽回三分之一的损失；更短的回答几乎无法挽回任何损失。因此，我们提出协议级评分标准（Protocol-level Rubrics，ProRubric），它保留评分标准所要求的内容，但改变聚合方式。它将检查清单分组为少数协议级维度。一个维度只有在其所有标准都成立且其失败条款未触发时才计分。分组一次性离线完成，且不改变优化器。ProRubric 将适当性提高 10.8 个百分点而不损失覆盖率，并在两个规模上均取得七个基准的最佳平均值。奖励有效性不仅由评分标准验证什么决定，还由其如何聚合决定。代码见 https://github.com/Estrellajer/ProRubric

## LatentLoop: Scaling Looped MoE Models with Asymmetric Compute Allocation

[LatentLoop：以非对称计算分配扩展循环 MoE 模型](https://arxiv.org/abs/2610.19975)

循环专家混合（MoE）模型将参数复用与稀疏计算相结合，在同等预算下提升性能。已有工作表明，即使不同循环访问共享参数，它们也可能扮演不同角色。为探究不同循环访问的贡献，我们在一个将共享块应用两次的模型中分别学习残差系数，观察到第一次访问的尺度更小。固定系数实验表明，降低第一次访问的尺度可保持或提升性能，而对第二次访问做相同降低则会损害性能。这种非对称性促使我们探索非对称计算分配。我们提出 LatentLoop：压缩第一次访问的序列，在第二次访问中保留完整分辨率，并重新分配节省的计算量以增大隐藏维度。我们进一步学习第一次访问对完整序列的更新强度，并在各次访问间共享 MoE 权重，同时使用独立的注意力参数以适应不同的序列分辨率。在覆盖 1.3B–7B 参数、最大预算超过 $10^{21}$ FLOPs 的 15 种配置中，LatentLoop 一致降低验证 NLL。在拟合 NLL 为 1.988 时，相对于原始 MoE 和循环基线，预测计算节省分别为 19.0% 和 7.9%。在 0-shot 和 5-shot 设置下，它在所有规模上均提升了九项基准的平均分数。这些结果表明，非对称计算分配是循环 MoE 模型的一个有前景的方向。

## Hear the World in Stereo: Learning Dynamic Spatial Correspondence for Immersive Joint Video-Audio Generation

[在立体声中聆听世界：面向沉浸式视频-音频联合生成的动态空间对应学习](https://arxiv.org/abs/2609.38748)

近期的视频-音频联合生成模型已实现较强的语义对应与时间同步。然而，AR/VR 和交互式游戏等应用进一步需要立体声音频来提供沉浸感，而这一点在很大程度上仍被忽视。有效的立体声音频要求感知到的声音位置与其对应视觉源的运动持续一致地演变。我们将这一性质称为动态空间对应（Dynamic Spatial Correspondence），并提出 StereoBind：一个将视觉源运动绑定到立体声生成的框架。StereoBind 利用运动轨迹，通过三种互补机制协调视觉运动与立体声音频。视觉运动绑定（Visual Motion Binding）建立源感知的视听对应关系，空间轨迹编码器（Spatial Track Encoder）捕捉绝对源位置，残差轨迹 RoPE（Residual Track RoPE）建模相对运动。为了监督与评估，我们构建了 StereoWorld-29K——一个带有配对运动轨迹的大规模立体声音视频数据集，以及用于衡量视听空间一致性的 StereoWorldBench。实验表明，StereoBind 在保持整体视听质量的同时，相较现有模型显著提升了立体声音频生成中的空间对齐。

## Cortex: Consolidating Context into Parametric Memory

[Cortex：将上下文整合为参数化记忆](https://arxiv.org/abs/2610.20399)

上下文可以提升大语言模型性能，但移除上下文后这些增益可能消失。受生物系统巩固（consolidation）启发，我们将记忆巩固（Memory Consolidation，MC）定义为内化这些增益，同时保留非目标能力，并把由上下文指定的编辑、技能学习和行为引导统一到一个共同目标下。我们引入一个包含五个任务族的测试平台，用于衡量在单次、批量与顺序更新下的巩固效果与保留效果。我们提出 Cortex，它生成前瞻性查询（prospective queries）以预判上下文的用途，并将上下文条件输出蒸馏为可合并的低秩更新或结构化前馈网络更新。在 4B–120B 的稠密与混合专家（mixture-of-experts）骨干模型上（包括纯文本与多模态模型），Cortex 在多数评测设置中处于经验性的巩固—保留帕累托前沿。在 14B 模型上进行 50 次顺序事实编辑后，Cortex-Structural 恢复了 88.9% 的上下文诱导增益，同时保留 99.8% 的原始非目标性能。

## SALD: Self-Referenced Advantage Learning for Diffusion Models

[SALD：面向扩散模型的自参考优势学习](https://arxiv.org/abs/2610.01496)

近期关于语言模型适配的研究表明，单个模型可以通过在演示或反馈增强的上下文中评估自身行为来获得有信息量的训练信号，并借助一个由学生模型已学习参数驱动的教师网络。受这种内部参考原理的启发，我们研究扩散模型如何在没有外部演示或教师网络的情况下识别自参考训练信号。我们提出 SALD，这是一个自参考训练框架，它使用同一模型在两个噪声水平上评估每个图像-文本对。较容易的低噪声路径在不跟踪梯度的情况下进行评估，以提供参考；而较难的较高噪声路径则提供训练梯度。SALD 并不直接蒸馏易路径的预测，而是利用两条路径误差之间的差异来自适应地调整难路径目标。所提出的优势引导扩散（Advantage-Guided Diffusion，AGD）将这种相对误差转换为可微的样本级权重。时间优势记忆（Temporal Advantage Memory，TAM）在训练过程中累积相对难度，并自适应地调整未来两个噪声水平之间的间隔。频谱优势分解（Spectral Advantage Decomposition，SAD）进一步比较两条路径的残差功率谱，并构造可微的、由频率导出的隐元素权重。所有组件共享同一组模型参数，既不需要外部教师网络，也不需要在训练或推理期间引入额外的可训练参数，并且无需修改推理过程。在多种架构和数据集上的实验表明，所提方法能够持续提升生成质量；同时，组件级消融实验量化了所提各组件的贡献。

## EviScene: Beyond "Is It AI?" for Agentic Image Factuality Assessment

[EviScene：超越“它是不是 AI 生成的？”——面向 Agent 的图像事实性评估](https://arxiv.org/abs/2610.14609)

判断图像是否由 AI 生成，并不能确定其描绘的情境是否有事实依据。我们提出图像事实性评估（Image Factuality Assessment）任务：给定一张图像和一条通用验证指令，系统需返回“支持”或“反驳”的判定，并给出有证据支撑的解释。在未提供文本声明的情况下，系统必须在调查过程中逐步细化事实性问题，并将外部证据与所描绘的具体情境对齐。我们推出 EviLens，这是一个经专家审核的基准，包含来自受控构建和网络采集的 10,174 张“支持”与“反驳”图像，覆盖十二类事实错误类型，并同时评估判定准确率和证据充分性。我们开发了 EviScene，这是一个多模态 ReAct Agent，交替进行视觉检查、外部检索和证据分析，利用新发现细化问题并重新查看相关图像细节。我们通过在经审核的教师轨迹上进行监督微调来训练紧凑策略，随后将特权在线策略自蒸馏（privileged on-policy self-distillation）应用于策略自身调查中经核验的决策。在 1,527 张图像的测试集上，训练后的 Qwen3.5-9B Agent 达到 79.05% 的平衡准确率和 52.26% 的严格证据充分率（Strict Evidence Sufficiency Rate, SESR），分别较同骨干基础 Agent 提升 6.71 和 9.37 个百分点。其 SESR 在受评估的 Agent 中最高。代码、模型和数据将在 https://github.com/wangzian828/EVISCENE 和 https://huggingface.co/ZiAnwang/EviScene 发布。

## ActionOPD: Distilling Decisions, Not Tokens

[ActionOPD：蒸馏决策，而非 Token](https://arxiv.org/abs/2610.19820)

将能力较强的语言模型 Agent 蒸馏到较小模型中，需要让学生模型的行为与教师模型对齐。这就引出一个根本问题：应该在哪些状态上、以何种粒度进行对齐？离线模仿提供密集但针对具体 Token 的监督，并且可能遭遇状态分布不匹配。Token 级同策略蒸馏（on-policy distillation，OPD）能缓解这种不匹配，但通常需要教师模型的 Token 概率和兼容的分词器。我们认为，语义动作（semantic action）是 Agent 蒸馏中一种自然的监督单元。为此，我们提出 ActionOPD，这是一种动作级同策略蒸馏方法，其动机是在学生模型遇到的状态上最大化教师动作的期望似然。在每个这类状态下，ActionOPD 分别从学生模型和黑盒教师模型采样动作，并根据学生动作与所采样教师动作的语义一致程度，对学生动作给予奖励。通过策略优化，ActionOPD 使学生模型在动作层面的行为与教师模型的决策对齐，而无需复现教师模型写出的推理过程，也无需访问教师模型的 Token 概率。我们用两个教师模型在多样化的精选工具使用任务上训练 Qwen3-4B 和 Qwen3-8B，在四个分布外基准上平均提升 3.3 至 6.9 个百分点。ActionOPD 能随学生模型规模和教师模型能力良好扩展，且不要求教师模型与学生模型属于同一模型家族或共享分词器。在 τ²-bench 上，ActionOPD 的表现与离线蒸馏和 Token 级 OPD 相比具有竞争力。我们还探索了 Self-ActionOPD，它使用同一模型的教师和特权上下文。这些结果确立了 ActionOPD 作为一种有前景的 Agent 蒸馏方法。

## Each Reward to Its Relevant Tokens: Reward-Specific Token-Level Credit Assignment for Multi-Reward RL

[将每个奖励分配给其相关 Token：多奖励 RL 的奖励特定 Token 级信用分配](https://arxiv.org/abs/2610.21439)

语言模型正越来越多地同时面向多个可验证奖励进行训练，例如工具调用的正确性与格式，或复杂指令中的各项约束。奖励解耦归一化（reward-decoupled normalization，GDPO）分别对每个奖励进行归一化，使不同奖励组合仍能保持各自不同的优势，但它仍将每个奖励的优势均匀分配到整个回复上，而每个验证器实际上只检查少量位置。我们提出 MRTPO，它利用各奖励验证器所检查的信息，将每个奖励的优势分配给与其相关的 Token，且无需辅助模型或 Token 级标注。对于每个奖励，策略模型会在包含和不包含该奖励验证器信息的两种情况下重放自身回复，并通过两种下一 Token 分布之间的逐 Token Jensen-Shannon 距离衡量每个 Token 的相关性，再重新分配优势。在 text-to-SQL、多约束指令遵循和工具调用任务上，MRTPO 相比对比方法收敛更快、性能更优。

## AReA: Adaptive Receptive-Field Attention for Efficient High-Resolution Diffusion Transformers

[AReA：用于高效高分辨率扩散 Transformer 的自适应感受野注意力](https://arxiv.org/abs/2610.17227)

生成超出 Diffusion Transformers（DiT）训练分辨率的图像仍然具有挑战性：Token 数量随分辨率快速增长，全注意力代价高昂，输出常出现结构畸变和细节退化。作者指出，统一的全局全注意力是这两类问题的共同来源。每一步都对全部 Token 做注意力会导致二次计算成本，并使模型接触到更多 Token 和超出训练范围的相对距离，从而把模型推向分布之外。作者观察到，注意力有效感受野在去噪过程中会收窄：早期步骤中为全局感受野，用于形成结构；后期步骤中为局部感受野，用于细化细节。据此提出 AReA，一种无需训练的注意力机制，其感受野随去噪进程由粗到细演化。在早期步骤中，AReA 对下采样后的 Key 和 Value 施加跨尺度粗粒度注意力，以捕获全局上下文；在后期步骤中，它在逐步缩小的窗口内施加局部注意力。实验表明，无需额外参数或训练，AReA 在多个目标分辨率和不同模型上均持续优于 SOTA 的免训练基线，同时速度更快、效率更高。

## VLA-Δ: Learning Physical State Transition for Vision-Language-Action Models

[VLA-Δ：为视觉-语言-动作模型学习物理状态转移](https://arxiv.org/abs/2610.21306)

视觉-语言-动作（VLA）模型将通过视觉-语言预训练获得的语义知识迁移到机器人控制中，并在各类基准上取得了强劲性能。然而，大多数 VLA 模型直接将观测映射为示教动作，没有对中间物理状态变化提供显式监督，因此容易过拟合观测与动作之间的对应关系。一些方法在语言、视觉或潜空间中引入中间推理或未来状态预测，以引导动作生成，但并未对物理状态转移本身提供显式监督。为此，我们提出 VLA-Δ，一个将当前状态与未来状态之间的物理变化作为显式学习目标的通用框架。为支持这一目标，我们构建了大规模预训练数据集，并推导出涵盖任务相关语义与视觉运动变化的物理状态转移标注，为连续动作生成提供更直接的监督。推理时，模型直接从当前观测生成动作，不引入额外推理开销。VLA-Δ 在 LIBERO 和 RoboTwin 上取得与 SOTA 相当的性能，并在真实机器人实验中优于 $\pi_{0.5}$。代码见 https://github.com/ZJU-OmniAI/VLA-Delta

## Mosaic: Multi-Session Agentic Reinforcement Learning

[Mosaic：多会话智能体强化学习](https://arxiv.org/abs/2610.22174)

现有大多数智能体强化学习方法假设单会话轨迹，即交互在一个持续累积的上下文中进行。然而，上下文压缩（context compaction）和子智能体分叉（subagent forking）等智能体技术可能产生跨多个会话的轨迹，导致单会话训练假设与推理时执行之间不匹配。为此，我们引入多会话智能体强化学习（Multi-Session Agentic Reinforcement Learning），这是一种更通用的设置，支持一条轨迹中包含任意数量的会话。在该设置下，一种广泛采用的方法是将轨迹级优势广播到所有会话，但这无法区分不同会话的贡献，也无法指导轨迹内的会话分配。为解决该问题，我们提出 Mosaic，一种采用无 critic 分层优化的多会话智能体 RL 方法。在轨迹层面，它将会话使用信号纳入优势估计；在会话层面，它根据估计的边际贡献塑造每个会话的优势。在 BrowseComp 上使用 Qwen3.5-4B 的实验表明，Mosaic 在上下文压缩和子智能体分叉两种场景下均优于广播方法，同时平均使用的会话数更少。进一步分析表明，我们的方法在会话效用和分配方面取得改进，我们认为这是多会话智能体 RL 未来进展的一个有前景的方向。

## ProgramGym: Scaling Training Environments for Long-Horizon Program Reproduction Agents

[ProgramGym：面向长周期程序复现 Agent 的可扩展训练环境](https://arxiv.org/abs/2610.13395)

编码 Agent 正越来越多地像软件工程师那样从零构建程序，而不再局限于解决仓库内的问题或根据给定需求文档生成仓库。然而，迫使 Agent 自行发现需求并决定系统应如何设计的可扩展、可验证训练环境仍然稀缺。此外，现有 Agent 工作流也无法支撑长周期开发，即 Agent 在实现前先探索参考程序。为解决这些挑战，我们提出 ProgramGym，一个由 Program-Env 和 Program-Agent 组成的框架，用于为长周期程序复现 Agent 提供可扩展训练环境。具体而言，Program-Env 通过反馈驱动循环从仓库构建可验证训练环境，该循环修复运行时沙箱构建和黑盒测试质量。使用这一新流程，我们获得了 1,648 个训练环境，覆盖 C、C++、Go 和 Rust。Program-Agent 将分析、实现和审查的角色隔离工作流与用于编译检查和故障恢复的修订管理相结合。在 ProgramBench 上的实验表明，Program-Env 和 Program-Agent 均提升了程序复现性能。在使用这些构建环境生成的轨迹上进行微调，将 Qwen3.8-27B 的性能从 34.87% 提升至 42.84%。Program-Agent 进一步将基础模型和 SFT 模型提升至 55.71% 和 56.25%，均超过一些旗舰模型。我们将发布 ProgramGym，以支持关于从零构建程序的编码 Agent 的进一步研究。

我们提出 CommerceGen-Studio，这是一个为电商 SKU（Stock Keeping Unit，库存量单位）生成商业级主图的端到端框架。该框架由一条三阶段流水线组成：信息抽取、语义改写和多条件生成。Prompt-Eval-Refine-Loop Agent（PERL-Agent）通过 VLM 与 LLM 角色的迭代闭环，并由无参考评分标准打分，将异构 SKU 元数据提炼为简洁的卖点文本列表。Layout Thinker Optimization（LTO）通过交替进行领域特定的策略优化，使改写器同时对齐标题与渲染图像质量。SKU-DiT 在 Reinforce-Distill-Reinforce（RDR）渐进式训练下训练，联合以白底商品图、商标裁剪图和结构化布局为条件，从而同时保持主体保真度、商标完整性和字符级文本准确率。该框架已在生产环境中以每天数百万张主图的规模运行，单图延迟为几秒；我们认为这使其成为首批以商业规模运行的此类系统之一。我们还发布 CommerceGen-Bench，这是一个从全品类线上流量中收集的困难案例基准。在该基准上，无论是否进行提示增强，我们的框架在两个编辑赛道上均取得所评估开源基线中的最高总分。它也能与规模大得多的闭源模型匹敌，并在指令遵循和商品融合这两项决定图片能否发布的属性上击败了其中若干模型。

计算机使用 Agent 能够执行日益复杂的 GUI 任务，但陌生软件和需要人类领域知识的工作流仍然具有挑战性。人类演示通过相同的 GUI 交互空间传递程序性知识，但复用需要在上下文中解释动作，并将工作流规则与任务特定细节分离。因此，我们提出 Work2Skill，一个捕获人类 GUI 经验以用于可复用 Agent 技能归纳的框架。WorkRecorder 提供该框架的基础设施，用于收集这些经验，对齐屏幕录制、鼠标和键盘事件以及可用的可访问性树信息。使用 WorkRecorder，我们构建了 WorkDemo-350，这是首个用于可复用 Agent 技能归纳和下游评估的人类桌面 GUI 演示同步多模态数据集。其 350 个演示经过完整性和任务成功筛选。然后，我们提出一种 Agent 式技能归纳方法，按需检查证据，以生成可复用技能，捕获工作流规则、步骤依赖关系和完成检查。在共享执行设置下，当相同的四个执行模型配备由每种方法归纳出的技能时，Work2Skill 取得最高分数和成功率。相较于相应的 No Skill 基线，平均分数提升在 MyPCBench Bounded Action 上为 4.67–10.54 分，在 OSWorld-Verified 的 286 个任务子集上为 3.11–7.50 分。我们的代码和数据可在 https://github.com/china-qijizhifeng/Work2Skill 获取。

## APEX: Asynchronous Prefix Denoising for Extreme Compression

[APEX：面向极端压缩的异步前缀去噪](https://arxiv.org/abs/2610.12843)

更少的潜在 Token 意味着更低的扩散成本。然而，激进的潜在压缩会造成重建-生成两难：增加通道数可以改善重建，却使生成更难。我们提出 APEX，即用于极端压缩的异步前缀去噪（Asynchronous Prefix denoising for EXtreme compression），它将分层潜在空间与按通道组进行的异步去噪相结合。我们的自编码器按从结构到细节的顺序排列通道前缀，而一个共享去噪器在不同局部时间步上生成这些前缀，且不增加 Token 数。在 ImageNet-512 上，APEX 在 64 倍和 128 倍压缩下，于每个评估的通道数上都优于现有方法。在训练和引导采样计算量相同的情况下，它在每个评估的预算下也优于 256-Token 模型，且计算量越低，收益越大。代码见 https://daviddinkevich.github.io/APEX。

## Seeing, Maintaining, and Learning: The Evolution of Multimodal Agent Memory

[看见、维护与学习：多模态 Agent 记忆的演进](https://arxiv.org/abs/2610.19366)

多模态模型与 Agent 已经出现，它们通过整合跨多种模态的信息，使 AI 系统能够更像人类一样从真实世界学习并与真实世界交互。然而，随着多模态 Agent 面向长时程任务和终身学习场景发展，如何让它们持续从复杂、异构的多模态数据中获取有用信息，仍然是一项重大挑战。应对这一挑战需要有效的记忆机制；这类机制能够维持跨会话的连续性，适应用户和环境的变化，并通过积累的经验改进记忆管理策略。我们提出了一个用于多模态 Agent 记忆的双轴分析框架，围绕两个关键问题展开：多模态信息如何形成与表示（轴 I，形成与表示），以及其管理如何随积累的经验而适应（轴 II，记忆管理）。轴 I“形成与表示”刻画保留哪些信息以及如何编码这些信息（例如模态特定嵌入、文本与结构化记录、潜在表示与参数化表示），以支持后续推理与行动。轴 II“记忆管理”区分三个层级：T1 静态记忆复用固定记忆；T2 动态记忆通过稳定策略更新记忆；T3 自演化记忆通过演化策略更新记忆。基于该框架，我们综合了反复出现的设计模式，并推导出若干原则：在源保真度与抽象化之间取得平衡，维护时间有效性与来源溯源，将记忆使用建立在可恢复证据之上，并随时间演化记忆策略。此外，我们讨论了多模态 Agent 记忆机制面临的挑战和潜在未来方向。

## Multi-Stream Attention Residuals

[多流注意力残差](https://arxiv.org/abs/2610.13630)

注意力残差（Attention Residuals, AttnRes）支持沿网络深度进行内容相关的检索，可视为沿深度轴的单流 softmax 注意力。受多头注意力沿序列轴取得成功的启发，我们提出多流注意力残差（Multi-Stream Attention Residuals, MSAR），这是 AttnRes 的扩展，将该机制推广到多头深度注意力，以极小的额外开销带来显著性能提升。MSAR 通过多尺度因果卷积从序列上下文中获取流多样性，使不同头能够通过不同的上下文视图检索历史表示，同时保持隐藏表示的完整性。检索到的流通过轻量级自适应混合进行组合，以生成单流层输入。通过保留单流来源并按需扩展，MSAR 支持多流计算，而无需持久的多流存储或通信。在 18B 和 28B MoE 规模的所有 12 个下游基准上，MSAR 始终优于先前的残差变体，包括标准残差连接、流形约束超连接（manifold-constrained Hyper-Connections, mHC）和 AttnRes。缩放律实验表明，相较于标准残差基线，MSAR 在等损失下实现 1.58 倍计算加速，而 AttnRes 为 1.35 倍，mHC 为 1.30 倍。这些结果使 MSAR 成为大规模预训练中颇具前景的残差架构。

## RSI-Anything: Unlocking Recursive Self-Improvement with World Models

[RSI-Anything：借助世界模型实现递归自我改进](https://arxiv.org/abs/2610.13912)

递归自我改进（RSI）旨在将交互经验转化为持久的能力提升，但依赖外部反馈的成本高昂，而且随着策略不断演化，世界模型的预测可能变得不可靠。为此，我们提出 RSI-Anything：这是一个基于 JEPA-Anything 构建的领域通用框架，利用预测式世界模型指导动作选择与学习数据选择。观测到的反馈会驱动策略或工作流改进，并推动条件世界模型自适应；组件检查与兼容性检查则决定是否保留更新后的策略-模型对。在多个计算与科学领域，RSI-Anything 均展现出显著收益。在代码修复任务中，在 coder 固定的条件下，成功率从使用静态验证器的 26.3% 提升至通过预测式选择达到的 29.2%，再经世界模型自适应后达到 31.2%，且测试使用量相当。图形用户界面（GUI）评估显示任务完成率更高，同时平均动作数减少 39.4%。在连续五个策略版本中，实验室规划得分从 21.80% 提升至 46.01%，增长超过一倍。在反应优化中，在相同的 40 次实验预算下，RSI-Anything 的平均最佳观测产率达到 96.15%，而贝叶斯优化为 82.16%。一个端到端的免疫科学应用进一步将工作流演化、预测建模与治疗假设生成连接起来。这些结果表明，预测式世界模型与保留的系统更新能够在多样环境中实现递归改进。

## Learning How to Remember: Memory Modality Selection for GUI Agents

[学习如何记忆：GUI Agent 的记忆模态选择](https://arxiv.org/abs/2610.17928)

近期视觉语言模型（VLM）的进展显著提升了 GUI Agent 的能力，而记忆增强（memory augmentation）已成为复用过往交互知识的一种有前景的方法。然而，现有的记忆增强 GUI Agent 通常采用固定的表示策略，将检索到的经验以静态模态提供。目前尚不清楚单一记忆模态是否始终最优，也不清楚模态偏好如何随交互步骤变化。本工作对基于 VLM 的 GUI Agent 中的记忆模态进行了系统研究。在多个 GUI 基准上，我们发现偏好的记忆表示强烈依赖于当前步骤。受此发现启发，我们提出 SwitchMem，一个在每一步动态选择文本或视觉记忆表示的路由框架。在三个 GUI 基准上，SwitchMem 优于依赖静态记忆表示的记忆增强基线。我们的发现验证了我们的主张：记忆模态是一个依赖步骤的决策，而非固定的设计选择。代码与项目资源见 https://txxnrd.github.io/switchmem

## Relevance Does Not Imply Applicability: Experience Activation for Personal GUI Agents

[相关性不等于适用性：面向个人 GUI Agent 的经验激活](https://arxiv.org/abs/2609.33304)

个人图形用户界面（GUI）Agent 依赖交互历史来从模糊指令中推断用户意图，并预判重复出现的日常流程。现有方法检索与任务相关的历史并将其追加到策略上下文中，隐含假设与任务相关的经验在该任务内的每个决策中仍然有用。我们发现，这种帮助主要体现在第一个决策上：检索到的历史能显著改善一个 episode 的开局步骤，但在其余 90% 的步骤中几乎没有持续收益，并且对于是否应当提出主动建议只能提供微弱指导。一条相关记录可能告诉 Agent 从哪里开始，却不能说明过去哪个动作适用于当前屏幕，也不能说明某个日常流程现在是否到期。根本问题在于相关性不等于适用性：相关性在任务层面确定，而适用性取决于决策时刻的具体情境。因此，我们将个性化重新表述为经验激活，并引入 ExpActivator，这是一个无需训练的框架，只激活适用于当前情境的经验。在执行过程中，ExpActivator 在冻结的 GUI 主干网络的潜在空间中将每个新屏幕与历史状态匹配，并提供对应动作作为参考。在执行之前，只有当当前时间和场景提供充分支持时，它才激活重复出现的意图，否则弃权。在四个 GUI 主干网络上，ExpActivator 使轨迹内步骤成功率平均提升 28%，在每个主干网络上均实现最佳个性化执行，同时使用的历史 Token 数量约为原来的五分之一，并达到最强主动基线约 2.3 倍的 Matthews 相关系数。经验的价值在于被激活之处，而非被追加之处。

## Continually Post-training Small Models via Synthetic Self-distillation

[通过合成自蒸馏持续后训练小模型](https://arxiv.org/abs/2610.13113)

持续后训练面临“获取”与“保持”的双重挑战：模型既要学习新能力，又要保留已有知识。自蒸馏微调（SDFT）借助上下文示例的自监督来缓解这一问题，但它依赖较强的上下文学习与指令遵循能力。因此，对于低时延、端侧使用至关重要的小模型，SDFT 会失效。为在更小规模上实现持续学习，我们首先定位了失效的根本原因。我们表明，获取效果差与遗忘程度均与后训练模型的分布偏移呈线性相关，这揭示了分布内学习的必要性。为此，我们提出合成自蒸馏（SynthSelf），将任务外包给规模略大、同系列的 aligner（对齐模型），以模仿 SDFT 的分布内重写。结合离策略（off-policy）监督与拒绝采样，该方法在不破坏小模型原始分布的前提下，提供了其所需的高质量监督。涵盖 4 个获取数据集（含一个混合数据集）与 14 个保持基准的评估显示，在 3 种小模型规模上，SynthSelf 一致优于 6 种方法（包括离策略与在策略蒸馏）。大量进一步分析证实，SynthSelf 为有效的小模型持续学习铺平了道路。

## SepGen: Multi-Stem Audio-Video Separation and Generation in a Single Model

[SepGen：在单一模型中实现多分轨音视频分离与生成](https://arxiv.org/abs/2610.11361)

一个 4D 音视频场景由视频、视频所描绘的动态几何结构以及场景中的声源组成，每个声源都有自己的位置和轨迹。要从新视角渲染这样的场景，每个声源都必须以独立波形形式提供，这样才能在信号混合之前，在场景中定位该声源并将其传播到观察者。联合音视频生成器可以合成视频及其音轨，但音轨会以单一混音形式输出，其中各声源无法单独获取。我们提出 SepGen，它扩展了一个预训练音视频生成器，使其能在一次联合采样运行中输出视频、混合音轨，以及每个带描述声源的一条波形。SepGen 支持两种互补模式：生成与分离。在生成模式下，每个声源描述指定其分轨包含的内容。例如，双人对话会按原始轮流顺序输出每位说话人各自的一个分轨。在分离模式下，输入混音保持干净，而描述指定要提取的内容，因此模型可以根据自由文本描述分解一段录音。我们在由文本合成的场景上评估生成，在由其他生成器渲染的场景以及语音、音乐和音效的真实录音上评估分离。给定混音和包含台词的描述，SepGen 优于语言条件分离器，在语音上表现最明显；当从描述中移除台词时，它仍保持领先。代码、检查点和数据集见 https://sepgen.github.io/
