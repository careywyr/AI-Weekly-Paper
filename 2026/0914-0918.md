## Continual Learning Mechanisms Compose for Long-Horizon Memorization

[持续学习机制的组合实现长时程记忆](https://arxiv.org/abs/2609.06986)

将互补的持续学习机制进行组合，可显著提升语言模型的长时程记忆能力，其做法是把数据锚点、函数锚点与权重锚点同合并式低秩更新相结合。语言模型可能需要内化随时间陆续到达的信息，并在后续多次更新中将其保留下来。为研究这一挑战，我们提出了长时程记忆（long-horizon memorization）设定：模型通过持续监督微调学习 100 个问答任务，且在推理时不保留早期训练样本、也不接收任务标识符。顺序更新会导致灾难性遗忘，而我们评估的任何单一持续学习机制都无法在这一时程上保持较强的记忆保持率。我们假设，针对互补遗忘来源的机制在组合后会更加有效。我们沿两个设计维度组织这些组合：数据、函数与权重锚点规定每次更新应保留哪些先验信息，而低秩分配规则决定后续更新被保留在何处。为系统检验该假设，我们构建了三个不同的 100 任务记忆数据集。我们引入任务级逐次减半（task-level successive halving）来搜索组合设计空间，并使用析因实验测量单项效应与交互效应。我们最优的方法将三种锚点与合并式 LoRA 相结合，在所有数据集中均位列前三，并将平均最终保持率从朴素顺序微调的 1.2% 提升至 34.9%，实现了 28 倍的提升。数据锚点与合并式 LoRA 带来的平均增益最大，并在三个数据集上均表现出超加性交互作用。总体而言，这些结果表明，组合互补机制能显著提升长时程记忆能力，超越任何单一机制所能达到的水平。

## ModularRSI: Modular and Generalizable Recursive Harness Self-Improvement

[ModularRSI：模块化且可泛化的递归 Harness 自我改进](https://arxiv.org/abs/2609.14857)

长程 Agent 的广泛应用使模型工作负载的输入量日益庞大。尽管已有研究大幅降低了长上下文计算的开销，但 prefill 的计算成本依然高昂，庞大的 KV Cache 也持续对 HBM 与 SSD 容量及数据传输带宽造成压力。计算、存储与带宽三方面的需求共同构成了进一步降低部署成本的主要瓶颈。为此，我们提出 DeepSeek-V4.1-Flash：一个多模态混合专家（MoE）模型，骨干参数规模为 552B，支持最长一百万 Token 的上下文。凭借因果编码器-解码器（Causal Encoder-Decoder，CED）架构，该模型在 decode 阶段每个 Token 激活 16B 参数，而在 prefill 阶段仅激活 8B 参数，显著提升了 Agent 类工作负载的成本效率。为突破 KV Cache 压缩的极限，DeepSeek-V4.1-Flash 将压缩稀疏注意力 2（Compressed Sparse Attention 2，CSA2）中的跨层 KV Cache 复用与 FP4 KV 缓存相结合。这些设计将其全局 KV Cache 占用（始终位于 HBM）降至每 Token 890 字节，约为 DeepSeek-V4-Flash 对应占用的 1/4。此外，通过名为 SWA Bounded Replay 的专用部署优化，DeepSeek-V4.1-Flash 将其持久化 KV Cache 占用（始终位于 SSD 或主机内存）降至 DeepSeek-V4-Flash 的约 1/8。尽管 KV Cache 占用大幅缩小，该模型的性能仍显著优于基线。我们还对 DeepSeek-V4 架构进行了精简，并引入若干高效的架构扩展。我们在包含 45T Token 的多模态语料上预训练 DeepSeek-V4.1-Flash，并进行了全面的后训练，在多样化的文本与多模态 Agent 场景中均取得强劲表现。模型检查点已发布于 https://huggingface.co/deepseek-ai/DeepSeek-V4.1-Flash。

## When EOS Tokens Disagree: Understanding Length Inflation in On-Policy Distillation

[当 EOS Token 不一致时：理解在线策略蒸馏中的长度膨胀](https://arxiv.org/abs/2609.20511)

本文研究在线策略蒸馏（On-Policy Distillation，OPD）中的长度膨胀问题，即学生模型的回复可能变得过长，甚至耗尽生成预算。作者发现，基础学生模型与经过后训练的教师模型之间的终止 Token 不匹配是导致该现象的重要来源。在 Qwen3、Llama 和 Gemma 上，即使两个模型声明的停止集合完全相同，它们的停止概率也可能落在不同的 EOS Token 上。这种不匹配会抑制学生模型偏好的终止动作，同时又无法可靠地传递教师模型偏好的替代动作。研究表明，仅对齐解码阶段的停止集合并不充分；而将功能等价的 EOS Token 视为一个共享的语义停止动作，可显著缓解全部三个模型家族中由不匹配引发的长度膨胀。为进一步理解终止行为在训练过程中的演化，作者研究了不同 K2-Horizon 训练阶段下的 OPD。这种分阶段分析表明，终止偏好在训练过程中可能发生显著变化，同时也揭示出在 OPD 训练后期存在一种独特的长度膨胀，且该现象在对齐终止行为后依然持续存在。综上，这些结果说明终止不匹配是 OPD 长度动态的一个重要但非全部来源。作者发布了包含所提出的终止处理修正的实现。

## Grouped Value Attention: Efficient KV Caching via On-Demand Key Reconstruction

[分组值注意力：通过按需键重建实现高效 KV 缓存](https://arxiv.org/abs/2609.13285)

## An Empirical Study of Harness Design for Coding Agents

[面向编码 Agent 的 Harness 设计实证研究](https://arxiv.org/abs/2609.20804)

Coding Harness（编码执行框架）决定了自主编码 Agent 如何把模型能力转化为长程软件工程表现，但现有工作通常把 Harness 当作整体系统来评估，各组件各自的效力仍不清楚。为支持组件级比较，作者采用一个轻量级 Coding Harness 展开研究：其执行循环保持固定，仅变化三个组件——规划、动作空间与上下文管理。在 SWE-Bench Verified 与 Terminal-Bench 2.1 上，针对四个模型共评估了 176 组匹配设置，覆盖五种上下文管理策略、四种上下文窗口预算，以及对规划与动作空间的定向消融。主要发现：(1) 上下文窗口预算越紧张，上下文管理的价值越大，其收益主要来自避免上下文溢出导致的失败。(2) 在各类上下文管理策略中，先做基于规则的剔除、再做基于 LLM 的摘要，整体效率最佳；而让被剔除内容可恢复则引入了模型极少使用的额外机制，且未带来准确率提升。(3) 规划的作用会从弱模型的准确率支撑，转变为强模型的成本节省手段，准确率变化不大。(4) 预定义工具对 bash 熟练度较弱的模型有提升；而具备 bash 能力的模型仅用 bash 接口即可有效工作，成本显著更低，在以命令行为主的任务上尤其如此。轨迹层面的分析解释了这些效应：上下文管理延长了执行轨迹，但基本不改变 Agent 行为；规划改变了轨迹停止的位置；动作空间则改变了代码编写的粒度。这些发现为模型感知与预算感知的 Harness 设计提供了依据，并给出了一个用于评估未来 Harness 组件的模块化框架。

## Breaking the Vision-Action Shortcut: Latent Interface Training for Generalizable Robotics Foundation Models

[打破视觉-动作捷径：面向可泛化机器人基础模型的潜在接口训练](https://arxiv.org/abs/2609.12641)

LIT 通过先训练不依赖图像的位姿条件动作先验，再借助位姿监督的潜在接口约束视觉输入并保留空间目标信息，从而提升机器人动作的泛化能力。机器人基础模型在分布内表现强劲，但在视觉分布偏移下往往性能退化。当模型从预训练视觉表示中学习生成动作时，可能利用训练分布内与示教动作相关的任务无关视觉线索。这类视觉-动作捷径（vision-action shortcut）在相关性随分布偏移发生变化时会损害泛化能力。缓解此类捷径需要在保留任务相关空间信息的同时，约束视觉信息用于动作生成的方式。我们提出潜在接口训练（Latent Interface Training，LIT），一种与框架无关的两阶段策略：先建立无图像的空间目标条件动作先验，再通过位姿监督的潜在接口约束视觉条件。第一阶段训练动作专家（action expert），以语言、机器人状态以及每个示教动作块的末端 SE(3) 末端执行器位姿为条件生成动作块，从而在不依赖视觉线索的情况下学习目标导向的动作生成。第二阶段引入潜在接口，聚合视觉与语义表示，并作为预训练动作专家唯一的视觉条件通路。该接口被监督以重建此前用于第一阶段条件化的末端位姿，从而促使其保留动作生成所需的目标相关空间信息。在四种视觉-语言-动作（VLA）与世界-动作架构（Pi0.5、MolmoAct2、FAST-WAM 和 ImageWAM）上，LIT 将 LIBERO-Plus 总体成功率提升 3.87–10.70 个百分点，同时保持或提升 LIBERO 平均成功率。真实世界评估显示，在未见过的相机配置、光照变化和干扰物条件下，三个任务合计成功率提升 13.30–16.70 个百分点。

## Rethinking Critic Learning in PPO: Understanding and Mitigating Value Flattening

[Rethinking Critic Learning in PPO：理解并缓解价值扁平化](https://arxiv.org/abs/2609.18708)

在大语言模型的强化学习中，Proximal Policy Optimization（PPO）通常使用 critic 来估计状态价值，以降低策略更新的方差。然而，我们发现 PPO critic 中存在一种系统性失效模式，称之为价值扁平化（Value Flattening）：由多次蒙特卡洛延续估计得到的状态价值在中间状态之间会发生剧烈变化，而 critic 的预测却相对平坦。我们在受控的 FrozenLake 环境中进一步观察到此现象，并发现随着状态空间增大，该现象更加明显。我们的理论与实证分析将价值扁平化与 critic 损失中的隐式方差惩罚，以及来自时间相关状态、梯度相似的冗余更新联系起来。受这些发现启发，我们提出了 SParse Proximal Policy Optimization（SP^3O），仅在每条响应中对少量彼此分离良好的状态施加价值损失，以缓解上述两种效应。在 Qwen3-Base 上的实验表明，每条响应仅监督三个状态的 SP^3O 即可缓解价值扁平化，并在不同模型规模和评测套件上持续提升所学策略。总体而言，我们的结果将价值扁平化识别为标准 PPO 中 critic 学习的一个重要却长期被忽视的失效模式，并表明一种简单的稀疏监督策略即可缓解该问题。

## SAS: Simple Attention Sparsification via End-to-End Optimization of Context Ranking

[SAS：通过上下文排序端到端优化实现的简单注意力稀疏化](https://arxiv.org/abs/2609.13141)

SAS 通过在注意力 softmax 内部引入连续门控，以语言建模损失端到端训练选择器，从而改进稀疏注意力，在紧预算下实现更优的上下文排序。

训练后注意力稀疏化通过为每个查询选择一小组上下文单元（Token 或块），降低预训练 Transformer 的二次累积注意力开销。现有可训练方法通常使用轻量级选择器对上下文单元打分，随后采用硬 Top-K 选择，这阻断了来自语言建模损失的梯度。因此，这些方法普遍蒸馏逐层的稠密注意力分布。尽管这能促使选择器按原模型中的稠密注意力权重对上下文单元排序，但该排序与固定注意力预算（即每个查询可关注的上下文单元数量）下各单元对预测的实际影响并不直接对齐，可能将有限预算浪费在效用较低的单元上。

为解决这一错位问题，我们提出简单注意力稀疏化（Simple Attention Sparsification，SAS），一种门控稀疏注意力机制，以语言建模损失端到端优化上下文排序。其核心思想是在训练期间将选择器的连续分数注入注意力 logits，使损失能够通过标准反向传播更新选择器。我们识别出若干对这一简洁设计在实践中奏效至关重要的选择：以对数形式将门控置于注意力 softmax 内部；使用归一化 softmax 门控，以始终保留的当前块为基准校准历史上下文；保留连续的选选择器分数，使模型学习相对优先级而非仅学习硬选择。为支持长序列训练，我们实现了一个内存高效的 Triton 核，将 SAS 集成到 FlashAttention 风格的计算中。在推理、长上下文理解与 Agent 任务中，SAS 在不同注意力预算下持续优于可训练稀疏注意力基线，在紧预算下提升尤为显著，表明其能为下游任务实现更有效的上下文排序。

## Confidence Comes from Experience: Experiential Confidence Estimation from Reasoning to Agents

[置信度源于经验：从推理到 Agent 的经验式置信度估计](https://arxiv.org/abs/2609.17708)

可靠置信度估计对于语言模型的可信部署越来越关键：一个经过校准的“输出正确概率”估计，决定了哪些结果可以交付、哪些需要上报、哪些应当重试。然而现有置信度估计器共享同一个设计前提：它们只读取当前推理过程，或对其进行内省，或对其 Token 概率打分，或对其重采样。我们认为，当前推理并不足以作为置信度的依据。为此提出 XConf（eXperiential Confidence，经验式置信度）：将置信度估计与模型积累的经验结合起来。经验以模型自身过往分级片段的记录形式存储，每条记录包含任务、模型反思、其声明的置信度、结果，以及评分到达后写下的一条经验教训。面对新任务时，XConf 的 Recall 阶段会检索在相似任务上、且模型当时声明置信度也相似的历史片段，并读取其历史成功率；Reflect 阶段则把该记录展示给模型，让其指出自己反复出现的失败模式，并在自身历史战绩的基础上重新声明置信度。该估计器与输出格式无关，无需访问 logit 或更新权重，且仅需一次答案生成。在覆盖推理、编程、多模态问答和交互式 Agent 的 9 个基准、来自 3 个模型家族的 4 个模型上，XConf 在 24 项比较中的 23 项里，判别能力（AUROC）优于或持平十样本自一致性方法，同时校准误差（ECE）显著更低，生成成本仅为后者的十分之一。将其用于选择性预测时，对置信度最低的 10% 片段弃答，可使 Agent 任务上的实际交付成功率最多提升 8.7 个百分点。因此，我们认为经验式置信度估计是未来通用置信度估计的一种新范式。

## JEPA-Anything: Learning Predictive Models across Different Worlds

[JEPA-Anything：跨不同世界学习预测模型](https://arxiv.org/abs/2609.20800)

世界建模使智能体能够预判后果、指导干预并从交互中学习。然而，预测模型仍局限于特定领域：能否用一套通用的学习原则支撑跨截然不同系统的世界建模？本文提出 JEPA-Anything，一个基于正交预测分解（Orthogonal Predictive Factorization，OPF）的领域无关框架。OPF 扩展了联合嵌入预测架构（Joint-Embedding Predictive Architecture），将潜在目标分解为互补因子，通过专用路径学习这些因子，并在共享的预测设计中重新组合。我们在七个领域评估 JEPA-Anything：视觉、生物学、临床轨迹、控制、分子动力学、物理场和天气。实验涵盖表征学习、干预预测、分布外泛化和长时程动力学，包括 10 个匹配的动力学任务、超过 1,000 个临床事件的预测，以及跨四个系统的 100 步分子推演。与匹配的 JEPA 基线相比，JEPA-Anything 在所有 10 个动力学任务上提升了报告指标，并将 Interventional Pong 上的单次干预预测误差降低 34.8%。在所有四个系统中，该方法取得了对比方法中最低的一步和 100 步分子误差。除预测之外，一个由因子提名发现的生物学干预在细胞共培养、患者来源类器官、肿瘤片段和小鼠中获得实验支持；潜在轨道模态恢复了开普勒标度指数，拟合斜率为 -1.4991。这些结果支持一种跨异构世界的通用因子化预测原则，将世界建模与干预及有实验依据的科学发现联系起来。代码：https://github.com/Gen-Verse/JEPA-Anything

## ReactHuman: A Physics-Grounded Benchmark for Human-Like Reactive Decision-Making in Embodied Multimodal LLMs

[ReactHuman：面向具身多模态 LLM 类人反应式决策的物理基础基准](https://arxiv.org/abs/2609.10895)

ReactHuman 是一个以物理为基础的基准，用于评估多模态大语言模型作为仿真人形机器人决策核心、面对突发家庭危险时的表现，并揭示出持续存在的反应式安全失效问题。

对突发物理危险做出反应（接住滑落的盘子、躲开掉落的刀），既是对具身智能的有意义检验，也是将多模态大语言模型（MLLM）部署为家用机器人决策核心的硬性要求。然而，现有评测要么通过视频问答被动地探查直觉物理（intuitive physics），要么针对导航、整理等需要深思熟虑的长时程任务；没有任何评测衡量模型能否把物理理解转化为即时的、安全攸关的动作。我们提出 ReactHuman，首个面向类人反应式决策的物理基础基准：被评测的 MLLM 充当仿真人形的“大脑”，应对突发的家庭危险。该基准涵盖 17 类事件族、超过 1,000 个可逐比特复现（bit-for-bit reproducible）的场景，其精确、无需标注的真值来自 240 Hz 刚体仿真，其中还包括外观与物理性质相矛盾的对抗性物体（例如泡沫铁砧、钢制苹果）。我们进一步设计了一套包含五项指标的评测套件，从合理、安全、物理基础三个轴向为每次反应打分。我们会对每一个提交的计划进行物理执行，使决策产生可观测的后果。借助这一测试框架，我们评测了 7 个具有代表性的 MLLM。结果表明，反应式安全远未解决：模型大约每三个危险就会有一个处理失当，它们依据固定倾向而非所观察到的场景行动，更相信外观而非运动，即便所选动作正确，也会在米级尺度上错过拦截点；这些失败都不会随模型规模增大而减少。ReactHuman 因此既提供了细粒度诊断，也为训练物理基础扎实、具备安全意识的具身 Agent 提供了可扩展的训练信号。基准地址：https://huggingface.co/datasets/Alan123/reacthuman-benchmark-scaled

## ProgramDistill: From Interactive Web Apps to Verifiable Reference-Guided SWE Tasks

[ProgramDistill：从交互式 Web 应用走向可验证的参考引导 SWE 任务](https://arxiv.org/abs/2609.18805)

编码 Agent 通常以 issue 或指令的形式给出期望行为来进行评估。但在实际 Web 开发中，Agent 需要从可运行的软件中推断行为，并在一个尚不完整的应用中将其实现。为此，作者提出了 ProgramDistill 基准，用于评估编码 Agent 在通过交互功能完整的参考应用所发现的功能上的表现。ProgramDistill 的构建方式是将应用分解为不同粒度的功能，每个功能都关联一组可通过其 gold patch（金标准补丁）执行的可重放行为。其 mine-craft-patch 流程在无人工干预的情况下，跨 26 个应用挖掘出 1,975 个可重放验证的行为，并构建了 4,063 个任务。在九个前沿编码 Agent 上，GPT-6 Astra 与 Claude Opus 5 在完整应用重建的累积工作流中成功率分别为 49.2% 和 28.8%。在部分应用重建中，当恢复深度从 1 增加到 8 时，成功率分别从 100% 降至 64.0%、从 96% 降至 32%。由此，ProgramDistill 提供了一个难度可控、可扩展的基准，用于评估和诊断编码 Agent，并为未来基于课程的训练提供了自然基础。

## Verifiable Social Reasoning for LLM Assistants

[面向 LLM 助手的可验证社会推理](https://arxiv.org/abs/2609.17496)

LLM 助手被广泛用于日常社交建议，但在此类咨询场景中评估其社会推理能力仍具挑战：其一，需要构建助手从主观的用户叙述中了解社交情境的设定；其二，他人的意图等社会属性通常缺乏可验证的真实标注。为解决这些挑战，我们提出 Fuse——一个用于研究以用户为中介的社会推理的多 Agent 模拟框架。在 Fuse 中，一个带有隐藏动机的目标 Agent 与其他 Agent（其中包含代表用户的 Agent）交互，随后该用户 Agent 咨询被评估的助手以推断目标 Agent 的动机，从而在构造上提供可验证的真实标注。模拟的保真度通过一项包含 24k 条标注的人类研究得到验证。我们将 Fuse 应用于 12 个 LLM，并通过系统性地分离关键因素展示了其分析价值，结果表明：(i) 用户中介会加剧社会推理本身的固有难度；(ii) LLM 对带有偏见的用户表述表现出系统性敏感；(iii) 模型可能需要比人类更多的细节才能得出正确预测；(iv) 更长的对话并不总能提升表现，尽管它提供了提出澄清性问题的机会。我们开源了 Fuse 以及一个包含 21k 条样本的数据集。

## Agora: Git as Shared Memory for Collective AutoResearch

[Agora：以 Git 作为集体自动化研究的共享记忆](https://arxiv.org/abs/2609.18094)

像 AutoResearch 这样的自主研究循环表明，单个编码 Agent 可以在无人值守的情况下改进训练配置。但若同时运行多个这样的循环，每个会话都从零开始，因此 Agent 越多往往意味着重复搜索越多，而非发现越多。Agora 为这类 Agent 提供了共享记忆：研究过程被记录为一个仅追加的有向无环图（DAG），存储在 Git 中，因此每一条主张都是一个提交，任何人都可以检出并重新运行。每个结果、洞见、假设、验证和报告都是不可变的提交，其父边表明它所基于的内容；一个派生索引暴露出研究前沿、被忽视的分支以及每条主张的验证状态，而一条感知多样性的选择规则则防止整个社区坍缩到单一领先者上。我们描述了该系统，并报告了其首次持续使用：一次持续近 12 天的运行，13 个语言模型工作单元在无分配任务、无中央规划者的情况下，共同研究一个权重迁移问题。给定 141 个预训练供体模型，以及一个冻结的 119.6M 参数注意力-SSM 混合模型（其维度与任何供体都不匹配），这些工作单元必须在没有训练数据和梯度更新的情况下初始化目标模型。它们发布了 1,703 项贡献，将评估指标从每字节 3.39 比特推进到 1.899 比特，弥补了与训练后的 GPT-2 124M 之间差距的 62%。获胜方案将供体的下一 Token 统计量压缩到目标的嵌入层和输出头中，然后通过对注意力、前馈和状态空间模块进行稀疏编辑，加入一个短程上下文信号。其 145 个提交的谱系横跨 15 个账户，并发布了 165 次独立复现，无一失败。我们描述了运行中途唯一一次将社区拉出单一文化的人类干预、该轨迹能够与不能够证明的内容，以及那个可以判定共享研究状态是否提升单位算力发现效率的受控对比实验。
